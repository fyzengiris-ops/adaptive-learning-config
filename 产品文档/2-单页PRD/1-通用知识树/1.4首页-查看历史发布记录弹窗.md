# 1.4 首页-查看历史发布记录弹窗【GPT更新】

# 页面目标
用于统一展示通用知识树模块下全部学段、全部学科的历史发布记录，支持按学段、学科和关键词进行筛选搜索，并通过滚动加载方式浏览历史版本信息，帮助用户快速查找、回溯和核对历史发布内容。

# 所属页面
知识体系管理 > 通用知识树 > 查看历史发布记录弹窗

# 页面区域

## A. 弹窗遮罩层
用于承载弹窗展示背景，突出当前弹窗内容。

## B. 弹窗容器
用于承载历史发布记录弹窗主体内容，包含标题区、筛选区、记录列表区和底部操作区。

## C. 标题区
用于展示弹窗标题、当前筛选结果总数以及关闭入口。

## D. 筛选区
用于按学段、学科进行筛选，并支持通过关键词搜索历史发布记录。

## E. 记录列表区
用于展示历史发布记录列表，支持滚动浏览和滚动加载。

## F. 底部操作区
用于提供关闭弹窗的操作入口。

# 组件说明

## A. 弹窗遮罩层组件
- A1. 遮罩层：全屏半透明遮罩，覆盖页面内容
- A2. 遮罩交互：点击遮罩层不关闭弹窗

## B. 弹窗容器组件
- B1. 弹窗主体：居中显示的白色弹窗容器
- B2. 固定头部区域：包含标题区和筛选区
- B3. 列表滚动区域：历史记录列表在该区域内独立滚动
- B4. 底部操作区：固定在弹窗底部

## C. 标题区组件
- C1. 历史记录图标：显示在标题左侧
- C2. 标题文本：显示【历史发布记录】
- C3. 记录总数：显示当前筛选结果总数，格式为【共 X 条记录】
- C4. 关闭按钮：位于弹窗右上角，点击关闭弹窗

## D. 筛选区组件
- D1. 学段筛选下拉框：支持选择【全部学段】【高中】【初中】【小学】
- D2. 学科筛选下拉框：根据当前筛选条件下的历史记录数据动态生成学科选项
- D3. 搜索输入框：支持输入关键词搜索版本号、发布说明、发布人姓名或账号
- D4. 搜索占位文案：显示【搜索版本号、描述、发布人...】

## E. 记录列表区组件
- E1. 历史记录卡片：用于展示单条历史发布记录
- E2. 版本号标签：显示版本号，如【v1.0】
- E3. 学段学科信息：显示【学段·学科】，如【高中·英语】
- E4. 发布时间：显示本次发布时间，格式为【YYYY-MM-DD HH:mm】
- E5. 发布说明：显示本次发布说明
- E6. 发布人信息：显示发布人姓名和账号，格式为【发布人：姓名（账号：XXXXXX）】
- E7. 空状态：无数据或无筛选结果时显示空状态提示
- E8. 加载中占位：首次加载或滚动加载时显示加载占位
- E9. 加载失败提示：接口失败时显示失败提示和重试入口

## F. 底部操作区组件
- F1. 关闭按钮：点击后关闭弹窗

# 交互逻辑

## 1. 打开弹窗
- 1.1、点击首页【查看历史发布记录】入口后，弹出【历史发布记录】弹窗
- 1.2、弹窗打开后，默认加载通用知识树模块下全部学段、全部学科的历史发布记录
- 1.3、弹窗默认按发布时间倒序展示记录，最新记录排在最前
- 1.4、弹窗打开后，列表滚动位置定位到顶部

## 2. 学段筛选
- 2.1、用户切换学段筛选后，刷新当前历史记录列表
- 2.2、学段变更后，学科下拉可选项联动刷新为当前学段下有历史记录的学科集合
- 2.3、若当前已选学科不在新学段的可选范围内，则学科自动重置为【全部学科】
- 2.4、学段切换后，搜索关键词保留不变
- 2.5、学段切换后，顶部总数同步更新为当前筛选结果总数

## 3. 学科筛选
- 3.1、用户切换学科筛选后，刷新当前历史记录列表
- 3.2、学科筛选项根据当前历史记录数据范围动态生成
- 3.3、当当前条件下无可选学科时，学科下拉置灰，并显示【暂无可选学科】
- 3.4、学科切换后，顶部总数同步更新为当前筛选结果总数

## 4. 关键词搜索
- 4.1、用户在搜索框输入关键词后，对历史记录列表进行搜索过滤
- 4.2、搜索采用关键词模糊匹配
- 4.3、输入内容自动去除首尾空格
- 4.4、仅输入空格时，视为无搜索条件
- 4.5、搜索可采用输入后实时触发的方式，并支持防抖处理
- 4.6、搜索关键词在学段或学科筛选切换时保留不变
- 4.7、搜索后，顶部总数同步更新为当前筛选结果总数

## 5. 多条件联动
- 5.1、学段、学科、关键词搜索三类条件可同时生效
- 5.2、多条件之间为【且】关系
- 5.3、任一条件变化后，列表结果和顶部总数均同步刷新

## 6. 滚动加载
- 6.1、历史记录列表采用滚动加载方式浏览数据
- 6.2、用户滚动至列表底部附近时，自动加载下一批记录
- 6.3、滚动加载过程中，列表底部显示加载中状态
- 6.4、全部数据加载完成后，不再触发后续加载

## 7. 查看记录
- 7.1、历史发布记录条目仅支持查看，不支持点击跳转
- 7.2、当前版本不支持从历史记录条目进入学科详情页
- 7.3、如后续需要查看版本详情，需另行增加【查看详情】能力

## 8. 关闭弹窗
- 8.1、点击右上角【关闭】图标，关闭弹窗
- 8.2、点击底部【关闭】按钮，关闭弹窗
- 8.3、点击遮罩层不关闭弹窗
- 8.4、按 ESC 不关闭弹窗
- 8.5、弹窗关闭后，再次打开时恢复默认初始状态并将列表滚动回顶部

# 业务规则

## 一、数据范围规则
1. 弹窗展示范围为通用知识树模块下全部学段、全部学科的历史发布记录
2. 历史记录数据覆盖高中、初中、小学三个学段
3. 每次正式发布均生成一条历史记录
4. 历史记录仅支持查看，不支持编辑、删除、回滚等操作

## 二、筛选规则
1. 学段筛选项固定为：【全部学段】【高中】【初中】【小学】
2. 学科筛选默认项为【全部学科】
3. 学科筛选项根据当前历史记录数据范围动态生成
4. 当学段选择为具体学段时，学科筛选项联动为该学段下有历史记录的学科集合
5. 默认筛选条件为：【全部学段】+【全部学科】+ 空搜索词
6. 学段、学科、关键词三类条件支持组合使用，且为【且】关系

## 三、搜索规则
1. 支持对版本号、发布说明、发布人姓名、发布人账号进行关键词模糊搜索
2. 搜索输入内容自动去除首尾空格
3. 仅输入空格时，按无搜索条件处理
4. 搜索支持实时触发，并可通过防抖优化搜索体验

## 四、排序规则
1. 历史记录默认按发布时间倒序排列
2. 最新发布时间的记录展示在最前
3. 当前版本不支持用户自定义排序方式

## 五、总数展示规则
1. 标题区显示的【共 X 条记录】表示当前筛选结果总数
2. 当学段、学科或搜索条件发生变化时，记录总数需同步更新
3. 无筛选结果时，总数显示为 0

## 六、记录条目展示规则
1. 每条记录需展示以下字段：
- 版本号
- 学段·学科
- 发布时间
- 发布说明
- 发布人姓名
- 发布人账号
2. 发布时间为空时，显示【--】
3. 发布说明为空时，显示【未填写发布说明】
4. 发布人为空时，显示【--】
5. 当前版本不展示额外标签信息，如出版社、年级等

## 七、权限规则
1. 教研主管可查看历史发布记录
2. 教研员可查看历史发布记录
3. 历史发布记录弹窗为只读能力，不提供新增、编辑、删除、跳转管理等操作权限

## 八、新旧功能数据一致性规则
1. 历史发布记录数据需基于通用知识树统一口径展示
2. 历史功能与本期新功能产生的有效发布记录，应统一纳入历史记录查询范围
3. 不允许出现新旧功能发布记录缺失、重复或口径不一致的情况
4. 发布说明、发布时间、发布人、版本号等核心字段需保持统一来源或统一同步结果

# 状态与异常

## 页面状态
- 首次加载中状态：列表区域显示骨架屏或 loading 占位
- 正常有数据状态：展示历史记录列表
- 筛选/搜索加载中状态：保留已有列表或显示局部加载态
- 无结果状态：展示空状态
- 加载失败状态：展示失败提示和重试入口
- 滚动加载中状态：列表底部显示加载中提示

## 异常与边界
- 网络异常时：显示失败提示，并支持重试
- 数据为空时：显示【暂无历史记录】空状态
- 筛选无结果时：显示空状态，并保留当前筛选条件
- 搜索无结果时：显示空状态，并保留当前搜索词
- 学科筛选无可选项时：下拉置灰，并显示【暂无可选学科】
- 若接口异常导致总数与列表不一致，应按统一结果重新刷新或提示异常，避免展示冲突数据
- 关闭弹窗后再次打开，需恢复默认初始状态并将列表滚动回顶部

| 新旧功能统一发布数据口径 | 统一主数据源或同步后的发布结果数据 | 保证历史记录展示一致性 |

# 技术要求

- 弹窗需支持固定头部区域、列表区独立滚动和底部操作区固定展示
- 弹窗需支持筛选、搜索、滚动加载等交互能力
- 弹窗需支持首次加载态、局部加载态、无结果态、失败态和正常态切换
- 列表数据需支持按发布时间倒序稳定展示
- 学科筛选项需随学段筛选联动刷新
- 关闭弹窗后再次打开，需恢复默认初始状态
- 历史记录数据需基于统一数据口径展示，确保新旧功能记录一致
- 在数据量较大时，需保证滚动浏览和滚动加载性能稳定
