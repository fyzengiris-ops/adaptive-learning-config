# 2.05 详情页-编辑态-右侧知识点结构【GPT更新】

# 页面目标
用于在知识树编辑态下维护当前选中知识点的前置知识点关系，并通过图谱方式展示当前知识点与前置知识点之间的关联结构。支持对当前知识点的直接前置知识点进行维护，同时支持递归维护前置知识点本身已关联的更早前置知识点，从而形成网状前置关系展示。

# 所属页面
知识体系管理 > 通用知识树 > 详情页 > 编辑态 > 右侧知识点结构

# 页面区域

## A. 标题区
用于展示当前选中知识点名称。

## B. Tab切换区
用于在【知识点信息】【知识点结构】【学习资源】三个内容模块之间切换。

## C. 知识点关联关系图区
用于展示当前知识点与前置知识点的图谱关系，并提供前置关系维护入口。

# 组件说明

## A. 标题区组件
- A1. 知识点标题：显示当前选中知识点名称，如【正多边形的镶嵌应用】

## B. Tab切换区组件
- B1. 知识点信息Tab：显示【知识点信息】
- B2. 知识点结构Tab：显示【知识点结构】
- B3. 学习资源Tab：显示【学习资源】
- B4. 当前选中态：当前Tab高亮显示
- B5. 未选中态：未选中的Tab保持普通态显示

## C. 知识点关联关系图区组件
- C1. 关系图标题：显示【知识点关联关系】
- C2. 提示说明：显示「右上角按钮可编辑当前知识点的前置知识；单击图中知识点，可直接在本页编辑对应知识点的前置知识」
- C3. 图例说明：展示【前置】【当前】两类节点标识
- C4. 当前知识点节点：使用固定的当前节点样式展示
- C5. 前置知识点节点：使用前置节点样式展示
- C6. 非末级前置知识点样式：需与末级前置知识点在视觉上区分，突出其仍包含下级知识点
- C7. 末级前置知识点样式：使用普通前置知识点节点样式
- C8. 关联连线：用于展示前置知识点与当前知识点之间的关系路径
- C9. 节点操作气泡：点击可编辑的前置知识点节点后，显示【编辑前置知识点】气泡按钮
- C10. 节点移除按钮：对允许移除的前置关系节点显示删除/移除入口
- C11. 图谱滚动条：当图谱宽度超出容器时，支持横向滚动查看完整关系图
- C12. 节点悬浮提示：鼠标悬浮在知识点节点上时，显示完整的知识点名称

# 交互逻辑

## 1. 页面进入
1.1、在编辑态下，选中左侧某个支持维护知识点结构的知识点后，右侧进入【知识点结构】页  
1.2、页面展示当前知识点名称、Tab切换区和知识点关联关系图  
1.3、若当前知识点已维护前置知识点关系，则默认展示对应图谱  
1.4、若当前知识点未维护任何前置知识点，则图谱中仅展示当前知识点  

## 2. Tab切换
2.1、点击【知识点信息】【知识点结构】【学习资源】Tab后，切换对应内容区域  
2.2、当前页面文档仅描述【知识点结构】Tab下的编辑内容  
2.3、切换Tab不自动触发保存，由顶部【完成编辑】统一提交当前编辑结果  

## 3. 图谱展示
3.1、图谱中固定展示当前知识点  
3.2、图谱展示当前知识点的直接前置知识点  
3.3、若这些直接前置知识点本身已维护了更早的前置知识点，则继续向前递归展开  
3.4、因此当前页面看到的前置关系可能是网状结构，而不是单层结构  
3.5、图谱中前置知识点需区分末级知识点和非末级知识点的样式  
3.6、图谱超出容器宽度时，支持横向滚动查看完整内容  
3.7、鼠标悬浮在知识点节点上时，显示完整的知识点名称（用于查看被截断的知识点名称）

## 4. 编辑前置知识点
4.1、当前页面支持维护当前知识点的直接前置知识点  
4.2、点击图谱中的可编辑前置知识点节点后，显示【编辑前置知识点】气泡按钮  
4.3、点击【编辑前置知识点】后，进入该节点的前置知识点维护流程  
4.4、因此当前页面不仅可维护当前知识点的前置知识点，也可递归维护其前置知识点本身已关联的更早前置知识点  
4.5、前置知识点的具体选择与配置通过前置知识点维护流程完成  

## 5. 移除前置关系
5.1、当前页面允许移除当前知识点的直接前置知识点关系  
5.2、当前页面也允许移除直接前置知识点所关联的其他前置知识点关系  
5.3、移除对象为“知识点之间的前置关系”，不是删除知识点实体本身  
5.4、移除后，当前图谱中的关系展示需同步更新  

## 6. 完成编辑
6.1、在编辑态下，对当前知识点及其递归前置关系的新增、移除、调整，先作为当前编辑结果保存在页面中  
6.2、点击顶部【完成编辑】后，退出编辑态，并将当前编辑结果统一提交保存  
6.3、若保存成功，则页面按保存后的结果展示  
6.4、若保存失败，需提示失败原因，并保留当前编辑结果，避免用户重新配置  

# 业务规则

## 一、适用对象规则
1. 当前页面用于维护当前选中知识点的知识点结构信息  
2. 当前页面维护范围聚焦于前置知识点关系  
3. 当前页面不承载知识点目录增删改查，目录维护由左侧知识树目录承担  

## 二、图谱展示规则
1. 图谱固定展示当前知识点  
2. 图谱展示当前知识点的直接前置知识点  
3. 若直接前置知识点已维护更早前置知识点，则图谱需递归向前展开  
4. 因此前置关系最终可能呈现为网状结构  

## 三、节点样式规则
1. 当前知识点使用固定当前节点样式展示  
2. 前置知识点统一使用前置节点样式展示  
3. 前置知识点中的非末级知识点，需使用与末级知识点不同的视觉样式  
4. 非末级知识点样式需体现其仍包含下级知识点  
5. 末级知识点样式用于表示最终知识点节点  

## 四、前置关系维护规则
1. 当前页面可维护当前知识点的直接前置知识点  
2. 当前页面也可递归维护前置知识点本身已关联的更早前置知识点  
3. 点击前置节点后出现的【编辑前置知识点】气泡按钮，是递归维护其他前置节点前置关系的入口  
4. 当前页面允许维护当前节点关联着的所有其他前置节点的前置节点信息  

## 五、前置关系移除规则
1. 当前页面允许移除当前知识点的直接前置知识点关系  
2. 当前页面也允许移除直接前置节点关联的其他前置节点关系  
3. 移除操作针对的是“前置关系”，不是删除知识点实体本身  
4. 移除后，图谱关系需实时更新展示  

## 六、保存规则
1. 前置关系的新增、移除、递归调整，均作为当前编辑结果暂存于编辑态中  
2. 点击顶部【完成编辑】后，统一提交保存  
3. 保存失败时，需提示失败原因，并保留当前编辑结果  
4. 保存成功后，页面展示最新的图谱结果  

## 七、空态与展示规则
1. 当前知识点未维护任何前置知识点时，图谱中仅展示当前知识点  
2. 当前知识点存在直接前置知识点，但这些前置知识点无更早前置关系时，仅展示当前知识点及这一层直接前置知识点  
3. 图谱内容超出容器宽度时，支持横向滚动查看  

## 八、数据一致性规则
1. 左侧知识树目录的数据口径，仍以乐课网平台对应学科已有知识树内容一致为目标  
2. 所谓一致，是指知识点名称、层级结构、增删改查结果一致  
3. 右侧【知识点结构】中的前置关系维护，为新功能新增能力  
4. 历史功能不要求同步承载知识点结构图谱及前置关系维护能力  
5. 历史功能与新功能之间，仍只要求知识树目录内容一致，不要求同步展示右侧新增的结构关系能力  

# 状态与异常

## 页面状态
- 正常编辑状态：显示当前知识点及其前置关系图谱
- 当前节点无前置状态：图谱中仅展示当前知识点
- 单层前置状态：展示当前知识点及直接前置知识点
- 网状前置状态：展示当前知识点及递归展开的前置关系网络
- 节点操作气泡显示状态：点击可编辑前置节点后显示【编辑前置知识点】入口
- 保存中状态：点击【完成编辑】后进入提交中状态

## 异常与边界
- 当前知识点无前置知识点时：图谱中仅显示当前知识点
- 图谱加载失败时：显示失败提示
- 图谱内容超宽时：支持横向滚动查看
- 保存失败时：提示失败原因，并保留当前编辑结果
- 节点关系移除失败时：提示失败原因，并保留当前编辑结果

# 技术要求

- 页面需支持Tab切换
- 页面需支持前置关系图谱展示
- 图谱中需区分当前节点、前置节点，以及前置节点中的末级/非末级样式差异
- 图谱需支持递归展开前置关系，形成网状结构展示
- 页面需支持通过节点气泡入口递归编辑其他前置节点的前置关系
- 页面需支持前置关系移除
- 页面需支持横向滚动查看完整图谱
- 页面需支持编辑结果统一提交保存
- 页面需支持保存失败后的结果保留
- 左侧知识树目录仍需与乐课网平台对应学科已有知识树内容保持一致
