# 2.3 详情页-编辑态-发布确认弹窗【GPT更新】

## 页面目标

用于对当前策略已保存但未发布的变更执行发布操作。用户可在弹窗中填写更新说明，选择立即发布或定时发布，并在确认后使本次策略变更立即生效或按设定时间生效。

## 所属页面

策略管理 > 策略广场 > 学情诊断 > 策略详情 > 编辑态 > 发布确认弹窗

---

## 页面定位

1. 当前页面为编辑态详情页中的发布确认弹窗。
2. 当前弹窗用于处理当前策略已保存但未发布的变更发布。
3. 当前弹窗可支持以下操作：
   - 查看新版本号
   - 填写更新说明
   - 选择立即发布或定时发布
   - 选择定时发布日期和时间
   - 取消发布
   - 确认发布 / 确认定时发布
4. 当前弹窗不承载以下能力：
   - 查看历史版本明细
   - 编辑策略内容
   - 删除策略
   - 回滚历史版本

---

## 页面结构

### A. 弹窗头部区域

用于展示弹窗标题和关闭入口。

| 元素 | 说明 |
|------|------|
| 弹窗标题 | 显示：**发布新版本** |
| 关闭按钮 | 位于弹窗右上角，点击后关闭当前弹窗 |

#### 展示规则

1. 弹窗标题固定展示为：**发布新版本**
2. 右上角展示关闭按钮
3. 关闭按钮点击后关闭当前弹窗，不执行发布操作

---

### B. 发布注意事项区域

用于展示发布注意事项提示信息。

| 元素 | 说明 |
|------|------|
| 提示标题 | 显示：**发布注意事项** |
| 提示说明 | 提示发布影响和建议发布时间段 |

#### 展示规则

1. 发布确认弹窗打开后，顶部固定展示【发布注意事项】提示区
2. 提示区展示以下文案：
   - **发布将影响线上用户的实际使用，建议避开用户高频使用的时间段。**
   - **建议发布时间段：凌晨 00:00 - 04:00**
3. 提示区为固定展示内容，不因发布方式切换而隐藏

---

### C. 发布信息填写区域

用于展示新版本号，并填写更新说明和发布时间设置。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 版本号 | 只读展示字段 | 是 | 展示系统自动生成的新版本号 |
| 更新说明 | 多行文本输入框 | 是 | 填写本次发布的更新说明 |
| 发布时间 | 单选项 | 是 | 选择立即发布或定时发布 |
| 定时发布日期 | 日期选择器 | 定时发布时必填 | 选择定时发布日期 |
| 定时发布时间 | 时间选择器 | 定时发布时必填 | 选择定时发布时间 |

---

## 字段规则

### 1. 版本号

1. 弹窗内【版本号】字段为只读展示字段
2. 版本号由系统根据当前最新已发布版本号自动生成
3. 用户不可手动修改版本号
4. 版本号格式为：**v主版本.次版本**（如 v1.0、v1.1）
5. 当前页面发布时，默认按次版本号递增生成新版本号  
   例如：`v1.0 → v1.1`

---

### 2. 更新说明

1. 更新说明为必填字段
2. 输入框为多行文本输入框
3. placeholder 为：**请填写本次更新的主要内容...**
4. 用户未填写更新说明时，不允许提交发布
5. 点击确认按钮后，若更新说明为空，系统需在弹窗内提示错误信息：**请填写更新说明**
6. 用户补充后方可继续提交

---

### 3. 发布时间

发布时间支持以下两种方式：

- 立即发布
- 定时发布

#### 展示规则

1. 弹窗默认选中：**立即发布**
2. 当用户选择【立即发布】时：
   - 不展示定时发布日期选择器
   - 不展示定时发布时间选择器
3. 当用户选择【定时发布】时：
   - 展示定时发布日期选择器
   - 展示定时发布时间选择器
4. 时间选择器默认值为：**02:00**

---

### 4. 定时发布日期

1. 仅在选择【定时发布】时展示
2. 为定时发布必填字段
3. 用户未选择发布日期时，不允许提交定时发布
4. 若未选择，则提示：**请选择定时发布日期**

---

### 5. 定时发布时间

1. 仅在选择【定时发布】时展示
2. 为定时发布必填字段
3. 默认值为：**02:00**
4. 用户未选择发布时间时，不允许提交定时发布
5. 若未选择，则提示：**请选择定时发布时间**
6. 定时发布时间必须晚于当前系统时间
7. 若用户选择的定时发布时间早于或等于当前时间，则阻断提交，并提示：**定时发布时间需晚于当前时间**

---

## 操作按钮区域

| 按钮 | 说明 |
|------|------|
| 取消 | 点击后关闭当前弹窗，不执行发布 |
| 主按钮 | 根据发布方式切换文案 |

#### 按钮文案规则

1. 当发布方式为【立即发布】时，底部主按钮文案显示：**确认发布**
2. 当发布方式为【定时发布】时，底部主按钮文案显示：**确认定时发布**

---

## 交互逻辑

### 1. 打开弹窗

1. 当当前策略存在已保存未发布变更时，编辑态页面展示橙色待发布状态条及【发布】按钮
2. 用户点击【发布】按钮后，打开发布确认弹窗
3. 弹窗打开后，系统默认初始化以下内容：
   - 更新说明为空
   - 发布方式默认选中【立即发布】
   - 定时发布时间默认值为【02:00】
   - 版本号自动生成并回显

---

### 2. 切换发布方式

#### 2.1 立即发布

1. 用户选择【立即发布】
2. 页面隐藏定时发布日期与定时发布时间字段
3. 底部主按钮文案显示为：**确认发布**

#### 2.2 定时发布

1. 用户选择【定时发布】
2. 页面展示定时发布日期与定时发布时间字段
3. 底部主按钮文案显示为：**确认定时发布**

---

### 3. 填写更新说明

1. 用户在更新说明输入框中填写本次发布的更新内容
2. 页面实时记录用户输入内容
3. 若更新说明为空，提交时阻断发布并提示对应错误信息

---

### 4. 选择定时发布时间

1. 用户选择【定时发布】后，可选择发布日期和发布时间
2. 系统校验所选发布时间是否有效
3. 若未选择日期或时间，或时间早于当前系统时间，则阻断提交并提示错误原因

---

### 5. 取消发布

1. 用户点击【取消】按钮，关闭当前弹窗
2. 用户点击右上角关闭按钮，关闭当前弹窗
3. 关闭弹窗后，不执行任何发布操作
4. 当前弹窗关闭后，本次临时填写内容不保留；下次重新打开时按默认状态重新初始化

---

### 6. 确认发布

#### 6.1 立即发布

1. 用户点击【确认发布】
2. 系统校验更新说明是否填写完整
3. 校验通过后，系统执行立即发布
4. 本次变更立即生效
5. 当前策略版本号更新为新版本号
6. 当前页面关闭发布弹窗
7. 当前页面清除待发布状态提示
8. 当前页面按最新已发布结果回显版本号与状态信息

#### 6.2 定时发布

1. 用户点击【确认定时发布】
2. 系统校验：
   - 更新说明是否填写完整
   - 定时发布日期是否已选择
   - 定时发布时间是否已选择
   - 定时发布时间是否晚于当前系统时间
3. 校验通过后，系统保存本次定时发布任务
4. 当前页面关闭发布弹窗
5. 当前策略在定时任务执行前保持待发布状态
6. 页面后续展示口径以定时发布状态规则为准

---

## 业务规则

### 一、发布范围规则

1. 当前弹窗仅用于发布当前策略已保存但未发布的变更
2. 当前弹窗不用于新建策略首次创建
3. 当前弹窗不处理其他策略的发布内容

### 二、版本号规则

1. 发布时系统自动生成新版本号
2. 版本号格式为：`v主版本.次版本.修订号`
3. 默认按修订号递增生成新版本号
4. 用户不可手动修改版本号

### 三、更新说明规则

1. 更新说明为必填字段
2. 未填写更新说明时，阻断提交发布

### 四、发布方式规则

1. 支持立即发布和定时发布两种方式
2. 弹窗默认选中【立即发布】
3. 选择定时发布后，必须补充完整的发布日期和发布时间

### 五、定时发布规则

1. 定时发布日期必填
2. 定时发布时间必填
3. 定时发布时间必须晚于当前系统时间
4. 定时发布时间默认值为 02:00

### 六、按钮文案规则

1. 立即发布方式下，主按钮文案为：**确认发布**
2. 定时发布方式下，主按钮文案为：**确认定时发布**

### 七、发布结果规则

#### 立即发布
1. 本次变更立即生效
2. 当前策略版本号更新为新版本号
3. 页面关闭发布弹窗
4. 页面清除待发布状态提示
5. 页面按最新已发布结果回显版本号与状态信息

#### 定时发布
1. 系统保存本次定时发布任务
2. 页面关闭发布弹窗
3. 当前策略在定时任务执行前保持待发布状态
4. 页面后续展示口径以定时发布状态规则为准

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 弹窗打开状态 | 当前发布确认弹窗已打开 |
| 立即发布状态 | 当前默认或已选择立即发布 |
| 定时发布状态 | 当前已选择定时发布 |
| 校验失败状态 | 用户提交时存在未通过校验项 |
| 提交成功状态 | 发布或定时发布提交成功 |

### 2. 校验失败处理

1. 更新说明为空时，阻断提交，并提示：**请填写更新说明**
2. 定时发布日期为空时，阻断提交，并提示：**请选择定时发布日期**
3. 定时发布时间为空时，阻断提交，并提示：**请选择定时发布时间**
4. 定时发布时间早于或等于当前时间时，阻断提交，并提示：**定时发布时间需晚于当前时间**

### 3. 异常处理规则

1. 发布提交失败时，页面需提示失败原因
2. 发布失败后，弹窗保持打开状态，便于用户修改后重新提交
3. 用户仍可主动关闭弹窗，取消本次发布操作

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 更新说明为空 | 阻断提交，提示请填写更新说明 |
| 选择定时发布但未选日期 | 阻断提交，提示请选择定时发布日期 |
| 选择定时发布但未选时间 | 阻断提交，提示请选择定时发布时间 |
| 定时发布时间早于当前时间 | 阻断提交，提示定时发布时间需晚于当前时间 |
| 用户点击取消 | 关闭弹窗，不执行发布 |
| 用户点击右上角关闭按钮 | 关闭弹窗，不执行发布 |
| 立即发布成功 | 关闭弹窗，清除待发布提示，回显最新已发布信息 |
| 定时发布成功 | 关闭弹窗，保留待发布状态，等待定时任务生效 |
