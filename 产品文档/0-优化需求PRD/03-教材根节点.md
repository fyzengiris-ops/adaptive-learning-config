# 教材根节点·课程总览 PRD

## 1. 页面范围

### 1.1 当前页面
- 页面名称：教材体系知识树 · 教材根节点 · 课程总览（专题课总览 / 拓展课总览 / 同步课总览）
- 所属模块：知识体系管理 · 教材体系知识树
- 页面路由/视图：`/knowledge-system`（知识体系管理 → 教材体系知识树 → 选中教材根节点「学科·年级」→ 「课程」Tab → 课程总览）
- 相关代码文件：
  - `src/app/knowledge-system/page.tsx`
  - `src/app/system-settings/TextbookTree.tsx`

### 1.2 上级页面/上游入口
- 上级页面：知识体系管理
- 入口位置：知识体系管理页「教材体系知识树」Tab → 进入某本教材详情 → 左侧章节树最上方「学科·年级」（教材名称虚拟节点）
- 进入方式：进入 `/knowledge-system`，切到教材体系知识树，打开教材后点选根节点，右侧切到「课程」
- 传入数据：当前教材、整本教材章节树及各章综合课/同步课配置
- 依赖状态：未选中具体章/节/小节；课程区内总览子 Tab（专题课总览 / 拓展课总览 / 同步课总览）；是否处于「编辑教材详情」（不影响总览只读）

### 1.3 下级页面/下游流程
- 下级页面/下游流程：课程预览、试卷预览（只读）；维护入口在章级「综合课维护」或节/小节同步课区（本总览不直接改写）
- 触发方式：总览内视频/试卷预览；切到对应章节点后进入综合课维护
- 传出数据：本总览不改写名单；预览不改变配置
- 后续状态：未在当前代码或注册表中确认由本总览触发的待发布变更
- 返回逻辑：关闭预览回到总览；点选章节点离开本总览进入章详情

### 1.4 范围边界摘要
- 本文档覆盖：教材根节点「课程」下已挂数字角标的专题课总览、拓展课总览、同步课总览及只读约束
- 本文档不覆盖：章级综合课维护编辑细则、教材级知识点总览、练习试卷总览、批量导入 / 习题册导入

## 2. 功能概述

教材根节点「课程」用于只读聚合查看整本教材的三类课程配置：专题课总览、拓展课总览、同步课总览。专题/拓展按章展示「视频下挂绑定试卷」；同步课沿用章→节→小节树形聚合同步课视频。无论是否「编辑教材详情」，本区均不可在总览内增删改。

本文档业务逻辑与页面数字角标、悬浮面板、右侧 PRD 面板同源，均来自需求注册表 `logicSections`。

## 3. 业务逻辑说明

### TB_TCO-001 教材根节点·课程入口

来源：代码事实 + 确认决策

#### 显示说明
1.1 左侧章节树点选最上方「学科·年级」（教材根节点、未选中具体章/节/小节）时，右侧进入教材级详情。
1.2 教材级顶栏 Tab 含「知识点」「课程」「练习试卷」；点「课程」进入本册所述课程总览区。

#### 操作说明
1.1 从章/节/小节切回根节点后，再进「课程」仍进入教材级课程总览，不再展示章级「综合课维护」。

#### 验收标准
1. 选中教材根节点并切到「课程」时，可见课程总览子 Tab，而非章级综合课维护。
2. 选中具体章节点时，不使用本册总览布局。

### TB_TCO-002 课程总览子 Tab

来源：代码事实 + 确认决策

#### 显示说明
1.1 「课程」下子 Tab 文案依次为「专题课总览」「拓展课总览」「同步课总览」，三者互斥，同时只亮一个。
1.2 进入教材根节点课程区时，默认停在「专题课总览」。
1.3 再次点选教材根节点（离开后再回来）时，子 Tab 重置为「专题课总览」，不记住上次停在拓展或同步。

#### 操作说明
1.1 点任一子 Tab 只切换下方总览内容区，不提交、不改章节数据。

#### 验收标准
1. 进入根节点课程区默认亮「专题课总览」。
2. 切到拓展/同步后再回根节点，「专题课总览」重新为默认选中。

### TB_TCO-003 专题课总览

来源：代码事实 + 确认决策

#### 显示说明
1.1 区域标题为「专题课总览」，并提示聚合展示各章专题课视频及绑定试卷（仅查看）。
1.2 按教材章节树的章节点顺序，逐章展示；每章先出现章标题条，再出现该章专题课内容。
1.3 章标题展示章名称，旁注「（X个课程·Y份试卷）」；X 为该章专题课视频条数，Y 为这些视频下已绑定练习试卷套数之和。
1.4 无专题课视频的章仍展示该章标题条，记为「（0个课程·0份试卷）」，内容区空态文案为「暂未添加视频」。
1.5 有视频时，按章编辑态同构：每个视频一块卡片；卡片头展示视频名、时长、体积、来源；卡片体展示该视频绑定的配套练习试卷。
1.6 某视频未绑定试卷时，卡片体空态为「暂未绑定配套练习试卷」。
1.7 视频行提供预览入口；不提供上传、从资源库选择、添加试卷、移除。

#### 数据规则
1.1 专题课数据取自各章「综合课·专题课」名单（章级维护结果），不聚合同步课叶子节点视频。
1.2 试卷只统计挂在该章专题课视频下的绑定试卷，不计入章「练习试卷」Tab、拓展课或同步课名单。
1.3 本总览只读镜像章级已保存/当前内存中的专题课配置，不在总览内改写名单。

#### 统计口径
1.1 X = 该章专题课视频条数。
1.2 Y = 该章全部专题课视频下绑定试卷条数合计（按绑定关系展开计数）。

#### 验收标准
1. 有样例数据的章可见「章名（N个课程·M份试卷）」及视频下挂试卷。
2. 无视频的章仍出现标题「（0个课程·0份试卷）」与「暂未添加视频」。
3. 总览内看不到添加/移除类操作按钮。

### TB_TCO-004 拓展课总览

来源：代码事实 + 确认决策

#### 显示说明
1.1 与「专题课总览」同一套结构与空态规则，仅数据换成各章「综合课·拓展课」。
1.2 章标题旁注「（X个课程·Y份试卷）」的 X/Y 口径分别对应拓展课视频条数与其绑定试卷合计。

#### 数据规则
1.1 拓展课数据取自各章「综合课·拓展课」名单，与专题课、同步课、章「练习试卷」Tab 分开。
1.2 本总览只读，不在总览内改写拓展课名单。

#### 验收标准
1. 切到「拓展课总览」后结构与专题课总览一致，内容为拓展课数据。
2. 空章同样展示「（0个课程·0份试卷）」与「暂未添加视频」。

### TB_TCO-005 同步课总览

来源：代码事实 + 确认决策

#### 显示说明
1.1 区域标题为「同步课总览」，提示聚合展示该教材下所有章节关联的同步课（仅查看）。
1.2 按章 → 节 → 小节（若有）树形聚合展示叶子同步课视频卡片；结构沿用原教材级同步课程总览。
1.3 章标题旁注「（N个课程）」中的 N 为该章（含子节点）同步课视频条数合计。
1.4 同步课卡片可预览；不提供增删改。

#### 数据规则
1.1 同步课取自节/小节上的同步课名单，不展示章级专题课/拓展课视频，也不在本区展示试卷绑定关系。
1.2 本总览只读镜像现有同步课配置。

#### 验收标准
1. 「同步课总览」仍按章/节/小节树展示同步课。
2. 不出现专题/拓展的「视频下挂试卷」模块形态。

### TB_TCO-006 课程总览只读约束

来源：代码事实 + 确认决策

#### 状态规则
1.1 无论当前是否处于「编辑教材详情」，专题课总览、拓展课总览、同步课总览均只能查看，不能在总览内维护视频或试卷。
1.2 允许的交互限于：切换三个总览子 Tab、预览视频、预览试卷（若入口存在）。
1.3 增删改专题/拓展课须进入对应章节点的「综合课维护」；增删改同步课须进入对应节/小节维护入口。

#### 验收标准
1. 打开「编辑教材详情」后，三个总览仍无上传/选课/添加试卷/移除按钮。
2. 预览仍可打开且关闭后名单不变。
