# 1.0 首页-查看历史发布记录弹窗【GPT更新】

## 页面目标

用于查看掌握程度划分模块下各学段（高中、初中、小学）的历史发布记录。用户可在弹窗中统一查看各学段已发布版本的版本号、学段归属、发布时间、更新说明、发布人等信息，以了解掌握程度划分配置的整体变更历史。

## 所属页面

策略管理 > 策略广场 > 掌握程度划分 > 首页 > 查看历史发布记录弹窗

---

## 页面定位

1. 当前页面为查看型弹窗页面。
2. 当前弹窗用于聚合展示掌握程度划分模块下各学段的历史发布记录。
3. 当前弹窗仅聚合以下三个学段的历史发布记录：
   - 高中
   - 初中
   - 小学
4. 当前页面不承载以下能力：
   - 学段筛选
   - 搜索
   - 点击记录跳转详情
   - 版本对比
   - 回滚版本
   - 删除记录

---

## 页面结构

### A. 弹窗头部区域

用于展示弹窗标题、记录数量及关闭入口。

| 元素 | 说明 |
|------|------|
| 历史图标 | 展示历史发布记录图标 |
| 弹窗标题 | 显示：**历史发布记录** |
| 记录数量 | 显示聚合后的历史发布记录总条数，文案格式为：**共 X 条记录** |
| 关闭按钮 | 位于弹窗右上角，点击后关闭当前弹窗 |

#### 展示规则

1. 弹窗标题固定展示为：**历史发布记录**
2. 记录数量表示当前掌握程度划分模块下，高中 / 初中 / 小学三个学段聚合后的历史发布记录总条数
3. 当弹窗重新打开并获取到最新数据后，数量按最新结果重新计算展示
4. 头部右侧展示关闭按钮

---

### B. 历史记录列表区域

用于展示掌握程度划分模块下各学段聚合后的历史发布记录列表。

#### 单条历史记录卡片展示内容

| 元素 | 说明 |
|------|------|
| 版本号 | 展示当前发布记录的版本号 |
| 学段归属文案 | 展示当前记录所属学段，格式为：{学段}·掌握度划分 |
| 发布时间 | 展示该版本的发布时间 |
| 更新说明 | 展示该版本对应的更新说明 |
| 发布人信息 | 展示发布人姓名和账号 |

#### 展示规则

1. 当前弹窗聚合展示高中、初中、小学三个学段的历史发布记录。
2. 所有记录按发布时间倒序排列，最新记录显示在最前。
3. 每条历史发布记录均需展示以下信息：
   - 版本号
   - 学段归属文案
   - 发布时间
   - 更新说明
   - 发布人姓名
   - 发布人账号
4. 学段归属文案格式统一为：**{学段}·掌握度划分**
5. 发布人信息展示格式统一为：**发布人：姓名（账号：XXXXXX）**
6. 列表区域支持弹窗内垂直滚动查看。

#### 学段归属文案示例

- 高中·掌握度划分
- 初中·掌握度划分
- 小学·掌握度划分

---

### C. 底部操作区域

用于提供关闭弹窗操作。

| 元素 | 说明 |
|------|------|
| 关闭按钮 | 位于弹窗底部右侧，点击后关闭当前弹窗 |

#### 展示规则

1. 底部固定展示【关闭】按钮
2. 当前弹窗不展示其他操作按钮

## 交互逻辑

### 1. 打开弹窗

1. 用户在掌握程度划分首页点击【查看历史发布记录】入口。
2. 系统打开当前历史发布记录弹窗。
3. 系统聚合以下三个学段的历史发布记录：
   - 高中
   - 初中
   - 小学
4. 聚合结果按发布时间倒序展示。
5. 头部【共 X 条记录】按最新聚合结果计算展示。

---

### 2. 查看历史记录

1. 用户可在弹窗中查看掌握程度划分模块下各学段的历史发布记录。
2. 历史记录列表按发布时间倒序展示。
3. 用户可通过滚动查看全部记录内容。

---

### 3. 关闭弹窗

1. 用户点击右上角关闭按钮后，关闭弹窗。
2. 用户点击底部【关闭】按钮后，关闭弹窗。
3. 弹窗关闭后，不保留本次查看过程中的临时滚动位置。
4. 用户下次重新打开弹窗时，系统按最新历史发布记录重新初始化弹窗内容与数量统计。

2. 用户可进行的操作仅包括：

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 加载中 | 弹窗打开后，系统正在加载并聚合各学段历史发布记录 |
| 正常状态 | 正常展示历史发布记录列表 |
| 空状态 | 高中 / 初中 / 小学三个学段均无历史发布记录 |
| 加载失败 | 历史发布记录加载失败 |

### 2. 空状态规则

1. 当掌握程度划分模块下高中 / 初中 / 小学三个学段均无任何历史发布记录时，列表区域展示空状态文案：**暂无发布记录**
2. 空状态下仍保留：
   - 弹窗头部
   - 关闭按钮
   - 底部关闭按钮

### 3. 加载失败规则

1. 当历史发布记录加载失败时，页面展示加载失败提示
2. 加载失败不影响用户关闭弹窗

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 高中 / 初中 / 小学均存在历史发布记录 | 聚合后按发布时间倒序展示 |
| 部分学段无记录、部分学段有记录 | 仅展示有记录的学段内容，统一按时间排序 |
| 三个学段均无历史发布记录 | 展示空状态：暂无发布记录 |
| 历史记录较多 | 支持弹窗内纵向滚动查看 |
| 用户关闭弹窗后再次打开 | 按最新历史发布记录重新初始化内容 |
| 历史发布记录加载失败 | 展示失败提示，并允许关闭弹窗 |
