# 知识点详情页面 PRD

## 1. 页面范围

### 1.1 当前页面
- 页面名称：通用知识树 · 末级知识点详情
- 所属模块：知识体系管理 · 通用知识树
- 页面路由/视图：`/knowledge-system`（知识体系管理 → 通用知识树 → 选中末级知识点后的详情区）
- 相关代码文件：
  - `src/app/knowledge-system/page.tsx`

  - `src/components/shared/KnowledgeCardTabletPreview.tsx`

  - `src/components/shared/ImportValidationModal.tsx`

### 1.2 上级页面/上游入口
- 上级页面：知识体系管理
- 入口位置：知识体系管理页「通用知识树」Tab
- 进入方式：进入 `/knowledge-system`，切到通用知识树，在左侧目录树选中末级知识点后展示详情
- 传入数据：当前知识树、当前选中末级知识点（含编辑暂存）
- 依赖状态：是否处于「编辑知识点详情」会话；详情区当前 Tab（知识点信息 / 关联考点 / 学习资源）

### 1.3 下级页面/下游流程
- 下级页面/下游流程：批量导入弹窗、导入校验结果弹窗、典型例题选题弹窗、知识卡片平板预览、添加子节点确认
- 触发方式：顶栏「批量导入」；学习资源中「系统选择」打开选题弹窗；平板预览入口；目录树添加子节点
- 传出数据：导入文件校验与写回、例题题干写入知识卡片、子节点结构变更
- 后续状态：保存编辑后进入待发布；取消编辑丢弃本次暂存
- 返回逻辑：关闭弹窗回到详情；取消/返回在有未保存修改时二次确认

### 1.4 范围边界摘要
- 本文档覆盖：末级知识点详情页**已挂数字角标**的全部业务逻辑（知识点信息、关联考点、学习资源·知识卡片）
- 本文档不覆盖：未挂角标的注册表切片、知识点结构 Tab 细则、视频/文字讲解细则、发布确认与定时发布

## 2. 功能概述

末级知识点详情用于配置单个知识点的学业要求与考频、关联考点、以及学习资源中的知识卡片（核心概念、考点清单、例题与 Tips）。编辑在同一次会话内暂存，经「保存编辑」统一提交。导入导出、选题弹窗、平板预览与添加子节点判定与上述配置耦合。

本文档业务逻辑与页面数字角标、悬浮面板同源，均来自需求注册表 `logicSections`（含已落盘 overlay）。

### KT_INFO_AR-001 学业要求卡片

来源：代码事实 + 确认决策

#### 显示说明
1.1 仅末级（叶子）知识点展示学业要求卡片，位置在考频卡片左侧、同排布局。
1.2 可选值：了解、理解、掌握、运用、超纲；字段非必填。
1.3 未配置时展示【未设置】；不区分「从未设置」与「已清空」。
1.4 非编辑态只读查看；编辑态为下拉选择（含「未设置」）。
1.5 学业要求无论是否已保存，都不在左侧知识树节点上显示标签；左侧末级仅保留考频标签。

#### 操作说明
1.1 编辑态选择后写入当前编辑暂存，不单独即时落库。
1.2 与考频、策略及结构/学习资源等同属一次编辑会话：切换 Tab/字段不自动保存、不丢暂存。
1.3 仅点击「保存编辑」统一提交；仅「取消/返回」在有未保存修改时二次确认后丢弃。

#### 数据规则
1.1 新建末级知识点时，学业要求默认未设置（不预填具体枚举值）。
1.2 保存后变更维度归属「知识点信息」；待发布变更详情文案保持笼统「修改知识点配置」。

#### 验收标准
1. 末级节点在考频左侧可见学业要求；非末级不展示。
2. 未设置展示【未设置】；编辑可选五档枚举或未设置。
3. 左侧树节点不出现学业要求标签。
4. 改后未点保存即取消，有确认且丢弃修改。

### KT_INFO_AR-003 保存编辑

来源：代码事实 + 确认决策

#### 操作说明
1.1 点击后统一提交本知识点编辑暂存中的全部改动（含学业要求、考频、策略及结构/学习资源等）。
1.2 提交后进入待发布；变更维度为「知识点信息」时，详情文案保持「修改知识点配置」笼统表述。

#### 异常情况处理
1.1 保存前先校验关联考点：空名称 Toast「请填写所有考点名称后再保存」；未选类型 Toast「请为所有考点选择类型」；重名 Toast「考点名称不能重复」。不通过则不提交，并切到「关联考点」Tab。
1.2 再校验知识卡片自定义模块：空名称 Toast「请填写所有模块的名称后再保存」；同一卡片内重名 Toast「模块名称不能重复」。不通过则不提交，停留当前 Tab，自动切到「学习资源」。

#### 数据规则
1.1 校验通过后去掉纯空要点和纯空模块条目（无正文且无配图），不因此拦截保存。
1.2 知识卡片有改动时，待发布变更记一条维度为「学习资源」的记录；无改动不记。与其他 Tab 的改动按维度拆分。

#### 验收标准
1. 保存后学业要求写入节点并可在只读态看到。
2. 待发布列表维度为知识点信息，详情文案笼统不点名单字段。
3. 模块重名时保存失败并 Toast「模块名称不能重复」，且不切换详情 Tab。
4. 只改知识卡片后保存，变更维度出现「学习资源」。

### KT_INFO_AR-006 导出知识树

来源：代码事实 + 确认决策

#### 数据规则
1.1 导出表的表头在七级标题之后、考频之前增加「学业要求」列。
1.2 仅末级知识点导出学业要求，取值为了解/理解/掌握/运用/超纲；未设置时该单元格留空（不写「未设置」文案）。
1.3 表头在考频之后增加「考点名称」「考点类型」两列，其后为前置知识点、出题策略。
1.4 仅末级知识点导出关联考点；多个考点用顿号（、）分隔，名称与类型按当前列表顺序一一对应。
1.5 无有效关联考点时，考点名称、考点类型两列留空。
1.6 导出表的顶部说明文案有更新，以当前原型导出的最新文案进行更新

#### 验收标准
1. 导出文件含学业要求列且位于考频左侧。
2. 未设置学业要求的末级行该列为空。
3. 导出文件在考频后含考点名称、考点类型列；多个考点顿号分隔且顺序对应。
4. 名称为空的考点不出现在导出的名称/类型列中。
5. 通用策略导出为【通用策略】。
6. 导出文件不含知识卡片列，顶行说明也不出现知识卡片相关文案。

### KT_INFO_AR-008 导入校验（新增）

来源：代码事实 + 确认决策

#### 校验规则
1.1 学业要求仅允许填写：了解、理解、掌握、运用、超纲；也允许留空或填写【清空】。
1.2 学业要求仅允许出现在末级知识点行；非末级填写则该行失败，不写回。
1.3 考点名称、考点类型仅允许填写在末级知识点行；非末级填写则该行失败，不写回。
1.4 考点名称、考点类型两列都留空：不更新该末级关联考点。
1.5 可以只填考点名称、不填考点类型（与页面编辑一致：允许先只填名称）。
1.6 不能只填考点类型、不填考点名称。该行校验失败。
1.7 名称和类型都填了：按顿号拆开后个数必须相同，并从左到右按顺序一一对应。名称比类型少或名称比类型多：该行失败，不截断、不自动补空。
1.8 考点类型仅允许：基础达标、综合进阶、高分冲刺。
1.9 同一行内考点名称不可重复。

#### 数据规则
1.1 留空：不更新该末级学业要求。
1.2 填写【清空】：将该末级学业要求置为未设置。
1.3 填写了解/理解/掌握/运用/超纲：更新为对应值。
1.4 导入通过项仍需经「保存编辑」统一提交。

#### 异常情况处理
1.1 校验失败时，校验结果弹窗「失败明细」的「失败原因」列展示下列文案；该行对应字段不写回。括号内为问题分类名称。
1.2 填写了非约定值（学业要求填写不合法）：学业要求值"{填写值}"无效，学业要求仅支持填写"了解 / 理解 / 掌握 / 运用 / 超纲"。
1.3 非末级行填写了学业要求（非末级节点填写学业要求）：学业要求仅允许填写在末级知识点行。
1.4 非末级填写关联考点（非末级节点填写关联考点）：关联考点仅允许填写在末级知识点行。
1.5 只填考点类型、没填考点名称（考点名称与类型不成对）：不能只填写考点类型，须同时填写考点名称。
1.6 名称和类型都填了但个数不一致，含名称比类型少、名称比类型多（考点名称与类型不成对）：考点名称数量（N）与考点类型数量（M）不一致。N、M 为按顿号拆开后的实际个数。
1.7 类型不是约定枚举（关联考点填写不合法）：考点类型"{填写值}"无效，仅支持"基础达标 / 综合进阶 / 高分冲刺"。
1.8 同一行名称重复（关联考点填写不合法）：考点名称存在重复项。
1.9 仅清空类型但名称列为空（考点名称与类型不成对）：仅清空考点类型时，考点名称列须填写实际考点名称。

#### 验收标准
1. 非法学业要求值可在校验结果中看到失败原因。
2. 非末级填写学业要求校验失败。

### KT_RE-003 关联考点表格（名称与类型）

来源：代码事实 + 确认决策

#### 显示说明
1.1 表格列：名称、类型；仅编辑态额外展示「操作」列。
1.2 查看态：
考点名称：只读，展示已保存名称
考点类型：根据用户选择回显，未填写的时候显示
1.3 编辑态：名称为输入框（占位「请输入名称」）；
类型为下拉，可选值为，基础达标、综合进阶、高分冲刺三类（具体值待定，后续可能会有变动）新增行允许类型暂为空值，保存时不为空即可

#### 展示顺序
1.1 列表顺序有业务含义，下游（知识卡片、平板预览、学生学习端等）须按配置后台当前顺序展示。
1.2 不提供上移/下移等手动调序；顺序由导入填写顺序与页面「添加考点」先后共同决定，保存后保持该顺序。

#### 数据规则
1.1 考点名称与类型是知识点维度主数据；同一知识点内考点名称不可重复。
1.2 名称/类型变更写入编辑暂存，须经「保存编辑」统一提交。

#### 异常情况处理
1.1 编辑失焦或保存时若同一知识点内出现重名，拦截并 Toast：「考点名称不能重复」。
1.2 点击「保存编辑」时若存在空名称，拦截并 Toast：「请填写所有考点名称后再保存」。
1.3 点击「保存编辑」时若存在未选择类型的考点，拦截并 Toast：「请为所有考点选择类型」。

#### 验收标准
1. 查看态名称即已保存名称，无「未命名」兜底；类型为三档标签之一。
2. 编辑态无排序按钮；添加两条后顺序与添加先后一致。
3. 改成重名后失焦或保存弹出「考点名称不能重复」。
4. 存在空名称或空类型时保存失败并出现对应 Toast。

### KT_RE-012 导入校验与写回（关联考点）

来源：代码事实 + 确认决策

#### 校验规则
1.1 关联考点仅允许填写在末级知识点行；非末级填写则该行失败，不写回。
1.2 考点名称、考点类型两列都留空：不更新该末级关联考点。
1.3 可以只填考点名称、不填考点类型（与页面编辑一致：允许先只填名称）。
1.4 不能只填考点类型、不填考点名称。该行校验失败。
1.5 名称和类型都填了：按顿号拆开后个数必须相同，并从左到右按顺序一一对应。名称比类型少或名称比类型多：该行失败，不截断、不自动补空。
1.6 考点类型仅允许：基础达标、综合进阶、高分冲刺。
1.7 同一行内考点名称不可重复。

#### 数据规则
1.1 这次导入表写了哪些考点名称，这个末级最后就只保留这些考点，不是在原列表后面追加。对照时看名称是不是一样。
1.2 线上有、这次也写了的名称：当成同一个考点，原来的说明和例题先留着。
1.3 线上有、这次没写的名称：这个旧考点删掉，知识卡片里对应说明和例题一并删除。
1.4 这次写了、线上没有的名称：当成新考点写入，说明和例题为空。
1.5 举例：线上现在是「函数、导数、极限」。这次导入表写「函数、不等式」。导入后只剩「函数、不等式」——「函数」还是原来那个考点，说明/例题先留着；「不等式」是新考点；「导数」「极限」删掉。
1.6 只填名称、类型列留空：仍按名称整表替换；线上已有的同名考点保留原来的类型；新增考点类型为空。
1.7 名称和类型都填了：类型也按导入表更新。
1.8 名称列填写【清空】/清空：无论类型列是否清空，清空该末级全部关联考点，并清除知识卡片中对应考点说明与例题。
1.9 仅类型列填写【清空】/清空、名称列有实际名称：只把各考点类型清空，名称按导入表中的名称保留。

#### 异常情况处理
1.1 校验失败时，校验结果弹窗「失败明细」的「失败原因」列展示下列文案；该行不导入。括号内为问题分类名称。
1.2 非末级填写（非末级节点填写关联考点）：关联考点仅允许填写在末级知识点行。
1.3 只填考点类型、没填考点名称（考点名称与类型不成对）：不能只填写考点类型，须同时填写考点名称。
1.4 名称和类型都填了但个数不一致，含名称比类型少、名称比类型多（考点名称与类型不成对）：考点名称数量（N）与考点类型数量（M）不一致。N、M 为按顿号拆开后的实际个数。
1.5 类型不是约定枚举（关联考点填写不合法）：考点类型"{填写值}"无效，仅支持"基础达标 / 综合进阶 / 高分冲刺"。
1.6 同一行名称重复（关联考点填写不合法）：考点名称存在重复项。
1.7 仅清空类型但名称列为空（考点名称与类型不成对）：仅清空考点类型时，考点名称列须填写实际考点名称。

#### 验收标准
1. 非末级填写考点校验失败。
2. 名称与类型数量不一致或非法类型可在结果中看到失败原因。
3. 文档/验收口径含：名称列清空整表清空；仅类型列清空则只清类型。

### KT_KC-025 批量导入

来源：代码事实 + 确认决策

#### 数据规则
1.1 导入模板表头在七级标题之后依次为：学业要求、考频、考点名称、考点类型、前置知识点、出题策略。模板仅含顶行填写说明 + 表头，不带示例数据行。
1.2 模板顶行说明新增【学业要求列】：仅末级可填「了解/理解/掌握/运用/超纲」；留空不更新；【清空】表示清空线上内容。
1.3 模板顶行说明新增【考点名称列】：仅末级可填，多个用顿号（、）分隔；留空不更新；【清空】表示清空线上全部关联考点（名称与类型都清空）；可只填考点名称、不填考点类型。
1.4 模板顶行说明新增【考点类型】列：仅末级可填「基础达标/综合进阶/高分冲刺」；不能只填类型不填名称；两列都填时多个用顿号分隔且须按顺序一一对应、个数相同；留空不更新已有考点的类型；仅类型列填写【清空】且名称列填写实际名称时，只清空各考点类型，名称按导入表内容保留。
1.5 学业要求写回：留空不更新该字段；【清空】将该末级置为未设置；填写合法枚举则更新为对应值。
1.6 关联考点两列都留空：不更新。名称列【清空】：清空该末级全部关联考点，并清除知识卡片中对应考点说明与例题。仅类型列【清空】、名称列有实际内容：只清空各考点类型。
1.7 这次导入表写了哪些考点名称，这个末级最后就只保留这些考点，不是在原列表后面追加。对照时看名称是不是一样。
1.8 线上有、这次也写了的名称：当成同一个考点，原来的说明和例题先留着。

线上有、这次没写的名称：这个旧考点删掉，卡片内容一并删除。

这次写了、线上没有的名称：当成新考点，说明和例题为空。
1.9 举例：线上现在是「函数、导数、极限」。这次导入表写「函数、不等式」。导入后只剩「函数、不等式」——「函数」还是原来那个考点，说明/例题先留着；「不等式」是新考点；「导数」「极限」删掉。
1.10 只填名称、类型列留空：仍按名称整表替换；线上已有的同名考点保留原来的类型；新增考点类型为空。名称和类型都填了：类型也按导入表更新。
1.11 导入通过项仍需经「保存编辑」统一提交。

#### 校验规则
1.1 学业要求仅允许填写了解、理解、掌握、运用、超纲，以及留空、【清空】；仅允许出现在末级行，非末级填写则失败。
1.2 考点名称、考点类型仅允许填写在末级行。可以只填考点名称、不填考点类型。不能只填考点类型、不填考点名称。
1.3 名称和类型都填了：按顿号拆开后个数必须相同，并从左到右一一对应。名称比类型少或名称比类型多：该行失败，不截断、不自动补空。
1.4 类型仅允许基础达标、综合进阶、高分冲刺；同一行内考点名称不可重复。

#### 异常情况处理
1.1 校验失败时，校验结果弹窗「失败明细」的「失败原因」列展示下列文案；该行对应字段不写回。括号内为问题分类名称。
1.2 学业要求填了非约定值（学业要求填写不合法）：学业要求值"{填写值}"无效，学业要求仅支持填写"了解 / 理解 / 掌握 / 运用 / 超纲"。
1.3 非末级填写学业要求（非末级节点填写学业要求）：学业要求仅允许填写在末级知识点行。
1.4 只填考点类型、没填考点名称（考点名称与类型不成对）：不能只填写考点类型，须同时填写考点名称。
1.5 名称和类型都填了但个数不一致，含名称比类型少、名称比类型多（考点名称与类型不成对）：考点名称数量（N）与考点类型数量（M）不一致。
1.6 考点类型不是约定枚举（关联考点填写不合法）：考点类型"{填写值}"无效，仅支持"基础达标 / 综合进阶 / 高分冲刺"。
1.7 同一行考点名称重复（关联考点填写不合法）：考点名称存在重复项。
1.8 非末级填写关联考点（非末级节点填写关联考点）：关联考点仅允许填写在末级知识点行。
1.9 仅清空类型但名称列为空（考点名称与类型不成对）：仅清空考点类型时，考点名称列须填写实际考点名称。

#### 验收标准
1. 下载模板含学业要求、考点名称、考点类型列，且顶行说明含上述留空/【清空】口径。
2. 非末级填写学业要求或考点则校验失败。
3. 导入后要点、模块、例题不被模板列改写；名称列【清空】会清掉对应知识卡片考点内容。
