## 本次变更摘要

线下已按现有页面开发完成。本批只在「通用知识树 → 学习资源 → 知识卡片 → 考点 → 典型例题」上做补充设计，并同步受影响的预览页展示。其他区域不改、不重审。

已确认口径（2026-11-24）：

- 现有典型例题是题干加解题步骤（标题、正文），不能按题库题目存储，也没有题目 ID，下游无法继续使用。
- 调整后，系统选择和手动维护都必须按资源库题目的存储要求保存，并带上题目 ID。好题本里的练习流程不在本批范围。
- 单选、多选、判断、填空、问答：结构为题干、答案、解析。
- 材料题：父题有题型和题干；子题各自有题型、题干、答案、解析。
- 选择题的选项、判断题的对错、填空的空，属于学生要先看到的题目内容，算在题干侧，不放进答案。学生在下游只看题：先看题干，可以自己想，也可以直接看答案和解析，不在本系统作答或提交。
- 子题不能再套材料题，子题题型只允许单选、多选、判断、填空、问答。
- 系统选题如果被改过内容，另存为一道新题并换新的题目 ID，原题不覆盖。
- 一个考点只保留一道典型例题。系统选择或重新维护都会替换这一道，不会并存多道。
