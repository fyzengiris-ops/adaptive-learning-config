# 2.1 详情页-非编辑态-发布记录弹窗【GPT更新】

## 页面目标

用于查看当前策略的历史发布记录。用户可在弹窗中查看该策略各已发布版本的版本号、发布时间、更新说明、发布人等信息，以了解当前策略的版本演进历史。

> 当前弹窗仅展示当前详情页对应策略的历史发布记录，不展示其他策略的发布记录。

## 所属页面

策略管理 > 策略广场 > 学情诊断 > 策略详情 > 发布记录弹窗

---

## 页面定位

1. 当前页面为策略详情页中的查看型弹窗页面。
2. 当前弹窗仅展示当前策略的历史发布记录。
3. 当前弹窗不承载以下能力：
   - 关键词搜索
   - 点击记录跳转详情
   - 版本回滚
   - 版本对比
   - 重新发布
   - 删除历史记录

---

## 页面结构

### A. 弹窗头部区域

用于展示弹窗标题和关闭入口。

| 元素 | 说明 |
|------|------|
| 弹窗标题 | 显示：**历史发布记录** |
| 关闭按钮 | 位于弹窗右上角，点击后关闭当前弹窗 |

#### 展示规则

1. 弹窗标题统一展示为：**历史发布记录**
2. 头部右侧展示关闭按钮

---

### B. 筛选栏区域

用于展示当前策略所属场景信息，筛选字段置灰不可选。

| 元素 | 说明 |
|------|------|
| 场景筛选字段 | 显示当前策略所属场景（同步学/期中期末考/寒暑假/中考/高考），置灰不可选 |

#### 展示规则

1. 筛选栏位于弹窗标题下方，列表区域上方
2. 筛选栏展示当前策略所属场景信息
3. 场景筛选字段置灰不可选，不可点击、不可修改
4. 筛选字段样式为：bg-gray-100 text-gray-500 cursor-not-allowed
5. 筛选栏用于展示当前策略的属性信息，与首页聚合历史发布记录弹窗的筛选字段保持一致

---

### C. 历史记录列表区域

用于展示当前策略的历史发布记录列表。

#### 单条历史记录卡片展示内容

| 元素 | 说明 |
|------|------|
| 版本号 | 展示当前发布记录的版本号 |
| 当前版本标签 | 当前最新已发布版本显示【当前版本】标签 |
| 发布时间 | 展示该版本的发布时间 |
| 更新说明 | 展示该版本对应的更新说明 |
| 发布人信息 | 展示发布人姓名和账号 |

#### 展示规则

1. 历史发布记录按发布时间倒序排列，最新已发布版本显示在最前。
2. 当前最新已发布版本对应的记录需展示【当前版本】标签。
3. 其余历史版本不展示该标签。
4. 每条发布记录必须展示以下信息：
   - 版本号
   - 发布时间
   - 更新说明
   - 发布人姓名
   - 发布人账号
5. 发布人信息展示格式统一为：**发布人：姓名（账号：XXXXXX）**
6. 列表区域支持弹窗内垂直滚动查看。

---

### D. 底部操作区域

用于提供关闭弹窗操作。

| 元素 | 说明 |
|------|------|
| 关闭按钮 | 位于弹窗底部右侧，点击后关闭当前弹窗 |

#### 展示规则

1. 底部固定展示【关闭】按钮
2. 当前弹窗不展示其他操作按钮

---

## 交互逻辑

### 1. 打开弹窗

1. 用户在策略详情页右上角【版本号区域】点击历史记录入口图标后，打开当前策略的发布记录弹窗。
2. 系统加载当前策略的历史发布记录数据。
3. 历史记录按发布时间倒序展示。

---

### 2. 查看历史记录

1. 用户可在弹窗中查看当前策略的各条历史发布记录。
2. 最新已发布版本展示【当前版本】标签。
3. 用户可通过滚动查看全部历史记录内容。

---

### 3. 关闭弹窗

1. 用户点击右上角关闭按钮后，关闭弹窗。
2. 用户点击底部【关闭】按钮后，关闭弹窗。
3. 弹窗关闭后，不保留本次查看过程中的临时滚动位置。
4. 用户下次重新打开弹窗时，系统按当前策略最新发布记录重新初始化弹窗内容。

## 操作说明

1. 用户打开弹窗后，可查看当前策略的所有历史发布记录。

## 业务规则

### 一、数据范围规则

1. 当前弹窗仅展示当前详情页对应策略的历史发布记录。
2. 不展示其他策略的历史发布记录。
3. 历史发布记录仅包含已完成发布的版本记录。

### 二、筛选栏规则

1. 当前弹窗展示当前策略所属场景信息
2. 场景筛选字段置灰不可选，仅用于信息展示
3. 场景类型包括：同步学、期中期末考、寒暑假、中考、高考
4. 筛选栏用于帮助用户理解当前策略的归属属性

### 三、排序规则

1. 历史发布记录按发布时间倒序排列。
2. 最新已发布版本排在最前。

### 四、当前版本标识规则

1. 当前最新已发布版本对应的记录展示【当前版本】标签。
2. 其他历史版本不展示该标签。

### 五、字段展示规则

1. 每条发布记录必须展示：
   - 版本号
   - 发布时间
   - 更新说明
   - 发布人姓名
   - 发布人账号
2. 发布人姓名与账号为必有字段，不保留缺失兜底规则。
3. 发布时间按真实发布数据展示。

### 六、页面能力范围规则

1. 当前页面为查看型弹窗页面。
2. 用户可进行的操作仅包括：
   - 查看当前策略的历史发布记录
   - 关闭弹窗
3. 当前页面不承载以下能力：
   - 点击记录跳转详情
   - 版本回滚
   - 版本对比
   - 重新发布
   - 删除历史记录

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 加载中 | 弹窗打开后，系统正在加载当前策略历史发布记录 |
| 正常状态 | 正常展示历史发布记录列表 |
| 空状态 | 当前策略暂无任何发布记录 |
| 加载失败 | 历史发布记录加载失败 |

### 2. 空状态规则

1. 当当前策略不存在任何历史发布记录时，弹窗列表区域展示空状态文案：**暂无发布记录**
2. 空状态下仍保留头部标题和底部关闭按钮

### 3. 加载失败规则

1. 当历史发布记录加载失败时，页面展示加载失败提示
2. 加载失败不影响用户关闭弹窗

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 当前策略存在历史发布记录 | 按发布时间倒序展示记录列表 |
| 当前策略无历史发布记录 | 展示空状态：暂无发布记录 |
| 历史记录仅 1 条 | 展示该条记录，并标记为【当前版本】 |
| 历史记录较多 | 支持弹窗内纵向滚动查看 |
| 用户关闭弹窗后再次打开 | 按当前策略最新发布记录重新初始化内容 |
| 历史发布记录加载失败 | 展示失败提示，并允许关闭弹窗 |
