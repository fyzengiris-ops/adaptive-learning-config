# 2.11 批量导入——校验结果弹窗

# 页面名称
批量导入知识点——校验结果弹窗

# 所属模块
知识体系管理 > 通用知识树

# 页面目标
用于承接用户上传 Excel 文件并点击【开始校验】后的结果反馈。

该弹窗不是直接执行导入，而是先对上传文件进行校验，并将校验结果清晰反馈给用户，帮助用户明确：
1. 本次上传文件是否可继续导入
2. 哪些数据校验通过
3. 哪些数据校验失败
4. 哪些数据被跳过 / 未更新
5. 失败原因是什么
6. 当前应执行【仅导入通过项】、【重新上传】、【下载错误明细】还是其他操作

# 上个页面
批量导入知识点弹窗（上传态）

# 下级页面
无

# 页面入口
用户在通用知识树详情页中点击【批量导入】后，进入上传态弹窗；
用户选择 Excel 文件后，点击【开始校验】，校验完成后进入本弹窗。

# 页面出口
1. 点击右上角【×】关闭弹窗，返回来源页面
2. 点击【取消】关闭弹窗，返回来源页面
3. 点击【重新上传】返回上传态
4. 点击【仅导入通过项】进入导入执行流程
5. 点击【开始导入】进入导入执行流程
6. 点击【下载错误明细】下载校验结果文件
7. 点击【下载模板】下载标准模板

# 页面说明
本页面用于展示导入文件的校验结果，不直接修改左侧树目录，仅对匹配成功节点的详情字段进行导入。

导入本质是：
**基于现有树节点的详情导入，不是树结构导入。**

即：
1. 系统先拿用户上传文件中的每一行标题路径，与线上现有树节点进行精确匹配
2. 匹配成功后，再继续校验详情字段
3. 详情字段校验通过，该行才允许导入
4. 匹配失败或详情字段校验失败，该行不导入
5. 不允许通过导入新增、删除、改名或移动树节点

# 页面布局规则
1. 弹窗头部固定
2. 弹窗底部操作区固定
3. 中间内容区域滚动
4. 失败明细默认仅展示失败行
5. 问题分类区默认提供【全部问题】筛选项
6. 校验通过 / 部分通过 / 行级全失败 / 文件级失败四种状态，视觉样式需明显区分

# 页面区域

## A. 弹窗头部
用于展示当前弹窗标题及关闭入口。

### 组件说明
- A1. 标题文本：显示【校验结果】
- A2. 关闭按钮：点击后关闭弹窗，返回来源页面，清空当前临时状态

### 交互逻辑
1. 点击【×】关闭弹窗
2. 若当前处于校验结果态，关闭后返回来源页面
3. 若当前处于导入中加载态，点击【×】弹出二次确认：
   - 提示文案：当前正在导入中，确定要关闭吗？关闭后已导入的数据不会回滚
   - 按钮：取消 / 确定关闭

---

## B. 校验结果概览区
用于展示本次校验的总体结果。根据校验结果展示不同状态卡片。

### 公共展示信息
所有状态卡片均展示以下基础信息：
1. 文件名称
2. 上传时间
3. 总行数（参与校验的有效数据行数）
4. 通过行数
5. 失败行数
6. 跳过行数（如存在）

> 说明：
> - “总行数”指参与校验的有效数据行数，不包含完全空白行
> - 完全空白行不参与校验、不计入总行数、不计入通过/失败/跳过

---

### 状态1：校验失败（文件级失败）
适用于整份文件不合法、无法进入行级校验的场景。

#### 组件说明
- B1. 失败图标：红色圆形 X 图标
- B2. 主标题：校验失败，当前文件无法导入
- B3. 辅助说明：请根据下方失败原因修正文件后重新上传
- B4. 结果信息区域：
  - 文件名称
  - 上传时间
  - 校验结果：失败
  - 可导入行数：0 行
- B5. 失败类型标签：文件级失败（红色圆角标签）

---

### 状态2：部分通过（存在行级失败）
适用于文件本身合法，但部分数据行校验失败的场景。

#### 组件说明
- B1. 提醒图标：橙色圆形三角感叹号图标
- B2. 主标题：校验完成，部分数据可导入
- B3. 辅助说明：通过校验的数据可继续导入，失败数据请下载明细后修正
- B4. 结果信息区域：
  - 文件名称
  - 上传时间
  - 总行数
  - 校验通过行数（绿色）
  - 校验失败行数（红色）
  - 跳过行数（灰色，若存在则展示）

---

### 状态3：校验通过
适用于文件本身合法，且所有参与更新的数据行全部通过校验的场景。

#### 组件说明
- B1. 成功图标：绿色圆形对勾图标
- B2. 主标题：校验通过，可直接导入
- B3. 辅助说明：本次文件未发现异常数据，可继续导入
- B4. 结果信息区域：
  - 文件名称
  - 上传时间
  - 总行数
  - 通过行数
  - 跳过行数（若存在则展示）

> 注：
> 若文件中存在“非末级节点且详情全空”的行，这些行记为【跳过 / 未更新】；
> 只要不存在失败行，且存在至少 1 行通过，页面仍展示为【校验通过】。

---

### 状态4：行级全失败
适用于文件本身合法，但所有有效数据行均未通过校验的场景。

#### 组件说明
- B1. 失败图标：红色圆形 X 图标
- B2. 主标题：校验失败，所有数据行均未通过
- B3. 辅助说明：请根据下方错误明细修正数据后重新上传
- B4. 结果信息区域：
  - 文件名称
  - 上传时间
  - 总行数
  - 通过行数：0 行
  - 失败行数
  - 跳过行数（若存在则展示）

---

## C. 问题分类汇总区
用于按错误类型对问题进行聚合展示，帮助用户快速定位错误分布。

### 文件级失败时
仅展示文件级错误卡片，不展示行级分类。

#### 组件说明
- C1. 文件级错误卡片：每个错误类型一个卡片，横向排列展示
  - 错误类型名称
  - 涉及条数（若需要）
  - 错误说明（副文案）

#### 可展示的文件级错误类型
1. 文件格式错误
2. 模板结构错误
3. 表头缺失或不匹配
4. 模板类型不匹配
5. 文件内容为空
6. 文件解析失败

---

### 行级失败 / 部分通过 / 行级全失败时
展示行级错误分类卡片，支持多个同时存在。

#### 组件说明
- C1. 筛选卡片区，固定提供：
  - 全部问题
  - 各错误分类卡片
- C2. 每个错误分类卡片包含：
  - 错误类型名称
  - 涉及行数（红色圆角标签）
  - 错误说明（副文案）

#### 交互逻辑
1. 默认选中【全部问题】
2. 点击某个错误类型卡片，失败明细表格自动筛选为对应类型
3. 点击【全部问题】，恢复全部失败数据展示

#### 可展示的行级错误类型
1. 标题路径不合法
2. 线上未匹配到对应节点
3. 标题列被修改导致无法匹配
4. 标题层级断裂
5. 同一节点重复导入
6. 考频填写不合法
7. 非末级节点填写考频
8. 前置知识点不存在
9. 前置知识点包含自身
10. 前置知识点重复填写
11. 前置知识点无法唯一识别
12. 出题策略不存在
13. 出题策略填写格式不合法
14. 非末级节点填写前置知识点
15. 非末级节点填写出题策略
16. 当前行未填写任何标题信息但填写了详情字段
17. 其他业务校验失败

---

## D. 失败原因说明区
用于展示更详细的失败原因说明。

### 场景1：文件级失败
以纵向列表展示失败原因，每条包含：
- D1. 序号标记：红色圆形序号
- D2. 错误标题
- D3. 错误描述

#### 示例文案
1. 错误标题：文件格式不支持
   - 错误描述：当前仅支持上传 Excel 文件（.xlsx / .xls）

2. 错误标题：模板表头不匹配
   - 错误描述：系统未识别到标准模板表头，请使用系统下载的模板填写后导入

3. 错误标题：模板内容为空
   - 错误描述：当前文件未识别到可校验的数据行

---

### 场景2：行级失败 / 部分通过 / 行级全失败
失败原因说明不单独纵向列说明，而是通过下方错误明细表格逐行展示。

## E. 错误明细表格区
用于逐行展示失败数据的具体原因，是本弹窗的核心区域。

### 展示规则
1. 仅在【部分通过】或【行级全失败】场景下展示
2. 默认仅展示失败行，不展示通过行和跳过行
3. 默认展示前 10 条，超出时支持展开查看全部
4. 支持跟随问题分类卡片筛选结果联动刷新

### 组件说明
- E1. 表格标题：失败明细
- E2. 右侧显示失败总条数
- E3. 表格字段如下：

| 列名 | 说明 |
|------|------|
| 序号 | 按当前表格展示顺序递增 |
| Excel行号 | 展示原 Excel 中的数据行号，格式如“第4行” |
| 知识点路径 | 将当前行中非空标题列拼接为完整路径 |
| 校验结果 | 固定为失败（红色标签） |
| 失败原因 | 展示具体失败原因 |

### 展开/收起逻辑
1. 默认展示前 10 条失败数据
2. 超出 10 条时，底部显示【展开查看全部 X 条】按钮
3. 点击后展示全部失败数据
4. 再次点击【收起】恢复默认展示条数

### 常见失败原因文案

#### 标题路径类
1. 未匹配到线上节点
   - 失败原因：系统未在当前知识树中找到与该标题路径完全一致的节点

2. 标题层级断裂
   - 失败原因：当前行标题层级填写不完整，存在跳级填写

3. 标题列被修改
   - 失败原因：导入仅支持使用导出的标题信息定位节点，不支持通过导入修改树目录

4. 同一文件中重复导入同一节点
   - 失败原因：当前文件中存在多个相同标题路径的数据行

5. 当前行未填写任何标题信息但填写了详情字段
   - 失败原因：当前行未填写任何标题信息，无法定位线上节点

#### 考频类
1. 考频值不合法
   - 失败原因：考频值“XX”无效，考频仅支持填写“高频 / 中频 / 低频”

2. 非末级节点填写考频
   - 失败原因：考频仅允许填写在末级知识点行

#### 前置知识点类
1. 前置知识点不存在
   - 失败原因：前置知识点“XX”在线上知识树中不存在

2. 前置知识点包含当前知识点自身
   - 失败原因：前置知识点不能包含当前知识点自身

3. 前置知识点重复填写
   - 失败原因：前置知识点存在重复项

4. 前置知识点无法唯一识别
   - 失败原因：前置知识点“XX”存在重名，系统无法唯一确认

5. 非末级节点填写前置知识点
   - 失败原因：前置知识点仅允许填写在末级知识点行

#### 出题策略类
1. 出题策略不存在
   - 失败原因：出题策略“XX”未在系统中找到对应个性化策略

2. 出题策略填写格式不合法
   - 失败原因：当前字段仅支持填写单个已存在的个性化策略名称

3. 非末级节点填写出题策略
   - 失败原因：出题策略仅允许填写在末级知识点行

## G. 校验中加载态
用于承接用户点击【开始校验】后的等待状态。

### 组件说明
- G1. Loading 图标：绿色旋转加载图标
- G2. 主文案：正在校验文件，请稍候…
- G3. 副文案：系统正在校验模板结构、标题路径及详情字段

### 交互逻辑
1. 校验过程中不可操作底部按钮
2. 校验完成后自动切换到对应结果态

## H. 导入中加载态
用于承接用户点击【仅导入通过项】或【开始导入】后的等待状态。

### 组件说明
- H1. Loading 图标：绿色旋转加载图标
- H2. 主文案：正在导入数据，请稍候…
- H3. 副文案：系统正在将校验通过的数据写入知识树当前编辑态

### 交互逻辑
1. 导入过程中不可操作底部按钮
2. 导入完成后自动切换到导入结果态

   - 当前正在导入中，确定要关闭吗？关闭后已导入的数据不会回滚

## I. 导入结果态
用于展示导入执行后的结果。

4. 右侧详情区域刷新为最新导入结果
5. 左侧树结构不刷新结构本身，仅刷新受详情影响的展示信息（如有）

# 交互逻辑

## 场景1：选择文件后点击开始校验
1. 用户在上传态弹窗中选择 Excel 文件
2. 上传成功后，【开始校验】按钮置为可点击
3. 用户点击【开始校验】
4. 弹窗进入校验中加载态
5. 系统执行文件级校验
6. 若文件级校验失败，进入【文件级失败态】
7. 若文件级校验通过，继续执行行级校验
8. 根据行级校验结果进入对应态：
   - 全部通过 → 校验通过态
   - 部分通过 → 部分通过态
   - 行级全失败 → 行级全失败态

---

## 场景2：文件级失败
1. 用户看到整份文件失败原因
2. 用户可选择：
   - 点击【重新上传】返回上传态
   - 点击【下载模板】重新获取标准模板
   - 点击【取消】关闭弹窗
3. 当前场景下不可执行导入

---

## 场景3：部分通过
1. 用户查看通过 / 失败 / 跳过数据统计
2. 用户查看问题分类卡片，可点击筛选
3. 用户查看错误明细表格
4. 用户可选择：
   - 点击【下载错误明细】下载带校验结果列的 Excel
   - 点击【重新上传】返回上传态，清空当前校验结果
   - 点击【仅导入通过项】仅对校验通过的数据行执行导入
   - 点击【取消】关闭弹窗

---

## 场景4：仅导入通过项
1. 用户点击【仅导入通过项】
2. 弹窗进入导入中加载态
3. 系统仅对校验通过的数据行执行导入
4. 失败行不进入导入
5. 跳过行不进入导入
6. 导入完成后：
   - 成功：展示导入结果态（成功导入 X 行），页面发布状态变为【待发布】
   - 失败：展示导入结果态（导入失败），toast 提示【导入失败，请稍后重试】

---

## 场景5：校验通过 - 开始导入
1. 用户点击【开始导入】
2. 弹窗进入导入中加载态
3. 系统对所有校验通过的数据行执行导入
4. 跳过行不进入导入
5. 导入完成后：
   - 成功：展示导入结果态（成功导入 X 行），页面发布状态变为【待发布】
   - 失败：展示导入结果态（导入失败），toast 提示【导入失败，请稍后重试】

---

## 场景6：重新上传
1. 用户点击【重新上传】
2. 弹窗返回上传态，清空当前校验结果
3. 用户可重新选择文件

---

## 场景7：下载错误明细
1. 用户点击【下载错误明细】
2. 系统下载基于原始上传文件生成的结果文件
3. 结果文件在原始文件基础上追加以下结果列：
   - 校验结果
   - 失败原因
4. 下载失败时，toast 提示【错误明细下载失败，请稍后重试】

---

## 场景8：关闭弹窗
1. 用户点击【取消】或右上角【×】关闭弹窗
2. 关闭后清空当前校验结果和临时状态
3. 再次打开批量导入弹窗时，回到上传态
4. 不保留上次校验结果

---

## 场景9：当前页面存在未保存编辑时进行批量导入
1. 若用户当前页面存在未保存编辑，仍允许进入批量导入流程
2. 批量导入成功后，导入结果与当前页面未保存编辑内容共同保留在当前编辑态
3. 若导入字段与当前页面已修改但未保存的字段存在冲突，以“后操作生效”为准：
   - 用户后执行的导入结果覆盖当前编辑态中的同字段旧值
4. 页面仍保持【待发布】状态

# 业务规则

## 一、校验与导入分离
1. 用户选择文件后，不自动校验
2. 用户点击【开始校验】后才执行校验
3. 校验仅检查数据合法性，不写入数据
4. 校验通过后，需用户主动点击【开始导入】或【仅导入通过项】才执行导入
5. 不存在“上传即导入”的流程

## 二、文件级失败时，整份文件不可导入
1. 一旦文件级校验失败，不进入行级校验
2. 不允许导入任何通过项
3. 用户必须修正文件后重新上传

## 三、行级失败不阻断其他通过行
1. 若文件级校验通过，则允许对每一行独立校验
2. 失败行不导入，通过行可继续导入
3. 跳过行不导入
4. 行级校验之间互不影响

## 四、基于现有树节点的详情导入
1. 导入的本质是“基于现有树节点的详情导入”，不是“树导入”
2. 系统先拿用户上传的每一行标题路径去和线上现有树节点做匹配
3. 匹配成功：该行对应的节点允许更新详情
4. 匹配失败：该行失败，不导入
5. 不允许通过导入新增树节点

## 五、行增减规则
1. 导入支持按行增减上传内容，但不支持通过导入新增树节点
2. 用户删除导入文件中的行 = 不更新这些节点，不等于删除线上节点
3. 用户新增行但匹配不到线上节点 → 该行失败，不导入
4. 未上传的节点不处理、不删除、不报错

## 六、标题路径匹配规则
1. 使用标题列（一级标题至七级标题）拼接为完整路径进行匹配
2. 不使用节点 ID 进行匹配（模板中不包含节点 ID）
3. 匹配时，将非空标题列按层级顺序用“ / ”拼接，与线上树目录路径做精确匹配
4. 若线上存在同名但路径不同的节点，以完整路径匹配为准

## 七、空白行与有效数据行规则
1. 完全空白行直接忽略，不参与校验，不计入总行数
2. “完全空白行”指：
   - 一级标题至七级标题全部为空
   - 考频、前置知识点、出题策略全部为空
   - 去除首尾空格后仍为空
3. 若标题列全部为空，但详情字段存在任意值，则该行判定失败
4. 该类失败归类为【当前行未填写任何标题信息但填写了详情字段】

## 八、详情字段覆盖规则
1. 左侧标题路径匹配成功后，才允许处理详情字段
2. 详情字段默认采用“有值才更新，空值不更新”规则
3. 文件中某字段留空，不覆盖线上对应字段
4. 若用户需要清空某字段，需填写系统约定的特殊标记值
5. 特殊标记值建议统一为：【[清空]】
6. 当字段值为【[清空]】时，导入后将线上对应字段清空
7. 后导入的数据覆盖先导入的数据

## 九、多次导入规则
1. 每次导入只更新本次文件中匹配成功且校验通过的节点详情
2. 不会覆盖之前已导入但本次文件中未包含的节点
3. 同一节点在多次导入中被不同数据覆盖时，后导入的覆盖先导入的

## 十、跳过 / 未更新规则
1. 非末级节点且详情字段全部为空时，该行记为【跳过 / 未更新】
2. 跳过行不判失败
3. 跳过行不计入导入成功行数
4. 跳过行仅在顶部汇总信息中统计，不进入失败明细表
5. 跳过行不触发任何线上数据更新

## 十一、考频规则
1. 仅末级知识点可填写考频
2. 非末级知识点不可填写考频，若填写则该行校验失败
3. 考频可选值仅支持：高频、中频、低频
4. 考频留空 = 不更新
5. 考频填写【[清空]】= 清空线上考频

## 十二、前置知识点规则
1. 仅末级知识点可填写前置知识点
2. 非末级知识点不可填写前置知识点，若填写则该行校验失败
3. 多个前置知识点使用顿号【、】分隔
4. 系统在校验前需对每项前置知识点做基础清洗：
   - 去除首尾空格
   - 忽略顿号两侧空格
5. 前置知识点名称必须在线上知识树中存在
6. 若存在同名知识点且系统无法唯一识别，则该行失败
7. 前置知识点不能包含当前知识点自身
8. 前置知识点不能重复填写
9. 前置知识点留空 = 不更新
10. 前置知识点填写【[清空]】= 清空线上前置知识点

## 十三、出题策略规则
1. 仅末级知识点可填写出题策略
2. 非末级知识点不可填写出题策略，若填写则该行校验失败
3. 出题策略留空 = 不更新当前策略
4. 若填写，必须为系统中已存在的个性化策略名称
5. 仅支持填写单个策略名称
6. 出题策略填写【[清空]】= 清空当前策略，由系统回退为默认通用策略
7. 若填写内容格式异常或填写多个策略名称，则该行失败

## 十四、重复行检测规则
1. 若同一文件中存在多条相同标题路径的数据行，所有重复行均校验失败
2. 失败原因标记为【同一文件中重复导入同一节点】

## 十五、标题层级连续性规则
1. 填写某级标题时，其上级标题必须连续填写
2. 不允许跳级填写
3. 例如：填写了五级标题，但三级或四级标题为空，则该行失败

## 十六、标题未匹配节点的展示规则
1. 当前模板不包含节点 ID，系统无法完全准确判断“标题被修改”与“线上无此节点”
2. 产品展示层允许保留以下两类文案：
   - 线上未匹配到对应节点
   - 标题列被修改导致无法匹配
3. 若系统后端无法精准识别修改原因，则统一按【线上未匹配到对应节点】返回
4. 若系统具备额外比对依据，则允许细分展示【标题列被修改导致无法匹配】

## 十七、权限规则
1. 仅教研主管可使用批量导入功能
2. 教研员不可使用批量导入功能

## 十八、结果展示规则
1. 页面中不得仅使用“导入失败”“数据异常”等模糊文案
2. 必须展示具体失败原因
3. 错误明细必须支持下载
4. 问题分类默认展示【全部问题】
5. 失败明细默认仅展示失败行

## 十九、导入写入位置规则
1. 导入结果写入当前编辑态
2. 不直接影响已发布版本
3. 发布后才对下游业务生效

# 状态与异常

## 页面状态
1. 校验中加载态：系统正在校验文件
2. 文件级失败态：整份文件校验失败
3. 部分通过态：部分行校验通过，部分行校验失败
4. 校验通过态：所有可更新行校验通过
5. 行级全失败态：文件合法但所有有效数据行校验失败
6. 导入中加载态：系统正在执行导入
7. 导入成功态：导入执行成功
8. 导入失败态：导入执行失败

# 异常与边界

| 异常场景 | 处理方式 |
|---|---|
| 文件解析失败 | 文件级失败，提示“文件解析失败，请确保上传的是有效的 Excel 文件” |
| 模板表头不匹配 | 文件级失败，提示“模板表头不匹配”，建议下载标准模板 |
| 文件内容为空 | 文件级失败，提示“模板内容为空” |
| 选择非 Excel 文件 | 文件级失败，提示“文件格式不支持” |
| 完全空白行 | 直接忽略，不参与校验 |
| 标题全空但详情有值 | 该行失败，提示“当前行未填写任何标题信息” |
| 标题路径匹配不到线上节点 | 该行失败，原因区分“未匹配到节点”或“标题被修改” |
| 标题层级断裂 | 该行失败，提示“标题层级填写不完整” |
| 同一文件重复路径 | 所有重复行失败，提示“同一文件中重复导入同一节点” |
| 考频值不合法 | 该行失败，提示具体不合法的值 |
| 非末级节点填写考频 / 前置知识点 / 出题策略 | 该行失败，提示仅末级节点可填写 |
| 非末级节点且详情全空 | 该行跳过，不更新 |
| 前置知识点不存在 | 该行失败，提示不存在的知识点名称 |
| 前置知识点无法唯一识别 | 该行失败，提示无法唯一识别的知识点名称 |
| 前置知识点包含自身 | 该行失败，提示不能包含自身 |
| 前置知识点重复 | 该行失败，提示存在重复项 |
| 出题策略不存在 | 该行失败，提示策略名称不存在 |
| 校验接口异常 | toast 提示“校验失败，请稍后重试”，保留当前文件，可再次校验 |
| 下载错误明细失败 | toast 提示“错误明细下载失败，请稍后重试” |
| 导入接口失败 | toast 提示“导入失败，请稍后重试”，校验结果页不关闭，用户可再次尝试 |
| 校验中关闭弹窗 | 允许关闭，再次打开回到上传态 |
| 导入中关闭弹窗 | 弹出二次确认，提示已导入数据不会回滚 |
| 关闭弹窗后重新打开 | 回到上传态，清空之前的校验结果 |

# 数据来源

| 数据名称 | 来源 | 用途 |
|---|---|---|
| 用户上传文件 | 用户本地 Excel 文件 | 作为批量导入数据源 |
| 线上知识树目录 | 当前学段学科的知识树数据 | 用于标题路径匹配 |
| 线上知识点名称集合 | 当前知识树所有节点名称 | 用于前置知识点校验 |
| 个性化策略列表 | 系统已有的个性化出题策略 | 用于出题策略名称校验 |
| 当前学段学科信息 | 当前页面上下文 | 作为导入目标范围和文件命名 |
| 当前用户角色 | 登录用户信息 | 控制导入权限 |
| 当前编辑态数据 | 当前页面未发布的编辑中数据 | 承接导入写入结果与页面未保存编辑合并 |
