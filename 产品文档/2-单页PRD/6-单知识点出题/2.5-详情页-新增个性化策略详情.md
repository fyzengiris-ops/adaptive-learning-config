# 2.5 详情页-新增个性化策略【codex更新】

## 1. 页面概述

### 页面目标

用于新增【个性化策略】。

用户进入页面后，需要选择学段、学科，填写策略名称，并配置题目组成规则。保存成功后，页面留在当前详情页并切换为查看模式，顶部展示待发布提示条和【发布】按钮。

### 所属页面

策略管理 > 策略广场 > 单知识点出题 > 个性化策略 > 新增个性化策略

### 页面状态说明

本页面为新增态。

新增态标题展示：

新增个性化策略

新增态不展示：

- 版本号
- 历史发布记录入口

保存成功进入查看态后，按个性化策略查看详情页规则展示。

---

## 2. 页面结构

页面由以下区域组成：

1. 页面头部区
2. 基础信息区
3. 题目组成配置区
4. 底部操作区

---

## 3. 页面头部区

### 3.1 返回入口

点击返回入口时：

1. 若页面没有未保存的内容，点击直接返回至单知识点出题的一级页面。
2. 若页面有未保存内容，弹出确认弹窗。

确认弹窗：

- 文案：新增内容还未保存，确认取消吗？
- 按钮：取消、确认

交互规则：

1. 点击弹窗【取消】，仅隐藏弹窗，页面停留在当前新增页面。
2. 点击弹窗【确认】，不保存用户新增的内容，页面返回至单知识点出题的一级页面。

### 3.2 页面标题

新增态标题：

新增个性化策略

说明：

- 新增态不展示版本号。
- 新增态不展示历史发布记录入口。
- 页面头部具体样式以 UI 稿为准。

---

## 4. 基础信息区

### 4.1 区域标题

展示：

基础信息

### 4.2 学段

字段类型：

下拉选择

选项：

- 高中
- 初中
- 小学

规则：

1. 从首页进入新增页时，默认带入首页当前选中的学段。
2. 用户可在新增页内手动切换学段。
3. 切换学段后，学科选项同步变化。
4. 若当前已选学科在新学段下不可用，则自动清空学科。
5. 保存时不单独校验学段为空场景。

### 4.3 学科

字段类型：

下拉选择

规则：

1. 学科选项跟随当前学段变化。
2. 个性化策略不做学科唯一性限制。
3. 当前学段支持的学科均可选择，不因已有个性化策略而置灰。
4. 保存时不单独校验学科为空场景。

学科联动规则：

各学段下具体展示哪些学科，根据乐课网当前学段下已有的学科数据进行展示。

### 4.4 策略名称

字段类型：

文本输入框

占位文案：

请输入策略名称

规则：

1. 策略名称为必填项。
2. 同一学段 + 学科下，策略名称不允许重复。
3. 输入框最多支持 50 个字符。
4. 超过 50 个字符时，不允许继续输入。
5. 中英文、数字、常见符号均允许输入。
6. 字符数按字符计算，中英文、数字、符号均按 1 个字符计。
7. 输入内容校验时去除首尾空格。
8. 仅输入空格视为未填写。

字数计数：

展示当前已输入字符数 / 50。

示例：

0/50

校验提示：

1. 未填写或仅输入空格时，提示【请输入策略名称】。
2. 同一学段 + 学科下策略名称重复时，提示【该策略名称已存在】。

## 5. 题目组成配置区

### 5.1 区域标题

展示：

题目组成配置

### 5.2 默认状态

新增个性化策略默认不添加掌握度区间。

用户需要点击【+ 添加区间】后，手动新增掌握度区间。

### 5.3 添加区间

点击【+ 添加区间】后，新增一条掌握度区间。

新增区间规则：

1. 新增区间默认带出起始值，结束值为空需用户手动填写。
2. 默认起始值取上一个区间的结束值。
3. 默认结束值为空。
4. 若上一个区间结束值已为 100，则提示用户先调整已有区间。
5. 系统不自动修改用户已配置的区间值。
6. 用户每次点添加区间后，都默认显示一行题型，默认显示的这一行题型，题量默认显示为1，难度默认显示为易1，其他难度默认显示为0。

### 5.4 删除区间

每个区间均可删除。

规则：

1. 删除区间时，该区间下的题目配置一并删除。
2. 点击【删除区间】后，显示确认弹窗。
3. 当页面只剩一个区间时，隐藏删除区间按钮（即每个策略至少需要有一条策略信息）。

确认弹窗：

弹窗文案：确认删除该区间的出题策略吗？

按钮：

- 取消
- 确认删除

按钮逻辑：

- 点击【取消】→ 仅隐藏弹窗，不删除区间。
- 点击【确认删除】→ 将被操作的区间删除。

### 5.5 区间题量汇总

区间标题处展示该区间的题量汇总。

格式：

共 X 题

计算规则：

该区间下所有题目配置行的题目数量之和。

### 5.6 区间排序

编辑过程中按用户创建顺序展示。

保存成功后，区间按起始值从小到大展示。

## 6. 掌握度区间规则

### 6.1 输入规则

掌握度区间由起始值和结束值组成，单位为百分比。

输入规则：

1. 起始值和结束值均为 0-100 的整数。
2. 起始值允许等于结束值。
3. 起始值不能大于结束值。
4. 区间之间允许存在空隙。
5. 区间之间不允许重叠。
6. 区间边界相接不视为重叠，例如 0%-40%、40%-70% 允许保存。

### 6.2 保存校验

保存时校验以下情况：

1. 区间值为空时，提示【请输入掌握度区间】。
2. 起始值大于结束值时，提示【掌握度区间起始值不能大于结束值】。
3. 区间存在重叠时，提示【掌握度区间不能重叠】。
4. 已添加的掌握度区间下无题目配置时，提示【已添加的掌握度区间，请至少添加一条题目配置规则】。

说明：

- 允许只配置一个掌握度区间。
- 允许起始值和结束值相等。
- 允许区间之间存在空隙。

---

## 7. 题目配置

### 7.1 添加题型

点击区间内【+ 添加题型】后，新增一条题目配置。

规则：

1. 同一区间内允许重复添加相同题型。
2. 题目配置行数量不限制。
3. 新增题目配置后，用户需补充题型、题量、难度分布、题目来源和知识点复合度。

### 7.2 删除题目配置

点击题目配置行删除入口后，直接删除该行。

删除题目配置行不需要二次确认。

### 7.3 题型

选项：下拉选项根据乐课网当前学段学科下有的题型进行显示。

规则：

1. 题型为必填项。
2. 默认选中第一个题型。

### 7.4 题量

输入规则：

1. 题量为必填项。
2. 仅允许输入正整数。
3. 不允许输入 0。
4. 不允许输入负数、小数和非数字字符。

保存校验：

题量为 0 时，提示【题目数量不能为 0】。

### 7.5 题目难度分布

难度项按 UI 文案展示为：

- 易
- 较易
- 中
- 较难
- 难

规则：

1. 每个难度项输入非负整数。
2. 各难度数量之和必须等于该行题量。
3. 保存时若不一致，提示【难度分布数量之和必须等于对应题型的题目总数】。

### 7.6 题目来源

题目来源为非必填项。

字段类型：

多选。

选项规则：

1. 题目来源根据不同学段展示对应可用来源。
2. 具体选项按菁优网不同学段支持的题目来源展示。

保存校验：无（题目来源为非必填项）。

### 7.7 知识点复合度

字段名称：

知识点复合度

选项：

- 单一知识点
- 非单一知识点

规则：

1. 知识点复合度为必填项。
2. 默认选中【单一知识点】。
3. 正常情况下不存在为空场景。

## 8. 保存逻辑

### 8.1 保存入口

新增态底部展示操作按钮：

- 取消
- 保存

说明：

- 顶部不展示保存和取消按钮。
- 按钮具体文案和样式以新增态 UI 稿为准。

### 8.2 保存校验顺序

点击保存后，按以下顺序校验：

1. 策略名称。
2. 掌握度区间。
3. 题目配置。

校验不通过时：

1. 停止保存。
2. 页面定位到首个错误位置。
3. 对应字段展示错误提示。

### 8.3 保存中状态

保存过程中：

1. 保存按钮展示加载状态。
2. 保存按钮不可重复点击。
3. 页面字段不可编辑。
4. 用户不可新增、删除或修改区间和题目配置。

### 8.4 保存成功

保存成功后：

1. 留在当前详情页。
2. 页面切换为查看模式。
3. 顶部显示待发布提示条。
4. 待发布提示条中展示【发布】按钮。

提示条文案：

当前策略有未发布变更，请发布后生效

### 8.5 保存失败

保存失败后：

1. 保留用户当前填写内容。
2. 页面恢复可编辑状态。
3. 保存按钮恢复可点击。
4. 不切换为查看模式。
5. 页面展示失败提示。

---

- 按钮：取消、确认

## 10. 未保存离开规则

以下页面内离开行为均需要检测未保存内容：

1. 点击返回。
2. 点击取消。
3. 点击侧边栏菜单跳转。

## 11. 历史记录关联说明

个性化策略正式发布后，将生成历史发布记录。

历史发布记录中展示发布时的策略名称。

若策略后续改名，历史记录仍展示发布当时的策略名称。

页面可编辑，用于创建个性化策略。

展示内容：

- 基础信息
- 题目组成配置

## 13. 异常与边界场景

### 13.1 策略名称为空

提示【请输入策略名称】。

### 13.2 策略名称重复

同一学段 + 学科下策略名称重复时，提示【该策略名称已存在】。

### 13.3 掌握度区间异常

以下情况保存时拦截：

- 区间值为空
- 起始值大于结束值
- 区间重叠

以下情况允许保存：

- 只有一个区间
- 起始值等于结束值
- 区间之间存在空隙
- 区间边界相接

### 13.4 题目配置异常

以下情况保存时拦截：

- 已添加区间下无题目配置
- 题量为 0
- 难度分布数量之和不等于题量
- 题目来源为空

## 14. 测试关注点

### 14.1 页面初始化

1. 从首页点击个性化策略【+ 新增】进入新增页。
2. 页面标题为【新增个性化策略】。
3. 新增页不展示版本号。
4. 新增页不展示历史发布记录入口。
5. 默认带入首页当前学段。
6. 学科跟随学段展示可选项。
7. 个性化策略学科不因已有个性化策略置灰。
8. 默认不添加掌握度区间。
9. 顶部不展示保存和取消按钮。

### 14.2 基础信息

1. 策略名称为空保存时，提示【请输入策略名称】。
2. 策略名称仅输入空格时，提示【请输入策略名称】。
3. 策略名称超过 50 字时无法继续输入。
4. 策略名称字数计数正确展示。
5. 同一学段 + 学科下策略名称重复时，提示【该策略名称已存在】。
6. 切换学段后，学科选项正确变化。
7. 当前学科在新学段不可用时，自动清空学科。
8. 保存时不单独校验学段和学科为空场景。

### 14.3 掌握度区间

1. 点击【+ 添加区间】可新增区间，每次添加后默认显示一行题型，题量默认显示为1，难度默认显示为易1，其他难度默认显示为0。
2. 删除区间时需要二次确认。
3. 当页面只剩一个区间时，隐藏删除区间按钮（即每个策略至少需要有一条策略信息）。
4. 允许只配置一个区间。
5. 允许区间之间存在空隙。
6. 允许起始值等于结束值。
7. 起始值大于结束值时保存失败。
8. 区间重叠时保存失败。
9. 区间边界相接不算重叠。
10. 保存成功后区间按起始值从小到大展示。

### 14.4 题目配置

1. 同一区间内允许重复添加相同题型。
2. 题目配置行数量不限制。
3. 删除题目配置行不需要二次确认。
4. 题量为 0 时保存失败。
5. 难度分布数量之和不等于题量时保存失败。
6. 题目来源为空时保存失败。
7. 题目来源随学段展示对应可用来源。
8. 知识点复合度默认选中【单一知识点】。

### 14.5 保存与离开

1. 保存中按钮不可重复点击。
2. 保存中页面不可编辑。
3. 保存成功后留在当前详情页并切换查看模式。
4. 保存成功后顶部展示待发布提示条和【发布】按钮。
5. 保存失败后保留用户已填写内容。
6. 点击返回、取消、侧边栏跳转时，若存在未保存内容，弹出离开确认。
7. 点击【确认】后，不保存用户新增的内容，页面返回至单知识点出题的一级页面。

### 14.6 历史记录

1. 新增保存后不会立即生成历史发布记录。
2. 正式发布成功后生成历史发布记录。
3. 历史发布记录中展示发布时的策略名称。
