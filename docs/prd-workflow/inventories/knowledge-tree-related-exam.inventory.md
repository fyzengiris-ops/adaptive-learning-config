## 必审对象

1. 「关联考点」Tab — Tab — 详情顶栏 Tab — 与信息/结构/资源并列；末级详情可见
2. 考点数量「共 N 个考点」 — 数量/统计 — Tab 内容区顶部 — 有数据时展示
3. 关联考点表格（名称/类型/操作） — 列表/表格 — Tab 主区 — 查看态只读；编辑态可改
4. 考点名称 — 字段 — 表格「名称」列 — 主数据；可空显示「未命名」
5. 考点类型 — 字段 — 表格「类型」列 — 三档枚举；编辑下拉
6. 添加考点 — 按钮 — 表格下方 — 仅编辑态
7. 删除考点 — 按钮 — 操作列 — 无例题直接删
8. 删除关联考点确认弹窗 — 弹窗 — 有例题时 — 确认后同步删知识卡片考点
9. 空态「暂无考点」 — 状态 — 无数据时 — 编辑态引导添加/导入
10. 保存编辑 — 按钮 — 详情顶栏 — 提交 `relatedExamPoints`；变更维度可记「关联考点」
11. 取消编辑 — 按钮 — 详情顶栏 — 丢弃含关联考点的暂存
12. 编辑知识点详情入口/回显 — 操作 — 详情顶栏 — 进入编辑时装载关联考点
13. 知识卡片·考点回显 — 列表/卡片 — 学习资源 Tab — 名称/类型只读回显；说明/例题可维护
14. 导出知识树（考点列+顶行说明） — 导入导出 — 导出按钮 — 考频后：考点名称、考点类型
15. 导入模板（考点列+填写说明） — 导入导出 — 下载模板 — 同上列序与【清空】/留空口径
16. 导入校验（考点名称/类型） — 校验 — 批量导入 — 末级、成对、枚举、去重等
17. 批量导入弹窗·考点说明 — 辅助文案 — 导入弹窗 — 可选值与顿号对应说明
18. 平板预览中的考点展示 — 预览 — 知识卡片「平板预览」 — 只读渲染关联考点（原待你定，确认时升为必审）

## 可跳过对象

1. 添加子节点时「有详细内容」判定 — 本轮不审；用户指定留待「学习资源」审核时再审
2. 知识点信息学业要求/考频/策略内部细则 — 已审或无本轮耦合
3. 知识点结构 Tab — 与本轮无耦合
4. 视频讲解细则 — 与本轮无耦合
5. 左侧目录树结构编辑细则 — 本轮未调整
6. 发布确认/定时发布等 — 本轮未调整
