# 章节课程 PRD

## 1. 页面范围

### 1.1 当前页面
- 页面名称：教材体系知识树 · 章详情 · 课程（综合课维护：专题课 / 拓展课）
- 所属模块：知识体系管理 · 教材体系知识树
- 页面路由/视图：`/knowledge-system`（知识体系管理 → 教材体系知识树 → 选中章节点 → 「课程」Tab → 综合课维护）
- 相关代码文件：
  - `src/app/knowledge-system/page.tsx`
  - `src/app/system-settings/TextbookTree.tsx`

### 1.2 上级页面/上游入口
- 上级页面：知识体系管理
- 入口位置：知识体系管理页「教材体系知识树」Tab
- 进入方式：进入 `/knowledge-system`，切到教材体系知识树，选中某本教材的章节点后，进入章详情并切到「课程」
- 传入数据：当前教材、当前章节点、编辑会话暂存
- 依赖状态：是否处于「编辑章节详情」；课程区内高阶 Tab（同步课总览 / 综合课维护）；综合课维护内专题课 / 拓展课

### 1.3 下级页面/下游流程
- 下级页面/下游流程：从资源库选择视频弹窗、本地上传视频弹窗、从资源库选择试卷弹窗、课程预览、试卷预览、移除确认
- 触发方式：专题课 / 拓展课操作栏按钮；卡片预览 / 移除
- 传出数据：本章专题课或拓展课的视频名单、试卷名单；本地上传视频在保存后写入个人资源库字段
- 后续状态：保存编辑后进入待发布（「课程」维度）；发布后本地上传视频才上架乐课网资源库
- 返回逻辑：关闭弹窗回到章详情课程区；取消编辑在有未保存修改时二次确认并丢弃暂存

### 1.4 范围边界摘要
- 本文档覆盖：教材体系知识树**章详情「课程」**中已挂数字角标的专题课、拓展课业务逻辑
- 本文档不覆盖：未挂角标的注册表切片、同步课总览内部、知识点 Tab、章级练习试卷聚合、教材级总览、小节同步课内部细则

## 2. 功能概述

章详情「课程」用于维护本章综合课：专题课与拓展课各自有独立的视频名单和练习试卷名单。编辑在同一次章节编辑会话内暂存，经「保存编辑」提交，待发布记「课程」维度。选课/选卷来自乐课网当前学段学科教材版本下、仅本章目录的资源；本地上传视频按已确认口径在保存与发布时反写个人资源库与上架。

本文档业务逻辑与页面数字角标、悬浮面板同源，均来自需求注册表 `logicSections`（含已落盘 overlay）。

### TB_CTC-017 取消

来源：代码事实 + 确认决策

#### 操作说明
1.1 相对进入编辑时的本章快照无内容变动：点「取消」直接退出编辑态，不弹窗，不记待发布。
1.2 有内容变动：点「取消」先弹出确认，文案「当前有未保存的修改，确定要取消吗？」按钮为「取消」「确认」。
1.3 点确认：丢弃本次会话全部改动（含专题课），恢复为进入「编辑章节详情」之前的状态，退出编辑态，不记待发布。
1.4 点弹窗「取消」或关闭：只隐藏确认弹窗，留在编辑态，暂存改动仍在。

#### 验收标准
1. 进入编辑后不改任何内容，点取消直接回到查看态，无弹窗。
2. 改了专题课后再点取消，出现「当前有未保存的修改，确定要取消吗？」；确认后专题课恢复进入编辑前，待发布不增加；弹窗取消后仍停在编辑态且改动仍在。
