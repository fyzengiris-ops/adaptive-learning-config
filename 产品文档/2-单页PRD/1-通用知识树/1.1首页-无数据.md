# 1.1 首页-无数据【GPT更新】

# 页面目标
用于展示通用知识树首页在当前学段下暂无学科数据时的空状态页面，引导用户快速新增第一个学科，或查看通用知识树模块的历史发布记录。

# 所属页面
知识体系管理 > 通用知识树

# 页面区域

## A. 顶部学段Tab栏
用于切换不同学段（高中、初中、小学）的学科列表。

## B. 操作栏
用于展示当前学段的学科数量统计、新增学科入口和历史发布记录入口。

## C. 空状态引导区
当当前学段下暂无学科时显示，用于引导用户新增第一个学科。

# 组件说明

## A. 顶部学段Tab栏组件
- A1. 学段Tab按钮：显示「高中」「初中」「小学」三个选项，点击切换对应学段
- A2. 当前选中态：选中项显示绿色背景和深绿色文字
- A3. 悬停态：非选中项悬停时显示浅灰背景

## B. 操作栏组件
- B1. 学科数量统计：显示「共 X 个学科」，包含书本图标
- B2. 新增学科按钮：翠绿色按钮，点击后打开新增学科弹窗
- B3. 查看历史发布记录按钮：位于操作栏右侧，点击后打开聚合历史发布记录弹窗

## C. 空状态引导区组件
- C1. 空状态图标：圆形灰色背景，内含书本图标
- C2. 空状态标题：显示「暂无学科」
- C3. 空状态说明：显示「{学段名称}学段尚未添加任何学科」
- C4. 添加按钮：翠绿色主按钮，显示「添加第一个学科」

# 交互逻辑

## 1. 页面初始化
- 1.1、进入通用知识树首页后，页面默认选中指定默认学段
- 1.2、系统自动加载该学段下的学科列表数据
- 1.3、若当前学段无学科数据，则展示空状态引导区
- 1.4、若当前学段已有学科数据，则切换为有数据状态页面展示

## 2. 切换学段Tab
- 2.1、点击其他学段Tab后，切换当前选中学段
- 2.2、系统刷新并加载目标学段下的学科数据
- 2.3、若目标学段无学科数据，则展示对应学段的空状态说明
- 2.4、切换学段后，清空当前页面已选中的学科和知识点上下文

## 3. 新增学科
- 3.1、点击【新增学科】按钮后，打开新增学科弹窗
- 3.2、点击【添加第一个学科】按钮后，效果等同于点击【新增学科】
- 3.3、新增成功后，关闭弹窗并刷新当前学段下的学科列表
- 3.4、若新增后当前学段已有学科数据，则页面从空状态切换为有数据状态

## 4. 查看历史发布记录
- 4.1、点击【查看历史发布记录】按钮后，打开聚合历史发布记录弹窗
- 4.2、弹窗中展示通用知识树模块下全部学段、全部学科的历史发布记录
- 4.3、弹窗支持按学段、学科和关键词进行筛选与搜索

## 5. 进入学科管理
- 5.1、当当前学段已有学科数据时，点击学科卡片中的【进入管理】按钮
- 5.2、进入对应学科的知识树详情页

# 业务规则

## 一、学段配置规则
1. 通用知识树首页仅展示「高中」「初中」「小学」三个学段
2. 页面默认选中指定默认学段，当前方案默认为「初中」
3. 各学段下的学科数据独立维护，互不影响

## 二、学科数量统计规则
1. 操作栏中的学科数量仅统计当前选中学段下的学科总数
2. 学科总数以当前学段实际学科列表数据为准

## 三、权限显示规则
1. 教研主管可见【新增学科】按钮和【添加第一个学科】按钮
2. 教研员隐藏新增学科相关按钮
3. 所有角色均可查看历史发布记录
4. 所有角色均可进入已有学科的详情页查看内容

## 四、空状态展示规则
1. 当当前学段下无学科数据时，显示空状态引导区
2. 空状态说明文案需随当前选中学段动态变化
3. 空状态下不展示学科卡片列表

## 五、发布状态展示规则
1. 若学科存在待发布变更，则展示「待发布 · X项变更」
2. 若学科已发布，则展示「已发布」
3. 若学科无发布记录，则不展示状态标记
4. 发布状态仅在有数据状态下的学科卡片中展示

# 状态与异常

## 页面状态
- 空状态：当前学段无学科数据，显示空状态引导区
- 有数据状态：当前学段有学科数据，显示学科卡片列表
- 学段切换状态：切换Tab后刷新对应学段的数据内容

## 异常与边界
- 当前学段无学科数据时：显示空状态，不展示学科卡片
- 所有学段均无学科数据时：切换任意学段都展示对应空状态
- 教研员身份下：隐藏新增入口，但页面其他查看能力正常保留
- 学科列表加载失败时：提示加载失败信息，并支持重新加载
- 历史发布记录加载失败时：提示加载失败信息，弹窗保持打开

# 数据来源

| 数据名称 | 来源 | 用途 |
|----------|------|------|
| 学段配置数据 | 系统预设 | 控制学段Tab显示 |
| 学科列表数据 | 乐课网对应学段下支持的学科数据 | 展示当前学段学科内容 |
| 学科发布状态 | 知识树发布状态数据 | 展示学科状态标记 |
| 当前用户身份 | 用户登录信息 | 控制新增相关按钮显隐 |

# 技术要求

- 学段Tab切换需支持前端无刷新切换
- 页面需根据当前学段数据自动切换空状态和有数据状态
- 按用户身份控制新增相关按钮显隐
- 空状态与有数据状态需共用同一页面上下文
