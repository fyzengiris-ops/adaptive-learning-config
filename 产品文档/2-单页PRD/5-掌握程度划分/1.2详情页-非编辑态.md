# 1.1 详情页-非编辑态【GPT更新】

## 页面目标

用于查看当前学段掌握程度划分策略的详细配置。用户可在页面中查看当前学段的掌握度等级配置、当前版本信息、当前发布状态，并可发起编辑、查看发布历史、发布等后续操作。

> 当前页面为单学段掌握程度划分策略详情页的非编辑态页面，不承载区间直接编辑行为。

## 所属页面

策略管理 > 策略广场 > 掌握程度划分 > 详情页 > 非编辑态

---

## 页面定位

1. 当前页面用于查看**单个学段**的掌握程度划分策略详情。
2. 当前页面为**非编辑态详情页**。
3. 页面核心职责包括：
   - 展示当前学段掌握度等级配置
   - 展示当前版本号
   - 展示当前发布状态
   - 按条件展示待发布或定时发布状态提示
   - 提供编辑入口
   - 提供当前学段发布历史入口
   - 在待发布状态下提供发布入口
4. 当前页面不承载配置直接编辑行为，配置修改需通过进入编辑态完成。

---

## 页面结构

### A. 页面头部区域

用于展示返回入口、学段信息、版本信息、状态信息及历史发布记录入口。

| 元素 | 说明 |
|------|------|
| 返回按钮 | 点击后返回掌握程度划分首页 |
| 学段图标 | 展示当前学段对应图标 |
| 页面标题 | 显示：**{学段}掌握度划分策略** |
| 页面描述 | 显示：**定义{学段}阶段知识点掌握程度的等级划分标准** |
| 版本信息 | 展示当前最新已发布版本号 |
| 历史发布记录入口图标 | 点击后打开当前学段的【发布历史】弹窗 |

#### 展示规则

1. 页面标题固定格式为：**{学段}掌握度划分策略**
2. 页面描述固定格式为：**定义{学段}阶段知识点掌握程度的等级划分标准**
3. 页面右上角【版本】展示当前最新已发布版本号
4. 用户可通过页面右上角历史记录入口图标打开当前学段的【发布历史】弹窗
6. 当前入口仅对应当前详情页所属学段，不展示其他学段历史数据

---

### B. 顶部状态提示区域

用于展示当前页面的待发布或定时发布状态。

| 状态条类型 | 说明 |
|------|------|
| 橙色待发布状态条 | 当前页面存在已保存但未发布的有效变更时展示 |
| 蓝色定时发布状态条 | 当前页面存在有效定时发布任务时展示 |

#### 展示规则

1. 当前页面顶部可能出现两类状态提示：
   - 橙色待发布状态条
   - 蓝色定时发布状态条
2. 两类状态条互斥展示，同一时刻仅展示一种
3. 当既无待发布变更，也无定时发布任务时，不展示顶部状态条

---

### C. 掌握程度区间配置卡片区域

用于展示当前学段掌握程度区间配置。

| 元素 | 说明 |
|------|------|
| 卡片标题 | 显示：**掌握程度区间配置** |
| 卡片副标题 | 显示：**配置{学段}各掌握等级的区间范围与颜色标识** |
| 编辑按钮 | 点击后进入编辑态页面 |
| 配置表格 | 展示当前学段掌握度等级、颜色标识、区间范围 |
| 提示文案 | 提示用户通过编辑按钮进行修改 |

#### 展示规则

1. 配置卡片区用于展示当前学段的掌握程度区间配置
2. 卡片头部展示：
   - 标题：**掌握程度区间配置**
   - 副标题：**配置{学段}各掌握等级的区间范围与颜色标识**
3. 卡片右上角展示【编辑】按钮
4. 用户点击【编辑】按钮后，进入编辑态页面
5. 在非编辑态下，所有区间值均为只读展示，不可直接修改

---

## 顶部状态规则

### 1. 橙色待发布状态条

#### 展示条件

1. 页面顶部橙色待发布状态条，**只有在当前页面配置发生信息变更并且用户执行保存后**才显示
2. 如果当前页面本身已经发布过，但用户本次进入页面后**没有产生新的信息变更**，则保存后**不显示**橙色待发布状态条
3. 是否显示橙色待发布状态条，取决于“当前是否存在已保存但未发布的有效变更”，而不是取决于页面是否曾经发布过

#### 展示内容

1. 待发布提示文案
2. 发布按钮

#### 文案示例

**有 X 项变更待发布，发布后才能生效**

#### 补充说明

1. 当页面显示橙色待发布状态条时，**不将【发布】按钮左侧的查看历史版本文字按钮和 icon 作为固定规则写入**
2. 当前文档中仅保留橙色待发布状态条的核心能力描述：
   - 待发布提示文案
   - 发布按钮

---

### 2. 蓝色定时发布状态条

#### 展示条件

1. 当存在有效定时发布任务时，展示蓝色定时发布状态条
2. 当当前策略存在已保存但未发布的变更且当前未处于有效定时发布状态时，展示橙色待发布状态条

#### 展示内容

1. 定时发布提示文案
2. 取消定时按钮

---

## 掌握程度等级与配置规则

### 1. 等级规则

1. 当前页面固定展示四个掌握度等级：
   - 优秀
   - 良好
   - 一般
   - 较弱
2. 各等级均有固定的颜色标识
3. 各等级区间共同覆盖 0% - 100%
4. 页面以当前已保存配置结果为准进行展示
5. 非编辑态下仅展示结果，不在本页展开区间自动联动逻辑

---

### 2. 配置表格规则

表格固定展示以下三列：

| 列名 | 说明 |
|------|------|
| 掌握度等级 | 展示等级名称及对应颜色圆点 |
| 颜色标识 | 展示该等级对应颜色色块 |
| 区间范围 | 展示该等级的最小值与最大值 |

#### 展示规则

1. 每行展示一个掌握度等级
2. 每行内容包括：
   - 等级名称
   - 对应颜色圆点
   - 对应颜色色块
   - 区间范围
3. 在非编辑态下，所有区间值均为只读展示，不可直接修改

## 交互逻辑

### 1. 进入详情页

1. 用户在掌握程度划分首页点击某个学段卡片的【进入管理】按钮
2. 系统进入该学段的详情页非编辑态
3. 页面展示当前学段的掌握程度区间配置、版本信息、状态信息及相关操作入口

---

### 2. 查看配置数据

1. 页面展示当前学段的四个掌握度等级配置
2. 每个等级展示：
   - 颜色圆点
   - 等级名称
   - 颜色色块
   - 区间范围
3. 当前页面为非编辑态，区间范围不可直接修改

---

### 3. 进入编辑态

1. 用户点击配置卡片右上角【编辑】按钮
2. 系统进入当前学段对应的编辑态页面
3. 用户进入编辑态后方可修改区间配置内容

---

### 4. 查看发布历史

1. 用户点击页面右上角历史记录入口图标
2. 系统打开当前学段的【发布历史】弹窗
3. 弹窗中展示当前学段的历史发布记录，不展示其他学段数据

---

### 5. 执行发布

1. 当页面存在已保存但未发布的有效变更时，顶部展示橙色待发布状态条
2. 用户点击状态条中的【发布】按钮后，进入发布流程
3. 发布完成后，页面按最新结果回显状态信息

---

### 6. 返回首页

1. 用户点击页面左上角【返回】按钮后，返回掌握程度划分首页
2. 当前页面为非编辑态详情页，不涉及未保存离开拦截
3. 返回后首页按最新数据回显对应学段卡片状态

## 业务规则

### 一、学段配置独立性规则

1. 高中、初中、小学三个学段的配置相互独立
2. 每个学段有独立的版本号和发布状态
3. 切换学段不影响其他学段配置

### 二、等级配置规则

1. 当前页面固定展示四个掌握度等级：
   - 优秀
   - 良好
   - 一般
   - 较弱
2. 各等级有独立颜色标识
3. 各等级区间共同覆盖 0% - 100%
4. 页面按当前已保存配置结果展示

### 三、待发布状态规则

1. 顶部橙色待发布条仅在当前页有信息变更且保存后显示
2. 若页面无新的有效变更，则即使曾发布过，也不显示橙色待发布条
3. 橙色待发布条仅用于表达“当前存在已保存但未发布的有效变更”

### 四、顶部状态展示规则

1. 页面顶部可能出现橙色待发布状态条或蓝色定时发布状态条
2. 两类状态条互斥展示，同一时刻仅展示一种
3. 当无待发布变更且无定时发布任务时，不展示状态条

### 五、非编辑态展示规则

1. 当前页面为非编辑态详情页
2. 当前页面不承载区间直接编辑行为
3. 配置修改需通过进入编辑态完成

### 六、历史发布记录入口规则

1. 用户可通过页面右上角历史记录入口图标打开当前学段的【发布历史】弹窗
2. 该入口仅对应当前详情页所属学段

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 非编辑态查看状态 | 页面按只读形式展示当前学段配置 |
| 已发布状态 | 页面当前线上生效版本处于已发布状态 |
| 待发布状态 | 页面存在已保存但未发布的有效变更，顶部展示橙色待发布状态条 |
| 定时发布状态 | 页面存在有效定时发布任务，顶部展示蓝色定时发布状态条 |

### 2. 异常与边界处理

1. 页面无待发布变更时，不显示橙色待发布状态条
2. 页面无定时发布任务时，不显示蓝色定时发布状态条
3. 页面进入非编辑态时，所有区间值均为只读展示
4. 当前页不把橙条中的“查看历史版本”按钮和 icon 作为固定规则写入

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 当前页有信息变更且已保存 | 展示橙色待发布状态条 |
| 当前页无新的有效变更 | 不展示橙色待发布状态条 |
| 当前页存在有效定时发布任务 | 展示蓝色定时发布状态条 |
| 当前页既无待发布变更也无定时发布任务 | 不展示顶部状态条 |
| 用户点击编辑 | 进入编辑态页面 |
| 用户点击历史记录入口 | 打开当前学段的发布历史弹窗 |
| 用户点击返回 | 返回掌握程度划分首页 |
