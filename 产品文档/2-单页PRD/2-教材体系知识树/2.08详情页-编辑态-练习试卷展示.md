# 2.08 详情页-编辑态-练习试卷展示【GPT更新】

# 页面目标
用于在【教材体系知识树】教材详情页中，查看和维护当前节点关联的练习试卷内容。

本页面需支持：
- 基于当前节点是否为末级节点，切换不同的展示与维护模式；
- 末级节点下直接维护练习试卷；
- 非末级节点下聚合查看其所有子节点的练习试卷内容；
- 支持从资源库选择练习试卷；
- 支持预览试卷内容；
- 支持移除当前节点关联的练习试卷。

> 说明：
> 1. 当前页面展示与可维护能力，优先依据当前节点是否为末级节点判断。
> 2. 末级节点支持直接维护练习试卷。
> 3. 非末级节点仅支持查看当前节点下各子节点聚合后的练习试卷内容。
> 4. 试卷预览能力对末级节点和非末级节点均生效。
> 5. 当前页仅支持从资源库选择练习试卷，不支持本地上传试卷。
> 6. 当前页管理的是“当前节点与练习试卷的关联关系”，不负责练习试卷资源库本体管理。

# 页面区域

## A. 标题行区
用于固定显示【章节详情】标题，右侧显示操作按钮。

## B. 章节名称行区
用于显示当前选中章节路径名称和 Tab 切换栏。

## C. 练习试卷操作栏区
用于展示当前练习试卷区域标题、数量和从资源库选择入口。

## D. 末级节点试卷展示区
用于展示当前末级节点直接关联的练习试卷内容。

## E. 非末级节点聚合展示区
用于聚合展示当前非末级节点下各子节点关联的练习试卷内容。

## F. 试卷预览弹窗区
用于预览试卷详细内容。

# 组件说明

## A. 标题行区组件
- A1. 标题文本：固定显示【章节详情】
- A2. 操作按钮区（编辑态下显示）：
  - 【批量导入】按钮：点击打开批量导入弹窗
  - 【取消】按钮：取消编辑，返回非编辑态
  - 【保存编辑】按钮：保存当前编辑结果，返回非编辑态

## B. 章节名称行区组件
- B1. 章节路径名称：显示当前选中章节的完整路径
  - 章级别：显示完整章名称
  - 节级别：显示"章序号-节名称"格式
- B2. Tab 切换栏：包含【知识点】【同步课程】【练习试卷】三个 Tab
- B3. 分割线：章节名称行底部带分割线

## C. 练习试卷操作栏区组件
- C1. 区域标题：
  - 非末级节点时显示【练习试卷总览】
  - 末级节点时显示【关联练习试卷】
- C2. 数量展示：
  - 非末级节点时显示各子节点对应的试卷数量（如有）
  - 末级节点有数据时显示当前节点试卷数量
- C3. 【从资源库选择】按钮：仅在末级节点编辑态下显示
- C4. 【批量删除】按钮：仅在末级节点编辑态且有试卷数据时显示，点击后弹出二次确认弹窗

## D. 末级节点试卷展示区组件
### D1. 末级节点无数据组件
- 空状态图标：试卷图标
- 空状态标题：显示【暂未关联练习试卷】
- 引导文案：显示【点击上方按钮添加练习试卷】

### D2. 末级节点有数据组件
- 试卷卡片：
  - 试卷图标
  - 试卷名称
  - 来源标签：显示【资源库】
  - 题量
  - 总分
  - 时长
  - 预览按钮
  - 删除按钮

## D. 非末级节点聚合展示区组件
- D1. 总览标题：显示【练习试卷总览】
- D2. 总览说明：显示【聚合展示该章节下所有有关联的试卷】
- D3. 子节点区块：
  - 子节点名称
  - 子节点试卷数量（如有）
  - 子节点试卷列表或空态
- D4. 子节点空态：显示【暂无试卷】
- D5. 聚合试卷卡片：
  - 试卷图标
  - 试卷名称
  - 题量
  - 总分
  - 时长
  - 预览按钮

## E. 试卷预览弹窗区组件
- E1. 弹窗标题：显示试卷名称
- E2. 基础信息区：显示题量、总分、时长
- E3. 右上关闭按钮：关闭预览弹窗
- E4. 试卷内容预览区：展示试卷题目内容
- E5. 题型分组区：按试卷实际内容中的题型进行分组展示
- E6. 题目列表区：按题号顺序展示题目内容
- E7. 底部【关闭】按钮：关闭预览弹窗

# 交互逻辑

## 1. 切换 Tab
- 用户点击【练习试卷】Tab 后：
  - 系统切换到练习试卷 Tab 内容区域
  - 当前选中节点保持不变
  - 页面不刷新，仅内容区域切换

## 2. 页面进入练习试卷 Tab
- 当用户进入练习试卷 Tab 时，系统先判断当前节点是否为末级节点
- 若当前节点为非末级节点：
  - 进入聚合查看态
- 若当前节点为末级节点：
  - 进入直接维护态

## 3. 非末级节点展示
- 当当前节点为非末级节点时：
  - 右侧显示【练习试卷总览】
  - 说明文案为【聚合展示该章节下所有有关联的试卷】
  - 按当前节点下各子节点逐项展示试卷内容
- 若某子节点下有试卷：
  - 展示该子节点下的试卷列表
- 若某子节点下无试卷：
  - 展示【暂无试卷】
- 非末级节点状态下不展示【从资源库选择】按钮

## 4. 末级节点无数据展示
- 当当前节点为末级节点且无练习试卷时：
  - 显示空状态
  - 展示【从资源库选择】按钮
  - 不展示试卷列表

## 5. 末级节点有数据展示
- 当当前节点为末级节点且已有练习试卷时：
  - 展示【关联练习试卷】标题与试卷数量
  - 展示试卷列表
  - 展示【从资源库选择】按钮

## 6. 从资源库选择试卷
- 仅在【编辑态 + 当前节点为末级节点】时，用户可点击【从资源库选择】按钮
- 点击后：
  - 打开练习试卷资源库选择弹窗
  - 用户可浏览、搜索、选择试卷
  - 已选试卷不可重复添加
  - 点击弹窗确认后，将选中的试卷写入当前节点练习试卷结果
  - 页面刷新为末级节点有数据展示态

## 7. 预览试卷
- 末级节点和非末级节点中的试卷卡片均支持预览
- 用户点击试卷卡片中的预览入口后：
  - 打开试卷预览弹窗
  - 弹窗中展示试卷名称、题量、总分、时长和试卷内容预览
- 题型分组与题目内容展示：
  - 以试卷真实内容为准进行预览和展示
  - 当前截图中的题型仅为示意，不作为固定题型范围
- 用户点击右上关闭按钮或底部【关闭】按钮后：
  - 关闭试卷预览弹窗

## 8. 删除试卷
- 仅在【编辑态 + 当前节点为末级节点】时，试卷卡片显示删除按钮
- 用户点击删除按钮后：
  - 系统将该试卷从当前节点试卷列表中移除
  - 删除仅作用于当前节点与该试卷之间的关联关系
  - 不删除资源库中的试卷实体本身
- 若删除后当前节点下无试卷，则切换为末级节点无数据展示态

## 8.1 批量删除试卷
- 仅在【编辑态 + 当前节点为末级节点 + 有试卷数据】时，显示【批量删除】按钮
- 用户点击【批量删除】按钮后，弹出二次确认弹窗
- 确认弹窗提示文案："确认删除当前小节下的所有练习试卷吗？"
- 弹窗按钮：【取消】【确认删除】
- 用户点击【确认删除】后删除当前小节下的所有练习试卷
- 用户点击【取消】关闭弹窗，不做任何删除
- 删除仅作用于当前小节，不影响其他小节的试卷

## 9. 目录结构变化后的联动
- 若当前节点因左侧目录结构变化，由末级节点变为非末级节点：
  - 当前页立即切换为非末级节点聚合查看态
  - 原有直接维护态退出
  - 后续按子节点聚合内容展示
- 若当前节点仍保持末级节点：
  - 继续展示末级节点维护态

# 业务规则

## 一、节点类型判断规则
1. 当前页面展示与维护能力，优先依据当前节点是否为末级节点判断。
2. 末级节点支持直接维护练习试卷。
3. 非末级节点不支持直接维护练习试卷，仅支持查看聚合内容。
4. 编辑态不等于所有节点都可直接维护练习试卷，必须同时满足【当前节点为末级节点】。

## 二、四类页面状态规则
1. 非末级节点 + 无数据：
   - 展示【练习试卷总览】
   - 按子节点逐项展示
   - 各子节点下显示【暂无试卷】

2. 末级节点 + 无数据：
   - 展示【关联练习试卷】
   - 展示空状态
   - 展示【从资源库选择】按钮

3. 非末级节点 + 有数据：
   - 展示【练习试卷总览】
   - 按子节点逐项展示
   - 有试卷的子节点展示试卷列表
   - 无试卷的子节点展示【暂无试卷】

4. 末级节点 + 有数据：
   - 展示【关联练习试卷】
   - 展示试卷数量
   - 展示试卷列表
   - 展示【从资源库选择】按钮

## 三、非末级节点展示规则
1. 非末级节点练习试卷页统一按“当前节点下各子节点内容总览”方式呈现。
2. 展示结构与当前章节下查看各小节练习试卷内容的样式保持一致。
3. 每个子节点独立展示自己的标题、数量和试卷列表 / 空态。
4. 非末级节点状态下，不展示【从资源库选择】按钮。
5. 非末级节点状态下，仅支持查看试卷聚合结果，不支持直接维护当前节点试卷。

## 四、末级节点展示规则
1. 当前节点为末级节点时，右侧展示【关联练习试卷】。
2. 末级节点无数据时：
   - 展示空状态
   - 展示【从资源库选择】按钮
3. 末级节点有数据时：
   - 展示试卷数量
   - 展示试卷列表
   - 展示【从资源库选择】按钮

## 五、试卷来源规则
1. 当前页仅支持从资源库选择练习试卷。
2. 当前页不支持本地上传试卷。
3. 当前页中的试卷按【资源库】来源展示。
4. 试卷展示信息包括：
   - 试卷名称
   - 题量
   - 总分
   - 时长
   - 来源标签【资源库】

## 六、资源库选择规则
1. 从资源库选择试卷仅适用于末级节点。
2. 从资源库选择试卷仅在编辑态下可用。
3. 已选中的试卷不可重复添加。
4. 资源库选题弹窗的内部结构和详细交互，后续由独立页面说明。
5. 当前页面仅保留资源库选卷入口及结果回写规则。

## 七、预览规则
1. 试卷预览能力对末级节点和非末级节点均生效。
2. 只要页面中存在试卷卡片，用户都可点击预览入口查看试卷预览弹窗。
3. 试卷预览属于查看能力，不受是否为末级节点限制。
4. 试卷预览弹窗统一展示：
   - 试卷名称
   - 题量
   - 总分
   - 时长
   - 按试卷实际内容进行分组和题目展示
   - 关闭入口
5. 当前截图中的题型内容仅为示意，实际以试卷真实内容为准。

## 八、删除规则
1. 删除试卷仅适用于末级节点编辑态。
2. 点击删除按钮，仅删除当前节点与该试卷之间的关联关系。
3. 不删除资源库中的试卷实体本身。
4. 资源库试卷被移除后，资源库中的原试卷仍然存在。
5. 批量删除：末级节点有试卷数据时，显示【批量删除】按钮（红色边框 + 删除图标），点击后弹出二次确认弹窗，提示"确认删除当前小节下的所有练习试卷吗？"，弹窗按钮【取消】【确认删除】，确认后删除当前小节下所有试卷，仅作用于当前小节。

## 九、页面范围规则
1. 当前页面仅用于维护当前节点与练习试卷的关联关系。
2. 当前页面不负责练习试卷资源库本体的完整管理。
3. 从资源库选择试卷属于引用 / 关联能力。
4. 当前页中的删除动作默认作用于关联关系，而非试卷实体本身。

## 十、权限规则
1. 教研主管可在末级节点编辑态下维护练习试卷。
2. 教研员也可在末级节点编辑态下维护练习试卷。
3. 当前页属于右侧详情维护能力的一部分，不属于左侧教材目录编辑范围。
4. 因此教研员在本页应具备练习试卷维护权限。
5. 试卷预览为查看能力，对可见用户均开放。

## 十一、结果回写规则
1. 点击资源库选择弹窗中的【确定】后，仅将当前选择结果写入当前教材详情页编辑态数据。
2. 页面刷新后按末级节点有数据态展示。
3. 当前页中的新增 / 删除试卷结果写入当前编辑态，并纳入后续统一发布变更处理。
4. 真正最终提交发生在点击顶部【完成编辑】时。

# 状态与异常

## 页面状态
- 非末级节点聚合查看态
- 末级节点无数据态
- 末级节点有数据态
- 试卷预览弹窗打开态

## 异常与边界
1. **无关联试卷**
   - 末级节点无试卷时，显示空状态提示

2. **聚合无数据**
   - 非末级节点下若子节点均无试卷，则各子节点下展示【暂无试卷】

3. **试卷加载失败**
   - 试卷数据加载失败时，提示加载失败并支持重试

4. **预览数据加载失败**
   - 试卷预览失败时，提示加载失败，不影响试卷列表查看

5. **重复引用资源库试卷**
   - 若用户尝试重复添加当前节点已关联试卷，应阻断并提示不可重复添加

6. **删除后清空**
   - 若末级节点删除最后一套试卷，页面切换为末级节点无数据态

7. **批量删除后清空**
   - 批量删除后当前小节切换为末级节点无数据态

# 技术要求

1. 当前页需根据节点是否为末级节点，动态切换展示模式。
2. 末级节点维护态与非末级节点聚合态需支持同页切换刷新。
3. 【从资源库选择】按钮仅在末级节点编辑态下显示。
4. 试卷预览能力需支持末级节点和非末级节点统一使用。
5. 当前页不支持本地上传试卷，仅支持资源库试卷引用。
6. 试卷预览内容需按试卷实际数据进行渲染，不写死固定题型结构。
7. 当前页不展开资源库选卷弹窗的详细内部实现，后续以独立页面为准。
