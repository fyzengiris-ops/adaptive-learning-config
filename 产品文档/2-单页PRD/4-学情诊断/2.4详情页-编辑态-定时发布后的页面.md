# 2.4 详情页-编辑态-定时发布后的页面【GPT更新】

## 页面目标

用于在策略详情页中展示当前策略已设置定时发布后的状态信息。当用户成功设置定时发布后，页面顶部显示定时发布状态条，提示待发布版本及预定发布时间，并提供取消定时发布能力。

## 所属页面

策略管理 > 策略广场 > 学情诊断 > 策略详情 > 定时发布后的页面状态

---

## 页面定位

1. 当前页面不是独立新页面，而是策略详情页在“已设置定时发布”后的页面状态。
2. 当前页面重点描述：
   - 蓝色定时发布状态条的展示规则
   - 蓝色定时发布状态条与橙色待发布状态条之间的切换规则
   - 定时发布期间进入编辑态后的状态流转规则
   - 再次发布时的弹窗信息回写规则
3. 发布确认弹窗的字段与交互细节，不在本页重复展开；本页仅引用其提交结果。

---

## 页面结构

### A. 顶部标题与状态区域

用于展示返回入口、策略名称、版本号、当前状态，以及定时发布后的顶部状态提示。

| 元素 | 说明 |
|------|------|
| 返回按钮 | 点击后返回上一层页面 |
| 页面标题 | 显示当前策略名称 |
| 版本号 | 展示当前待发布版本号 |
| 状态 | 展示当前策略状态 |
| 蓝色定时发布状态条 | 当前策略已成功设置定时发布时展示 |
| 取消定时按钮 | 位于蓝色定时发布状态条右侧 |

#### 展示规则

1. 当当前策略已成功设置定时发布，且当前无新的已保存未发布变更时，页面顶部展示**蓝色定时发布状态条**。
2. 蓝色定时发布状态条与橙色待发布状态条互斥展示，同一时刻仅展示一种。
3. 当当前策略处于定时发布展示态时：
   - 页面右上角版本号展示为：**待发布版本号**
   - 页面右上角状态展示为：**待发布**
4. 页面顶部蓝色定时发布状态条用于提示该待发布版本将在指定时间自动发布。

#### 蓝色定时发布状态条文案

**vX.X.X 版本将于您设定的时间（YYYY-MM-DD HH:mm）自动发布**

---

### B. 表单只读展示区域

用于展示当前策略的只读内容，包括基本信息、题目筛选条件、题目组成配置。

| 区块 | 说明 |
|------|------|
| 基本信息区块 | 展示策略名称、学段、学科、年级 |
| 题目筛选条件区块 | 展示题目来源（**本期暂不做**）、年份范围 |
| 题目组成配置区块 | 展示各配置方案明细 |

> **⚠️ 题目来源本期暂不做**：该字段因上游题目缓存业务还未完成，无法提供题目来源字段的接口，故本期先不做，待上游完成该需要的开发后，学情诊断业务再把题目来源这个字段给加上。

#### 展示规则

1. 当页面处于定时发布后的查看状态时，页面内容按详情页非编辑态口径只读展示。
2. 用户可查看当前策略已保存的待发布内容。
3. 用户可从当前状态进入编辑态继续修改策略。

---

## 状态条规则

### 1. 蓝色定时发布状态条

#### 展示条件

当满足以下业务条件时，页面顶部展示蓝色定时发布状态条：

1. 当前策略已成功设置定时发布
2. 定时发布时间尚未到达
3. 当前页面内容未产生新的已保存未发布变更
4. 当前页面回显内容仍对应上一次定时发布任务的待发布版本内容

#### 展示内容

1. 成功状态图标
2. 待发布版本号
3. 预定发布时间
4. 【取消定时】按钮

---

### 2. 橙色待发布状态条

#### 展示条件

当满足以下业务条件时，页面顶部展示橙色待发布状态条：

1. 当前策略存在已保存但未发布的变更
2. 当前策略未处于有效的蓝色定时发布展示态

#### 展示说明

1. 橙色待发布状态条表示：当前策略已有待发布版本，但未设置有效的自动发布时间
2. 用户可通过橙色待发布状态条右侧【发布】按钮再次进入发布确认弹窗

---

## 交互逻辑

### 1. 设置定时发布成功后的页面回显

1. 用户在发布确认弹窗中选择【定时发布】，并完成发布日期、发布时间、更新说明填写后提交。
2. 系统保存定时发布任务。
3. 提交成功后，页面关闭发布确认弹窗。
4. 页面进入定时发布展示态，顶部展示蓝色定时发布状态条。
5. 页面右上角版本号展示为待发布版本号。
6. 页面右上角状态展示为：**待发布**。

---

### 2. 取消定时发布

1. 用户点击蓝色定时发布状态条右侧【取消定时】按钮。
2. 系统取消当前定时发布任务。
3. 取消定时成功后：
   - 蓝色定时发布状态条消失
   - 页面顶部改为显示**橙色待发布状态条**
4. 当前待发布版本仍然存在，因此：
   - 页面右上角版本号仍展示：**待发布版本号**
   - 页面右上角状态仍展示：**待发布**

---

### 3. 从定时发布态进入编辑态

1. 当页面当前处于蓝色定时发布展示态时，用户点击【编辑】按钮后，进入编辑态。
2. 进入编辑态后，**蓝色定时发布状态条不再展示**。
3. 用户在编辑态中可正常修改当前策略内容。
4. 进入编辑态时，系统仍需保留“上一次已设置的定时发布任务信息”，供后续保存后判断是否恢复展示。

---

### 4. 二次编辑后未改动保存

1. 当页面原本处于蓝色定时发布展示态，用户进入编辑态后如**未实际修改策略内容**。
2. 用户点击【保存】后，页面应继续保留原定时发布任务。
3. 保存完成后，页面顶部应**恢复显示原蓝色定时发布状态条**。
4. 恢复展示的蓝色状态条内容，应继续回显原定时发布任务中的：
   - 待发布版本号
   - 预定发布时间

---

### 5. 二次编辑后有改动保存

1. 当页面原本处于蓝色定时发布展示态，用户进入编辑态后如**实际修改了策略内容**。
2. 用户点击【保存】后，若本次保存形成新的已保存未发布变更，则：
   - 原蓝色定时发布状态条不再展示
   - 页面顶部改为展示**橙色待发布状态条**
3. 此时表示：原定时发布任务不再适用于当前最新保存内容，当前策略需重新执行发布或重新设置定时发布。

---

### 6. 再次点击发布时的信息回写

1. 当用户从橙色待发布状态条再次点击【发布】按钮打开发布确认弹窗时，
2. 弹窗需优先回写用户上一次已填写的发布信息。
3. 回写内容包括：
   - 更新说明
   - 发布方式（立即发布 / 定时发布）
   - 若上次选择过定时发布，则回写上次选择的发布日期与发布时间
4. 用户可在此基础上继续修改并重新提交。

---

### 7. 定时发布时间到达后的页面回显

1. 当定时发布时间到达并发布执行成功后：
   - 蓝色定时发布状态条不再展示
   - 页面右上角版本号更新为已正式发布版本号
   - 页面右上角状态更新为：**已发布**
   - 页面顶部不再展示橙色待发布条
2. 若定时任务执行失败，则页面需按失败结果回显，并提示用户后续处理方式，具体以失败处理规范为准。

---

## 业务规则

### 一、状态条展示规则

1. 当用户已成功设置定时发布，且在定时时间到达前，页面顶部显示：**蓝色定时发布状态条**
2. 当策略存在已保存但未发布的变更，且当前未处于有效定时发布状态时，页面顶部显示：**橙色待发布状态条**
3. 蓝色定时发布状态条与橙色待发布状态条互斥展示，同一时刻仅展示一种

### 二、蓝色定时发布状态条规则

1. 蓝色定时发布状态条展示的是：**上一次定时发布任务对应的待发布版本信息**
2. 仅当当前页面内容未产生新的已保存未发布变更时，才展示蓝色定时发布状态条
3. 若当前页面内容已不再与该定时发布任务对应版本一致，则不再展示蓝色定时发布状态条

### 三、取消定时规则

1. 用户取消定时发布后，当前待发布版本仍然存在
2. 蓝色定时发布状态条切换为橙色待发布状态条
3. 页面右上角版本号仍展示待发布版本号
4. 页面右上角状态仍展示：**待发布**

### 四、编辑期间状态流转规则

1. 用户从蓝色定时发布展示态进入编辑态后，页面暂不展示蓝色定时发布状态条
2. 编辑完成点击保存后：
   - 若本次保存未形成新的有效变更，则恢复原蓝色定时发布状态条
   - 若本次保存形成新的有效变更，则页面改为显示橙色待发布状态条

### 五、再次发布信息回写规则

1. 当用户再次从橙色待发布状态条点击【发布】时，发布确认弹窗需回写上一次填写过的信息
2. 回写内容包括更新说明、发布方式、定时发布日期、定时发布时间
3. 用户可在回写基础上继续修改并重新提交

### 六、定时发布完成后的回收规则

1. 定时任务执行成功后，页面不再展示蓝色定时发布状态条
2. 页面右上角版本号更新为正式发布版本号
3. 页面右上角状态更新为：**已发布**
4. 页面顶部不再展示橙色待发布条

## 显示说明

### 1. 页面整体展示说明

1. 当前页面不是独立新页面，而是策略详情页的定时发布后状态。
2. 页面由顶部标题与状态区域、表单只读展示区域构成。
3. 页面重点展示当前待发布版本的定时发布信息与后续状态切换结果。

### 2. 顶部状态展示说明

1. 当策略已成功设置定时发布且当前无新的有效变更时，页面顶部展示蓝色定时发布状态条。
2. 蓝色状态条需展示待发布版本号、预定发布时间、取消定时按钮。
3. 取消定时后，顶部状态条切换为橙色待发布状态条。
4. 定时任务执行成功后，不再展示蓝色或橙色状态条。

### 3. 表单区域展示说明

1. 当前页面表单内容按详情页非编辑态口径只读展示。
2. 用户可查看当前待发布内容。
3. 用户可从当前状态进入编辑态继续修改。

---

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 蓝色定时发布展示态 | 已设置定时发布，当前无新变更，顶部展示蓝色定时发布状态条 |
| 橙色待发布展示态 | 当前存在待发布变更但无有效定时发布，顶部展示橙色待发布状态条 |
| 已发布展示态 | 定时任务执行成功后，页面恢复正常已发布状态 |
| 定时任务执行失败态 | 定时任务执行失败，页面按失败结果回显并提示用户后续处理 |

### 2. 异常处理规则

1. 若定时任务执行失败，则页面需提示失败结果，并按失败处理规范回显页面状态。
2. 若定时发布任务信息失效或异常，页面不得继续展示错误的蓝色定时发布状态条。
3. 若当前待发布内容已不再匹配原定时任务对应版本，则页面需切换为橙色待发布状态条展示。

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 当前策略已设置定时发布，且时间未到 | 展示蓝色定时发布状态条 |
| 用户取消定时发布 | 蓝色条消失，回显橙色待发布条 |
| 用户进入编辑态但未改动保存 | 恢复原蓝色定时发布状态条 |
| 用户进入编辑态并改动保存 | 显示橙色待发布条 |
| 用户再次点击发布 | 发布确认弹窗回写上次填写过的信息 |
| 定时任务到时且执行成功 | 页面恢复为已发布态 |
| 定时任务执行失败 | 页面按失败结果提示并回显当前状态 |

3. 当前页面不替代编辑页、发布确认弹窗页和历史发布记录弹窗页。
