# 1.2 首页-新增学科弹窗【GPT更新】

# 页面目标
用于在通用知识树首页为当前学段新增学科目录。用户可从当前学段可新增的学科列表中选择学科，完成通用知识树学科目录创建。学科排序沿用乐课网原有的学科 ID 排序逻辑。

# 所属页面
知识体系管理 > 通用知识树 > 新增学科弹窗

# 页面区域

## A. 弹窗遮罩层
用于承载新增学科弹窗的背景遮罩。

## B. 弹窗容器
用于承载弹窗主体内容，包含标题区、表单区和底部操作区。

## C. 表单区域
用于填写新增学科所需信息，包括学科名称。

## D. 操作按钮区
用于执行取消和确定操作。

# 组件说明

## A. 弹窗遮罩层组件
- A1. 遮罩层：全屏半透明遮罩
- A2. 遮罩点击：点击遮罩不关闭弹窗

## B. 弹窗容器组件
- B1. 弹窗主体：居中显示的白色弹窗
- B2. 标题：显示【新增学科 - {学段名称}】
- B3. 关闭按钮：点击后关闭弹窗

## C. 表单区域组件
- C1. 学科名称字段
  - C1.1. 标签：显示【学科名称】，带必填标识
  - C1.2. 下拉选择框：展示当前学段下可新增的学科列表
  - C1.3. 默认占位：显示【请选择学科】
  - C1.4. 提示文案：显示【从当前学段可用学科中选择】
  - C1.5. 已存在学科：当前学段已存在的学科在下拉列表中置灰显示，不可选择，且显示"已存在"标识
  - C1.6. 悬停提示：鼠标悬停在置灰的学科上时，显示提示信息"该学科已存在"

## D. 操作按钮区组件
- D1. 取消按钮：点击后关闭弹窗
- D2. 确定按钮：点击后发起新增学科保存

# 交互逻辑

## 1. 打开弹窗
- 1.1、用户点击【新增学科】或【添加第一个学科】后，打开新增学科弹窗
- 1.2、弹窗标题根据当前选中学段动态展示
- 1.3、系统加载当前学段可新增的学科列表
- 1.4、学科名称默认未选择

## 2. 选择学科
- 2.1、用户点击学科名称下拉框后，展开当前学段可新增学科列表
- 2.2、选择某个学科后，下拉框回填所选学科名称
- 2.3、当前学段已存在的学科在下拉列表中置灰显示，不可选择
- 2.4、鼠标悬停在置灰的学科上时，显示提示信息"该学科已存在"
- 2.5、置灰的学科右侧显示"已存在"标识

## 4. 关闭弹窗
- 4.1、点击【取消】或右上角关闭按钮后，关闭弹窗
- 4.2、关闭后本次未保存内容失效
- 4.3、再次打开弹窗时，表单恢复初始状态

## 5. 确认新增
- 5.1、点击【确定】后，系统先执行前端校验
- 5.2、校验通过后，调用新增学科接口
- 5.3、接口请求期间，【确定】按钮进入加载态，且不可重复点击
- 5.4、保存成功后，关闭弹窗，刷新当前学段的学科列表，并提示【新增成功】
- 5.5、保存失败时，弹窗保持打开，并保留当前填写内容

# 业务规则

## 一、学科名称规则
1. 学科名称为必填项
2. 学科名称只能从当前学段可新增学科列表中选择，不支持手动输入
3. 学科列表来源于平台中当前学段已有的学科数据
4. 下拉框展示当前学段所有可用学科，但已存在的学科置灰不可选
5. 已存在的学科置灰显示，鼠标悬停时提示"该学科已存在"，右侧显示"已存在"标识

## 二、权限规则
1. 仅教研主管可见首页中的新增学科相关入口
2. 教研员不可打开新增学科弹窗
3. 新增学科接口需进行服务端权限校验
4. 前端入口隐藏不作为唯一权限控制手段，后端必须同步拦截

## 三、重复新增规则
1. 当前学段下，同一学科仅允许新增一次
2. 已存在的学科在下拉列表中置灰显示，不可重复选择
3. 若因并发或异常请求导致重复提交，接口需返回【该学科已存在，无法重复新增】

## 四、可新增学科为空规则
1. 若当前学段下所有可用学科均已完成新增，则首页新增入口置灰不可点击
2. 置灰态下需提示【当前学段暂无可新增学科】
3. 若异常进入弹窗且当前无可新增学科，则学科名称下拉框置灰，不可操作
4. 无可新增学科时，【确定】按钮不可用

## 五、保存规则
1. 字段校验通过后，才允许发起新增请求
2. 保存成功后，需同步刷新当前学段首页学科列表
3. 保存失败时，不关闭弹窗，并保留当前填写内容
4. 若新旧功能数据同步失败，则本次新增视为失败

## 六、校验规则
1. 学科名称未选择时，提示【请选择学科】
2. 校验未通过时，不发起保存请求
3. 字段内容修改后，对应错误提示需重新校验或消失

## 七、新旧功能数据互通规则
1. 通用知识树新增学科产生的数据，需与历史功能使用同一主数据口径，或通过同步机制保证新旧功能数据一致
2. 在新功能中新增学科后，历史功能中对应学科目录数据也需同步可见
3. 若历史功能中对应口径数据发生变更，新功能中也需同步更新
4. 新增学科接口成功的前提，需满足新旧功能数据一致性要求
5. 若新旧数据同步失败，则本次新增视为失败，并返回明确错误提示

# 状态与异常

## 页面状态
- 初始状态：学科未选择
- 可编辑状态：可正常选择学科
- 保存中状态：确定按钮加载中，不可重复点击
- 无可新增学科状态：学科下拉框置灰，确定按钮不可用

## 异常与边界
- 学科未选择时：提示【请选择学科】
- 学科重复新增时：提示【该学科已存在，无法重复新增】
- 无操作权限时：提示【无操作权限】
- 新旧数据同步失败时：提示明确失败原因，本次新增不生效
- 网络异常时：提示【网络异常，请重试】

# 数据来源

| 数据名称 | 来源 | 用途 |
|----------|------|------|
| 当前学段名称 | 首页当前选中的学段 | 用于标题展示及确定新增归属学段 |
| 当前学段平台可用学科列表 | 平台学科基础数据 | 生成学科下拉选项 |
| 当前学段已添加学科列表 | 通用知识树首页数据 | 过滤不可重复新增的学科 |
| 当前用户角色信息 | 登录用户信息 | 控制入口显示及权限校验 |

# 接口需求

| 接口名称 | 用途 | 状态 |
|----------|------|------|
| 获取当前学段可新增学科列表接口 | 获取当前学段可供选择的学科数据 | 待补充 |
| 新增学科接口 | 创建当前学段下新的学科目录 | 待补充 |
| 获取当前学段学科列表接口 | 新增成功后刷新首页学科列表 | 待补充 |

# 技术要求

- 弹窗采用条件渲染控制显示与隐藏
- 弹窗需支持居中展示
- 学科列表在弹窗打开时异步加载
- 表单需支持必填校验
- 前端需做选项过滤，后端需做重复新增校验
- 关闭弹窗后，表单恢复初始状态
- 权限控制需由前端显隐与后端校验共同完成
