# 1.1 首页-查看历史发布记录【GPT更新】

## 页面目标

用于查看学情诊断策略模块下的历史发布记录。用户可在弹窗中按场景筛选、按关键词搜索历史发布记录，并查看各版本的版本号、策略名称、学段/学科/年级、发布说明、发布时间、发布人等信息。

> 历史发布记录仅展示已完成发布的版本记录，不包含未发布草稿、待发布变更记录。

## 所属页面

策略管理 > 策略广场 > 学情诊断 > 首页 > 查看历史发布记录

---

## 页面结构

### A. 弹窗头部区域

用于展示弹窗标题、当前结果数量及关闭入口。

| 元素 | 说明 |
|------|------|
| 历史图标 | 展示历史发布记录图标 |
| 弹窗标题 | 显示【历史发布记录】 |
| 记录数量 | 显示当前筛选条件和搜索条件下的记录数量，文案格式为【共 X 条记录】 |
| 关闭按钮 | 位于弹窗右上角，点击后关闭当前弹窗 |

---

### B. 筛选与搜索区域

用于对当前历史发布记录列表进行场景筛选与关键词搜索。

| 元素 | 说明 |
|------|------|
| 场景筛选 | 下拉选择场景，支持：全部场景 / 同步学 / 期中期末考 / 寒暑假 / 中考 / 高考 |
| 关键词搜索框 | 支持输入关键词搜索历史发布记录 |

#### 场景筛选规则

1. 场景筛选用于过滤当前弹窗中展示的历史发布记录列表。
2. 场景筛选默认值为【全部场景】。
3. 当用户切换场景筛选后，历史记录列表按所选场景重新过滤。
4. 记录数量统计需随筛选结果同步更新。

#### 关键词搜索规则

1. 关键词搜索支持对以下信息进行模糊匹配：
   - 版本号
   - 策略名称
   - 发布说明
   - 发布人姓名
   - 发布人账号
2. 搜索框 placeholder 为：**搜索版本号、描述、发布人...**
3. 搜索条件与场景筛选可叠加生效。
4. 当用户输入关键词后，列表结果与“共 X 条记录”数量统计需同步更新。

---

### C. 历史记录列表区域

用于展示符合当前筛选条件和搜索条件的历史发布记录列表。

#### 单条历史记录卡片展示内容

| 元素 | 说明 |
|------|------|
| 版本号 | 展示本次发布的版本号，如【v1.0】 |
| 策略名称 | 展示该条发布记录对应的策略名称 |
| 标签信息 | 展示该策略对应的学段 / 学科 / 年级 |
| 发布说明 | 展示该版本对应的发布说明 |
| 发布时间 | 展示本次发布时间，位于卡片右侧 |
| 发布人信息 | 展示发布人姓名与账号 |

#### 列表展示规则

1. 历史发布记录按发布时间倒序排列，最新记录显示在最前。
2. 每条历史发布记录均归属于一个明确的场景类型，该场景类型用于支持顶部场景筛选。
3. 当前卡片是否显式展示场景文案，以最终 UI 定稿为准；即使卡片不显式展示，数据层仍需包含场景字段。
4. 本期单条历史记录仅用于查看，不支持点击跳转到对应策略详情页。
5. 列表区域支持弹窗内垂直滚动浏览。

#### 标签展示规则

| 标签类型 | 说明 |
|----------|------|
| 学段标签 | 展示如【高中】、【初中】等 |
| 学科标签 | 展示如【数学】 |
| 年级标签 | 展示如【高一】、【初三】等 |

1. 标签展示顺序固定为：**学段 → 学科 → 年级**
2. 标签仅用于展示该条发布记录所对应策略的基础归属信息

#### 版本号展示规则

1. 版本号使用独立标签样式展示。
2. 版本号文案格式统一为：**v主版本.次版本**（如 v1.0、v1.1）
3. 版本号用于标识本条历史记录对应的已发布版本。

#### 发布时间展示规则

1. 发布时间统一按 **YYYY-MM-DD HH:mm** 格式展示。
2. 历史记录按发布时间倒序排列，最新发布时间显示在前。

#### 发布人展示规则

1. 发布人信息展示格式为：**发布人：姓名（账号：XXXXXX）**
2. 发布人姓名与账号为必有字段，页面需按固定格式展示。

用于提供弹窗关闭操作。

| 元素 | 说明 |
|------|------|

## 交互逻辑

### 1. 打开弹窗

1. 用户在首页点击【查看历史发布记录】入口。
2. 系统打开【历史发布记录】弹窗。
3. 弹窗展示在当前页面中央，并带页面遮罩层。
4. 系统加载学情诊断策略模块下的历史发布记录数据。
5. 列表按发布时间倒序展示全部历史发布记录。
6. 顶部场景筛选默认值为【全部场景】。
7. 搜索框默认为空。

---

### 2. 场景筛选

1. 用户点击场景筛选下拉框。
2. 系统展示可选场景项：
   - 全部场景
   - 同步学
   - 期中期末考
   - 寒暑假
   - 中考
   - 高考
3. 用户选择某一场景后：
   - 历史记录列表按所选场景过滤；
   - 记录数量同步更新；
   - 列表内容刷新为符合条件的结果。

---

### 3. 关键词搜索

1. 用户在搜索框中输入关键词。
2. 系统对当前历史发布记录进行模糊搜索匹配。
3. 搜索结果与场景筛选结果叠加生效。
4. 列表内容根据当前条件实时更新。
5. 标题区【共 X 条记录】数量同步更新。

---

### 4. 列表查看

1. 用户可在弹窗内上下滚动查看历史发布记录。
2. 当前页面为查看型弹窗页面。
3. 用户可进行的操作包括：
   - 场景筛选
   - 关键词搜索
   - 滚动查看
   - 关闭弹窗
4. 本期页面不承载以下能力：
   - 点击历史记录跳转详情
   - 发布
   - 撤回
   - 回滚
   - 版本对比

---

### 5. 关闭弹窗

1. 用户点击右上角关闭按钮或底部【关闭】按钮后，弹窗关闭。
2. 弹窗关闭后，本次查看过程中的临时筛选条件与搜索关键词不保留。
3. 用户下次重新打开弹窗时，页面按默认状态初始化：
   - 场景筛选默认为【全部场景】
   - 搜索关键词默认为空
   - 列表默认按发布时间倒序展示全部历史发布记录

---

## 显示说明

### 1. 弹窗整体展示说明

1. 弹窗用于查看学情诊断策略模块下的历史发布记录。
2. 弹窗由头部区域、筛选与搜索区域、历史记录列表区域、底部操作区组成。
3. 弹窗打开后，用户无需跳转页面即可在当前页完成历史记录查看。

### 2. 头部展示说明

1. 头部展示历史图标、标题【历史发布记录】、记录数量及关闭入口。
2. 头部中的【共 X 条记录】表示当前筛选条件和搜索条件下的记录数量。
3. 当无筛选、无搜索条件时，该数量表示学情诊断策略历史发布记录的全量条数。

### 3. 筛选与搜索展示说明

1. 场景筛选位于搜索框左侧。
2. 搜索框用于对当前历史发布记录进行关键词检索。
3. 筛选和搜索区域始终展示，不因列表为空而隐藏。

### 4. 列表展示说明

1. 列表区展示符合当前条件的历史发布记录卡片。
2. 每条卡片需展示版本号、策略名称、学段/学科/年级、发布说明、发布时间、发布人信息。
3. 卡片为查看型展示，不提供点击跳转能力。
4. 列表区内容超出可视区域时，支持垂直滚动查看。

### 5. 底部操作区展示说明

1. 底部固定展示【关闭】按钮。
2. 当前页面无其他确认类、提交类操作按钮。

## 操作说明

### 1. 查看历史记录

1. 用户点击首页【查看历史发布记录】后，打开当前弹窗。
2. 弹窗默认展示全部历史发布记录。
3. 历史记录默认按发布时间倒序排列。

### 2. 场景筛选操作

1. 用户可通过场景筛选查看某一场景下的历史发布记录。
2. 切换筛选条件后，列表即时刷新。
3. 数量统计与列表结果保持一致。

### 3. 搜索操作

1. 用户可通过关键词搜索目标历史记录。
2. 搜索结果与场景筛选结果叠加生效。
3. 搜索结果为空时，列表区展示空结果状态。

### 4. 关闭操作

1. 用户可通过右上角关闭按钮关闭弹窗。
2. 用户可通过底部【关闭】按钮关闭弹窗。
3. 弹窗关闭后，下次重新打开按默认状态初始化。

## 业务规则

### 一、数据范围规则

1. 当前弹窗仅展示【学情诊断策略】模块下的历史发布记录。
2. 历史发布记录仅包含已完成发布的版本记录。
3. 未发布草稿、待发布变更记录不在当前弹窗中展示。

### 二、排序规则

1. 历史发布记录按发布时间倒序排列。
2. 最新发布的记录展示在最前。

### 三、场景归属规则

1. 每条历史发布记录均归属于一个明确场景。
2. 场景字段用于支持顶部场景筛选。
3. 场景归属应与首页固定场景分组口径保持一致：
   - 同步学
   - 期中期末考
   - 寒暑假
   - 中考
   - 高考

### 四、筛选与搜索规则

1. 场景筛选与关键词搜索支持组合使用。
2. 列表结果、数量统计需随筛选和搜索条件同步更新。
3. 默认状态下展示全部场景的全部历史发布记录。

### 五、查看规则

1. 单条历史记录本期仅支持查看，不支持点击跳转到对应策略详情页。
2. 当前弹窗不支持版本对比、发布回滚、撤回等扩展操作。

### 六、状态重置规则

1. 弹窗关闭后，临时筛选条件和搜索关键词不保留。
2. 下次打开时恢复默认状态。

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 加载中 | 弹窗打开后，历史发布记录数据加载中 |
| 正常状态 | 正常展示筛选区、搜索区和历史记录列表 |
| 空状态 | 当前模块下暂无任何历史发布记录 |
| 空结果状态 | 当前筛选条件或搜索条件下无匹配历史记录 |
| 加载失败 | 历史发布记录加载失败 |

### 2. 空状态规则

1. 当学情诊断策略模块下无任何历史发布记录时，列表区展示空状态文案：**暂无历史发布记录**
2. 空状态下仍保留顶部筛选与搜索区域，以及底部关闭按钮

### 3. 空结果状态规则

1. 当用户设置筛选条件或搜索条件后无匹配结果时，列表区展示空结果状态文案：**暂无符合条件的历史记录**
2. 空结果状态下仍保留顶部筛选与搜索区域，便于用户调整条件

### 4. 加载失败规则

1. 当历史发布记录数据加载失败时，页面展示加载失败提示
2. 页面需提供重试能力
3. 加载失败时，不影响用户关闭弹窗

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 当前模块下无历史发布记录 | 展示空状态：暂无历史发布记录 |
| 场景筛选后无结果 | 展示空结果状态：暂无符合条件的历史记录 |
| 搜索后无结果 | 展示空结果状态：暂无符合条件的历史记录 |
| 场景筛选与搜索叠加后无结果 | 展示空结果状态：暂无符合条件的历史记录 |
| 发布记录较多 | 列表区支持弹窗内垂直滚动浏览 |
| 用户关闭弹窗后重新打开 | 按默认状态重新初始化筛选与搜索条件 |
| 数据加载失败 | 展示失败提示，并提供重试能力 |
