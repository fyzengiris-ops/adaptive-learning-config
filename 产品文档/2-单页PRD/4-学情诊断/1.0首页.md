# 1.0 首页

## 页面目标

用于按学段、学科、场景维度查看学情诊断策略，并按固定场景分组展示对应策略卡片；用户可在对应场景下新增策略、进入策略管理页，并查看历史发布记录。

> 本期页面展示全部固定场景分组，但仅维护同步学场景下的策略配置能力。

## 所属页面

策略管理 > 策略广场 > 学情诊断 > 首页

---

## 页面结构

### A. 标题栏区域

用于展示当前页面的模块名称、功能说明及顶部操作入口。

| 元素 | 说明 |
|------|------|
| 返回按钮 | 点击后返回上一级页面【策略广场】 |
| 模块图标 | 显示学情诊断策略模块图标 |
| 模块标题 | 显示【学情诊断策略】 |
| 模块说明 | 显示文案：【针对不同学段、学科、学习场景，配置初次诊断出题策略】 |
| 历史发布记录入口 | 点击【查看历史发布记录】后，进入学情诊断策略的历史发布记录查看界面 |

---

### B. 筛选栏区域

用于按学段、学科、年级、场景筛选当前首页中各场景分组下展示的策略卡片。

| 元素 | 说明 |
|------|------|
| 学段筛选 | 下拉选择学段，数据来源：拉取乐课网小初高三个学段（小学 / 初中 / 高中） |
| 学科筛选 | 下拉选择学科，展示当前学段下支持的学科 |
| 场景筛选 | 下拉选择场景，支持：全部 / 同步学 / 期中期末考 / 寒暑假 / 中考 / 高考 |

#### 筛选规则

1. 学段、学科筛选作用于各场景分组下的策略卡片集合。
2. 场景分组本身为固定结构，不因学段、学科筛选而消失。
3. 分组标题中的“X个策略”表示当前筛选条件下该场景分组内可展示的策略数量。
4. 当某场景分组在当前筛选条件下无可展示策略时，该分组内容区显示空状态。
5. 页面默认筛选值以系统初始化配置为准；当前原型中默认为：
   - 学段：高中
   - 学科：数学
   - 场景：全部

---

### C. 固定场景分组区域

用于按固定场景分组展示学情诊断策略卡片。

#### 固定分组说明

学情诊断策略首页按固定场景分组展示，固定场景分组包含：

1. 同步学
2. 期中期末考
3. 寒暑假
4. 中考
5. 高考

以上分组按既定顺序自上而下展示，无论某场景下当前是否存在策略，页面均展示该场景分组容器。

#### 分组头部组件

| 元素 | 说明 |
|------|------|
| 场景图标 | 根据场景类型展示对应图标与颜色 |
| 场景名称 | 显示当前场景名称，如【同步学】 |
| 策略数量 | 显示当前筛选条件下该场景分组内的策略数量，文案格式为【（X个策略）】 |
| 新增按钮 | 位于分组右上角，用于新增该场景下的策略 |

#### 场景图标规则

| 场景 | 图标含义 | 视觉色值方向 |
|------|----------|-------------|
| 同步学 | 学习类图标 | 蓝色系 |
| 期中期末考 | 试卷/考试类图标 | 紫色系 |
| 寒暑假 | 目标/专题类图标 | 橙色系 |
| 中考 | 升学考试类图标 | 绿色系 |
| 高考 | 升学考试类图标 | 红色系 |

#### 分组显示规则

1. 页面始终展示全部固定场景分组。
2. 当场景筛选为【全部】时，全部固定分组均展示。
3. 当场景筛选为具体场景时，页面仍保留固定场景分组结构：
   - 被选中的场景分组展示符合其他筛选条件的策略卡片；
   - 未选中的场景分组不展示策略卡片，并显示分组内空状态。
4. 当某场景分组在当前筛选条件下无匹配策略时，该分组内容区显示空状态文案：【暂无策略，点击“新增”添加】。

---

### D. 策略卡片区域

用于展示某一场景下的具体策略信息，并提供进入管理入口。

#### 卡片基础信息

| 元素 | 说明 |
|------|------|
| 策略图标 | 与所属场景分组图标风格保持一致 |
| 策略名称 | 显示策略名称，如【高中数学同步诊断】 |
| 策略基础信息 | 显示策略对应的学段 / 学科，格式为【高中 \| 数学】 |
| 版本号 | 显示当前策略最新已发布版本号，如【v1.0】；未发布时显示【版本号：--】 |
| 状态标签 | 显示当前策略状态 |
| 进入管理 | 点击后进入该策略的管理页 |

#### 卡片状态规则

| 状态 | 说明 | 版本号显示 | 状态标签显示 |
|------|------|------------|--------------|
| 已发布 | 当前策略不存在未发布变更 | 显示最新已发布版本号（如 v1.0） | 绿色【已发布】标签 |
| 待发布·X项变更 | 当前策略已存在已发布版本，且相较最近一次已发布版本存在未发布修改 | 显示最新已发布版本号 | 黄色【待发布】标签 |
| 新增（未发布） | 当前策略已创建但尚未发布任何版本 | 显示【版本号：--】 | 橙色【待发布】标签 |
| 定时发布 | 当前策略已设置定时发布任务 | 显示即将发布的版本号 | 蓝色【定时发布】标签 |

#### 状态说明补充

1. “X项变更”表示当前策略相较最近一次已发布版本的未发布变更项数量，由系统自动统计生成。
2. 首页中的版本号统一展示该策略的最新已发布版本号。
3. 若策略尚未发布任何版本，则版本号显示为【版本号：--】，状态标签显示橙色【待发布】。
4. 定时发布状态下，状态标签显示蓝色【定时发布】，鼠标悬停可查看定时发布时间。

#### 进入管理规则

1. 本期仅同步学场景下的策略支持进入管理并执行后续维护操作。
2. 同步学场景下，已发布、待发布、新增状态的策略均支持进入管理。
3. 其他场景策略卡片当前仅做展示，不作为本期维护入口。
4. 若后续版本未提供其他场景只读查看能力，则其他场景不展示可操作的【进入管理】入口；若原型阶段保留展示，则以占位展示为准，不纳入本期开发范围。

## 交互逻辑

### 1. 页面加载逻辑

1. 页面初始化后，加载首页所需基础数据，包括：
   - 筛选项数据
   - 各场景分组下的策略数据
   - 历史发布记录入口状态
2. 系统根据默认筛选条件，计算各固定场景分组下可展示的策略卡片。
3. 页面按固定顺序展示全部场景分组。
4. 每个分组内根据当前筛选结果展示策略卡片或空状态。
5. 分组标题中的策略数量按当前筛选结果实时计算。

---

### 2. 筛选交互逻辑

#### 2.1 学段切换

1. 用户切换学段后：
   - 学科选项联动更新为该学段下可选学科；
   - 页面重新按当前筛选条件计算各固定分组下的展示结果。

#### 2.2 学科切换

1. 用户切换学科后：
   - 页面重新按当前筛选条件过滤各分组下的策略卡片；
   - 固定场景分组结构不变。

#### 2.3 场景切换

1. 用户切换场景后：
   - 页面仍保留全部固定场景分组；
   - 被选中的场景分组展示符合当前条件的策略卡片；
   - 未选中的场景分组不展示策略卡片，并显示空状态。

---

### 3. 新增策略逻辑

#### 3.1 新增入口规则

1. 页面展示全部固定场景分组。
2. 本期仅支持【同步学】场景下的策略新增与维护。
3. 其他场景分组当前仅做展示，不纳入本期新增能力范围。

#### 3.2 新增操作流程

1. 用户点击【同步学】分组右上角【新增】按钮。
2. 系统进入该场景对应的新建策略页面。
3. 新建页面默认带入以下信息：
   - 当前点击的场景
   - 首页当前已选的学段
   - 首页当前已选的学科
4. 用户完成新建并返回首页后，新策略展示在【同步学】分组下。
5. 若新策略尚未发布，则首页卡片状态显示为【新增】。

#### 3.3 唯一性规则

1. 新增策略需遵循策略唯一性校验规则。
2. 同一业务主键下不允许重复新增策略。
3. 首页仅引用唯一性校验规则，具体校验口径以下游新建页规则为准。

---

### 4. 进入管理逻辑

1. 用户点击同步学场景下某策略卡片的【进入管理】按钮后，进入对应策略管理页。
2. 进入管理页后，用户可对该策略进行后续配置维护。
3. 用户从新建页或管理页返回首页后，首页需按当前筛选条件重新加载并展示最新数据。
4. 首页中策略状态、版本号、变更数量均以最新接口返回结果为准。

---

### 5. 历史发布记录逻辑

1. 用户点击页面右上角【查看历史发布记录】入口后，进入学情诊断策略的历史发布记录查看界面。
2. 历史发布记录默认展示学情诊断策略模块下的全量发布记录。
3. 首页当前筛选条件不影响历史发布记录的默认查询范围。
4. 历史发布记录仅展示已发生发布动作的版本记录，不包含未发布草稿数据。

---

## 显示说明

### 1. 分组展示说明

1. 首页固定展示全部场景分组，不因数据为空而隐藏分组。
2. 每个分组头部需展示：
   - 场景图标
   - 场景名称
   - 当前筛选结果下的策略数量
   - 新增入口（是否可用按本期范围控制）
3. 分组内容区展示当前筛选条件下的策略卡片列表。
4. 若当前分组无策略，则显示空状态文案：【暂无策略，点击“新增”添加】。

### 2. 策略卡片展示说明

1. 每张策略卡片展示策略名称、学段、学科、状态、版本号等信息。
2. 策略名称优先使用用户已配置的策略名称。
3. 学段 / 学科信息按固定格式展示，字段间以竖线分隔。
4. 已发布与待发布状态均展示最新已发布版本号。
5. 新增状态不展示正式版本号。

### 3. 顶部区域展示说明

1. 页面顶部展示返回入口、模块标题、模块说明及历史发布记录入口。
2. 顶部筛选栏固定展示学段、学科、场景三个筛选维度。
3. 页面初始化时，默认展示系统配置的默认筛选项。

---

## 操作说明

### 1. 返回操作

1. 用户点击顶部【返回】按钮后，返回上一级页面【策略广场】。
2. 若首页当前无未提交操作，则直接返回。
3. 本页面本身不承载编辑表单，不涉及未保存离开拦截。

### 2. 筛选操作

1. 用户切换任一筛选项后，页面立即按最新条件刷新各分组展示结果。
2. 筛选操作不改变固定场景分组结构。
3. 各分组中的策略数量、卡片列表、空状态需同步刷新。

### 3. 新增操作

1. 用户点击同步学分组右上角【新增】后，进入新建策略页。
2. 新建页默认带入当前筛选条件中的学段、学科。
3. 新建成功返回首页后，对应策略展示在同步学分组下。

### 4. 进入管理操作

1. 用户点击同步学策略卡片中的【进入管理】后，进入对应策略管理页。
2. 管理完成返回首页后，首页按最新数据重新展示策略状态。

### 5. 历史发布记录操作

1. 用户点击右上角【查看历史发布记录】后，进入历史发布记录查看界面。
2. 历史发布记录默认展示学情诊断策略模块下的全量已发布记录。

## 状态与异常说明

### 1. 数据状态

| 状态 | 说明 |
|------|------|
| 加载中 | 页面初次加载时，展示加载中状态 |
| 加载成功 | 页面正常展示筛选栏、固定分组及策略数据 |
| 加载失败 | 页面主数据加载失败时，展示失败提示及重试能力 |

### 2. 分组状态

| 状态 | 说明 |
|------|------|
| 分组有数据 | 展示该分组下的策略卡片 |
| 分组无数据 | 展示该分组内容区空状态文案 |
| 分组未开放维护 | 分组可展示，但不提供本期可用维护入口 |

### 3. 筛选异常

| 情况 | 处理方式 |
|------|----------|
| 筛选项加载失败 | 对应筛选组件不可用，并提示加载失败 |
| 筛选后某分组无数据 | 保留分组容器，在内容区展示空状态 |
| 筛选后全部分组均无数据 | 仍展示全部固定场景分组，每个分组展示空状态 |

### 4. 跳转异常

| 情况 | 处理方式 |
|------|----------|
| 点击新增校验失败 | 提示失败原因，停留当前页 |
| 点击进入管理失败 | 提示失败原因，停留当前页 |
| 历史发布记录加载失败 | 提示失败原因，并支持重试 |

### 5. 刷新回显规则

1. 用户从新建页或管理页返回首页后，首页按当前筛选条件重新拉取并展示最新数据。
2. 首页中的策略状态、版本号、变更数量均以最新接口返回结果为准。
3. 若策略状态已发生变化，首页需同步回显最新状态，不允许沿用本地旧状态。

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 页面下暂无任何策略数据 | 仍展示全部固定场景分组，每个分组显示空状态 |
| 某场景分组暂无策略 | 保留该分组，并显示【暂无策略，点击“新增”添加】 |
| 场景筛选为全部 | 全部固定场景分组正常展示 |
| 场景筛选为具体场景 | 仍展示全部固定场景分组；选中场景展示数据，其余分组显示空状态 |
| 同步学无策略 | 分组保留，支持点击【新增】创建首个策略 |
| 非同步学有历史策略但本期不维护 | 卡片可展示，但不纳入本期维护流程 |
| 新增策略尚未发布 | 首页卡片状态显示为【新增】 |
| 已发布策略存在未发布修改 | 首页卡片状态显示为【待发布·X项变更】 |
| 页面重新进入 | 按系统默认值或最近保留的筛选条件重新加载页面数据，具体以下游统一规范为准 |

## 数据与字段要求

### 0. 筛选项数据来源

| 筛选项 | 数据来源 | 说明 |

| 场景 | 系统配置 | 固定场景列表，由系统配置定义 |

| 学段 | 用于筛选与展示 |
| 学科 | 用于筛选与展示 |
| 最新已发布版本号 | 用于卡片版本号展示 |
| 当前状态 | 用于展示已发布 / 待发布 / 新增 |

### 2. 历史发布记录所需核心字段

| 字段 | 说明 |
|------|------|

| 策略名称 | 发布记录对应策略名称 |
| 场景 | 发布记录所属场景 |
| 发布版本号 | 本次发布版本号 |
| 发布时间 | 发布时间 |
| 发布人 | 执行发布的操作人 |

## 权限与范围说明

1. 当前页面面向具备学情诊断策略查看权限的后台用户开放。
2. 本期仅同步学场景纳入维护范围。
3. 其他场景当前仅作为固定分组展示，不作为本期新增与维护能力入口。
4. 若后续版本扩展到其他场景，沿用当前首页固定分组结构及状态展示逻辑。
