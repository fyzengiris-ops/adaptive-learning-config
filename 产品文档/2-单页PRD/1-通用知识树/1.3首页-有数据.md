# 1.3 首页-有数据【GPT更新】

# 页面目标
用于展示通用知识树模块下当前学段已建立的学科目录，支持学段切换、查看全模块历史发布记录、新增学科，以及进入对应学科的知识树管理页，帮助用户快速了解各学科知识树的建设情况、发布状态和维护进度。

# 所属页面
知识体系管理 > 通用知识树

# 页面区域

## A. 知识树类型切换区
用于在知识体系管理模块下切换不同知识树类型，包括【通用知识树】【教材体系知识树】【专题体系知识树】。

## B. 学段筛选与历史记录区
用于切换当前查看的学段，并提供【查看历史发布记录】入口。

## C. 学科统计与操作区
用于展示当前学段下已建立学科目录的数量，并提供【新增学科】入口。

## D. 学科卡片列表区
用于以卡片形式展示当前学段下已建立的学科目录，每个卡片展示学科基础信息、发布状态、统计信息及主操作入口。

# 组件说明

## A. 知识树类型切换区组件
- A1. 知识树类型Tab：显示【通用知识树】【教材体系知识树】【专题体系知识树】三个切换项
- A2. 当前选中态：当前所在类型高亮显示
- A3. 切换入口：点击不同知识树类型后，进入对应类型首页

## B. 学段筛选与历史记录区组件
- B1. 学段Tab按钮组：横向显示【高中】【初中】【小学】三个学段
- B2. 当前选中态：当前选中学段高亮显示
- B3. 查看历史发布记录入口：点击后进入通用知识树历史发布记录页面

## C. 学科统计与操作区组件
- C1. 学科数量统计：显示当前学段下已建立的学科目录数量，格式为【共 X 个学科】
- C2. 新增学科按钮：显示【+ 新增学科】，用于新增当前学段下的学科目录

## D. 学科卡片列表区组件
- D1. 学科卡片：用于展示单个学科目录信息
- D2. 学科图标：根据不同学科显示对应图标
- D3. 学科名称：显示当前学科名称
- D4. 学段与版本信息：显示当前学科所属学段及最近一次已发布版本号
- D5. 发布状态标记：位于卡片右上角，显示当前学科的发布状态
  - 已发布：显示【已发布】
  - 待发布：显示【待发布 · X项变更】
- D6. 知识点总数：显示当前学科知识树下的知识点总数
- D7. 最近更新时间：显示当前学科最近一次内容修改时间
- D8. 进入管理按钮：显示【进入管理】，用于进入当前学科的知识树详情管理页

# 交互逻辑

## 1. 页面初始化
- 1.1、页面首次进入时，默认选中第一个学段【高中】
- 1.2、默认进入【通用知识树】首页
- 1.3、系统加载当前学段下已建立的学科目录列表及学科数量统计信息

## 2. 切换知识树类型
- 2.1、点击【教材体系知识树】或【专题体系知识树】Tab后，进入对应知识树类型首页
- 2.2、点击【通用知识树】Tab时，停留或返回当前页面
- 2.3、切换知识树类型后，不保留当前页面的学科卡片选中状态

## 3. 切换学段Tab
- 3.1、点击【高中】【初中】【小学】任一学段Tab后，切换当前查看学段
- 3.2、切换后刷新当前学段下的学科数量统计和学科卡片列表
- 3.3、切换后，【查看历史发布记录】入口继续保留

## 4. 查看历史发布记录
- 4.1、点击【查看历史发布记录】后，进入通用知识树历史发布记录页面
- 4.2、目标页面展示通用知识树模块下全部学段的历史发布记录

## 5. 新增学科
- 5.1、点击【新增学科】按钮后，弹出【新增学科】弹窗
- 5.2、弹窗默认带入当前选中的学段
- 5.3、新增成功后，刷新当前学段下的学科数量统计和学科卡片列表

## 6. 进入学科管理
- 6.1、点击学科卡片内的【进入管理】按钮后，进入该学科的知识树详情管理页
- 6.2、仅【进入管理】按钮可点击进入详情页，学科卡片其他区域不可点击
- 6.3、进入详情页后，页面上下文切换为当前学科的知识树维护内容

## 7. 学科卡片悬停效果
- 7.1、鼠标悬停学科卡片时，卡片边框高亮显示
- 7.2、卡片阴影增强，突出可操作感
- 7.3、【进入管理】按钮保持主操作入口的视觉强调

# 业务规则

## 一、学段规则
1. 通用知识树首页固定支持【高中】【初中】【小学】三个学段
2. 页面默认选中第一个学段【高中】
3. 学段切换仅影响当前页面展示的学科数量统计和学科卡片列表
4. 学段本身为固定范围，不支持用户自定义新增、删除或编辑

## 二、学科来源与展示规则
1. 当前页面展示的学科，来源于平台中当前学段已有学科与通用知识树已建立目录数据的交集
2. 页面仅展示当前学段下已在通用知识树中建立目录的学科
3. 学科列表不采用固定写死枚举，具体学科以平台当前学段已有学科数据为准
4. 学科卡片需展示学科图标、学科名称、所属学段、版本号、知识点总数、最近更新时间和发布状态

## 三、学科排序规则
1. 学科卡片列表按学科 ID 升序展示
2. 学科排序沿用乐课网原有的学科 ID 排序逻辑
3. 学科排序仅影响当前学段下通用知识树首页的展示顺序，不影响平台其他模块的学科顺序

## 四、学科数量统计规则
1. 学科数量统计口径为：当前选中学段下，已在通用知识树中建立目录的学科数量
2. 新增学科成功后，学科数量需实时刷新

## 五、知识点总数与更新时间规则
1. 知识点总数显示当前学科知识树下的知识点总数量
2. 最近更新时间显示当前学科最近一次内容修改时间
3. 最近更新时间统计口径为内容最近一次变更时间，不等同于最近发布时间
4. 当知识点总数或更新时间数据异常缺失时，页面需展示兜底值，避免卡片区域空白

## 六、发布状态规则
1. 学科卡片需展示当前学科的发布状态
2. 当该学科不存在未发布变更时，显示【已发布】
3. 当该学科存在未发布变更时，显示【待发布 · X项变更】
4. X的计算规则：
   - X 表示有变更的知识点数量，按知识点维度聚合
   - 同一知识点的多次变更仅计1项
   - 变更类型包括：知识点基础信息变更、前后置关系变更、高频信息变更、出题策略信息变更、绑定视频资源变更
5. X的显示规则：
   - X ≤ 99 时，显示实际数值，如【待发布 · 5项变更】
   - X > 99 时，显示【待发布 · 99+项变更】
6. 点击【待发布 · X项变更】标签时，不触发跳转，仅作为状态展示
7. 学科卡片中展示的版本号为当前学科最近一次已发布版本号
8. 若学科尚未完成首次发布，则版本号展示为空或展示兜底值【--】
9. 乐课网历史知识点数据同步到新功能后，新功能的状态显示为【已发布】

## 七、权限规则
1. 仅教研主管可新增学科目录
2. 教研主管可见并可点击【新增学科】按钮
3. 教研员不可见【新增学科】按钮
4. 教研主管与教研员均可查看首页学科列表
5. 教研主管与教研员均可点击【进入管理】进入学科详情页
6. 进入学科详情页后的具体编辑权限，由详情页权限规则继续控制
7. 【新增学科】相关接口需进行服务端权限校验，前端按钮显隐不作为唯一权限控制手段

## 八、历史发布记录规则
1. 首页中的【查看历史发布记录】入口，查看范围为通用知识树模块下全部学段的历史发布记录
2. 历史发布记录以独立页面承载，不在首页中以弹窗形式展示
3. 首页仅提供跳转入口，不承载历史发布记录明细内容

## 九、新旧功能数据互通规则
1. 通用知识树首页展示的数据，需与历史已有功能及本期新功能保持统一数据口径
2. 历史功能中对通用知识树相关数据的变更，需同步影响首页展示结果
3. 本期新功能中对通用知识树相关数据的变更，亦需同步影响历史功能展示结果
4. 首页学科卡片中的知识点总数、最近更新时间、发布状态、版本信息等数据，需基于统一主数据源或同步后的一致数据结果展示
5. 不允许出现历史功能与新功能展示口径不一致、数据不同步的情况

# 状态与异常

## 页面状态
- 页面首次加载状态：页面初始化时加载当前默认学段下的学科数量和学科列表
- 学段切换加载状态：切换学段后，列表区域进入加载中状态
- 有数据展示状态：显示当前学段下的学科卡片列表
- 待发布状态：学科卡片右上角显示【待发布 · X项变更】
- 已发布状态：学科卡片右上角显示【已发布】
- 无新增权限状态：页面正常展示列表，但不显示【新增学科】按钮

## 异常与边界
- 当前学段无学科数据时：显示空状态页面，并提供对应引导
- 学科列表加载失败时：显示加载失败提示，并支持重试
- 网络异常时：提示【网络异常，请稍后重试】
- 学科统计信息异常时：页面需展示兜底值，避免信息缺失导致布局错乱
- 学科更新时间缺失时：显示【--】
- 学科版本号缺失时：显示【--】
- 新旧功能数据同步异常时：首页不应展示不一致结果，需按统一失败处理策略进行拦截或兜底提示
- 用户无新增权限时：不展示【新增学科】按钮，但不影响查看列表及进入详情页
- 点击【查看历史发布记录】后，若目标页面加载失败，需在目标页提供失败提示及重试机制

| 学科知识点统计数据 | 通用知识树统计数据 | 显示知识点总数 |

| 学科版本信息 | 发布记录数据 | 显示最近一次已发布版本号 |

# 技术要求

- 页面需支持按学段切换数据展示，切换时无整页刷新
- 学科卡片列表需支持按排序字段稳定展示
- 首页展示数据需基于统一主数据源或同步后的一致数据结果，不允许新旧功能展示口径分裂
- 权限控制需同时覆盖前端展示控制与后端接口校验
- 学科卡片信息需采用聚合数据结构返回，避免前端多接口分散拼装导致状态不一致
- 页面需支持加载态、失败态、空态和正常态切换
- 历史发布记录入口需跳转至独立页面，不在当前页以内嵌弹窗承载
- 页面视觉上需突出当前选中学段、当前知识树类型及学科卡片主操作入口
