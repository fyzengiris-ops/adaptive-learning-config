# 2.2 详情页-查看通用策略详情【codex更新】

## 1. 页面概述

### 页面目标

用于查看已有【通用策略】的完整配置内容。

用户可在查看态下查看基础信息、掌握度区间、题目组成配置、当前版本和发布状态，并可进行编辑、发布、取消定时、删除和查看历史发布记录等操作。

### 所属页面

策略管理 > 策略广场 > 单知识点出题 > 通用策略详情 > 查看态

---

## 2. 页面结构

页面由以下区域组成：

1. 页面头部区
2. 状态提示区
3. 基础信息区
4. 题目组成配置区
5. 底部操作区

---

## 3. 页面头部区

### 3.1 返回入口

点击【返回】后返回上一页。

规则：

1. 从首页进入详情页时，返回首页后保留进入详情页前的类型、学段、学科筛选条件。
2. 查看态不存在未保存内容，返回时不弹出确认提示。

### 3.2 页面标题

展示：

通用策略详情

### 3.3 版本号

展示当前已发布版本号。

格式示例：

版本：v1.2

规则：

1. 已发布状态下，展示当前已发布版本号。
2. 待发布状态下，仍展示当前已发布版本号。
3. 编辑保存后版本号不自动递增。
4. 仅正式发布后生成并展示新版本号。

### 3.4 历史发布记录入口

页面头部右侧展示历史发布记录入口。

点击后打开当前策略的历史发布记录弹窗。

规则：

1. 历史发布记录入口始终展示。
2. 即使当前策略暂无历史发布记录，也可点击打开弹窗。
3. 无历史记录时，弹窗展示空状态。

---

## 4. 状态提示区

状态提示区根据策略状态展示。

### 4.1 已发布状态

已发布状态不展示状态提示条。

页面仅通过头部版本号展示当前已发布版本。

### 4.2 待发布状态

当策略存在未发布变更时，展示待发布提示条。

提示文案：

新增策略，需要发布后才能生效

右侧操作：

发布

点击【发布】后，打开发布确认弹窗，对应 2.4 页面。

### 4.3 定时发布状态

当策略已设置定时发布时，展示定时发布提示条。

提示文案：

vX.X 版本将于 YYYY-MM-DD HH:mm 自动发布

右侧操作：

取消定时

点击【取消定时】后，弹出确认弹窗。

确认后：

1. 取消定时发布。
2. 策略状态切换为待发布。
3. 页面展示待发布提示条。
4. 待发布提示条右侧展示【发布】按钮。

### 4.4 草稿状态

如策略存在草稿状态，页面仍可查看策略内容，并展示编辑和删除操作。

草稿状态不展示【发布】按钮。

---

## 5. 基础信息区

### 5.1 区域标题

展示：

基础信息

### 5.2 学段

只读展示策略所属学段。

示例：

高中

### 5.3 学科

只读展示策略所属学科。

示例：

数学

说明：

查看态下，学段和学科均不可编辑，不展示下拉控件。

---

## 6. 题目组成配置区

### 6.1 区域标题

展示：

题目组成配置

### 6.2 只读展示规则

查看态下，题目组成配置仅支持查看。

不展示以下编辑入口：

- 添加区间
- 删除区间
- 添加题型
- 删除题目配置
- 输入框
- 下拉选择控件

### 6.3 掌握度区间展示

每个掌握度区间展示：

- 掌握度范围
- 区间题量汇总
- 题目配置明细

掌握度范围格式：

0% — 40%

区间题量汇总格式：

共 X 题

计算规则：

该区间下所有题目配置行的题量之和。

### 6.4 题目配置明细

每条题目配置展示：

- 题型
- 题量
- 题目难度分布
- 题目来源
- 知识点复合度

题目难度分布按 UI 稿展示为：

- 易
- 较易
- 中
- 较难
- 难

题目来源展示规则：

1. 已配置题目来源时，以标签形式展示。
2. 题目来源为空时，展示【未配置】。
3. 题目来源为空不影响查看态展示。

知识点复合度展示：

- 单一知识点
- 非单一知识点

### 6.5 无掌握度区间

当策略无任何掌握度区间时，题目组成配置区展示空状态。

空状态文案：

暂无掌握度区间配置

规则：

1. 不展示表格。
2. 仍展示底部【编辑】按钮。
3. 用户可点击【编辑】进入编辑态后重新添加区间。

---

## 7. 底部操作区

查看态底部展示主要操作按钮。

按钮位置以 UI 稿为准：

- 删除：位于底部左侧
- 编辑：位于底部右侧

### 7.1 编辑

所有策略状态下均展示【编辑】按钮。

点击后进入编辑态，对应 2.1 页面。

进入编辑态后：

1. 学段和学科仍为只读。
2. 题目组成配置可编辑。
3. 若存在待发布配置，编辑态加载最新待发布配置。
4. 若不存在待发布配置，编辑态加载当前已发布配置。

### 7.2 删除

所有策略状态下均展示【删除】按钮。

点击后弹出删除确认弹窗。

删除弹窗保留当前代码设计效果：

1. 仅展示一个删除确认弹窗。
2. 展示下游影响警告。
3. 不增加二次确认。
4. 不要求输入策略名称。

确认删除后：

1. 删除整个策略。
2. 已发布版本和待发布变更一并删除。
3. 删除不可恢复。
4. 删除成功后返回首页。
5. 首页列表中不再展示该策略。
6. 下游业务立即无法获取该通用策略。
7. 返回首页后展示删除成功提示。

---

## 8. 发布操作

### 8.1 发布入口

仅待发布状态展示【发布】按钮。

已发布状态不展示【发布】按钮。

定时发布状态不展示【发布】按钮，仅展示【取消定时】按钮。

### 8.2 点击发布

点击【发布】后，打开发布确认弹窗。

具体发布方式、立即发布或定时发布规则，由 2.4 页面定义。

---

## 9. 历史发布记录

### 9.1 弹窗范围

详情页历史发布记录弹窗仅展示当前策略的发布记录。

与首页历史发布记录弹窗不同：

- 首页弹窗展示单知识点出题模块下所有策略的发布记录。
- 详情页弹窗只展示当前策略的发布记录。

### 9.2 筛选与搜索

详情页历史发布记录弹窗保留筛选和搜索能力。

规则：

1. 筛选条件锁定为当前策略范围。
2. 用户不能通过筛选切换到其他策略的历史记录。
3. 关键词搜索可用于查找当前策略下的历史发布记录。

### 9.3 无历史记录

当前策略无历史发布记录时，弹窗展示空状态。

---

## 10. 策略不存在

### 10.1 URL 中策略 ID 不存在

当用户通过 URL 直接访问不存在的策略 ID 时，页面展示 404 状态。

展示内容：

- 策略不存在
- 返回首页按钮

点击【返回首页】后，回到首页。

### 10.2 查看过程中策略被他人删除

如果用户正在查看策略详情时，该策略被其他用户删除：

1. 页面保持当前数据展示不变。
2. 不提前展示删除提示。
3. 用户执行编辑、发布、删除、取消定时操作时，提示【该策略不存在或已被删除】。
4. 提示后提供返回首页入口。

说明：

历史发布记录为只读入口，不纳入该操作拦截范围。

---

## 11. 页面加载

### 11.1 加载中

进入详情页时，页面展示加载态，待策略详情加载完成后展示内容。

加载态表现以 UI 稿为准，可使用骨架屏或局部加载状态。

### 11.2 数据加载失败

数据加载失败不作为正常用户状态定义。

若出现详情数据加载失败，视为异常缺陷处理，不在页面中展示空壳详情页。

---

## 12. 页面状态汇总

### 12.1 已发布

展示内容：

- 页面详情内容
- 当前已发布版本号
- 历史发布记录入口
- 删除按钮
- 编辑按钮

不展示：

- 状态提示条
- 发布按钮

### 12.2 待发布

展示内容：

- 页面详情内容
- 当前已发布版本号
- 待发布提示条
- 发布按钮
- 历史发布记录入口
- 删除按钮
- 编辑按钮

### 12.3 定时发布

展示内容：

- 页面详情内容
- 当前已发布版本号
- 定时发布提示条
- 取消定时按钮
- 历史发布记录入口
- 删除按钮
- 编辑按钮

### 12.4 策略不存在

展示 404 状态和返回首页按钮。

---

## 13. 测试关注点

### 13.1 页面进入

1. 从首页点击【进入管理】后，进入通用策略查看态。
2. 页面展示策略基础信息和题目组成配置。
3. 页面加载中展示加载态。
4. URL 中策略 ID 不存在时，展示【策略不存在】和返回首页按钮。
5. 详情数据加载失败视为异常缺陷，不展示空壳页面。

### 13.2 头部与返回

1. 页面标题展示【通用策略详情】。
2. 头部展示当前已发布版本号。
3. 待发布状态下，版本号仍展示当前已发布版本。
4. 点击返回后，回到首页并保留进入详情页前的筛选条件。

### 13.3 状态提示

1. 已发布状态不展示状态提示条。
2. 待发布状态展示待发布提示条和【发布】按钮。
3. 定时发布状态展示定时发布提示条和【取消定时】按钮。
4. 点击【取消定时】后弹出确认弹窗。
5. 取消定时成功后，页面切换为待发布状态并展示【发布】按钮。

### 13.4 查看内容

1. 学段、学科为纯文本展示。
2. 掌握度区间为只读展示。
3. 题目配置为只读展示。
4. 不展示新增、删除、输入和下拉编辑控件。
5. 每个区间展示【共 X 题】。
6. 题目来源为空时展示【未配置】。
7. 无掌握度区间时展示【暂无掌握度区间配置】。

### 13.5 操作按钮

1. 所有状态下均展示【编辑】按钮。
2. 所有状态下均展示【删除】按钮。
3. 删除按钮位于底部左侧。
4. 编辑按钮位于底部右侧。
5. 点击【编辑】进入编辑态。
6. 无掌握度区间时仍允许点击【编辑】。

### 13.6 发布与删除

1. 仅待发布状态展示【发布】按钮。
2. 点击【发布】打开 2.4 发布确认弹窗。
3. 点击【删除】弹出删除确认弹窗。
4. 删除确认弹窗保留当前代码设计效果。
5. 删除成功后返回首页。
6. 删除成功后首页不再展示该策略。
7. 删除成功后展示删除成功提示。
8. 删除后下游业务立即无法获取该通用策略。

### 13.7 历史发布记录

1. 历史发布记录入口始终展示。
2. 无历史记录时也可打开弹窗。
3. 详情页历史记录仅展示当前策略记录。
4. 弹窗保留筛选和搜索能力。
5. 筛选条件锁定为当前策略范围，不能切换到其他策略。

### 13.8 被他人删除

1. 查看过程中策略被他人删除时，页面保持当前数据展示。
2. 不提前展示删除提示。
3. 点击编辑、发布、删除、取消定时时，提示【该策略不存在或已被删除】。
4. 提示后提供返回首页入口。
