# 2.05 详情页-编辑态-同步课程展示【GPT更新】

# 页面目标
用于在【教材体系知识树】教材详情页编辑态下，查看和维护当前节点对应的同步课程内容。

本页面需支持：
- 基于当前节点是否为末级节点，切换不同的展示与维护模式；
- 末级节点下直接维护同步课程；
- 非末级节点下聚合查看其所有子节点的同步课程内容；
- 支持上传课程、从资源库选择课程、预览课程、移除课程等能力。

> 说明：
> 1. 当前页面是否可直接维护同步课程，不仅取决于是否处于编辑态，还取决于当前节点是否为末级节点。
> 2. 仅在【编辑态 + 当前节点为末级节点】时，才支持直接维护同步课程。
> 3. 非末级节点仅支持查看当前节点下各子节点聚合后的同步课程内容，不支持直接维护当前节点同步课程。
> 4. 课程预览能力对末级节点和非末级节点均生效。
> 5. 从资源库选择课程的独立弹窗，后续有单独页面说明，当前页仅保留入口与联动规则，不展开其内部细节。

# 页面区域

## A. 标题行区
用于固定显示【章节详情】标题，右侧显示操作按钮。

## B. 章节名称行区
用于显示当前选中章节路径名称和 Tab 切换栏。

## C. 同步课程操作栏区
用于展示当前同步课程区域标题、数量、上传课程入口、从资源库选择入口等操作信息。

## D. 同步课程内容展示区
用于根据当前节点是否为末级节点，展示不同形态的同步课程内容。

## E. 课程预览区
点击预览入口时，用乐课网原本预览视频的组件，新开页预览视频。

# 组件说明

## A. 标题行区组件
- A1. 标题文本：固定显示【章节详情】
- A2. 操作按钮区（编辑态下显示）：
  - 【批量导入】按钮：点击打开批量导入弹窗
  - 【取消】按钮：取消编辑，返回非编辑态
  - 【保存编辑】按钮：保存当前编辑结果，返回非编辑态

## B. 章节名称行区组件
- B1. 章节路径名称：显示当前选中章节的完整路径
  - 章级别：显示完整章名称
  - 节级别：显示"章序号-节名称"格式
- B2. Tab 切换栏：包含【知识点】【同步课程】【练习试卷】三个 Tab
- B3. 分割线：章节名称行底部带分割线

## C. 同步课程操作栏区组件
- C1. 区域标题：
  - 非末级节点时显示【同步课程总览】+ 附注——若当前定位到大的章节，则显示「（聚合展示该章节下所有节关联的课程）」；若当前定位到非大的章节也非末级小节，则显示「（聚合展示该节下所有子节关联的课程）」
  - 末级节点时显示【关联同步课程】+ 课程数量「（N个）」
- C2. 数量展示：
  - 非末级节点时显示各子节点对应的课程数量
  - 末级节点有数据时显示当前节点课程数量
- C3. 【上传课程】按钮：仅在末级节点编辑态下显示
- C4. 【从资源库选择】按钮：仅在末级节点编辑态下显示

## D. 同步课程内容展示区组件
### D1. 非末级节点展示组件
- 按子节点分组展示同步课程内容
- 每个子节点块包含：
  - 子节点标题 + 该子节点关联的节点数量，含X小节
  - 子节点课程数量（如有）
  - 子节点课程列表或空态提示
- 课程卡片样式与末级节点详情态完全一致，采用统一renderCourseCard渲染函数，showRemove=false不展示移除按钮

### D2. 末级节点无数据组件
- 空状态图标（Video图标，灰色）
- 空状态标题：显示【暂未关联同步课程】
- 编辑态下额外显示引导文案：【点击上方按钮添加同步课程】
- 空态区域样式：居中布局，灰色虚线边框（border-dashed border-gray-300），灰色浅背景（bg-gray-50），py-8内间距

### D3. 末级节点有数据组件
- 课程卡片（与2.00非编辑态样式完全一致，采用统一renderCourseCard渲染函数，showRemove=true）：
  - 课程图标（蓝色圆角背景，40×40px，内嵌白色Video图标）
  - 课程名称（超长截断）
  - 来源标签（本地上传=蓝色标签/资源库=绿色标签，缺失不展示）
  - 时长（Clock图标+时长文字，缺失显示--）
  - 视频大小
  - 教师信息（上传该视频的账号的教师名称，有值展示无值隐藏）
  - 预览按钮（Play图标，hover蓝色高亮）
  - 移除按钮（X图标，hover红色高亮，仅编辑态+末级节点展示）
- 卡片统一样式：蓝色浅色背景（bg-blue-50）+蓝色边框（border-blue-200）+圆角（rounded-lg），内间距p-3，元素间距gap-3
- 每个课程独立一张卡片展示

## D. 视频预览说明
- D1. 点击预览按钮，用乐课网原本预览视频的组件，新开页预览视频

## F. 删除视频资源弹窗组件
- F1. 弹窗容器：标题「请选择视频资源删除方式」，宽度400px左右，居中显示
- F2. 选项1（默认选中）：仅配置后台删除

  - 选项标题：「仅配置后台删除」
  - 选项描述：「只删除视频资源在配置后台与当前小节的绑定关系」
  - 悬浮样式：蓝色边框+浅蓝背景
- F3. 选项2：全网删除
  - 单选按钮（红色accent）
  - 选项标题：「全网删除」（红色文字）
  - 选项描述：「删除后，全网将不可查看该视频」
  - 悬浮样式：红色边框+浅红背景
- F4. 取消按钮：灰色边框样式，点击关闭弹窗不执行删除
- F5. 确认按钮：颜色随选项变化
  - 选择选项1时：蓝色样式
  - 选择选项2时：红色样式（强调危险操作）
- F6. 遮罩层：半透明黑色背景，点击遮罩层不关闭弹窗

# 交互逻辑

## 1. 切换 Tab
- 用户点击【同步课程】Tab 后：
  - 系统切换到同步课程Tab内容区域
  - 当前选中节点保持不变
  - 页面不刷新，仅内容区域切换

## 2. 页面进入同步课程Tab
- 当用户进入同步课程Tab时，系统先判断当前节点是否为末级节点
- 若当前节点为非末级节点：
  - 进入聚合查看态
- 若当前节点为末级节点：
  - 进入直接维护态

## 3. 非末级节点展示
- 当当前节点为非末级节点时：
  - 右侧显示【同步课程总览】
  - 说明文案为【聚合展示该章节下所有有关联的课程】
  - 按当前节点下各子节点逐项展示课程内容
- 若某子节点下有课程：
  - 展示该子节点下的课程列表
- 若某子节点下无课程：
  - 展示【暂无课程】

## 4. 末级节点无数据展示
- 当当前节点为末级节点且无同步课程时：
  - 显示空状态
  - 展示【上传课程】按钮
  - 展示【从资源库选择】按钮
  - 不展示课程列表

## 5. 末级节点有数据展示
- 当当前节点为末级节点且已有同步课程时：
  - 展示【关联同步课程】标题与课程数量
  - 展示课程列表
  - 展示【上传课程】按钮
  - 展示【从资源库选择】按钮

## 6. 上传课程
- 仅在【编辑态 + 当前节点为末级节点】时，用户可点击【上传课程】按钮
- 点击后：
  - 打开文件选择器
  - 用户选择本地视频文件
  - 上传成功后，将课程添加到当前节点同步课程列表
  - 页面刷新为末级节点有数据展示态
- 上传后的课程来源标记为【本地上传】

## 7. 从资源库选择课程
- 仅在【编辑态 + 当前节点为末级节点】时，用户可点击【从资源库选择】按钮
- 点击后：
  - 打开资源库选课弹窗
  - 用户可浏览、搜索、选择课程
  - 已选课程不可重复添加
  - 点击弹窗确认后，将选中的课程写入当前节点同步课程结果
  - 页面刷新为末级节点有数据展示态
- 从资源库引用的课程来源标记为【资源库】

## 8. 预览课程
- 末级节点和非末级节点中的课程卡片均支持预览
- 用户点击课程卡片中的预览入口后：
  - 用乐课网原本预览视频的组件，新开页预览视频
  - 弹窗中展示课程名称、时长、视频预览区
- 用户点击关闭按钮或底部【关闭】按钮后：
  - 关闭新开预览页面

## 9. 移除课程
- 仅在【编辑态 + 当前节点为末级节点】时，课程卡片显示移除按钮（X图标）
- 用户点击移除按钮后，可直接将视频删除，无二次弹窗确认
  - 用户点击「取消」后关闭弹窗，不执行删除操作
  - 若移除后当前节点下无课程，则切换为末级节点无数据展示态
- 删除操作即时生效于编辑结果，记录编辑变更

## 10. 目录结构变化后的联动
- 若当前节点因左侧目录结构变化，由末级节点变为非末级节点：
  - 当前页立即切换为非末级节点聚合查看态
  - 原有直接维护态退出
  - 后续按子节点聚合内容展示
- 若当前节点仍保持末级节点：
  - 继续展示末级节点维护态

# 业务规则

## 一、节点类型判断规则
1. 当前页面展示与维护能力，优先依据当前节点是否为末级节点判断。
2. 末级节点支持直接维护同步课程。
3. 非末级节点不支持直接维护同步课程，仅支持查看聚合内容。
4. 编辑态不等于所有节点都可直接维护同步课程，必须同时满足【当前节点为末级节点】。

## 二、四类页面状态规则
1. 末级节点 + 无数据：
   - 展示【关联同步课程】
   - 展示空状态
   - 展示【上传课程】和【从资源库选择】按钮

2. 末级节点 + 有数据：
   - 展示【关联同步课程】
   - 展示课程数量
   - 展示课程列表
   - 展示【上传课程】和【从资源库选择】按钮

3. 非末级节点 + 无数据：
   - 展示【同步课程总览】
   - 按子节点逐项展示
   - 各子节点下显示【暂无课程】

4. 非末级节点 + 有数据：
   - 展示【同步课程总览】
   - 按子节点逐项展示
   - 有课程的子节点展示课程列表
   - 无课程的子节点展示【暂无课程】

## 三、非末级节点展示规则
1. 非末级节点同步课程页统一按“当前节点下各子节点内容总览”方式呈现。
2. 展示结构与当前章节下查看各小节同步课程内容的样式保持一致。
3. 每个子节点独立展示自己的标题、数量和课程列表 / 空态（空态文案：「暂无课程」）。
4. 非末级节点状态下，不展示【上传课程】按钮。
5. 非末级节点状态下，不展示【从资源库选择】按钮。
6. 非末级节点状态下，仅支持查看课程聚合结果，不支持直接维护当前节点课程。
7. 非末级节点下的课程卡片不展示移除按钮（showRemove=false）。

## 四、末级节点展示规则
1. 当前节点为末级节点时，右侧展示【关联同步课程】。
2. 末级节点无数据时：
   - 展示空状态
   - 展示【上传课程】按钮
   - 展示【从资源库选择】按钮
3. 末级节点有数据时：
   - 展示课程数量
   - 展示课程列表
   - 展示【上传课程】按钮
   - 展示【从资源库选择】按钮
4. 末级节点编辑态下，课程卡片展示移除按钮（showRemove=true），点击可移除课程关联。

## 五、课程来源规则
1. 同步课程分为两种来源：
   - 本地上传
   - 资源库
2. 本地上传课程显示【本地上传】标签（蓝色标签）。
3. 资源库课程显示【资源库】标签（绿色标签）。
4. 来源标签缺失时不展示。
5. 所有课程卡片字段统一展示，不因来源不同而区分字段：
   - 课程名称（通用展示字段）
   - 时长（Clock图标+时长文字，缺失显示--）
   - 视频大小（有值展示，无值隐藏）
   - 教师信息（上传该视频的账号的教师名称，有值展示，无值隐藏）
   - 预览按钮（对所有来源课程均生效）
   - 移除按钮（仅末级节点编辑态下展示）

## 六、上传规则
1. 上传课程仅适用于末级节点。
2. 上传课程仅在编辑态下可用。
3. 用户上传成功后，课程写入当前节点同步课程列表。
4. 上传课程页面当前不强制展开独立上传进度区样式，若存在上传中反馈，以后续单独设计为准。

## 七、资源库选择规则
1. 从资源库选择课程仅适用于末级节点。
2. 从资源库选择课程仅在编辑态下可用。
3. 已选中的课程不可重复添加。
4. 资源库选课弹窗的内部结构和详细交互，后续由独立页面说明。
5. 当前页面仅保留资源库选课入口及结果回写规则。

## 八、预览规则
1. 同步课程预览能力对末级节点和非末级节点均生效。
2. 只要页面中存在课程卡片，用户都可点击预览入口，用乐课网原本预览视频的组件，新开页预览视频。
3. 课程预览属于查看能力，不受是否为末级节点限制。
4. 课程预览使用乐课网原有组件在新页面中打开。

## 九、移除规则
1. 移除课程仅适用于末级节点编辑态。
2. 点击移除按钮（X图标）后，可直接将视频删除，无二次弹窗确认。
3. 删除操作即时生效于编辑结果，记录编辑变更。
4. 在编辑状态下，在【关联同步课程】字段的后面，显示固定的静态提示文案——删除视频，仅代表在当前页面解除关联关系，不影响原视频在资源库中的存在。

## 十、与目录结构联动规则
1. 左侧目录结构变化会影响当前页面的展示与维护能力。
2. 当当前节点由末级节点变为非末级节点后：
   - 右侧退出直接维护态
   - 切换为聚合查看态
3. 当当前节点重新成为末级节点时，才恢复直接维护能力。

## 十一、页面范围规则
1. 当前页面仅用于维护当前节点与同步课程的关联关系。
2. 当前页面不负责课程资源库本体的完整管理。
3. 资源库课程选择属于引用 / 关联能力。
4. 当前页中的移除动作默认弹出删除确认弹窗，用户选择删除方式后确认执行；选择「仅配置后台删除」时仅作用于关联关系，选择「全网删除」时同时删除课程实体。

## 十二、权限规则
1. 仅在编辑态下才可能进入同步课程直接维护能力。
2. 即使处于编辑态，也只有末级节点可直接维护同步课程。
3. 无编辑权限的角色不可执行上传、引用、移除等操作。
4. 课程预览为查看能力，不受是否具有编辑权限限制。

# 状态与异常

## 页面状态
- 非末级节点聚合查看态
- 末级节点无数据态
- 末级节点有数据态
- 课程预览（新开页）
- 删除视频资源弹窗打开态：弹窗打开时显示删除方式选择，默认选中「仅配置后台删除」

## 异常与边界
1. **无关联课程**
   - 末级节点无课程时，显示空状态提示

2. **聚合无数据**
   - 非末级节点下若子节点均无课程，则各子节点下展示【暂无课程】

3. **课程加载失败**
   - 课程数据加载失败时，提示加载失败并支持重试

4. **预览数据加载失败**
   - 课程预览失败时，提示加载失败，不影响课程列表查看

5. **重复引用资源库课程**
   - 若用户尝试重复添加当前节点已关联课程，应阻断并提示不可重复添加

6. **上传失败**
   - 本地课程上传失败时，应提示上传失败，并保留当前页面状态

7. **保存失败**
   - 新增、移除课程保存失败时，应提示失败，并保留当前页面可恢复状态，具体以后续实现拍板为准

8. **全网删除视频资源**
   - 选择「全网删除」时，确认按钮为红色样式，强调操作不可逆风险

# 技术要求

1. 当前页需根据节点是否为末级节点，动态切换展示模式。
2. 末级节点维护态与非末级节点聚合态需支持同页切换刷新。
3. 上传课程和资源库选择课程入口仅在末级节点编辑态下显示。
4. 课程预览能力需支持末级节点和非末级节点统一使用。
5. 所有课程卡片统一展示字段，不因来源类型不同而差异化展示，来源仅通过标签区分。
6. 当前页不展开资源库选课弹窗的详细内部实现，后续以独立页面为准。
