# 2.0 详情页-新增通用策略【codex更新】

## 1. 页面概述

### 页面目标

用于新增【通用策略】。

用户进入页面后，需要选择学段、学科，并配置掌握度区间及对应题目组成规则。保存成功后，页面留在当前详情页并切换为查看模式，顶部展示待发布提示条。

### 所属页面

策略管理 > 策略广场 > 单知识点出题 > 通用策略 > 新增通用策略

### 页面状态说明

本页面需区分以下状态：

1. 新增态：新建通用策略时使用。
2. 查看态：保存成功后进入，只读展示策略内容。
3. 编辑态：查看态下点击【编辑】后进入。

新增态与已有策略编辑态展示不同：

- 新增态标题为【新增通用策略】，不展示版本号和历史记录入口。
- 已有策略查看/编辑态标题、版本号、历史记录入口等内容以对应详情页 UI 稿为准。

## 2. 页面结构

页面由以下区域组成：

1. 页面头部区
2. 基础信息区
3. 题目组成配置区
4. 底部操作区

## 3. 页面头部区

### 3.1 返回入口

点击返回入口时：

1. 若页面没有未保存的内容，点击直接返回至单知识点出题的一级页面。
2. 若页面有未保存内容，弹出确认弹窗。

确认弹窗：

- 文案：新增内容还未保存，确认取消吗？
- 按钮：取消、确认

交互规则：

1. 点击弹窗【取消】，仅隐藏弹窗，页面停留在当前新增页面。
2. 点击弹窗【确认】，不保存用户新增的内容，页面返回至单知识点出题的一级页面。

### 3.2 页面标题

新增态标题：

新增通用策略

说明：

- 新增态不展示版本号。
- 新增态不展示历史记录入口。
- 面包屑及头部具体展示样式以 UI 稿为准。

## 4. 基础信息区

### 4.1 区域标题

展示：

基础信息

### 4.2 学段

字段类型：

下拉选择

选项：

- 高中
- 初中
- 小学

规则：

1. 学段为必填项。
2. 从首页进入新增页时，默认带入首页当前选中的学段。
3. 用户可在新增页内手动切换学段。
4. 切换学段后，学科选项同步变化。
5. 若当前已选学科在新学段下不可用，或已存在通用策略，则自动清空学科。

### 4.3 学科

字段类型：

下拉选择

规则：

1. 学科为必填项。
2. 学科选项跟随当前学段变化。
3. 已存在通用策略的学科置灰不可选。
4. 已存在通用策略的学科右侧标注【已有策略】。
5. 当前学段下所有学科均已有通用策略时，下拉中所有学科置灰，并提示【当前学段下所有学科均已有通用策略】。

学科联动规则：

各学段下具体展示哪些学科，根据乐课网当前学段下已有的学科数据进行展示。

未选择学科保存时：

1. 学科字段下方显示红色提示【请选择学科】。
2. 页面自动定位到基础信息区。

异常规则：

若学科信息加载失败，学科下拉不可用，并提示【学科信息加载失败，请稍后再试】。

## 5. 题目组成配置区

### 5.1 区域标题

展示：

题目组成配置

### 5.2 默认状态

新增页默认不添加掌握度区间。

用户需要点击【+ 添加区间】后，手动新增掌握度区间。

### 5.3 添加区间

点击【+ 添加区间】后，新增一条掌握度区间。

新增区间规则：

1. 新增区间默认带出起始值，结束值为空需用户手动填写。
2. 默认起始值取上一个区间的结束值。
3. 默认结束值为空。
4. 若上一个区间结束值已为 100，则提示用户先调整已有区间。
5. 系统不自动修改用户已配置的区间值。
6. 用户每次点添加区间后，都默认显示一行题型，默认显示的这一行题型，题量默认显示为1，难度默认显示为易1，其他难度默认显示为0。

### 5.4 删除区间

每个区间均可删除。

规则：

1. 删除区间时，该区间下的题目配置一并删除。
2. 点击【删除区间】后，显示确认弹窗。
3. 当页面只剩一个区间时，隐藏删除区间按钮（即每个策略至少需要有一条策略信息）。

确认弹窗：

弹窗文案：确认删除该区间的出题策略吗？

按钮：

- 取消
- 确认删除

按钮逻辑：

- 点击【取消】→ 仅隐藏弹窗，不删除区间。
- 点击【确认删除】→ 将被操作的区间删除。

### 5.5 区间题量汇总

区间标题处展示该区间的题量汇总。

格式：

共 X 题

计算规则：

该区间下所有题目配置行的题目数量之和。

### 5.6 区间排序

编辑过程中按用户创建顺序展示。

保存成功后，区间按起始值从小到大展示。

## 6. 掌握度区间规则

### 6.1 输入规则

掌握度区间由起始值和结束值组成，单位为百分比。

每个区间标题栏下方显示取值说明：区间取值说明：除最后一段为左闭右闭外，其余均为左闭右开。

输入规则：

1. 起始值和结束值均为 0-100 的整数。
2. 起始值允许等于结束值。
3. 起始值不能大于结束值。
4. 区间之间允许存在空隙。
5. 区间之间不允许重叠。
6. 区间边界相接不视为重叠，例如 0%-40%、40%-70% 允许保存。

### 6.2 保存校验

保存时校验以下情况：

1. 区间值为空时，提示【请输入掌握度区间】。
2. 起始值大于结束值时，提示【掌握度区间起始值不能大于结束值】。
3. 区间存在重叠时，提示【掌握度区间不能重叠】。
4. 已添加的掌握度区间下无题目配置时，提示【已添加的掌握度区间，请至少添加一条题目配置规则】。

说明：

- 允许只配置一个掌握度区间。
- 允许起始值和结束值相等。
- 允许区间之间存在空隙。

---

## 7. 题目配置

### 7.1 添加题型

点击区间内【+ 添加题型】后，新增一条题目配置。

规则：

1. 同一区间内允许重复添加相同题型。
2. 题目配置行数量不限制。
3. 新增题目配置后，用户需补充题型、题量、难度分布、题目来源和知识点复合度。

### 7.2 删除题目配置

点击题目配置行删除入口后，直接删除该行。

删除题目配置行不需要二次确认。

### 7.3 题型

选项：下拉选项根据乐课网当前学段学科下有的题型进行显示。

规则：

1. 题型为必填项。
2. 默认选中第一个题型。

### 7.4 题量

输入规则：

1. 题量为必填项。
2. 仅允许输入正整数。
3. 不允许输入 0。
4. 不允许输入负数、小数和非数字字符。

保存校验：

题量为 0 时，提示【题目数量不能为 0】。

### 7.5 题目难度分布

难度项按 UI 文案展示为：

- 易
- 较易
- 中
- 较难
- 难

规则：

1. 每个难度项输入非负整数。
2. 各难度数量之和必须等于该行题量。
3. 保存时若不一致，提示【难度分布数量之和必须等于对应题型的题目总数】。

### 7.6 题目来源

题目来源为非必填项。

字段类型：

多选。

选项规则：

1. 题目来源根据不同学段展示对应可用来源。
2. 具体选项按菁优网不同学段支持的题目来源展示。

保存校验：无（题目来源为非必填项）。

### 7.7 知识点复合度

字段名称：

知识点复合度

选项：

- 单一知识点
- 非单一知识点

规则：

1. 知识点复合度为必填项。
2. 默认选中【单一知识点】。
3. 正常情况下不存在为空场景。

---

## 8. 通用策略唯一性规则

同一学段下，同一学科仅允许存在一个通用策略。

规则：

1. 已存在通用策略的学科在学科下拉中置灰不可选。
2. 用户进入页面时某学科可选，但保存前该学科被其他用户创建通用策略时，保存失败。
3. 保存失败提示【该学段学科已存在通用策略，请重新选择】。
4. 用户需重新选择可用学科后再保存。

---

## 9. 保存逻辑

### 9.1 保存入口

新增态底部展示操作按钮：

- 取消
- 保存

说明：

- 顶部不展示保存和取消按钮。
- 按钮具体文案和样式以新增态 UI 稿为准。
- 已有策略编辑态的按钮文案以对应 UI 稿为准。

### 9.2 保存校验顺序

点击保存后，按以下顺序校验：

1. 基础信息：学段、学科。
2. 掌握度区间：是否为空、起始值是否大于结束值、是否重叠。
3. 题目配置：是否存在配置、题量、难度分布、题目来源、知识点复合度。

校验不通过时：

1. 停止保存。
2. 页面定位到首个错误位置。
3. 对应字段展示错误提示。

### 9.3 保存中状态

保存过程中：

1. 保存按钮展示加载状态。
2. 保存按钮不可重复点击。
3. 页面字段不可编辑。
4. 用户不可新增、删除或修改区间和题目配置。

### 9.4 保存成功

保存成功后：

1. 留在当前详情页。
2. 页面切换为查看模式。
3. 顶部显示待发布提示条。
4. 待发布提示条中展示【发布】按钮。

提示条文案：

新增策略，需要发布后才能生效

> 注：该提示信息，在1.0期通用知识树、教材体系知识树新增策略的时候，也显示这个提示文案。

### 9.5 保存失败

保存失败后：

1. 保留用户当前填写内容。
2. 页面恢复可编辑状态。
3. 保存按钮恢复可点击。
4. 不切换为查看模式。
5. 页面展示失败提示。

## 13. 异常与边界场景

### 13.1 学科信息加载失败

学科下拉不可用，提示【学科信息加载失败，请稍后再试】。

### 13.2 当前学段所有学科均已有通用策略

学科下拉中所有学科置灰，并提示【当前学段下所有学科均已有通用策略】。

### 13.3 保存时学科已被占用

提示【该学段学科已存在通用策略，请重新选择】。

### 13.4 掌握度区间异常

以下情况保存时拦截：

- 区间值为空
- 起始值大于结束值
- 区间重叠

以下情况允许保存：

- 只有一个区间
- 起始值等于结束值
- 区间之间存在空隙
- 区间边界相接

### 13.5 题目配置异常

以下情况保存时拦截：

- 已添加区间下无题目配置
- 题量为 0
- 难度分布数量之和不等于题量
- 题目来源为空
