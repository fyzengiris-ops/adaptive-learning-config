# 2.00 详情页-非编辑态

# 页面目标
用于展示【教材体系知识树】中某教材的详情信息。

当前页为教材详情页的**非编辑态**，主要用于：
- 查看教材基础信息、当前维护版本号、当前状态；
- 查看教材章节结构；
- 查看当前选中节点下的知识点、同步课程、练习试卷内容；
- 承接导出教材、编辑章节详情、删除教材等操作入口。

> 说明：
> 1. 本页由首页教材卡片【进入管理】进入。
> 2. 当前页展示的教材目录，需与乐课网平台已有教材目录数据保持一致。
> 3. 当前页为非编辑态页面，编辑态能力以后续页面或后续状态文档为准。
> 4. 本次更新后，教材目录支持 **章 → 二级小节 → 三级小节** 的展示形态，同时兼容 **章 → 二级小节** 的目录形态；**若乐课网线上实际目录层级大于三级，则以线上实际层级为准，系统需兼容展示**。

知识体系管理 > 教材体系知识树 > 教材详情页

# 页面区域

## A. 顶部提示条区
用于展示编辑章节树结构的生效时机说明，以及待发布变更提示。

## B. 顶部导航操作区
用于返回列表，以及承接删除教材、导入教材、导出教材等操作入口。

## C. 左侧教材信息与章节树区
用于展示教材基础信息、当前维护版本、当前状态，以及教材章节结构树。**进入详情页时，左侧章节树自动处于可编辑状态。**

## D. 右侧章节详情区
用于展示当前选中节点的详细信息，包含【知识点】【同步课程】【练习试卷】三个 Tab 页面。

# 组件说明

## A. 顶部提示条区组件
- A1. 固定提示条：
  - 主标题：显示「编辑章节树结构（新增、删除、改名、移动节点），不同的下游业务生效时机不同：」
  - 生效说明：
    - ✅ 实时生效：全乐课网平台仅涉及知识树展示、不涉及版本号的下游业务
    - ⏳ 发布后生效：涉及版本号的下游业务（自适应学习系统）
  - 关闭按钮：用户可手动关闭提示条，本次会话内不再显示
- A2. 待发布提示条（编辑后自动显示）：
  - 显示条件：用户对左侧章节树进行新增、删除、改名、移动节点操作后自动显示
  - 显示内容：橙色提示条，显示「有 X 项变更待发布，发布后才能生效」
  - 显示顺序：待发布提示条显示在固定提示条上方
  - 【发布】按钮：点击进入发布确认流程

## B. 顶部导航操作区组件
- B1. 【返回】按钮：返回教材列表页
- B2. 【删除】按钮：删除当前教材（仅教研主管可见）
- B3. 【导入教材】按钮：导入教材数据（仅教研主管可见）
- B4. 【导出教材】按钮：导出当前教材数据

## C. 左侧教材信息与章节树区组件
- C1. 教材信息卡片：
  - 教材标题：教材名称 | 学段 | 学科 | 版本类别（如：数学·九年级上册 | 初中 | 数学 | 浙教版）
  - 当前维护版本号：如 `v1.0`
  - 当前状态：如【已发布】
- C2. 章节结构标题：显示【章节结构】
- C3. 章节树节点（自动处于可编辑状态）：
  - 按教材目录层级展示章节结构
  - 支持三类节点：
    - 章节点
    - 二级小节节点
    - 三级小节节点
  - 节点支持展开/收起
  - 节点右侧展示对应知识点数量
  - **编辑态下显示**：拖拽手柄、编辑按钮、删除按钮、添加小节按钮
- C4. 节点选中态：当前选中节点高亮显示
- C5. 底部【添加章】按钮：用于新增顶级章节
- C6. 左侧滚动区域：章节树区域支持独立滚动

## D. 右侧章节详情区组件
- D1. 标题行：固定显示【章节详情】
- D2. 操作按钮区：
  - 【导出教材】按钮：始终显示
  - 【编辑章节详情】按钮：始终可点击（不再受左侧树编辑状态影响）
- D3. 章节名称行：
  - 左侧：显示当前选中章节路径名称
  - 右侧：Tab 切换栏
- D4. Tab 切换栏：包含【知识点】【同步课程】【练习试卷】三个 Tab
- D5. 知识点 Tab 内容区
- D6. 同步课程 Tab 内容区
- D7. 练习试卷 Tab 内容区

# 交互逻辑

## 1. 页面进入
- 用户从首页点击教材卡片【进入管理】后进入当前详情页
- 页面加载当前教材基础信息、章节树及默认选中节点对应的详情内容
- 页面首次进入时，默认选中当前教材章节树中的第一个可展示节点
- 默认选中后，右侧同步展示对应详情内容
- **左侧章节树自动处于可编辑状态**，无需点击额外按钮进入编辑态

## 2. 返回教材列表
- 用户点击【返回】按钮后，返回教材列表页

## 3. 左侧章节树编辑
- **自动编辑态**：进入详情页后，左侧章节树自动处于可编辑状态
- 用户可直接对左侧章节树进行以下操作：
  - 新增章：点击底部【添加章】按钮
  - 新增小节：点击节点上的添加按钮
  - 编辑节点名称：点击节点上的编辑按钮
  - 删除节点：点击节点上的删除按钮
  - 拖拽排序：拖拽节点手柄调整顺序
- **编辑后自动显示待发布提示条**：
  - 用户对左侧章节树进行任何编辑操作后，顶部自动显示橙色待发布提示条
  - 提示内容：「有 X 项变更待发布，发布后才能生效」
  - 待发布提示条显示在固定提示条上方
- 不同角色的编辑权限不同：
  - 教研主管：可编辑教材目录及各目录对应的详情信息
  - 教研员：可编辑每个教材目录对应的详情信息，但不可编辑教材目录本身
- **左右两侧编辑可同时进行**，无互斥限制

## 4. 右侧章节详情编辑
- 用户点击右侧【编辑章节详情】按钮后，进入章节详情编辑态
  - 右侧详情区变为可编辑态
  - 右侧操作按钮变为【批量导入】【取消】【保存编辑】
- **右侧【编辑章节详情】按钮始终可点击**，不受左侧树编辑状态影响

## 5. 查看节点详情
- 用户点击左侧章节树中的某个节点后：
  - 当前节点高亮
  - 右侧切换展示该节点对应的详情内容
- 不同层级节点进入右侧后的展示模式不同

## 6. 切换 Tab
- 用户点击【知识点】【同步课程】【练习试卷】Tab 后：
  - 系统切换当前激活 Tab
  - 右侧展示对应类型的数据内容
- 当前选中节点保持不变，仅切换内容视图

## 7. 导出教材
- 用户点击顶部导航区的【导出教材】按钮后：
  - 触发当前教材导出流程
- 具体导出内容、范围、格式以后续专门页面为准

## 8. 导入教材
- 用户点击顶部导航区的【导入教材】按钮后：
  - 触发教材导入流程
- 此按钮仅教研主管可见
- 具体导入内容、格式以后续专门页面为准

## 9. 删除教材
- 用户点击顶部导航区的【删除】按钮后：
  - 弹出二次确认
  - 确认后执行删除操作
- 删除成功后返回教材列表页
- 删除失败时停留当前页，并提示删除失败
- 此按钮仅教研主管可见

# 业务规则

## 一、页面定位规则
1. 当前页为教材详情页，**进入页面后左侧章节树自动处于可编辑状态**。
2. 当前页支持查看与编辑，同时承接导出、删除等上层操作入口。
3. 当前页展示的教材目录需与乐课网平台已有教材目录数据保持一致。
4. 不允许新功能与乐课网原有教材目录长期不一致。

## 二、教材信息展示规则
1. 左侧教材信息卡片展示：
   - 教材名称（如：数学·九年级上册）
   - 学段（如：初中）
   - 学科（如：数学）
   - 版本类别（如：浙教版）
   - 当前维护版本号
   - 当前状态
2. 当前维护版本号用于表示当前教材树配置版本，如 `v1.0`。
3. 当前状态在本页展示为当前正式生效状态，如【已发布】。

## 三、权限规则
1. 教研主管作为具备教材体系知识树维护权限的后台角色，可见：
   - 左侧章节树的全部编辑能力（新增、编辑、删除、拖拽排序）
   - 顶部导航区【导入教材】按钮
   - 顶部导航区【删除】按钮
   - 右侧【编辑章节详情】按钮
   - 顶部导航区【导出教材】按钮
2. 教研员可见：
   - 左侧章节树的只读查看（不可编辑教材目录）
   - 右侧【编辑章节详情】按钮
   - 顶部导航区【导出教材】按钮
3. 教研员不可见：
   - 左侧章节树的编辑操作按钮（添加、编辑、删除按钮）
   - 底部【添加章】按钮
   - 顶部导航区【导入教材】按钮
   - 顶部导航区【删除】按钮
4. 教研员点击【编辑章节详情】后，只能编辑每个教材目录对应的详情信息，不能编辑教材目录本身。
5. **左右两侧编辑可同时进行，无互斥限制**。

## 四、章节树规则
1. 左侧章节树按教材目录层级展示。
2. **进入详情页时，左侧章节树自动处于可编辑状态**（教研主管）。
3. 当前版本需兼容以下两种目录结构：
   - 结构A：章 → 二级小节
   - 结构B：章 → 二级小节 → 三级小节
4. **若乐课网线上实际目录层级大于三级，则以线上实际层级为准，系统需兼容展示。**
5. 章节点支持展开/收起。
6. 二级小节在存在三级小节时，支持展开/收起。
7. 每个节点右侧展示对应知识点数量。
8. 当前选中节点需高亮显示。
9. 左侧章节树区域支持独立滚动。
10. 当前教材章节树结构需与乐课网原有教材目录结构保持一致。

## 五、节点类型规则
1. 当前页的右侧展示逻辑需按节点层级区分处理。
2. 当前节点分为以下四种展示场景：
   - 场景A：选中章节点
   - 场景B：选中二级小节节点，且该二级小节下存在三级小节
   - 场景C：选中三级小节节点
   - 场景D：选中二级小节节点，且该二级小节下不存在三级小节
3. 不同场景下，三个 Tab 的展示样式与信息组织方式不同。

# 六、右侧详情区总规则

## 6.1 标题行规则
1. 右侧顶部标题行固定显示为【章节详情】（不再跟随节点名称变化）。
2. 标题行右侧显示操作按钮：
   - 【导出教材】按钮：始终显示
   - 【编辑章节详情】按钮：始终可点击（不再受左侧树编辑状态影响）

## 6.2 章节名称行规则
1. 标题行下方新增章节名称行，采用左右布局。
2. 左侧显示当前选中章节路径名称：
   - 章级别：显示完整章名称（如"第一章 二次函数"）
   - 节级别：显示"章序号-节名称"格式（如"第一章-1.1 二次函数"）
   - 小节级别：显示"章序号-节名称-小节名"格式
3. 章序号提取规则：从章名称中提取序号部分（如"第一章 二次函数" → "第一章"）
4. 右侧显示 Tab 切换栏：【知识点】【同步课程】【练习试卷】。
5. 章节名称行底部带分割线。

## 6.3 Tab 规则
1. 右侧内容区统一支持三个 Tab，所有节点均展示：
   - 知识点
   - 同步课程
   - 练习试卷
2. 当前页为详情页（左侧树自动处于可编辑状态）：
   - 右侧内容区默认为查看态
   - 点击【编辑章节详情】后进入编辑态
3. 空态文案按 Tab 维度区分：
   - 知识点空态：`暂无关联知识点` 或 `暂无知识点`
   - 同步课程空态：`暂无关联同步课程` 或 `暂无课程`
   - 练习试卷空态：`暂无关联练习试卷` 或 `暂无试卷`
4. 若存在查看入口，仅支持预览/查看，不支持修改（编辑态除外）。

## 6.4 编辑态下的右侧布局变化
1. 进入章节详情编辑态后，右侧布局发生以下变化：
   - **标题行右侧按钮变化**：
     - 非编辑态：【导出教材】【编辑章节详情】
     - 编辑态：【批量导入】【取消】【保存编辑】
   - **章节名称行和 Tab 栏位置不变**：仍在标题行下方，左侧显示章节路径，右侧显示 Tab 切换
   - **内容区变为可编辑态**：
     - 末级节点：展示新增、删除、拖拽排序等编辑入口
     - 非末级节点：保持聚合查看态，不可直接编辑
2. 点击【取消】按钮：
   - 退出编辑态，返回非编辑态
   - 不保存本次编辑结果
3. 点击【保存编辑】按钮：
   - 保存当前编辑结果
   - 退出编辑态，返回非编辑态
   - 若有变更，教材进入待发布状态

## 6.5 右侧展示模式总览
1. 章节点：右侧采用**章级聚合展示态**
2. 二级小节（有三级小节）：右侧采用**二级小节聚合展示态**
3. 三级小节：右侧采用**三级小节详情展示态**
4. 二级小节（无三级小节）：右侧采用**二级小节详情展示态**

# 七、知识点 Tab 规则

## 7.1 场景A：章节点 - 知识点 Tab

### 7.1.1 无数据
1. 当选中章节点并切换到【知识点】Tab 时，展示【知识点总览】。
2. 按该章下各二级小节聚合展示，采用连接线样式。
3. 若某二级小节下存在三级小节，则继续向下展示该二级小节下的三级小节及其知识点情况。
4. 若某节点下无知识点，则显示对应空态。
5. 无数据区域展示【暂无知识点】。

### 7.1.2 有数据
1. 当选中章节点且章下存在知识点数据时，仍展示【知识点总览】。
2. 展示口径为该章下所有二级小节/三级小节的聚合结果。
3. 连接线样式展示规则：
   - 左侧显示垂直连接线和圆点
   - 章节主色调为绿色（emerald）
   - 圆点大小：二级小节 12px，三级小节 10px
4. 若二级小节无三级小节，则直接在二级小节下展示知识点列表。
5. 若二级小节有三级小节，则在各三级小节下分别展示知识点列表。
6. 每个有数据的节点需展示对应知识点数量。
7. 支持展示【全景图谱】入口：
   - 点击后展示当前节点/小节的知识点关系图谱
   - 图谱区域支持收起
8. 知识点列表展示：
   - 主知识点：星形图标 + 名称
   - 延伸知识点：圆点图标 + 名称（缩进展示）
9. 当前页为非编辑态，不展示编辑入口。

---

## 7.2 场景B：二级小节节点（有三级小节）- 知识点 Tab

### 7.2.1 无数据
1. 当选中二级小节节点，且该节点下存在三级小节，但当前范围内无知识点数据时：
   - 右侧展示【知识点总览】
   - 按该二级小节下各三级小节聚合展示
2. 每个三级小节单独占一块区域展示。
3. 无数据时，各三级小节下显示【暂无知识点】。

### 7.2.2 有数据
1. 当选中二级小节节点，且该节点下存在三级小节，同时存在知识点数据时：
   - 右侧展示【知识点总览】
   - 按三级小节维度分别展示
2. 采用连接线样式展示。
3. 每个三级小节标题旁显示该三级小节知识点数量。
4. 各三级小节下展示其关联知识点列表。

2. 试卷数据按教材章节维度组织，末级节点（三级小节或无三级小节的二级小节）可直接关联试卷。
3. 聚合展示时，按节点层级向下汇总试卷数据。
4. 试卷来源标签区分：
   - 资源库：从乐课网试卷资源库选择关联
   - 本地上传：用户手动上传的试卷
5. 试卷预览功能：点击预览入口（眼睛图标）可查看试卷详情内容，预览为只读模式。

# 十、数量展示规则

## 10.1 左侧章节树数量规则
1. 章节点右侧数量：
   - 展示该章范围内直接或下属节点关联的知识点统计结果
2. 二级小节节点右侧数量：
   - 若该节点无三级小节，则展示当前二级小节直接关联知识点数量
   - 若该节点有三级小节，则展示该二级小节范围内下属三级小节知识点聚合数量
3. 三级小节节点右侧数量：
   - 展示当前三级小节直接关联知识点数量

## 10.2 右侧标题数量规则
1. 当为详情展示态时：
   - 知识点显示知识点数量
   - 同步课程显示课程数量
   - 练习试卷显示试卷数量
2. 当为聚合展示态时：
   - 每个聚合节点单独展示其对应数量
3. 无数据时可不展示数量，或展示 `0`，以最终前端实现为准，但同一页面内口径需统一。

# 十一、状态与异常

## 页面状态
- 详情页默认状态：进入详情页后，左侧章节树自动处于可编辑状态，右侧为查看态
- 待发布状态：用户编辑左侧章节树后，顶部显示待发布提示条
- 章级聚合展示态：选中章节点时进入
- 二级小节聚合展示态：选中"有三级小节"的二级小节节点时进入
- 三级小节详情展示态：选中三级小节节点时进入
- 二级小节详情展示态：选中"无三级小节"的二级小节节点时进入
- 右侧编辑态：点击【编辑章节详情】后，右侧进入可编辑状态

## 异常与边界
1. **教材无章节数据**
   - 若当前教材无章节数据，右侧展示空态提示

2. **未选中任何节点**
   - 显示引导提示："请选择一个章节"
   - 副标题："在左侧章节树中选择章节查看详情"

3. **知识点空态**
   - 当前节点或聚合范围无知识点时，显示对应知识点空态

4. **同步课程空态**
   - 当前节点或聚合范围无课程时，显示对应课程空态

5. **练习试卷空态**
   - 当前节点或聚合范围无试卷时，显示对应试卷空态

6. **删除失败**
   - 删除失败时停留当前页，并提示删除失败

7. **详情数据加载失败**
   - 当前教材详情加载失败时，应提示加载失败并支持重试

8. **字段缺失容错**
   - 若课程、试卷、知识点的部分补充字段缺失，应按缺省值展示，不应导致整条数据不可见
   - 具体缺省值规则：时长/题量/总分缺失时显示 `--`，课程来源/试卷来源标签缺失时不展示来源标签

9. **目录兼容场景**
   - 同一教材中可能同时存在"有三级小节的二级小节"和"无三级小节的二级小节"
   - 页面需按当前选中节点的实际结构动态切换展示模式，不允许使用单一固定样式套全部节点

# 十四、技术要求

1. 页面采用左右分栏布局（左侧 1/3，右侧 2/3）。
2. 左侧为教材信息与章节树区域，右侧为章节详情区域。
3. 左右区域均支持独立滚动。
4. 右侧需支持【知识点】【同步课程】【练习试卷】Tab 切换。
5. 页面需兼容两类目录结构：
   - 章 → 二级小节
   - 章 → 二级小节 → 三级小节
6. 右侧展示逻辑需根据当前节点层级与是否存在下级节点动态切换。
7. 图谱区域需支持知识点关系可视化展示。
8. **进入详情页后，左侧章节树自动处于可编辑状态**（教研主管），支持拖拽排序与章节编辑能力。
9. 页面需支持当前教材目录与乐课网已有教材目录的一致性展示。
10. **顶部提示条需支持固定提示条（可关闭）和待发布提示条（编辑后自动显示）两种状态**。
11. 章节名称行需根据节点层级动态计算显示路径：
    - 使用正则提取章序号（如"第一章"）
    - 节级别显示"章序号-节名称"格式
