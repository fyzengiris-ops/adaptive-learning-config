- 本次变更摘要：教材根节点「课程」下新增三个只读总览子 Tab（专题课总览、拓展课总览、同步课总览）；专题/拓展按章聚合「视频下挂绑定试卷」

## 已确认决策（产品对话确认）

1. 默认 Tab
   - 结论：进入教材根节点课程区时，默认停在「专题课总览」；再次回到根节点时重置为「专题课总览」。
   - 影响范围：课程总览子 Tab

2. 拓展课总览结构
   - 结论：与专题课总览完全同一套结构（章标题 + 视频块 + 绑定试卷）。
   - 影响范围：拓展课总览

3. 空章展示
   - 结论：某章没有专题/拓展课视频时，仍显示「章名（0个课程·0份试卷）」+ 空态「暂未添加视频」。
   - 影响范围：专题课总览、拓展课总览

4. 章内展示形态
   - 结论：按章编辑态「一个视频一块，下面挂绑定试卷」的只读版排布；不展示上传/选课/添加试卷/移除。
   - 影响范围：专题课总览、拓展课总览

5. 编辑态约束
   - 结论：无论教材树为编辑态或非编辑态，三个总览均为只读查看，不可编辑。
   - 影响范围：课程总览全区
