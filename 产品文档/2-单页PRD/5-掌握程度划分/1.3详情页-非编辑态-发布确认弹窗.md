# 1.3 详情页-非编辑态-发布确认弹窗【GPT更新】

## 页面目标

用于对当前学段掌握程度划分策略的待发布变更执行发布确认。用户可在弹窗中查看版本号变化、填写更新说明、选择立即发布或定时发布，并确认本次发布操作。

> 当前弹窗仅处理当前详情页所属学段的待发布变更，不处理其他学段的发布内容。

## 所属页面

策略管理 > 策略广场 > 掌握程度划分 > 详情页 > 非编辑态 > 发布确认弹窗

---

## 页面定位

1. 当前页面为当前学段详情页下的发布确认弹窗。
2. 当前弹窗用于处理当前学段已保存但未发布的变更发布。
3. 当前弹窗可支持以下操作：
   - 查看版本号变化
   - 填写更新说明
   - 选择立即发布或定时发布
   - 选择定时发布日期和时间
   - 查看本次变更内容
   - 取消发布
   - 确认发布 / 确认定时发布
4. 当前弹窗不承载以下能力：
   - 查看其他学段待发布内容
   - 编辑策略配置内容
   - 删除策略
   - 回滚版本

---

## 页面结构

### A. 弹窗头部区域

用于展示弹窗标题和关闭入口。

| 元素 | 说明 |
|------|------|
| 弹窗标题 | 显示：**发布确认** |
| 关闭按钮 | 位于弹窗右上角，点击后关闭当前弹窗 |

#### 展示规则

1. 弹窗标题固定展示为：**发布确认**
2. 头部右侧展示关闭按钮
3. 关闭按钮点击后关闭当前弹窗，不执行发布操作

---

### B. 发布注意事项区域

用于展示发布注意事项提示信息。

| 元素 | 说明 |
|------|------|
| 提示标题 | 显示：**发布注意事项** |
| 提示说明 | 提示发布影响和建议发布时间段 |

#### 展示规则

1. 弹窗顶部固定展示【发布注意事项】提示区
2. 提示区文案固定为：
   - **发布将影响线上用户的实际使用，建议避开用户高频使用的时间段。**
   - **建议发布时间段：凌晨 00:00 - 04:00**
3. 提示区不因发布方式切换而隐藏

---

### C. 发布信息填写区域

用于展示版本号变化、填写更新说明，并选择发布时间方式。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 版本号 | 只读展示字段 | 是 | 展示当前版本号与新版本号变化 |
| 更新说明 | 多行文本输入框 | 是 | 填写本次发布的更新说明 |
| 发布时间 | 单选项 | 是 | 选择立即发布或定时发布 |
| 定时发布日期 | 日期选择器 | 定时发布时必填 | 选择定时发布日期 |
| 定时发布时间 | 时间选择器 | 定时发布时必填 | 选择定时发布时间 |

---

## 字段规则

### 1. 版本号

1. 弹窗内展示【版本号】区域。
2. 版本号区域固定展示：
   - 当前版本号
   - 箭头
   - 新版本号
3. 当前版本号展示当前已发布版本。
4. 新版本号由系统自动生成或沿用当前待发布版本号。
5. 用户不可手动修改版本号。

#### 展示示例

**当前版本：v1.0 → v1.1**

---

### 2. 更新说明

1. 更新说明为必填字段。
2. 输入框为多行文本输入框。
3. placeholder 为：**请输入本次发布的更新说明...**
4. 用户未填写更新说明时，不允许提交发布。
5. 用户点击确认按钮后，若更新说明为空，页面需提示：**请输入本次发布的更新说明**
6. 用户补充完成后方可继续提交。

---

### 3. 发布时间

发布时间支持以下两种方式：

- 立即发布
- 定时发布

#### 展示规则

1. 弹窗默认选中：**立即发布**
2. 当用户选择【立即发布】时：
   - 不展示定时发布日期选择器
   - 不展示定时发布时间选择器
3. 当用户选择【定时发布】时：
   - 展示定时发布日期选择器
   - 展示定时发布时间选择器
4. 时间选择器默认值为：**02:00**

---

### 4. 定时发布日期

1. 仅在选择【定时发布】时展示
2. 为定时发布必填字段
3. 用户未选择发布日期时，不允许提交定时发布
4. 若未选择，则提示：**请选择定时发布日期**

---

### 5. 定时发布时间

1. 仅在选择【定时发布】时展示
2. 为定时发布必填字段
3. 默认值为：**02:00**
4. 用户未选择发布时间时，不允许提交定时发布
5. 若未选择，则提示：**请选择定时发布时间**
6. 定时发布时间必须晚于当前系统时间
7. 若所选时间早于或等于当前时间，则阻断提交，并提示：**定时发布时间需晚于当前时间**

---

### D. 底部操作区域

用于提供取消和确认发布操作。

| 按钮 | 说明 |
|------|------|
| 取消 | 点击后关闭当前弹窗，不执行发布 |
| 主按钮 | 根据发布方式切换文案 |

#### 按钮文案规则

1. 当发布方式为【立即发布】时，底部主按钮文案显示：**确认发布**
2. 当发布方式为【定时发布】时，底部主按钮文案显示：**确认定时发布**
3. 底部左侧按钮固定为：**取消**

---

## 交互逻辑

### 1. 打开弹窗

1. 用户在当前学段详情页的待发布状态条中点击【发布】按钮后，打开发布确认弹窗。
2. 弹窗打开后，系统默认初始化以下内容：
   - 更新时间说明为空，或回写上一次已填写信息
   - 发布方式默认选中【立即发布】，或按上次信息回写
   - 定时发布时间默认值为【02:00】
   - 版本号自动生成并回显
3. 当前弹窗仅加载当前学段的待发布变更内容。

---

### 2. 回写已有发布信息

1. 若当前策略已存在上一次填写过的发布信息，则再次打开发布确认弹窗时优先回写已有信息。
2. 回写内容包括：
   - 更新说明
   - 发布方式（立即发布 / 定时发布）
   - 若为定时发布，则回写定时发布日期与定时发布时间
3. 用户可在回写内容基础上继续修改后重新提交。

---

### 3. 切换发布方式

#### 3.1 立即发布

1. 用户选择【立即发布】
2. 页面隐藏定时发布日期与定时发布时间字段
3. 底部主按钮文案显示为：**确认发布**

#### 3.2 定时发布

1. 用户选择【定时发布】
2. 页面展示定时发布日期与定时发布时间字段
3. 底部主按钮文案显示为：**确认定时发布**

---

### 4. 填写更新说明

1. 用户在更新说明输入框中填写本次发布的更新内容
2. 页面实时记录用户输入内容
3. 若更新说明为空，提交时阻断发布并提示对应错误信息

---

### 5. 选择定时发布时间

1. 用户选择【定时发布】后，可选择发布日期和发布时间
2. 系统校验所选发布时间是否有效
3. 若未选择日期或时间，或时间早于当前系统时间，则阻断提交并提示错误原因

---

### 6. 取消发布

1. 用户点击【取消】按钮，关闭当前弹窗
2. 用户点击右上角关闭按钮，关闭当前弹窗
3. 关闭弹窗后，不执行任何发布操作
4. 当前弹窗关闭后，本次临时填写内容不保留；下次重新打开时按最近一次有效发布信息或默认状态重新初始化

---

### 7. 确认发布

#### 7.1 立即发布

1. 用户点击【确认发布】并校验通过后，系统执行立即发布。
2. 发布成功后：
   - 当前待发布变更立即生效
   - 当前版本号更新为新版本号
   - 弹窗关闭
   - 页面顶部待发布状态提示消失
   - 页面按最新已发布结果回显版本号与状态

#### 7.2 定时发布

1. 用户点击【确认定时发布】并校验通过后，系统保存定时发布任务。
2. 提交成功后：
   - 弹窗关闭
   - 页面进入定时发布展示态
   - 页面顶部展示蓝色定时发布状态条
   - 页面右上角按待发布版本与待发布状态回显

---

## 业务规则

### 一、发布范围规则

1. 当前弹窗仅用于发布当前学段已保存但未发布的变更
2. 当前弹窗不处理其他学段的待发布内容
3. 当前弹窗不用于编辑配置本身

### 二、版本号规则

1. 弹窗内展示当前版本号到新版本号的变化
2. 当前版本号为当前已发布版本
3. 新版本号由系统自动生成或沿用当前待发布版本号
4. 用户不可手动修改版本号

### 三、更新说明规则

1. 更新说明为必填字段
2. 未填写更新说明时，阻断提交发布
3. 页面需提示对应错误信息

### 四、定时发布规则

1. 当用户选择【定时发布】时，必须同时完成：
   - 定时发布日期选择
   - 定时发布时间选择
2. 定时发布时间默认值为：**02:00**
3. 定时发布时间必须晚于当前系统时间

### 五、变更内容展示规则

1. 变更内容区仅展示当前学段本次待发布的变更摘要
2. 不展示其他学段待发布内容
3. 每条变更需展示变更类型标签和变更说明

### 六、按钮文案规则

1. 当发布方式为【立即发布】时，主按钮文案为：**确认发布**
2. 当发布方式为【定时发布】时，主按钮文案为：**确认定时发布**
3. 底部左侧按钮固定为：**取消**

### 七、发布结果规则

#### 立即发布
1. 当前待发布变更立即生效
2. 当前版本号更新为新版本号
3. 弹窗关闭
4. 页面顶部待发布状态提示消失
5. 页面按最新已发布结果回显版本号与状态

#### 定时发布
1. 系统保存当前学段的定时发布任务
2. 弹窗关闭
3. 页面进入定时发布展示态
4. 页面顶部展示蓝色定时发布状态条
5. 页面右上角按待发布版本与待发布状态回显

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 弹窗打开状态 | 当前发布确认弹窗已打开 |
| 立即发布状态 | 当前默认或已选择立即发布 |
| 定时发布状态 | 当前已选择定时发布 |
| 校验失败状态 | 用户提交时存在未通过校验项 |
| 提交成功状态 | 发布或定时发布提交成功 |

### 2. 校验失败处理

1. 更新说明为空时，阻断提交，并提示：**请输入本次发布的更新说明**
2. 定时发布日期为空时，阻断提交，并提示：**请选择定时发布日期**
3. 定时发布时间为空时，阻断提交，并提示：**请选择定时发布时间**
4. 定时发布时间早于或等于当前时间时，阻断提交，并提示：**定时发布时间需晚于当前时间**

### 3. 异常处理规则

1. 发布提交失败时，页面需提示失败原因
2. 发布失败后，弹窗保持打开状态，便于用户修改后重新提交
3. 用户仍可主动关闭弹窗，取消本次发布操作

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 当前学段存在待发布变更 | 允许打开发布确认弹窗 |
| 更新说明为空 | 阻断提交，提示请输入本次发布的更新说明 |
| 选择定时发布但未选日期 | 阻断提交，提示请选择定时发布日期 |
| 选择定时发布但未选时间 | 阻断提交，提示请选择定时发布时间 |
| 定时发布时间早于当前时间 | 阻断提交，提示定时发布时间需晚于当前时间 |
| 用户点击取消 | 关闭弹窗，不执行发布 |
| 用户点击右上角关闭按钮 | 关闭弹窗，不执行发布 |
| 立即发布成功 | 关闭弹窗，清除待发布提示，回显最新已发布信息 |
| 定时发布成功 | 关闭弹窗，进入定时发布展示态 |
