## 已确认决策

1. 字段：考点名称（保存校验）
   - 决策：B
   - 结论：保存时若存在空名称则拦截，Toast：「请填写所有考点名称后再保存」
   - 影响范围：保存编辑、关联考点表格名称列

2. 字段：考点名称（同一知识点内重名）
   - 决策：A
   - 结论：页面与导入一致，同一知识点内名称不可重复；编辑失焦或保存时若重名则拦截，Toast：「考点名称不能重复」
   - 影响范围：页面编辑、导入校验、保存

3. 按钮：添加考点（默认类型）
   - 决策：D
   - 结论：新增行类型为空，保存前必须选择；未选则拦截，Toast：「请为所有考点选择类型」
   - 影响范围：添加考点、类型下拉、保存校验

4. 列表：关联考点顺序
   - 决策：C
   - 结论：顺序有业务含义，保证下游按配置后台当前顺序展示；不做手动上移/下移；以导入顺序与页面添加先后为准，保存后保持该顺序
   - 影响范围：关联列表、导入写回、知识卡片/平板预览/下游展示顺序

5. 按钮：删除考点（无例题时）
   - 决策：C + 自定义文案
   - 结论：无例题且无考点说明时直接删除；无例题但已有考点说明时二次确认。弹窗文案：「确定删除当前考点吗？（删除后，知识卡片中对应内容将一并删除）」
   - 影响范围：关联考点删除、知识卡片同步删除

6. 弹窗：删除关联考点确认（有例题时）
   - 决策：B + 自定义文案
   - 结论：有例题或有考点说明任一存在即弹窗；确认后同步删除关联考点及知识卡片对应内容。弹窗文案与第 5 条统一：「确定删除当前考点吗？（删除后，知识卡片中对应内容将一并删除）」
   - 影响范围：删除确认弹窗、知识卡片考点说明/例题

7. 导入：写回策略与知识卡片内容
   - 决策：自定义方案（A+D）
   - 结论：填写考点名称时整表覆盖该末级关联考点列表（不是追加）。对照看名称是否一样：线上有、这次也写了的名称视为同一考点，尽量保留原说明/例题；线上有、这次没写的旧考点及其卡片内容删除；这次写了、线上没有的名称视为新增。允许只填考点名称、类型列留空（与页面可先只填名称一致）：已有同名考点保留原类型，新增考点类型为空。不允许只填考点类型。名称与类型都填时，须数量、顺序一一对应。本仓库为产品原型，真实写回以文档口径为准
   - 影响范围：批量导入写回、关联考点与知识卡片 id 关联

8. 导入：【清空】触发条件
   - 决策：自定义方案
   - 结论：两列分开处理——① 考点名称列填写【清空】/清空时，无论类型列是否清空，将该末级全部关联考点清空（名称与类型都清空）；② 仅考点类型列填写【清空】/清空、名称列有实际内容时，只清空各考点的类型，考点名称按导入文件中的实际名称回显/保留
   - 影响范围：导入模板说明、导入校验与写回

9. 导出：空名称考点
   - 决策：B
   - 结论：导出时跳过名称为空的考点（该对名称与类型均不导出）
   - 影响范围：导出 Excel 考点名称/考点类型列

10. 知识卡片·考点回显
    - 决策：A+B
    - 结论：卡片侧不可增删改名称/类型，只能改说明/例题；空态保留原说明，并增加跳转按钮「去维护考点」，点击后切到「关联考点」Tab（编辑态则保持编辑）
    - 影响范围：学习资源 Tab 知识卡片空态与跳转

11. 预览：平板预览考点展示
    - 决策：A + 补充
    - 结论：预览保留「考点N」水印（学生端样式）；预览中考点展示顺序须与后台配置顺序一致
    - 影响范围：知识卡片平板预览

12. 按钮：保存编辑（变更维度）
    - 决策：C
    - 结论：维度按实际改动的字段集合拆分多条变更（知识点信息 / 关联考点 / 知识点结构 / 学习资源各一条，有改动才记）
    - 影响范围：待发布变更列表
