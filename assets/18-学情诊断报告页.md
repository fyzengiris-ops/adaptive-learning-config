# 页面名称
学情诊断报告页

# 页面目标
用于展示学生完成学情诊断后的结果报告，帮助学生从“知识点掌握情况”“题目作答情况”“知识点明细分析”三个层面理解本次诊断结果，并支持从报告页返回自适应学习首页、查看题目详情、进入推荐学习或单知识点学习。

# 页面区域

## A. 顶部导航与章节信息区
用于展示页面基础导航信息及本次诊断章节信息，包括：
- 返回按钮
- 页面标题【诊断报告】
- 本次诊断章节名称
- 【推荐学习】按钮

## B. 知识点掌握统计区
用于从个人与班级两个视角，展示当前章节下知识点掌握情况，包括：
- 当前学生知识点掌握统计卡片
- 当前学生所在班级知识点掌握统计卡片

## C. 题目分析区
用于按题型分组展示本次诊断各题目的作答结果，包括：
- 各题型分组标题
- 各题结果标识
- 题目详情入口

## D. 知识点分析区
用于按知识点粒度展示本次诊断相关分析数据，包括：
- 知识点名称
- 掌握度
- 班级掌握度
- 本次诊断题目数
- 累计练习题数
- 操作按钮【去学习】

# 组件说明

## A. 顶部导航与章节信息区组件
- A1. 返回按钮：点击后返回自适应学习首页
- A2. 页面标题：固定显示【诊断报告】
- A3. 章节名称：显示本次诊断的章节名称
- A4. 推荐学习按钮：本期点击显示 toast【敬请期待~】，V0.8.1 起支持推荐学习逻辑

## B. 知识点掌握统计区组件
- B1. 学生统计卡片：展示当前学生在本次诊断章节下的知识点掌握等级分布
- B2. 班级统计卡片：展示当前班级在本次诊断章节下的人均知识点掌握情况
- B3. 优秀进度条：展示距离“全部优秀”的进度
- B4. 未练习值：展示未练习知识点数量或人均数量
- B5. 提示问号入口：点击显示弹窗提示

## C. 题目分析区组件
- C1. 题型分组标题：按题型分组展示题目
- C2. 题目结果项：展示每道题的批改结果
- C3. 题目详情入口：点击进入题目详情页 / 题目解析页

## D. 知识点分析区组件
- D1. 表头字段：
  - 知识点名称
  - 掌握度
  - 班级掌握度
  - 本次诊断题目数
  - 累计练习题数
  - 操作
- D2. 知识点行：展示单个知识点对应的分析数据
- D3. 班级掌握度提示问号：点击显示弹窗提示
- D4. 去学习按钮：本期点击显示 toast【敬请期待~】，V0.8.1 起进入专项学习页面

# 交互逻辑

## 1. 点击返回
- 点击左上角【返回】后，返回自适应学习系统首页
- 返回后，首页恢复到进入学情诊断前的：
  - 场景
  - 学科
  - 章节定位

## 2. 页面初始化
- 进入页面后，显示本次诊断章节名称
- 展示学生个人知识点掌握统计
- 展示班级知识点掌握统计
- 展示题目分析
- 展示知识点分析表格

## 3. 点击掌握统计区问号
- 点击提示问号后，显示弹窗提示

## 4. 点击题目分析中的题目结果项
- 点击任一题目结果项后，进入题目详情页 / 题目解析页

## 5. 点击班级掌握度问号
- 点击提示问号后，显示弹窗提示

## 6. 点击知识点【去学习】
- 本期点击后，显示 toast 提示【敬请期待~】
- V0.8.1 起，点击后进入对应知识点的专项学习页面

## 7. 点击【推荐学习】
- 本期点击后，显示 toast 提示【敬请期待~】
- V0.8.1 起，按当前章节范围内知识点学习顺序与掌握度数值进行推荐学习

# 业务规则

## 一、返回规则
1. 点击【返回】后，返回自适应学习系统首页。
2. 返回首页时，需定位至用户进入学情诊断前的首页位置。
3. 恢复范围包括：
   - 场景
   - 学科
   - 章节定位
4. 返回首页后不可统一落到固定首页，如不可统一落到【同步学-英语】。

## 二、章节展示规则
1. 页面显示本次诊断的章节名称。
2. 报告页中的章节名称为静态结果展示，不支持在本页切换章节。

## 三、知识点掌握统计区规则
1. 知识点掌握统计区分为个人视角和班级视角两张统计卡片。
2. 左侧卡片展示当前学生在本次诊断章节下的知识点掌握等级分布。
3. 右侧卡片展示当前学生所在班级在同章节范围下的人均知识点掌握情况。
4. 统计维度均为知识点，不是题目数。

### 3.1 学生统计卡片规则
1. 根据诊断结果，按照掌握度等级划分规则，显示学生基于本次诊断的知识点掌握分布情况。
2. 掌握度等级划分规则通过配置后台获取。
3. 展示类别包括：
   - 优秀
   - 良好
   - 一般
   - 较弱
   - 未练习
4. 优秀类别需有特殊标识，标识样式以 UI 稿为准。
5. 优秀类别需从视觉上体现距离“全部优秀”的差距。
6. 优秀进度值计算方式为：
   - 当前学生优秀知识点总数 ÷ 当前章节知识点总数
7. 显示当前学生还未练习的知识点数量。
8. 即使学生已完成学情诊断，仍需显示“未练习”数值，便于与班级进行对比。

### 3.2 班级统计卡片规则
1. 在【班级 + 指定章节】维度下，统计各掌握等级的人均知识点数量。
2. 统计对象为当前班级全部在读学生。
3. 统计章节范围为当前选定章节下的全部知识点。
4. 按知识点掌握等级分组统计：
   - 优秀
   - 良好
   - 一般
   - 较弱
   - 未练习单独统计，不计入以上四个等级
5. 结果按照四舍五入保留 1 位小数。

### 3.3 班级掌握等级计算规则
1. 某掌握等级总数 = 班级内每位学生在该章节下，该掌握等级的知识点数量之和。
2. 若学生在该等级下无知识点，按 0 计入。
3. 未练习知识点不计入任一掌握等级。
4. 某掌握等级人均知识点数 = 该等级总知识点数 ÷ 班级学生总人数。
5. 分母固定为班级学生总人数，不因学生是否学习而变化。

### 3.4 班级优秀进度规则
1. 班级优秀进度用于体现班级距离“全部优秀”的差距。
2. 计算方式为：
   - 班级当前优秀总数 ÷ 当前章节知识点总数

### 3.5 班级未练习规则
1. 从班级人均维度，显示该班级人均有多少个知识点还未练习。
2. 未练习定义：对学生而言，尚未产生掌握度结果的知识点，即为未练习。
3. 结果按照四舍五入保留 1 位小数。
4. 计算规则：
   - 班级未练习人均值 = 班级未练习总数 ÷ 班级学生总人数
   - 班级未练习总数 = 班级内每位学生的未练习知识点数量之和
   - 某学生未练习数 = 章节总知识点数 - 该学生已产生掌握度的知识点数

### 3.6 班级数据取数时间规则
1. 班级维度的数据，除当前学生自己的数据外，每半天更新一次。
2. 统计时间为：
   - 每天凌晨 00:00
   - 每天中午 12:00
3. 当某学生在某时段完成学情诊断时，在上个时段统计数据的基础上，再加上当前学生的数据，以此生成班级维度展示数据。

## 四、题目分析区规则
1. 题目分析模块按题型分组展示。
2. 相同题型的题目归为一类。
3. 各题型排序规则与作业报告保持一致。
4. 若作业报告代码中无明确题型排序规则，则需按学科补齐规则。
5. 每个题目显示批改结果，结果类型包括：
   - √
   - ×
   - 未答
   - 半对
6. 若有主观题，只要主观题自批得分不是满分或零分，就显示【半对】图标。
7. 点击题目结果项后，进入题目详情页 / 题目解析页。

## 五、知识点分析区规则
1. 显示本次诊断涉及到的所有知识点名称。
2. 每一行代表一个知识点。
3. 表格字段包括：
   - 知识点名称
   - 掌握度
   - 班级掌握度
   - 本次诊断题目数
   - 累计练习题数
   - 操作

### 5.1 当前学生掌握度规则
1. 按照掌握度公式计算规则以及掌握程度划分规则，显示各知识点的掌握度数值和对应等级。
2. 具体掌握度数值在显示时，四舍五入保留整数。

### 5.2 班级掌握度规则
1. 以班级为单位，统计该班级所有学生在该章节内对应知识点的人均掌握度。
2. 统计对象为当前班级全部在读学生。
3. 统计章节范围为当前选定章节下的全部知识点。
4. 结果按照四舍五入保留 1 位小数。
5. 计算规则：
   - 各知识点掌握数值 = 在该章节范围内，各知识点已有数据之和 ÷ 各知识点已有数据的学生人数
6. 班级维度的数据，除当前学生自己的数据外，每半天更新一次。
7. 统计时间为：
   - 每天凌晨 00:00
   - 每天中午 12:00
8. 当某学生在某时段完成学情诊断时，在上个时段统计数据的基础上，再加上当前学生的数据，以此生成班级维度展示数据。

### 5.3 本次诊断题目数规则
1. 显示对应知识点在本次诊断中出现的题目数量。
2. 统计口径：
   - 只要某题目包含 A 知识点，无论题目是否仅包含 A 知识点，A 知识点出现的题目数量都 +1

### 5.4 累计练习题数规则
1. 显示当前知识点累计练习过的题目数量。
2. 可覆盖学生先进行单知识点练习、尚未进行学情诊断的历史练习场景。

### 5.5 去学习按钮规则
1. 本期点击【去学习】时，显示 toast 提示【敬请期待~】。
2. V0.8.1 起，每个知识点都显示【去学习】按钮。
3. V0.8.1 起，点击【去学习】后，直接进入该知识点的专项学习页面。

## 六、推荐学习按钮规则
1. 本期点击【推荐学习】时，显示 toast 提示【敬请期待~】。
2. V0.8.1 起，点击【推荐学习】后，按照当前章节内知识点学习的先后关系，以及各知识点掌握度数值进行推荐。
3. 推荐优先级规则为：
   - 越先学习的知识点优先级越高
   - 在学习顺序相同前提下，掌握度数值越低优先级越高
4. 各知识点学习先后关系通过配置后台获取。
5. 若当前推荐知识点系统检测出最好先进行溯源学习，则显示弹窗提醒。
6. 当前知识点是否需要进入溯源学习，以及需要溯源的知识点信息，通过配置后台获取。

## 七、提示问号规则
1. 页面中的提示问号入口点击后，显示弹窗提示。
2. 顶部掌握统计区问号的具体弹窗页面由后续单独说明。
3. 知识点分析区班级掌握度问号的具体弹窗页面由后续单独说明。

# 状态与异常

## 页面状态
- 诊断报告默认展示状态
- 个人掌握统计展示状态
- 班级掌握统计展示状态
- 题目分析展示状态
- 知识点分析表格展示状态
- 推荐学习按钮可点击状态
- 去学习按钮可点击状态

## 异常与边界
1. 报告页中的章节名称为静态结果展示，不支持切换章节。
2. 班级维度数据中，当前学生自己的最新结果需并入展示，其余学生数据按半天更新。
3. 主观题只要不是满分或零分，题目分析中均按【半对】展示。
4. 班级掌握度与班级掌握等级分布需严格区分：
   - 班级掌握等级分布使用“人均知识点数”
   - 班级掌握度使用“知识点人均掌握数值”
5. 本期【推荐学习】与【去学习】按钮均不实际跳转，仅展示 toast 提示。

# 数据来源

## 1. 章节名称
- 来源：本次诊断任务上下文
- 用途：展示报告页章节名称

## 2. 当前学生信息
- 来源：当前登录账号信息
- 包含：
  - 学生姓名
  - 行政班级名称
- 用途：展示个人与班级统计卡片

## 3. 掌握度等级划分规则
- 来源：配置后台
- 用途：用于个人掌握统计与知识点掌握度等级展示

## 4. 班级维度统计数据
- 来源：班级统计数据快照 + 当前学生最新诊断结果
- 用途：用于班级统计卡片与班级掌握度展示

## 5. 题目分析数据
- 来源：本次诊断题目结果数据
- 用途：用于按题型展示题目结果与进入题目详情页

## 6. 知识点分析数据
- 来源：本次诊断知识点映射结果 + 掌握度计算结果 + 历史练习数据
- 用途：用于展示知识点表格各字段

## 7. 参考提示弹窗数据
- 来源：页面说明规则
- 用途：用于问号提示弹窗展示
