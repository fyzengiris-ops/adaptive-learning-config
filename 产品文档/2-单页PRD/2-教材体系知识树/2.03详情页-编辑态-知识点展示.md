# 2.03 详情页-编辑态-知识点展示【GPT更新】

# 页面目标
用于在【教材体系知识树】教材详情页编辑态下，查看和维护当前节点对应的知识点内容。

本页面需支持：
- 基于当前节点是否为末级节点，切换不同的展示与维护模式；
- 末级节点下直接维护知识点；
- 非末级节点下聚合查看其所有子节点的知识点内容；
- 支持新增知识点、删除知识点、拖拽排序、查看全景图谱等能力。

> 说明：
> 1. 当前页面是否可直接维护知识点，不仅取决于是否处于编辑态，还取决于当前节点是否为末级节点。
> 2. 仅在【编辑态 + 当前节点为末级节点】时，才支持直接维护知识点。
> 3. 非末级节点仅支持查看当前节点下各子节点聚合后的知识点内容，不支持直接维护当前节点知识点。
> 4. 全景图谱中的知识点连接关系，基于通用知识树中维护的前后置关系生成。
> 5. 当前页面的全景图谱中，仅展示本小节已关联的知识点，不展示“本小节知识点 / 非本小节知识点”的备注说明。

# 所属页面
知识体系管理 > 教材体系知识树 > 教材详情页 > 右侧章节详情区 > 知识点Tab

> 说明：进入详情页后，左侧章节树自动处于可编辑状态，右侧【编辑章节详情】按钮始终可点击，左右两侧编辑可同时进行。

# 页面区域

## A. 标题行区
用于固定显示【章节详情】标题，右侧显示操作按钮。

## B. 章节名称行区
用于显示当前选中章节路径名称和 Tab 切换栏。

## C. 知识点操作栏区
用于展示当前知识点区域标题、数量、排序提示、全景图谱入口、新增知识点入口等操作信息。

## D. 知识点内容展示区
用于根据当前节点是否为末级节点，展示不同形态的知识点内容。

## E. 全景图谱展示区
用于在末级节点且存在知识点时，展示本小节知识点全景图谱。

## F. 知识点选择弹窗区
用于从通用知识树中选择 / 引用知识点。

# 组件说明

## A. 标题行区组件
- A1. 标题文本：固定显示【章节详情】
- A2. 操作按钮区（编辑态下显示）：
  - 【批量导入】按钮：点击打开批量导入弹窗
  - 【取消】按钮：取消编辑，返回非编辑态
  - 【保存编辑】按钮：保存当前编辑结果，返回非编辑态

## B. 章节名称行区组件
- B1. 章节路径名称：显示当前选中章节的完整路径
  - 章级别：显示完整章名称
  - 节级别：显示"章序号-节名称"格式
- B2. Tab 切换栏：包含【知识点】【同步课程】【练习试卷】三个 Tab
- B3. 分割线：章节名称行底部带分割线

## C. 知识点操作栏区组件
- C1. 区域标题：
  - 非末级节点时显示【知识点总览】
  - 末级节点时显示【关联知识点】
- C2. 数量展示：
  - 非末级节点时显示各子节点对应的知识点数量
  - 末级节点有数据时显示当前节点知识点数量
- C3. 排序提示：仅在末级节点且知识点数量大于 1 时显示【可拖拽排序】
- C4. 【全景图谱】按钮：仅在末级节点且有知识点时显示
- C5. 【+ 知识点】按钮：仅在末级节点时显示

## D. 知识点内容展示区组件
### D1. 非末级节点展示组件
- 按子节点分组展示知识点内容
- 每个子节点块包含：
  - 子节点标题
  - 子节点知识点数量（如有）
  - 子节点知识点列表或空态提示

### D2. 末级节点无数据组件
- 空状态图标
- 空状态标题：显示【暂未关联知识点】
- 空状态说明：显示【点击上方按钮从知识树引用知识点】

### D3. 末级节点有数据组件
- 知识点列表项：
  - 拖拽手柄
  - 知识点名称
  - 删除按钮
- 每个知识点独立一行展示

## E. 全景图谱展示区组件
- E1. 图谱标题区：显示【本节知识点全景图谱】及知识点数量说明
- E2. 图谱画布区：展示当前小节知识点及其前后置关系
- E3. 图谱展开/收起控制：支持展开/收起图谱区域

## F. 知识点选择弹窗区组件
- F1. 弹窗标题栏：显示当前节点名称
- F2. 关闭按钮：关闭弹窗
- F3. 左侧可选知识点区：展示通用知识树中的可选知识点
- F4. 右侧已选知识点区：展示当前已选中的知识点
- F5. 取消按钮：关闭弹窗，不保存
- F6. 确定按钮：保存知识点关联，关闭弹窗

# 交互逻辑

## 1. 切换 Tab
- 用户点击【知识点】【同步课程】【练习试卷】Tab 后：
  - 系统切换到对应 Tab 内容
  - 当前选中节点保持不变
  - 页面不刷新，仅内容区域切换
- **右侧【编辑章节详情】按钮始终可点击**，不受左侧树编辑状态影响

## 2. 页面进入知识点 Tab
- 当用户进入知识点 Tab 时，系统先判断当前节点是否为末级节点
- 若当前节点为非末级节点：
  - 进入聚合查看态
- 若当前节点为末级节点：
  - 进入直接维护态

## 3. 非末级节点展示
- 当当前节点为非末级节点时：
  - 右侧显示【知识点总览】
  - 说明文案为【聚合展示该章节下所有节的知识点】
  - 按当前节点下各子节点逐项展示知识点内容
- 若某子节点下有知识点：
  - 展示该子节点下的知识点列表
- 若某子节点下无知识点：
  - 展示【暂无知识点】

## 4. 末级节点无数据展示
- 当当前节点为末级节点且无知识点时：
  - 显示空状态
  - 展示【+ 知识点】按钮
  - 不展示知识点列表
  - 不展示全景图谱按钮

## 5. 末级节点有数据展示
- 当当前节点为末级节点且已有知识点时：
  - 展示【关联知识点】标题与知识点数量
  - 展示知识点列表
  - 展示【可拖拽排序】提示
  - 展示【全景图谱】按钮
  - 展示【+ 知识点】按钮

## 6. 新增知识点
- 用户点击【+ 知识点】按钮后：
  - 打开知识点选择弹窗
- 弹窗中：
  - 左侧展示通用知识树
  - 右侧展示当前已选知识点
- 用户从通用知识树中选择知识点后：
  - 知识点加入右侧已选区
- 用户点击【确定】后：
  - 保存当前节点知识点关联
  - 刷新知识点列表
  - 记录变更为【添加知识点】
- 用户点击【取消】或关闭弹窗后：
  - 关闭弹窗，不保存修改

## 7. 删除知识点
- 用户在末级节点知识点列表中点击删除按钮后：
  - 系统直接删除该知识点，不弹二次确认
  - 刷新知识点列表
  - 记录变更为【删除知识点】
- 若删除后当前节点下无知识点：
  - 切换为末级节点无数据展示态

## 8. 拖拽排序知识点
- 仅在【编辑态 + 当前节点为末级节点 + 知识点数量大于 1】时支持拖拽排序
- 用户拖拽知识点手柄后：
  - 系统调整知识点顺序
  - 刷新知识点列表顺序
- 排序结果仅影响当前末级节点知识点列表的展示顺序，不改变图谱中的前后置关系逻辑

## 9. 查看全景图谱
- 仅在末级节点且存在知识点时显示【全景图谱】按钮
- 用户点击【全景图谱】按钮后：
  - 展开全景图谱区域
  - 展示当前小节已关联知识点之间的关系图谱
- 图谱关系基于通用知识树中维护的前后置关系生成
- 当前页面中不展示“本小节知识点 / 非本小节知识点”的图例备注说明

## 10. 目录结构变化后的联动
- 若当前节点因左侧目录结构变化，由末级节点变为非末级节点：
  - 当前页立即切换为非末级节点聚合查看态
  - 原有直接维护态退出
  - 后续按子节点聚合内容展示
- 若当前节点仍保持末级节点：
  - 继续展示末级节点维护态

# 业务规则

## 一、节点类型判断规则
1. 当前页面展示与维护能力，优先依据当前节点是否为末级节点判断。
2. 末级节点支持直接维护知识点。
3. 非末级节点不支持直接维护知识点，仅支持查看聚合内容。
4. 编辑态不等于所有节点都可直接维护知识点，必须同时满足【当前节点为末级节点】。

## 二、四类页面状态规则
1. 非末级节点 + 无数据：
   - 展示知识点总览
   - 各子节点下无知识点时，显示【暂无知识点】

2. 非末级节点 + 有数据：
   - 展示知识点总览
   - 按子节点分块展示知识点内容
   - 有知识点的子节点展示列表
   - 无知识点的子节点展示【暂无知识点】

3. 末级节点 + 无数据：
   - 展示空状态【暂未关联知识点】
   - 展示说明文案【点击上方按钮从知识树引用知识点】
   - 展示【+ 知识点】按钮

4. 末级节点 + 有数据：
   - 展示关联知识点列表
   - 展示知识点数量
   - 展示【可拖拽排序】提示
   - 展示【全景图谱】按钮
   - 展示【+ 知识点】按钮

## 三、非末级节点展示规则
1. 非末级节点知识点页统一按“当前节点下各子节点内容总览”方式呈现。
2. 展示结构与当前章节下查看各小节知识点内容的样式保持一致。
3. 每个子节点独立展示自己的标题、数量和知识点列表 / 空态。
4. 非末级节点状态下，不展示【+ 知识点】按钮。
5. 非末级节点状态下，不支持直接删除或排序当前节点知识点。

## 四、末级节点展示规则
1. 当前节点为末级节点时，右侧展示【关联知识点】。
2. 末级节点无数据时：
   - 展示空状态
   - 展示【+ 知识点】按钮
3. 末级节点有数据时：
   - 展示知识点数量
   - 展示知识点列表
   - 展示排序提示
   - 展示全景图谱入口
   - 展示【+ 知识点】按钮

## 五、知识点来源规则
1. 当前页面新增知识点时，不支持手动自由输入知识点名称。
2. 新增知识点需从通用知识树中选择 / 引用。
3. 已被当前小节关联的知识点，不允许重复引用。
4. 空态时的提示文案需与“从知识树引用知识点”的规则保持一致。

## 六、知识点展示规则
1. 当前页面按单层知识点列表展示。
2. 每条知识点独立一行展示。
3. 当前页面不采用“主知识点 / 延伸知识点”展开收起结构。
4. 知识点间关系通过全景图谱展示，不通过列表中的层级结构体现。

## 七、排序规则
1. 知识点拖拽排序仅适用于末级节点的直接关联知识点列表。
2. 非末级节点不支持知识点排序。
3. 排序结果作用于当前末级节点下知识点列表的展示顺序。
4. 全景图谱中的节点关系不因排序而改变前后置逻辑。

## 八、删除规则
1. 删除知识点时，不弹二次确认。
2. 用户点击删除按钮后，系统直接删除对应知识点。
3. 删除后立即刷新列表。
4. 删除结果需记录为【删除知识点】待发布变更。

## 九、全景图谱规则
1. 全景图谱仅在末级节点且有知识点时展示。
2. 全景图谱中只展示当前小节已关联的知识点。
3. 图谱中知识点之间的连线关系，基于通用知识树中维护的前后置关系生成。
4. 当前页 md 中不展示“本小节知识点 / 非本小节知识点”的图例说明。
5. 当前页不扩展展示非本小节知识点。
6. **数据一致性规则**：
   - 全景图谱呈现的知识点前置关联关系，需以通用知识树发布后的数据为准
   - 若通用知识树未发布，则全景图谱展示的是上一版本已发布的前置关联关系
   - 即：教材体系知识树与通用知识树的发布可能不同步，全景图谱需始终使用通用知识树已发布的稳定版本数据，确保展示内容的一致性和稳定性

## 十、与目录结构联动规则
1. 左侧目录结构变化会影响当前页面的展示与维护能力。
2. 当当前节点由末级节点变为非末级节点后：
   - 右侧退出直接维护态
   - 切换为聚合查看态
3. 当当前节点重新成为末级节点时，才恢复直接维护能力。

## 十一、变更记录规则
1. 新增知识点，记录为【添加知识点】。
2. 删除知识点，记录为【删除知识点】。
3. 知识点排序变化，如需进入待发布变更集合，按系统既定规则记录。
4. 所有相关变更需进入待发布变更集合，供后续发布确认使用。

## 十二、权限规则
1. 仅在编辑态下才可能进入知识点直接维护能力。
2. 即使处于编辑态，也只有末级节点可直接维护知识点。
3. 无编辑权限的角色不可执行新增、删除、排序等操作。

# 状态与异常

## 页面状态
- 非末级节点聚合查看态
- 末级节点无数据态
- 末级节点有数据态
- 知识点选择弹窗打开态
- 全景图谱展开态

## 异常与边界
1. **无知识点**
   - 末级节点无知识点时，显示空状态提示

2. **聚合无数据**
   - 非末级节点下若子节点均无知识点，则各子节点下展示【暂无知识点】

3. **知识点加载失败**
   - 知识点数据加载失败时，提示加载失败并支持重试

4. **知识点关系图谱加载失败**
   - 图谱数据加载失败时，提示加载失败，不影响知识点列表查看

5. **引用重复知识点**
   - 若用户尝试重复引用当前小节已关联知识点，应阻断并提示不可重复添加

6. **保存失败**
   - 新增、删除、排序知识点保存失败时，应提示失败，并保留当前页面可恢复状态，具体以后续实现拍板为准

| 通用知识树数据 | 通用知识树数据源 | 用于新增知识点时选择 / 引用 |

| 编辑态状态 | 当前页面状态 | 控制是否允许知识点维护操作 |

# 技术要求

1. 当前页需根据节点是否为末级节点，动态切换展示模式。
2. 末级节点维护态与非末级节点聚合态需支持同页切换刷新。
3. 知识点列表需支持末级节点下的拖拽排序。
4. 新增知识点需支持从通用知识树中选择 / 引用。
5. 全景图谱需支持基于通用知识树前后置关系生成。
6. 当前页全景图谱中仅展示本小节已关联知识点。
7. 页面不展示“本小节知识点 / 非本小节知识点”的图例备注说明。
