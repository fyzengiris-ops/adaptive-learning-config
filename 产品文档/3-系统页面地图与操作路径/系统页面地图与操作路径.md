# 自适应学习配置后台系统页面地图与操作路径总文档【GPT整合版】

## 一、文档说明

本文档用于梳理【自适应学习配置后台】当前核心模块的系统页面全貌、页面层级关系、关键操作路径与页面间跳转逻辑，便于用于：

1. 开发快速理解整个配置后台的页面结构与主链路  
2. 产品评审时统一页面口径、边界和交互范围  
3. 测试梳理页面覆盖范围、核心操作链路和异常回流路径  
4. 后续继续补充单页详细 PRD 时，作为母文档和导航文档使用  
5. 开发将系统结构进一步提供给 AI 时，作为高层级页面地图与跳转说明文档  

本文档当前整合以下模块：
1. 通用知识树
2. 教材体系知识树
3. 策略广场
   - 学前诊断策略
   - 掌握程度划分

本文档重点关注以下内容：
1. 系统包含哪些模块与页面
2. 页面之间的上下级关系
3. 页面从哪里进入、到哪里返回
4. 页面中的关键点击路径
5. 当前版本已支持与未支持的能力边界
6. 发布、定时发布、导入导出、同步规则等关键流程在页面链路中的位置

> 说明：
> - 本文档为“总母文档”，用于整合多个模块的系统页面地图。
> - 各模块的单独页面 PRD、详细字段规则、状态规则，仍建议继续保留在各自模块的详细 md 文档中。
> - 本文档重点是“页面地图 + 操作路径 + 页面关系”，不是替代单页详细 PRD。

## 四、系统主流程总链路

### 4.1 从模块入口进入知识体系管理

乐课平台  
→ 点击左侧导航【知识体系管理】  
→ 进入知识体系管理模块  
&emsp;├── 进入【通用知识树首页】  
&emsp;└── 进入【教材体系知识树-首页】

### 4.2 从模块入口进入策略广场

乐课平台  
→ 点击左侧导航【策略管理】  
→ 进入【策略广场】  
&emsp;├── 进入【学前诊断策略-首页】  
&emsp;└── 进入【掌握程度划分-首页】

### 4.3 知识树模块主链路

#### 通用知识树
通用知识树首页  
→ 进入学科详情页（非编辑态）  
→ 点击【编辑知识树】  
→ 进入编辑态  
→ 点击【完成编辑】  
&emsp;├── 无实际变更 → 返回详情页，状态不变  
&emsp;└── 有实际变更 → 返回详情页，进入待发布状态  
→ 点击【发布】  
→ 进入发布确认弹窗  
→ 立即发布 / 定时发布

#### 教材体系知识树
教材体系知识树-首页  
→ 进入详情页（非编辑态）  
→ 进入编辑态（两种入口）：
  ─── 方式一：点击左侧【编辑树结构】按钮（仅教研主管可见）
  │     → 进入树结构编辑态
  │     → 左侧章节树可编辑，右侧详情区保持只读
  │     → 顶部导航区显示【完成编辑】【导入教材】【导出教材】按钮
  │
  ─── 方式二：点击右侧【编辑章节详情】按钮
        → 进入章节详情编辑态
        → 左侧章节树保持只读，右侧详情区可编辑
        → 右侧操作按钮变为【批量导入】【取消】【保存编辑】
→ 点击【完成编辑】/【保存编辑】
&emsp;→ 返回详情页（非编辑态）  
&emsp;→ 若有变更，进入待发布状态  
→ 点击【发布】  
→ 进入发布确认弹窗  
→ 立即发布 / 定时发布

### 4.4 策略广场主链路

#### 学前诊断策略
学前诊断策略-首页  
→ 新增策略 / 进入已有策略详情  
→ 详情页（非编辑态）  
→ 点击【编辑】  
→ 进入编辑态  
→ 点击【保存】  
&emsp;→ 返回非编辑态  
&emsp;→ 根据结果显示待发布状态或定时发布状态  
→ 点击【发布】  
→ 打开发布确认弹窗  
→ 立即发布 / 定时发布

#### 掌握程度划分
掌握程度划分-首页  
→ 进入当前学段详情页（非编辑态）  
→ 点击【编辑】  
→ 进入编辑态  
→ 点击【保存】  
&emsp;→ 返回非编辑态  
&emsp;→ 根据结果显示待发布状态或定时发布状态  
→ 点击【发布】  
→ 打开发布确认弹窗  
→ 立即发布 / 定时发布

## 六、模块一：通用知识树

- 学科知识树维护
- 知识点信息维护
- 知识点结构维护
- 批量导入 / 导出
- 发布 / 定时发布

## 十一、系统关键回流路径

### 11.1 首页与详情页回流

- 通用知识树首页 → 详情页 → 返回首页
- 教材体系知识树-首页 → 详情页 → 返回首页

- 掌握程度划分-首页 → 详情页 → 返回首页

### 11.2 非编辑态与编辑态回流

#### 通用知识树
详情页（非编辑态）  
→ 点击【编辑知识树】  
→ 进入编辑态  
→ 点击【完成编辑】  
&emsp;├── 无实际变更 → 回到详情页，状态不变  
&emsp;└── 有实际变更 → 回到详情页，并进入待发布状态

#### 教材体系知识树
详情页（非编辑态）  
→ 点击【编辑教材】  
→ 进入编辑态  
→ 点击【完成编辑】  
&emsp;→ 返回详情页（非编辑态）  
&emsp;→ 如有改动，页面进入待发布状态

#### 学前诊断策略
详情页（非编辑态）  
→ 点击【编辑】  
→ 进入编辑态  
→ 点击【保存】  
&emsp;├── 无有效变更 → 返回非编辑态，不显示橙色条  
&emsp;└── 有有效变更 → 返回非编辑态，显示橙色条

#### 掌握程度划分
详情页（非编辑态）  
→ 点击【编辑】  
→ 进入编辑态  
→ 点击【保存】  
&emsp;├── 无有效变更 → 返回非编辑态，不显示橙色条  
&emsp;└── 有有效变更 → 返回非编辑态，显示橙色条

### 11.3 弹窗关闭回流路径

- 首页历史发布记录弹窗关闭 → 返回首页
- 详情页发布历史弹窗关闭 → 返回详情页
- 发布确认弹窗关闭 → 返回详情页
- 添加知识点弹窗关闭 → 返回知识点页
- 编辑前置知识点弹窗关闭 → 返回知识点结构页
- 课程资源库选择弹窗关闭 → 返回同步课程页
- 课程预览弹窗关闭 → 返回原触发页
- 试卷资源库选择弹窗关闭 → 返回练习试卷页
- 试卷预览弹窗关闭 → 返回原触发页
- 导入教材弹窗关闭 → 返回编辑态

### 11.4 定时发布状态回流

#### 通用知识树 / 教材体系知识树 / 学前诊断策略 / 掌握程度划分 共性规则

详情页顶部蓝色定时发布提醒条 / 蓝色定时发布状态条  
→ 进入编辑态  
→ 完成编辑  
&emsp;├── 无变更 → 恢复蓝色条  
&emsp;└── 有变更 → 切换橙色待发布条  
→ 再次点击【发布】  
→ 重新进入发布确认弹窗  
→ 回写上次填写说明  
→ 合并展示上次待发布内容与本次新增变更内容
