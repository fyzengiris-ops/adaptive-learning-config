# 1.0 首页-无数据【GPT更新】

# 页面目标
用于展示【教材体系知识树】首页在当前范围内无教材数据时的页面状态，并作为教材体系知识树模块的初始化承接页面。

本页面需支持：
- 按学段、学科、版本进行筛选；
- 在无教材数据时向用户明确反馈当前状态；
- 提供新增教材入口；
- 支持查看历史发布记录；
- 承接乐课网原有教材树数据同步后的无数据状态展示。

> 说明：
> 1. 本页面的“无数据”是指：当前页面加载后，在当前筛选范围内不存在可展示的教材数据。
> 2. 本页面需结合乐课网平台原有教材树数据同步结果进行判断，不能仅以新功能侧是否新增过教材作为无数据依据。
> 3. 本页面属于教材体系知识树首页的空态表现，不是独立模块页面。

# 所属页面
知识体系管理 > 教材体系知识树 > 首页

# 页面区域

## A. 顶部筛选栏
用于按学段、学科、版本筛选教材数据，并提供查看历史发布记录与新增教材入口。

## B. 无数据展示区
用于在当前筛选条件下无教材数据时，展示空态说明、引导文案及新增教材操作入口。

---

# 组件说明

## A. 顶部筛选栏组件
- A1. 学段选择器：下拉选择框，选项为乐课网平台已有的学段数据
- A2. 学科选择器：下拉选择框，选项为当前所选学段下，乐课网平台已有的学科数据
- A3. 版本选择器：下拉选择框，选项为当前筛选范围下乐课网平台已有的版本数据，默认支持【全部版本】
- A4. 【查看历史发布记录】按钮：点击进入历史发布记录相关页面或后续对应能力
- A5. 【新增教材】按钮：点击进入新增教材流程

## B. 无数据展示区组件
- B1. 空态图标：用于提示当前暂无教材数据
- B2. 空态标题：用于明确提示当前暂无教材
- B3. 空态说明文案：用于说明当前无数据原因及下一步可执行操作
- B4. 空态操作按钮：【新增教材】按钮，点击进入新增教材流程

# 交互逻辑

## 1. 页面进入
- 用户进入【教材体系知识树】首页后，系统先加载当前筛选条件下的教材列表数据
- 若当前筛选范围内不存在可展示教材，则展示无数据页面状态
- 顶部筛选栏正常可用，不因无数据状态而禁用

## 2. 学段筛选
- 用户切换学段后：
  - 系统更新学科下拉选项；
  - 版本下拉选项同步更新为当前条件下可选版本；
  - 页面重新加载教材数据
- 若切换后存在教材数据，则从无数据态切换为有数据态
- 若切换后仍无教材数据，则保持无数据态

## 3. 学科筛选
- 用户切换学科后：
  - 系统保留当前学段；
  - 更新版本可选项；
  - 页面重新加载教材数据
- 若存在匹配教材，则切换至有数据态
- 若不存在匹配教材，则保持无数据态

## 4. 版本筛选
- 用户切换版本后：
  - 页面按新的筛选条件重新加载教材数据
- 当选择【全部版本】时：
  - 表示查询当前筛选范围下全部版本类别对应的教材

## 5. 顶部新增教材
- 用户点击顶部【新增教材】按钮后：
  - 进入新增教材流程
  - 新增成功后，教材应纳入教材体系知识树统一管理范围
  - 若新增教材满足当前筛选条件，则页面从无数据态切换为有数据态
  - 新增完成后，教材默认进入待发布状态

## 7. 空态区新增教材
- 用户点击空态区【新增教材】按钮后：
  - 进入新增教材流程
  - 新增逻辑与顶部【新增教材】保持一致
  - 新增成功后，若满足当前筛选条件，则直接在首页展示新增教材卡片

## 8. 查看历史发布记录
- 用户点击【查看历史发布记录】按钮后：
  - 进入历史发布记录相关页面或对应能力
  - 具体记录展示规则以后续独立页面为准

# 业务规则

## 一、无数据判定规则
1. 本页面“无数据”是指：在当前筛选条件下，首页无可展示教材数据。
2. 无数据判定需基于【乐课网原有教材树同步数据】与【新功能侧教材数据】的统一结果进行判断。
3. 不得仅因新功能侧尚未新增教材，就直接判定为无数据。
4. 若乐课网平台原有教材树中已存在教材，且满足当前筛选条件，则应展示为有数据态，而非无数据态。
5. 仅当同步结果与当前筛选条件下均无教材时，才展示无数据态。

## 二、首页数据展示规则
1. 首页展示的数据来源于【乐课网原有教材树数据】与【新功能扩展数据】的统一结果。
2. 乐课网平台原有教材树中已存在的教材数据，需同步显示在本页面中。
3. 用户不需要先在新功能中重新新增教材，原平台已有教材只要满足筛选条件，即应在首页展示。
4. 本页面展示的是同一套教材树主体数据，不应将原功能与新功能拆成两套孤立教材数据。
5. 若教材仅同步了基础目录数据，但尚未维护扩展信息，也应正常展示为有数据态，而不是无数据态。

## 三、筛选规则
1. 学段下拉选项，取乐课网平台已有的学段数据。
2. 学科下拉选项，取当前所选学段下，乐课网平台已有的学科数据。
3. 版本下拉选项，取当前筛选范围下乐课网平台已有的版本数据，并支持【全部版本】。
4. 学段、学科为核心筛选条件，版本为辅助筛选条件。
5. 当前页面示例值可沿用首页默认筛选逻辑，不因无数据态改变筛选规则。

## 四、空态展示规则
1. 当页面处于无数据态时，顶部筛选栏仍需保留并可正常操作。
2. 空态区需明确提示当前暂无教材数据。
3. 空态区需提供明确的新增教材入口，便于用户快速完成初始化操作。
4. 空态文案应优先表达“当前筛选范围下暂无教材”，避免误导用户理解为系统完全不可用。
5. 若后续切换筛选条件后存在教材数据，应立即切换为有数据页面，不继续停留在空态页。

## 五、目录同步规则
1. 教材树目录为原有功能与新功能联动维护的数据对象。
2. 原有乐课网功能区修改教材树目录后，新功能首页需同步展示最新目录结果。
3. 新功能侧修改教材树目录后，原有功能区目录数据也需同步更新。
4. 首页展示以同步后的最新教材目录数据为准。
5. 不允许原有功能与新功能长期维护两套不一致的教材目录数据。
6. 若同步存在延迟，应以最终同步结果刷新首页展示数据。

## 六、发布状态规则
1. 当页面处于无数据态时，不展示教材卡片级发布状态。
2. 新增教材成功后，新增教材默认进入待发布状态。
3. 若后续因筛选切换进入有数据态，则对应教材按实际状态展示【已发布】【待发布】。
4. 原有功能区改动教材目录后，如该教材满足当前筛选条件并已同步进入首页，则应按待发布或实际发布状态展示，不应继续展示为空态。

## 七、新增规则
1. 顶部【新增教材】与空态区【新增教材】均用于新增教材主体数据。
2. 新增教材成功后，应纳入教材体系知识树统一管理范围。
3. 新增教材后，应同步进入新旧功能联动链路。
4. 新增后的教材默认进入待发布状态。
5. 同一教材不允许重复新增。
6. 去重建议口径为：同一学段、学科、版本类别、教材名称、教材版次组合下，不允许重复新增。
7. 若与乐课网平台原有教材树中已有教材重复，应阻断新增并提示不可重复新增。

## 八、权限规则
1. 具备教材体系知识树维护权限的后台角色，可见：
   - 顶部【新增教材】按钮
   - 空态区【新增教材】按钮
2. 无维护权限的角色，仅可查看空态信息，不可新增。
3. 当前截图示例角色【教研主管】应具备新增权限。

# 状态与异常

## 页面状态
- 加载中：页面初次进入且数据尚未返回时，展示加载中状态
- 无数据状态：当前筛选条件下无可展示教材时，展示空态内容
- 有数据状态：当前筛选条件下存在教材数据时，切换为首页有数据态
- 同步处理中：若原平台教材树数据正在同步中，可展示加载中或同步中状态，不应直接判定为空

## 异常与边界
1. **原平台数据同步失败**
   - 当乐课网已有教材树数据同步失败时，应提示数据同步异常
   - 未完成同步前，不应直接将页面永久判定为无数据

2. **筛选结果为空**
   - 若系统中存在教材数据，但当前筛选条件下无匹配教材，可展示当前页面空态
   - 空态文案应强调“当前筛选范围下暂无教材”

3. **新增后未及时刷新**
   - 若新增教材成功，但列表未及时刷新，应自动刷新页面数据或提示用户刷新后查看
   - 若新增教材满足当前筛选条件，应切换至有数据态

4. **新增后同步失败**
   - 若新增教材成功但未能同步进入统一目录体系，则该次新增不可视为最终成功
   - 应明确提示新增失败或同步失败

5. **历史发布记录入口异常**
   - 若点击历史发布记录入口后对应能力加载失败，应提示加载失败并支持重试
   - 具体异常处理以后续独立页面为准

# 技术要求

1. 页面需支持按学段、学科、版本进行筛选查询。
2. 页面需支持基于乐课网原有教材树数据与新功能数据的统一结果判断是否进入无数据态。
3. 页面需支持乐课网原有教材树数据的同步接入与展示判断。
4. 页面需支持原有功能与新功能目录同步后的统一结果展示。
5. 页面需支持按权限控制新增入口显示。
6. 页面需支持从无数据态切换至有数据态的自动刷新与状态更新。
7. 页面需支持局部字段缺省时的容错展示，不因部分字段缺失导致整页不可用。
8. 页面需支持后续历史发布记录能力接入。
