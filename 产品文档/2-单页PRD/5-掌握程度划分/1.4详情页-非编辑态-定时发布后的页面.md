# 1.4 详情页-非编辑态-定时发布后的页面【GPT更新】

## 页面目标

用于在当前学段掌握程度划分策略详情页中展示定时发布后的页面状态。当用户成功设置定时发布后，页面顶部展示蓝色定时发布状态条；当定时任务被取消或当前内容形成新的待发布变更后，页面顶部切换为橙色待发布状态条。

> 当前页面仅描述当前详情页所属学段的定时发布后状态，不处理其他学段的定时发布状态。

## 所属页面

策略管理 > 策略广场 > 掌握程度划分 > 详情页 > 非编辑态 > 定时发布后的页面

---

## 页面定位

1. 当前页面为单学段详情页在“已设置定时发布”后的非编辑态页面状态。
2. 当前页面重点描述：
   - 蓝色定时发布状态条的展示规则
   - 蓝色定时发布状态条与橙色待发布状态条之间的切换规则
   - 从定时发布态进入编辑态后的状态流转规则
   - 再次发布时的弹窗信息回写规则
3. 当前页面不替代发布确认弹窗、编辑态页面和发布历史弹窗页面。

---

## 页面结构

### A. 页面头部区域

用于展示返回入口、学段信息、版本信息与状态信息。

| 元素 | 说明 |
|------|------|
| 返回按钮 | 点击后返回掌握程度划分首页 |
| 学段图标 | 展示当前学段对应图标 |
| 页面标题 | 显示：**{学段}掌握度划分策略** |
| 页面描述 | 显示：**定义{学段}阶段知识点掌握程度的等级划分标准** |
| 版本信息 | 展示当前版本号 |
| 状态信息 | 展示当前页面状态对应的版本状态 |

#### 展示规则

1. 页面标题固定格式为：**{学段}掌握度划分策略**
2. 页面描述固定格式为：**定义{学段}阶段知识点掌握程度的等级划分标准**
3. 当当前学段已成功设置定时发布后：
   - 页面右上角版本号展示为：**待发布版本号**
   - 页面右上角状态展示为：**待发布**
4. 当用户取消定时后：
   - 页面右上角版本号仍展示：**待发布版本号**
   - 页面右上角状态仍展示：**待发布**
5. 当定时任务到达并成功执行发布后：
   - 页面右上角版本号更新为：**正式已发布版本号**
   - 页面右上角状态更新为：**已发布**

---

### B. 顶部状态提示区域

用于展示当前页面所处的发布状态。

| 状态条类型 | 说明 |
|------|------|
| 蓝色定时发布状态条 | 当前学段已成功设置定时发布，且当前内容仍与该定时任务一致时展示 |
| 橙色待发布状态条 | 当前学段存在已保存但未发布的有效变更，且当前未处于有效定时发布状态时展示 |

#### 展示规则

1. 当当前学段已成功设置定时发布，且在定时时间到达前，页面顶部展示：**蓝色定时发布状态条**
2. 当当前学段存在已保存但未发布的有效变更，且当前未处于有效定时发布状态时，页面顶部展示：**橙色待发布状态条**
3. 蓝色定时发布状态条与橙色待发布状态条互斥展示，同一时刻仅展示一种

---

### C. 掌握程度区间配置卡片区域

用于展示当前学段的掌握程度区间配置内容。

| 元素 | 说明 |
|------|------|
| 卡片标题 | 显示：**掌握程度区间配置** |
| 卡片副标题 | 显示：**配置{学段}各掌握等级的区间范围与颜色标识** |
| 编辑按钮 | 点击后进入编辑态页面 |
| 配置表格 | 展示当前学段掌握度等级、颜色标识、区间范围 |
| 提示文案 | 提示用户通过编辑按钮进行修改 |

#### 展示规则

1. 页面主体展示【掌握程度区间配置】卡片。
2. 当页面处于蓝色定时发布展示态时，卡片中展示的是**当前待发布版本对应的配置内容**。
3. 当前页面仍为非编辑态，表格内容只读展示，不可直接修改。
4. 用户若需修改内容，必须点击【编辑】按钮进入编辑态。

---

## 顶部状态规则

### 1. 蓝色定时发布状态条

#### 展示条件

1. 当前学段已成功设置定时发布
2. 定时发布时间尚未到达
3. 当前页面内容未产生新的已保存未发布变更
4. 当前页面回显内容仍对应上一次定时发布任务的待发布版本内容

#### 展示内容

1. 定时发布提示文案
2. 【查看历史版本】按钮
3. 【取消定时】按钮

#### 文案示例

**v{版本号} 版本将于您设定的时间（{日期} {时间}）自动发布**

**完整示例**：v1.1 版本将于您设定的时间（2026-04-25 02:00）自动发布

#### 补充规则

1. 当页面处于蓝色定时发布展示态时，状态条右侧可展示：
   - 【查看历史版本】按钮
   - 【取消定时】按钮
2. 【查看历史版本】按钮用于打开当前学段的发布历史弹窗
3. 该按钮为当前页面设计中的一部分，与普通详情页头部的历史入口图标属于不同位置的入口，但指向同一类历史查看能力

---

### 2. 橙色待发布状态条

#### 展示条件

1. 当前学段存在已保存但未发布的有效变更
2. 当前学段未处于有效定时发布状态

#### 展示内容

1. 待发布提示文案
2. 发布按钮

#### 补充规则

1. 当页面切换为橙色待发布状态条后，用户仍可继续：
   - 点击【编辑】进入编辑态
   - 点击【发布】重新进入发布确认弹窗
2. 橙色待发布状态条表示：当前学段已有待发布版本，但当前没有有效的自动发布时间安排

## 交互逻辑

### 1. 设置定时发布成功后的页面回显

1. 用户在发布确认弹窗中选择【定时发布】，并完成发布日期、发布时间、更新说明填写后提交。
2. 系统保存当前学段的定时发布任务。
3. 提交成功后，页面关闭发布确认弹窗。
4. 页面进入定时发布展示态，顶部展示蓝色定时发布状态条。
5. 页面右上角版本号展示为待发布版本号。
6. 页面右上角状态展示为：**待发布**。

---

### 2. 取消定时发布

1. 用户在定时发布时间到达前点击【取消定时】按钮后，系统取消当前定时发布任务。
2. 取消成功后：
   - 蓝色定时发布状态条消失
   - 页面顶部切换为**橙色待发布状态条**
3. 此时表示：当前学段仍存在待发布版本，但不再按原定时间自动发布。
4. 页面仍允许用户继续执行编辑或重新发布操作。

---

### 3. 从定时发布态进入编辑态

1. 当页面当前处于蓝色定时发布展示态时，用户点击【编辑】按钮后，进入编辑态。
2. 进入编辑态后，**蓝色定时发布状态条不再展示**。
3. 用户可在编辑态中正常修改当前学段配置内容。
4. 进入编辑态时，系统仍需保留“当前已设置的定时发布任务信息”，供后续保存后判断页面应恢复哪一种状态条。

---

### 4. 二次编辑后未改动保存

1. 当页面原本处于蓝色定时发布展示态，用户进入编辑态后**未实际修改配置内容**。
2. 用户点击【保存】后，页面应继续保留原定时发布任务。
3. 保存完成后，页面顶部应**恢复显示原蓝色定时发布状态条**。
4. 恢复展示的蓝色状态条应继续回显原定时发布任务对应的信息。

---

### 5. 二次编辑后有改动保存

1. 当页面原本处于蓝色定时发布展示态，用户进入编辑态后**实际修改了配置内容**。
2. 用户点击【保存】后，若本次保存形成新的已保存未发布变更，则：
   - 原蓝色定时发布状态条不再展示
   - 页面顶部改为展示**橙色待发布状态条**
3. 此时表示：原定时发布任务不再适用于当前最新保存内容，当前学段需重新执行发布或重新设置定时发布。

---

### 6. 再次点击发布时的信息回写

1. 当用户从橙色待发布状态条再次点击【发布】按钮打开发布确认弹窗时，弹窗需优先回写用户上一次已填写的发布信息。
2. 回写内容包括：
   - 上次填写的变更说明
   - 上次选择的发布时间方式（立即发布 / 定时发布）
   - 若上次选择过定时发布，则回写上次选择的定时发布日期与定时发布时间
3. 用户可在回写内容基础上继续修改并重新提交。

---

### 7. 两次变更内容的合并回写

1. 当用户原本已设置定时发布，后续重新进入编辑态并再次修改配置后，
2. 若页面由蓝色定时发布状态条切换为橙色待发布状态条，
3. 用户再次点击【发布】进入发布确认弹窗时，
4. 弹窗中的【本次变更内容】区域需展示：
   - 上一次定时发布对应但尚未正式生效的变更内容
   - 本次重新编辑后新增的变更内容
5. 两次产生的变更内容应合并后统一回显，供用户确认当前待发布版本将包含的完整变更范围。

---

### 8. 定时发布时间到达后的页面回显

1. 当定时发布时间到达并发布执行成功后：
   - 蓝色定时发布状态条不再展示
   - 页面顶部不再展示橙色待发布状态条
   - 页面右上角版本号更新为正式已发布版本号
   - 页面右上角状态更新为：**已发布**
2. 页面主体继续按最新已发布配置内容进行回显。

---

## 业务规则

### 一、状态条展示规则

1. 当当前学段已成功设置定时发布，且在定时时间到达前，页面顶部展示：**蓝色定时发布状态条**
2. 当当前学段存在已保存但未发布的有效变更，且当前未处于有效定时发布状态时，页面顶部展示：**橙色待发布状态条**
3. 蓝色定时发布状态条与橙色待发布状态条互斥展示，同一时刻仅展示一种

### 二、蓝色定时发布状态条规则

1. 蓝色定时发布状态条展示的是：**当前定时发布任务对应的待发布版本信息**
2. 仅当当前页面内容未产生新的已保存未发布变更时，才展示蓝色定时发布状态条
3. 若当前页面内容已不再与该定时发布任务对应版本一致，则不再展示蓝色定时发布状态条

### 三、取消定时规则

1. 用户取消定时发布后，当前待发布版本仍然存在
2. 蓝色定时发布状态条切换为橙色待发布状态条
3. 页面右上角版本号仍展示待发布版本号
4. 页面右上角状态仍展示：**待发布**

### 四、编辑期间状态流转规则

1. 用户从蓝色定时发布展示态进入编辑态后，页面暂不展示蓝色定时发布状态条
2. 编辑完成点击保存后：
   - 若本次保存未形成新的有效变更，则恢复原蓝色定时发布状态条
   - 若本次保存形成新的有效变更，则页面改为显示橙色待发布状态条

### 五、再次发布信息回写规则

1. 当用户再次从橙色待发布状态条点击【发布】时，发布确认弹窗需回写上一次填写过的信息
2. 回写内容包括：
   - 变更说明
   - 发布时间方式
   - 定时发布日期
   - 定时发布时间
3. 用户可在回写基础上继续修改并重新提交

### 六、变更内容合并展示规则

1. 当原定时发布任务尚未正式生效，又产生了新的配置修改时，
2. 发布确认弹窗中需合并展示两次变更内容
3. 合并后的变更内容用于表达当前待发布版本的完整变更范围

### 七、定时发布完成后的回收规则

1. 定时任务执行成功后，页面不再展示蓝色定时发布状态条
2. 页面右上角版本号更新为正式发布版本号
3. 页面右上角状态更新为：**已发布**
4. 页面顶部不再展示橙色待发布条

## 显示说明

### 1. 页面整体展示说明

1. 当前页面为单学段详情页在定时发布后的非编辑态页面
2. 页面由页面头部区域、顶部状态提示区域、掌握程度区间配置卡片区域组成
3. 页面重点展示当前待发布版本的定时发布信息与后续状态切换结果

### 2. 页面头部展示说明

1. 页面头部展示返回按钮、学段图标、页面标题、页面描述
2. 页面右上角展示版本号与状态
3. 当页面处于定时发布后的非编辑态时，右上角版本号与状态按待发布口径展示

### 3. 顶部状态展示说明

1. 当当前学段存在有效定时发布任务时，页面顶部展示蓝色定时发布状态条
2. 当当前学段存在待发布变更但无有效定时发布任务时，页面顶部展示橙色待发布状态条
3. 当既无待发布变更，也无定时发布任务时，页面顶部不展示状态条

### 4. 配置卡片区展示说明

1. 配置卡片区展示当前学段的掌握程度区间配置
2. 页面主体展示的配置内容与当前待发布版本保持一致
3. 当前页面为非编辑态，配置表格内容均为只读展示
4. 用户点击【编辑】按钮后方可进入编辑态修改内容

---

## 操作说明

### 1. 查看操作

1. 用户可查看当前学段的定时发布状态、版本号、状态及配置内容
2. 用户可通过顶部状态条判断当前页面所处的发布状态

### 2. 取消定时操作

1. 用户点击蓝色定时发布状态条中的【取消定时】按钮后，取消当前定时发布任务
2. 取消成功后，页面切换为橙色待发布状态条展示态

### 3. 编辑操作

1. 用户点击配置卡片右上角【编辑】按钮后，进入编辑态页面
2. 编辑保存后，页面根据是否产生新的有效变更，决定恢复蓝色条或切换橙色条

### 4. 再次发布操作

1. 当页面显示橙色待发布状态条时，用户可点击【发布】按钮进入发布确认弹窗
2. 弹窗需回写上次已填写的变更说明和发布时间信息，并合并展示两次产生的变更内容

---

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 蓝色定时发布展示态 | 已设置定时发布，当前无新变更，顶部展示蓝色定时发布状态条 |
| 橙色待发布展示态 | 当前存在待发布变更但无有效定时发布，顶部展示橙色待发布状态条 |
| 已发布展示态 | 定时任务执行成功后，页面恢复正常已发布状态 |

### 2. 异常与边界处理

1. 用户取消定时发布后，页面需切回橙色待发布状态条
2. 用户进入编辑态后未改动保存，页面需恢复原蓝色定时发布状态条
3. 用户进入编辑态后改动保存，页面需切换为橙色待发布状态条
4. 用户再次发布时，弹窗需回写上次填写的变更说明，并合并展示两次产生的变更内容

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 当前学段已设置定时发布，且时间未到 | 展示蓝色定时发布状态条 |
| 用户取消定时发布 | 蓝色条消失，切换为橙色待发布条 |
| 用户进入编辑态但未改动保存 | 恢复原蓝色定时发布状态条 |
| 用户进入编辑态并改动保存 | 显示橙色待发布条 |
| 用户再次点击发布 | 发布确认弹窗回写上次填写过的信息，并合并展示两次变更内容 |
| 定时任务到时且执行成功 | 页面恢复为已发布态 |

## 权限与范围说明
