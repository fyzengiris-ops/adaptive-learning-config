## 已确认决策

1. 字段：学业要求卡片（新建末级默认值）
   - 影响类型：A
   - 决策：A
   - 结论：新建末级知识点时，学业要求、考频均默认未设置
   - 影响范围：新建节点初始值、只读【未设置】展示、导出空列

2. 字段：考频卡片（未设置展示）
   - 影响类型：B
   - 决策：A
   - 结论：无值一律展示【未设置】，不区分从未设置 / 已清空
   - 影响范围：只读展示、编辑态下拉「未设置」选项

3. 按钮：保存编辑
   - 影响类型：B
   - 决策：A
   - 结论：变更详情保持笼统「修改知识点配置」；维度为「知识点信息」
   - 影响范围：待发布变更列表文案

4. 按钮：取消编辑
   - 影响类型：B
   - 决策：A
   - 结论：有未保存修改（含仅改学业要求）时取消须二次确认，确认后丢弃；文案「当前有未保存的修改，确定要放弃吗？」
   - 影响范围：取消 / 返回确认弹窗

5. 操作：编辑中切换字段 / Tab（与既有考频规则对齐）
   - 影响类型：B
   - 决策：自定义方案
   - 结论：与既有考频及《2.04》一致——编辑态下本知识点各字段（含学业要求、考频、策略及结构/学习资源等）均可改，写入临时缓存；切换 Tab/字段不自动保存、不丢暂存；仅「保存编辑」统一提交；仅「取消/返回」在有未保存时弹确认。学业要求不另定特殊保存规则。
   - 影响范围：编辑会话、Tab 切换、保存/取消

6. 显示：左侧知识树标签
   - 影响类型：B（展示边界）
   - 决策：自定义方案
   - 结论：学业要求无论是否已保存，都不在左侧知识树节点上显示标签；左侧末级仅保留考频标签
   - 影响范围：左侧树节点标签

7. 导出：学业要求空值单元格
   - 影响类型：A
   - 决策：A
   - 结论：未设置时导出该列留空（不写「未设置」文案）
   - 影响范围：导出 Excel 数据区

8. 导入：模板是否含示例行
   - 影响类型：A
   - 决策：A
   - 结论：模板仅含顶行填写说明 + 表头，不带示例数据行
   - 影响范围：下载导入模板

9. 导入：留空 / 【清空】 / 写回
   - 影响类型：A
   - 决策：自定义方案
   - 结论：业务逻辑与后续 PRD 须写清——留空不更新该字段；【清空】将该末级学业要求置为未设置；填写了解/理解/掌握/运用/超纲则更新为对应值。本仓库为产品原型，代码不必实现真实写回，以文档口径为准。
   - 影响范围：PRD / logicSections；不强制改导入写回实现

10. 文案：批量导入弹窗说明列表
    - 影响类型：B
    - 决策：自定义方案
    - 结论：弹窗为感叹号 + 标题「导入说明」，列表文案为：
      1. 请先下载模板文件，按照模板格式填写知识点数据
      2. 二级标题为必填项，三、四、五级标题根据实际情况填写
      3. 前置知识点如有多个，用顿号（、）间隔
      4. 学业要求可选值：了解、理解、掌握、运用、超纲
      5. 考频可选值：高频、中频、低频
    - 影响范围：批量导入弹窗说明区（完整填写规则仍以 Excel 顶行为准）
