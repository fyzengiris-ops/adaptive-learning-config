# 1.1 首页-+新增弹窗【GPT更新】

# 页面目标
用于在【教材体系知识树】首页中，用户从某个固定教材版本分组右上角点击【新增】后，新增该版本下的教材主体数据。

用户可在弹窗中填写学段、学科、教材名称等信息完成新增操作。  
本弹窗中的【教材版本】为固定回显字段，不允许修改。  
新增成功后，该教材需纳入教材体系知识树统一管理范围，并进入后续发布链路。

> 说明：
> 1. 本弹窗对应首页中某个固定教材版本分组右上角的【新增】入口。
> 2. 本弹窗与首页顶部【新增教材】弹窗的历史业务要求保持一致。
> 3. 两个弹窗的核心差异在于：本弹窗中的【教材版本】由入口分组决定，固定回显，不允许用户修改。

---

# 所属页面
知识体系管理 > 教材体系知识树 > 首页

---

# 页面区域

## A. 弹窗头部
用于展示弹窗标题和关闭按钮，提供关闭弹窗的交互入口。

## B. 表单区域
用于填写新增教材的各项信息，包括学段、学科、教材版本、教材名称等字段。

## C. 操作按钮区
用于放置取消和确定按钮，支持用户取消操作或提交新增教材。

---

# 组件说明

## A. 弹窗头部组件
- A1. 标题：显示【新增教材】
- A2. 关闭按钮：显示关闭图标，点击后关闭弹窗

## B. 表单区域组件
- B1. 学段选择器：下拉选择框，必填字段，选项为乐课网平台已有的学段数据
- B2. 学科选择器：下拉选择框，必填字段，选项为当前所选学段下乐课网平台已有的学科数据
- B3. 教材版本回显框：固定展示当前入口分组对应的教材版本，禁用态展示，不可编辑
- B4. 教材名称输入框：文本输入框，必填字段，placeholder 显示【请输入教材名称，如：数学·九年级上册（2024版）】

## C. 操作按钮区组件
- C1. 【取消】按钮：点击后关闭弹窗
- C2. 【确定】按钮：点击后校验表单并提交新增教材

# 交互逻辑

## 1. 打开弹窗
- 用户点击某个教材版本分组右上角【新增】按钮后，打开新增教材弹窗
- 系统自动带入当前分组对应的教材版本
- 弹窗打开时，学段、学科字段自动带入首页顶部当前的筛选项值：
  - 若首页顶部已选择学段，则弹窗中学段字段默认显示该学段
  - 若首页顶部已选择学科，且该学科属于当前带入的学段，则弹窗中学科字段默认显示该学科
  - 若首页顶部未选择学段或学科（如显示"全部学段"、"全部学科"），则弹窗中对应字段默认显示【请选择】
- 学段、学科带入后，用户仍可手动更改
- 教材版本字段显示当前入口分组对应版本，且不可修改
- 教材名称输入框默认为空

## 2. 关闭弹窗
- 用户点击右上角关闭按钮或【取消】按钮后，直接关闭弹窗
- 关闭后本次未提交的数据不保留
- 再次打开弹窗时，表单恢复为初始状态，并重新带入当前入口分组的教材版本

## 3. 选择学段
- 用户选择学段后：
  - 系统加载该学段下可选的学科数据
  - 学科字段重置为【请选择】
- 学段未选择时，学科不可完成有效选择

## 4. 选择学科
- 用户选择学科后：
  - 系统基于当前学段与当前固定教材版本，完成后续校验所需数据准备
- 若学科变更：
  - 不影响教材版本字段，教材版本仍保持为当前入口分组固定版本

## 5. 查看教材版本
- 教材版本字段固定展示当前入口分组对应的版本名称
- 用户不可在本弹窗中修改教材版本
- 教材版本值由入口上下文决定，不允许手工切换到其他版本

## 6. 填写教材名称
- 用户输入教材名称
- 教材名称为必填字段
- 输入内容用于标识新增教材主体名称

## 7. 提交表单
- 用户点击【确定】按钮后，系统进行表单校验
- 若必填字段未填写，则阻断提交，并提示对应字段未填写
- 若重复校验未通过，则阻断提交，并提示教材已存在，不可重复新增
- 若校验通过，则提交新增教材数据
- 新增成功后：
  - 关闭弹窗
  - 刷新首页教材列表
  - 新教材展示在当前入口版本分组下
  - 若新增教材满足当前首页其他筛选条件，则在当前页面中立即可见
  - 新增教材默认进入待发布状态

# 业务规则

## 一、字段规则
1. 学段为必填字段。
2. 学科为必填字段。
3. 教材版本为固定回显字段，不允许编辑。
4. 教材名称为必填字段。
5. 当前弹窗不包含独立的年级字段。

## 二、选项来源规则
1. 学段下拉选项，取乐课网平台已有的学段数据。
2. 学科下拉选项，取当前所选学段下乐课网平台已有的学科数据。
3. 教材版本字段值，取当前入口分组对应的版本数据。
4. 本弹窗中教材版本不通过下拉选择产生，而是由入口上下文直接带入。
5. 学段、学科不使用固定写死枚举，均以乐课网实际已有数据为准。

## 三、默认值规则
1. 学段默认带入首页顶部当前选中的学段筛选项；若首页未选择具体学段（如显示"全部学段"），则默认显示【请选择】。
2. 学科默认带入首页顶部当前选中的学科筛选项；若首页未选择具体学科（如显示"全部学科"），则默认显示【请选择】。
3. 若带入的学科不属于带入的学段，则学科字段重置为【请选择】。
4. 教材版本默认回显当前入口分组对应版本。
5. 教材名称默认值为空。
6. 学段、学科带入后，用户可手动更改，不受带入值限制。

## 四、联动规则
1. 学段变更后，学科选项需根据当前学段重新加载。
2. 学段变更后，学科字段需重置。
3. 学科变更后，不影响教材版本字段。
4. 教材版本字段在整个弹窗使用过程中保持固定，不随学段、学科切换而变化。
5. 若当前学段下无可选学科，应明确提示用户当前暂无可选数据。

## 五、校验规则
1. 提交前需校验所有必填字段是否已填写。
2. 教材名称提交前需去除首尾空格。
3. 去除首尾空格后，教材名称若为空，则视为未填写。
4. 教材名称应设置最大长度限制，超长时阻断提交并提示。
5. 提交时需校验当前入口分组对应版本是否有效存在；若版本上下文丢失或无效，则阻断提交并提示。

## 六、去重规则
1. 新增教材提交时，系统需校验是否与现有教材重复。
2. 去重校验范围需同时包含：
   - 乐课网原有教材树中已存在的教材数据
   - 新功能侧已存在的教材数据
3. 去重建议口径为：同一学段、学科、教材版本、教材名称组合下，不允许重复新增。
4. 若判定为重复教材，应阻断提交，并提示教材已存在，不可重复新增。

## 七、新增成功后规则
1. 新增成功后，教材纳入教材体系知识树统一管理范围。
2. 新增成功后，首页需刷新教材列表。
3. 新增教材应展示在当前入口对应的教材版本分组下。
4. 若新增教材满足当前首页筛选条件，则应在当前页面中立即展示。
5. 新增教材默认进入待发布状态。
6. 后续需通过发布流程完成正式生效。

## 八、权限规则
1. 具备教材体系知识树维护权限的后台角色可使用本弹窗新增教材。
2. 无维护权限的角色不可发起新增操作。
3. 当前页面示例角色【教研主管】应具备新增权限。

## 九、与顶部新增教材弹窗的差异规则
1. 顶部新增教材弹窗中，教材版本由用户选择。
2. 本弹窗中，教材版本由入口分组固定带入，不允许修改。
3. 除教材版本字段的进入方式与可编辑性外，其余核心业务要求与顶部新增教材弹窗保持一致。

# 状态与异常

## 页面状态
- 弹窗打开状态：显示新增教材弹窗
- 弹窗关闭状态：关闭新增教材弹窗
- 提交中状态：用户点击【确定】后，按钮进入提交处理中，避免重复提交

## 异常与边界
1. **必填项未填写**
   - 点击【确定】时，如必填项为空，则阻断提交并提示对应字段未填写

2. **下拉数据加载失败**
   - 当学段、学科数据加载失败时，应提示加载失败并支持重试

3. **联动后无可选数据**
   - 当选择学段后无可选学科时，应提示当前暂无可选数据，并阻断提交

4. **入口版本上下文异常**
   - 若弹窗打开时未正确带入当前入口分组对应版本，或带入版本无效，则应提示版本信息异常，并阻断提交

5. **重复校验未通过**
   - 当新增教材命中重复规则时，应阻断提交并提示教材已存在

6. **重复校验失败**
   - 当重复校验接口异常时，应提示校验失败，请稍后重试，不应直接放行新增

7. **新增提交失败**
   - 当新增接口调用失败时，弹窗不关闭，保留用户当前已填写内容，并提示提交失败

8. **新增后列表未及时刷新**
   - 新增成功后，如首页列表未及时更新，应自动刷新列表或重新拉取数据

# 数据来源

| 数据名称 | 来源 | 用途 |
|----------|------|------|
| 学段数据 | 乐课网已有学段数据 | 提供学段下拉选项 |
| 学科数据 | 当前学段下乐课网已有学科数据 | 提供学科下拉选项 |
| 当前入口版本数据 | 首页当前版本分组上下文 | 提供教材版本固定回显值 |
| 已有教材数据 | 乐课网原有教材树数据 + 新功能侧教材数据 | 用于重复校验 |
| 首页筛选条件 | 当前首页状态 | 用于新增成功后判断是否在首页立即展示 |
| 首页学段筛选项 | 首页顶部学段筛选器当前值 | 作为弹窗学段字段默认值带入 |
| 首页学科筛选项 | 首页顶部学科筛选器当前值 | 作为弹窗学科字段默认值带入 |

# 接口需求

| 接口名称 | 用途 | 状态 |
|----------|------|------|
| 获取学段选项接口 | 获取乐课网已有学段数据 | 待补充 |
| 获取学科选项接口 | 获取当前学段下乐课网已有学科数据 | 待补充 |
| 教材重复校验接口 | 校验新增教材是否已存在 | 待补充 |
| 新增教材接口 | 提交新增教材主体数据 | 待补充 |
| 刷新首页教材列表接口 | 新增成功后刷新首页列表数据 | 待补充 |

# 技术要求

1. 弹窗需支持从首页某个固定教材版本分组右上角【新增】入口唤起。
2. 弹窗打开时，需自动读取首页顶部学段、学科筛选器的当前值，并作为弹窗学段、学科字段的默认值带入。
3. 学段、学科字段需支持动态加载。
4. 学段、学科字段需支持联动刷新。
5. 教材版本字段需支持从入口上下文自动带入并固定回显。
6. 提交前需进行必填校验与重复校验。
7. 提交中需防止重复点击提交。
8. 新增成功后需刷新首页数据，并正确更新当前版本分组展示。
9. 提交失败时需保留用户已填写内容，避免重复录入。
