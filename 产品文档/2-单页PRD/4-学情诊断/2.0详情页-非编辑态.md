# 2.0 详情页-非编辑态【GPT更新】

## 页面目标

用于以非编辑态查看学情诊断策略的详细配置信息。用户可在当前页面查看策略基本信息、题目筛选条件、题目组成配置，并可发起编辑、删除、发布等后续操作。

> 当前页面为只读查看页，页面本身不承载字段直接编辑；用户需通过页面操作按钮进入后续编辑或发布流程。

## 所属页面

策略管理 > 策略广场 > 学情诊断 > 策略详情

---

## 页面定位

1. 当前页面为已有策略的详情查看页。
2. 当前页面为非编辑态页面，所有策略字段均以只读形式展示。
3. 当前页面支持发起以下后续操作：
   - 编辑
   - 删除
   - 发布
4. 当前页面不承载以下能力：
   - 字段直接编辑
   - 新建策略
   - 历史发布记录弹窗
   - 定时发布状态展示

---

## 页面结构

### A. 顶部标题与状态区域

用于展示返回入口、策略名称、版本号、当前状态以及变更提示信息。

| 元素 | 说明 |
|------|------|
| 返回按钮 | 点击后返回学情诊断策略首页 |
| 页面标题 | 显示当前策略名称 |
| 有更新标签 | 仅在存在已保存但未发布的变更时显示 |
| 版本号 | 显示当前最新已发布版本号 |
| 待发布状态条 | 仅在存在已保存但未发布的变更时显示 |
| 发布按钮 | 位于待发布状态条右侧，点击后进入发布流程 |

#### 显示规则

1. 页面标题展示当前策略名称。
2. 页面右上角【版本号】展示当前最新已发布版本号。
3. 当前页面**不展示面包屑**。
5. 当前页面不展示【新增】标签。
6. 当前页面顶部仅在存在已保存未发布变更时显示【有更新】标签与待发布状态条。

---

### B. 基本信息区域

用于只读展示当前策略的基础配置信息。

| 字段 | 说明 |
|------|------|
| 策略名称 | 展示当前策略名称 |
| 学段 | 展示当前策略所属学段 |
| 学科 | 展示当前策略所属学科 |

#### 展示规则

1. 当前区域所有字段均为只读展示。
2. 用户不可在当前页直接修改字段值。

---

### C. 题目筛选条件区域

用于只读展示当前策略的题目筛选条件。

| 字段 | 说明 |
|------|------|
| 题目来源 | 展示当前已选择的题目来源；未选择则显示不限。<br/>**⚠️ 本期暂不做**：该字段因上游题目缓存业务还未完成，无法提供题目来源字段的接口，故本期先不做，待上游完成该需要的开发后，学情诊断业务再把题目来源这个字段给加上。 |
| 年份范围 | 展示当前已配置的年份范围 |

#### 展示规则

1. 当前区域所有字段均为只读展示。
2. 题目来源字段在当前业务阶段为**单选结果展示**。**（本期暂不做）**
3. 若策略已选择题目来源，则展示对应单个题目来源标签。
4. 若策略未选择题目来源，则展示：**不限**。
5. 年份范围展示当前策略已保存的配置值。

---

### D. 题目组成配置区域

用于只读展示当前策略的题目组成方案。

| 列名 | 说明 |
|------|------|
| 知识点总数 | 展示当前配置行的知识点数量 |
| 单知识点出题数 | 展示当前配置行的单知识点出题数 |
| 单知识点题目难度分布 | 展示易 / 较易 / 中档 / 较难 / 难五档分布 |
| 单知识点选题约束 | 展示当前配置行的题型约束 |
| 调整题数 | 展示当前配置行的增减题量 |
| 总出题数 | 展示当前配置行单独计算后的总题数 |
| 操作 | 非编辑态下仅展示删除图标占位或禁用态展示，以最终 UI 稿为准 |

#### 展示规则

1. 当前区域所有字段均为只读展示。
2. 每一行配置方案独立展示。
3. 每一行的总出题数为该行单独计算结果。
4. 总出题数计算公式为：  
   **总出题数 = 知识点总数 × 单知识点出题数 + 调整题数**
5. 非编辑态下不支持直接修改表格内任一字段。
6. 表格内容超出区域宽度时，支持横向滚动查看。

---

### E. 底部操作区域

用于提供当前策略的后续操作入口。

| 按钮 | 说明 |
|------|------|
| 删除 | 点击后弹出删除确认弹窗 |
| 编辑 | 点击后进入编辑流程 |

#### 展示规则

1. 当前页面底部展示【删除】【编辑】按钮。
2. 删除按钮位于左侧。
3. 编辑按钮位于右侧。
4. 当前页面不展示【取消】【保存】按钮。

## 顶部状态规则

当策略当前**不存在已保存但未发布的变更**时，页面处于普通查看态。

#### 展示内容

1. 显示返回按钮
2. 显示策略名称
3. 显示版本号
4. 显示当前状态
5. 显示各配置区域只读内容

#### 不展示内容

1. 不显示【有更新】标签
2. 不显示橙色待发布状态条
3. 不显示发布按钮

---

### 2. 有更新查看态

当策略当前**存在已保存但未发布的变更**时，页面处于有更新查看态。

#### 展示内容

1. 显示返回按钮
2. 显示策略名称
3. 显示版本号
4. 显示当前状态
5. 显示【有更新】标签
6. 显示橙色待发布状态条
7. 显示待发布状态条右侧【发布】按钮
8. 显示各配置区域只读内容
9. 显示底部【删除】【编辑】按钮

#### 待发布状态条文案

**该策略有变更，需要发布后才能生效**

---

## 版本与状态展示规则

1. 页面右上角【版本号】展示当前最新已发布版本号。
2. 页面右上角【状态】展示当前线上生效版本的发布状态。
3. 当策略当前已发布且无未发布变更时：
   - 显示版本号
   - 显示状态【已发布】
   - 不显示【有更新】标签
   - 不显示待发布状态条
4. 当策略当前已发布且存在已保存未发布变更时：
   - 右上角仍显示当前已发布版本号
   - 右上角状态仍显示【已发布】
   - 额外显示【有更新】标签
   - 额外显示橙色待发布状态条
5. “有信息变更且保存后”是显示【有更新】标签与待发布状态条的前提条件。
6. 若仅进入页面查看、未发生变更并保存，则不显示上述两项信息。

## 交互逻辑

### 1. 页面加载

1. 用户进入当前策略详情页。
2. 系统根据策略 ID 加载对应策略详情数据。
3. 页面以非编辑态回显已保存的策略信息。
4. 系统根据当前策略是否存在已保存未发布变更，决定页面显示为：
   - 普通查看态
   - 有更新查看态

---

### 2. 编辑操作

1. 用户点击页面底部【编辑】按钮。
2. 系统进入当前策略对应的编辑流程。
3. 进入编辑后，用户方可修改策略内容。

---

### 3. 删除操作

1. 用户点击页面底部【删除】按钮。
2. 系统弹出删除确认弹窗。
3. 用户确认删除后，系统删除当前策略。
4. 删除成功后，返回学情诊断策略首页。
5. 首页对应场景分组中不再展示该策略卡片。
6. 首页列表需按最新数据刷新回显。

---

### 4. 发布操作

1. 当页面存在已保存未发布变更时，顶部展示待发布状态条及【发布】按钮。
2. 用户点击【发布】按钮后，进入发布流程。
3. 发布完成后，页面状态按最新发布结果重新回显。

---

### 5. 返回操作

1. 用户点击顶部【返回】按钮后，返回学情诊断策略首页。
2. 返回后，首页需按最新数据回显对应策略状态。
3. 当前页面为非编辑态详情页，不涉及未保存离开拦截。

---

## 业务规则

### 一、页面状态规则

1. 当前页面仅包含两种查看态：
   - 普通查看态
   - 有更新查看态
2. 普通查看态下，不显示【有更新】标签和待发布状态条。
3. 有更新查看态下，显示【有更新】标签和待发布状态条。
4. “有信息变更且保存后”是进入有更新查看态的前提条件。

### 二、字段展示规则

1. 当前页面所有业务字段均为只读展示。
2. 详情页展示结果需与策略已保存内容保持一致。
3. 题目来源按单选结果展示，不按多选展示。

### 三、版本状态规则

1. 版本号始终展示当前最新已发布版本号。
2. 状态始终展示当前线上生效版本状态。
3. 未发布变更通过【有更新】标签和待发布状态条表达，不直接覆盖右上角状态展示。

### 四、删除规则

1. 删除需二次确认。
2. 删除成功后返回首页。
3. 首页需按最新结果刷新，不再展示该策略。

### 五、发布规则

1. 仅当存在已保存未发布变更时，页面展示发布入口。
2. 发布完成后，页面需重新回显最新状态。

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 加载中 | 页面正在加载策略详情数据 |
| 普通查看态 | 无已保存未发布变更的只读查看状态 |
| 有更新查看态 | 有已保存未发布变更的只读查看状态 |
| 加载失败 | 策略详情加载失败 |
| 删除处理中 | 用户确认删除后，系统正在删除策略 |

### 2. 异常处理规则

1. 当策略详情加载失败时，页面需提示加载失败信息，并提供返回或重试能力。
2. 当删除失败时，页面需提示删除失败原因，并保留当前详情页。
3. 当发布失败时，页面需提示发布失败原因，并保留当前页面状态。

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 当前策略无已保存未发布变更 | 不显示【有更新】标签与待发布状态条 |
| 当前策略存在已保存未发布变更 | 显示【有更新】标签与待发布状态条 |
| 仅进入页面查看，无任何变更保存 | 视为普通查看态 |
| 题目来源未配置 | 展示为【不限】 |
| 配置表格内容较宽 | 支持横向滚动查看 |
| 删除当前策略成功 | 返回首页，并从对应分组移除该策略 |
| 策略详情加载失败 | 提示失败，并支持返回或重试 |
