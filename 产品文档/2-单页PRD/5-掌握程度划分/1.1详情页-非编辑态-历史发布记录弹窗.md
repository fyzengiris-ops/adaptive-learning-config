# 1.1 详情页-非编辑态-历史发布记录弹窗【GPT更新】

## 页面目标

用于查看当前学段掌握程度划分策略的历史发布记录。用户可在弹窗中查看各已发布版本的版本号、发布时间、发布人、配置快照及变更记录，并通过展开/收起查看版本详情。

> 当前弹窗仅展示当前详情页对应学段的历史发布记录，不展示其他学段的发布记录。

## 所属页面

策略管理 > 策略广场 > 掌握程度划分 > 详情页 > 非编辑态 > 历史发布记录弹窗

---

## 页面定位

1. 当前页面为单学段详情页下的查看型历史弹窗。
2. 当前弹窗仅用于展示当前详情页所属学段的历史发布记录。
3. 当前页面不承载以下能力：
   - 搜索
   - 点击记录跳转详情
   - 版本对比
   - 回滚版本
   - 删除记录

---

## 页面结构

### A. 弹窗头部区域

用于展示弹窗标题和关闭入口。

| 元素 | 说明 |
|------|------|
| 弹窗标题 | 显示：**发布历史** |
| 关闭按钮 | 位于弹窗右上角，点击后关闭当前弹窗 |

#### 展示规则

1. 弹窗标题固定展示为：**发布历史**
2. 头部右侧展示关闭按钮

---

### B. 筛选栏区域

用于展示当前详情页所属学段信息，筛选字段置灰不可选。

| 元素 | 说明 |
|------|------|
| 学段筛选字段 | 显示当前详情页所属学段（高中/初中/小学），置灰不可选 |

#### 展示规则

1. 筛选栏位于弹窗标题下方，列表区域上方
2. 筛选栏展示当前详情页所属学段信息
3. 学段筛选字段置灰不可选，不可点击、不可修改
4. 筛选字段样式为：bg-gray-100 text-gray-500 cursor-not-allowed
5. 筛选栏用于展示当前详情页的属性信息

---

### C. 历史版本列表区域

用于展示当前学段的历史发布记录列表。

#### 单条历史版本卡片展示内容

| 元素 | 说明 |
|------|------|
| 版本号 | 展示当前发布记录的版本号 |
| 发布时间 | 展示该版本的发布时间 |
| 发布人信息 | 展示发布人姓名和账号 |
| 展开/收起图标 | 用于切换当前版本记录详情的展开或收起状态 |
| 更新说明 | 展开后展示该版本的更新说明 |
| 配置快照 | 展开后展示该版本对应的当前学段掌握程度区间配置快照 |
| 变更记录 | 展开后展示该版本对应的变更记录（有则展示） |

#### 展示规则

1. 历史版本列表按发布时间倒序排列，最新版本显示在最前。
2. 弹窗初次打开时，所有版本默认收起。
3. 用户点击某条版本记录头部后，可切换该版本的展开/收起状态。
4. 版本展开后展示：
   - 更新说明
   - 当前学段配置快照
   - 变更记录（有则展示）
5. 发布人信息展示格式统一为：**发布人：姓名（账号：XXXXXX）**
6. 列表区域支持弹窗内垂直滚动查看。

---

### D. 底部操作区域

用于提供关闭弹窗操作。

| 元素 | 说明 |
|------|------|
| 关闭按钮 | 位于弹窗底部右侧，点击后关闭当前弹窗 |

#### 展示规则

1. 底部固定展示【关闭】按钮
2. 当前弹窗不展示其他操作按钮

---

## 配置快照展示规则

1. 版本展开后，展示该版本对应的**当前学段掌握程度区间配置快照**
2. 配置快照内容包括：
   - 学段名称
   - 各掌握度等级名称
   - 等级颜色标识
   - 各等级区间范围
3. 当前页不展示其他学段的快照内容

### 配置快照示例内容

- 优秀：76% - 100%
- 良好：51% - 75%
- 一般：26% - 50%
- 较弱：0% - 25%

---

## 变更记录展示规则

1. 当该版本存在变更记录时，展开后显示【变更记录】区域
2. 每条变更记录需展示：
   - 变更类型标签（如：修改）
   - 变更内容说明
3. 当前页为单学段详情页，变更记录默认按当前学段内容展示
4. 若当前版本无变更记录，则不展示【变更记录】区域

---

## 交互逻辑

### 1. 打开弹窗

1. 用户在详情页标题栏右侧点击历史记录入口图标后，打开当前学段的历史发布记录弹窗
2. 系统加载当前学段的历史发布记录数据
3. 历史版本列表按发布时间倒序展示
4. 弹窗初次打开时，所有版本默认收起

---

### 2. 展开版本详情

1. 用户点击某条版本记录头部
2. 页面展开该版本详情区域
3. 展开后显示：
   - 更新说明
   - 当前学段配置快照
   - 变更记录（若存在）

---

### 3. 收起版本详情

1. 用户再次点击已展开的版本记录头部
2. 页面收起该版本详情区域
3. 恢复为收起态展示

---

### 4. 关闭弹窗

1. 用户点击右上角关闭按钮后，关闭弹窗
2. 用户点击底部【关闭】按钮后，关闭弹窗
3. 弹窗关闭后，不保留本次展开状态
4. 用户下次重新打开弹窗时，系统按当前学段最新历史发布记录重新初始化弹窗内容，并恢复为全部版本默认收起

## 操作说明

1. 用户打开弹窗后，可查看当前学段的全部历史发布记录
2. 用户可通过展开/收起操作查看各版本详细内容

1. 用户可通过右上角关闭按钮关闭弹窗

3. 关闭后再次打开，按最新数据重新初始化内容

## 业务规则

### 一、数据范围规则

1. 当前弹窗仅展示当前详情页所属学段的历史发布记录
2. 不展示其他学段的历史发布记录
3. 历史发布记录仅包含已完成发布的版本记录

### 二、筛选栏规则

1. 当前弹窗展示当前详情页所属学段信息
2. 学段筛选字段置灰不可选，仅用于信息展示
3. 学段类型包括：高中、初中、小学
4. 筛选栏用于帮助用户理解当前详情页的归属属性

### 三、排序规则

1. 历史记录按发布时间倒序排列
2. 最新版本展示在最前

### 四、展开收起规则

1. 弹窗初次打开时，所有版本默认收起
2. 用户点击某条版本记录头部后，可切换展开或收起状态
3. 关闭弹窗后，展开状态不保留
4. 再次打开时，恢复为全部版本默认收起

### 五、字段展示规则

1. 每条历史发布记录必须展示：
   - 版本号
   - 发布时间
   - 发布人姓名
   - 发布人账号
2. 展开后必须展示：
   - 更新说明
   - 当前学段配置快照
3. 若存在变更记录，则额外展示变更记录区域
4. 发布人信息展示格式固定为：**发布人：姓名（账号：XXXXXX）**

### 六、页面能力范围规则

1. 当前页面为查看型弹窗页面
2. 用户可进行的操作仅包括：
   - 查看当前学段历史发布记录
   - 展开/收起版本详情
   - 关闭弹窗
3. 当前页面不承载以下能力：
   - 学段筛选
   - 搜索
   - 点击记录跳转详情
   - 版本对比
   - 回滚版本
   - 删除记录

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 加载中 | 弹窗打开后，系统正在加载当前学段历史发布记录 |
| 正常状态 | 正常展示历史版本列表 |
| 空状态 | 当前学段暂无历史发布记录 |
| 加载失败 | 历史发布记录加载失败 |
| 收起态 | 版本卡片为默认收起状态 |
| 展开态 | 当前版本卡片已展开，显示详细内容 |

### 2. 空状态规则

1. 当当前学段不存在任何历史发布记录时，列表区域展示空状态文案：**暂无发布记录**
2. 空状态下仍保留：
   - 弹窗标题
   - 右上角关闭按钮
   - 底部关闭按钮

### 3. 加载失败规则

1. 当历史发布记录加载失败时，页面展示加载失败提示
2. 加载失败不影响用户关闭弹窗

---

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 当前学段存在历史发布记录 | 按发布时间倒序展示版本列表 |
| 当前学段无历史发布记录 | 展示空状态：暂无发布记录 |
| 某版本无变更记录 | 展开后不展示【变更记录】区域 |
| 历史记录较多 | 支持弹窗内纵向滚动查看 |
| 用户关闭弹窗后再次打开 | 按最新历史记录重新初始化内容，并恢复默认收起状态 |
| 历史发布记录加载失败 | 展示失败提示，并允许关闭弹窗 |
