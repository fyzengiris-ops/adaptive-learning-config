## 已确认决策

1. 数量/统计：知识卡片顶栏「N 要点 · N 模块 · N 考点」
   - 决策：A
   - 结论：要点=有正文或配图的条数；模块=有实质内容的模块数；考点=关联考点个数（无说明/例题也计入）
   - 影响范围：知识卡片标题区计数

2. 保存：空白要点 / 空白模块条目
   - 决策：A
   - 结论：允许保存空要点/空条目；保存后去掉纯空行（无正文且无配图）；查看态和学生端不出现空行；不因此拦截保存
   - 影响范围：保存编辑、核心概念要点/模块条目、学生端展示

3. 操作：要点粘贴拆分
   - 决策：自定义方案
   - 结论：去掉该模块功能，不再提供点击后 Ctrl+V 按序号拆分要点
   - 影响范围：核心概念 · 要点区编辑态

4. 字段：要点/模块配图
   - 决策：自定义方案
   - 结论：配图通过富文本上传；上传支持 GIF，以及其他格式的静态图片
   - 影响范围：要点/模块正文编辑、学生端配图展示
   - 说明：富文本工具条本期不审交互细节，Skill2 仍写配图与工具条业务逻辑占位，后续由用户完善

5. 字段：自定义模块名称（空名称 / 重名）
   - 决策：A
   - 结论：保存时模块名称不能为空、同一卡片内不能重名；空名称 Toast：「请填写所有模块名称后再保存」；重名 Toast：「模块名称不能重复」
   - 影响范围：自定义模块、保存编辑

6. 字段：典型例题题干 / 考点说明（保存与学生端展示）
   - 决策：A + 补充
   - 结论：题干、解题步骤、解题要点全部选填，保存不拦截。题干和考点说明都没有时，该考点不在学生端展示。界面上去掉必填/选填标记
   - 影响范围：考点说明、典型例题、保存编辑、学生端/平板预览展示

7. 弹窗：系统选择（覆盖已有例题）
   - 决策：自定义方案
   - 结论：点击「系统选择」不弹窗，直接打开选题弹窗。在选题弹窗内点「选用」时再判断：当前考点已有例题才弹出确认，文案：「当前考点已有例题，是否确认更改为新的例题？」按钮为取消、确认。点取消：关掉确认框，仍留在选题弹窗可继续浏览；点确认：覆盖当前例题（题干、解题步骤、解题要点）
   - 影响范围：典型例题「系统选择」、资源库选题弹窗

8. 弹窗：删除要点/模块/例题/步骤/要点（有内容时）
   - 决策：A + 补充
   - 结论：无内容直接删；有内容二次确认。标题：「确认删除吗？」正文：「{对象名}内已有内容，删除后不可恢复。确定要删除吗？」按钮「取消 / 删除」。编辑态要点/模块条目至少保留一个空占位
   - 影响范围：要点、自定义模块、例题、解题步骤、解题要点删除

9. 预览：平板预览空态
   - 决策：A + 补充
   - 结论：无核心概念实质内容时展示「暂无」；无关联考点时展示「暂无」；有考点但无例题时，典型例题模块展示「暂无」；有考点但无考点说明时，考点说明展示「暂无」。学业要求/考频有值才盖章；考点顺序与关联考点一致；保留「考点N」水印（沿用关联考点已确认口径）
   - 影响范围：知识卡片平板预览

10. 弹窗：添加子节点「该知识点已有详细内容」
    - 决策：A
    - 结论：末级添加子节点时，下列任一即弹窗：要点有正文或配图；自定义模块有名称或条目内容/配图；知识卡片已存考点扩展记录；已填写知识点Tips；已有关联考点；已有视频或文字讲解。编辑态空白占位要点不算。弹窗含义：添加后变为非末级，知识点信息、结构、学习资源无法继续维护
    - 影响范围：左侧树添加子节点确认

11. 区域：选题弹窗题目列表展示
    - 决策：A
    - 结论：折叠只显示题干；展开显示答案、解析。来源/题型/难度本期不展示
    - 影响范围：选题弹窗题目卡片

12. 字段：选题弹窗搜索范围
    - 决策：A
    - 结论：只搜题干关键词；无匹配展示「暂无符合条件的题目」；数量为过滤后的「共 N 题」
    - 影响范围：选题弹窗搜索框与空态

13. 操作：关闭选题弹窗
    - 决策：A
    - 结论：仅右上角关闭；点遮罩不关；关闭后清空搜索词和展开状态
    - 影响范围：选题弹窗关闭

14. 数据：点「选用」后写入知识卡片的内容
    - 决策：A
    - 结论：只写入题干、解题步骤、解题要点；答案和解析仅供选题时预览，不进入知识卡片
    - 影响范围：选用回写典型例题

15. 状态：题库来源范围
    - 决策：自定义方案
    - 结论：题库题目来源为当前教研员账号的个人资源库
    - 影响范围：选题弹窗题目列表数据范围

16. 列表：选题弹窗题目展开
    - 决策：B
    - 结论：可以同时展开多题
    - 影响范围：选题弹窗题目卡片展开/收起

17. 区域：考点清单页「知识点Tips」
    - 决策：补充（用户指定空态文案）
    - 结论：考点子 Tab 拆成两个并列模块：上方「考点清单」、下方「知识点Tips」。进入该 Tab 先看到考点相关信息。Tips 属于当前知识点，不跟某个考点、也不跟某道例题走；与例题内「解题要点」不是同一模块。编辑态默认一条；可点「添加Tips」继续增加；不少于 2 条时可上移、下移、删除，只剩 1 条时不可删除。选填，保存不因未填写而拦截，保存时去掉纯空行。配置端全部未填写时展示静态提示：「不填写，则学生端【知识点Tips】模块显示暂无」。无关联考点时，仅「考点清单」模块内展示「暂无考点」+「去维护考点」，不覆盖下方 Tips。学生端/平板预览的考点清单页同样先展示考点、后展示 Tips；有内容按顺序展示（多条编号），未填写时模块仍在、内容为「暂无」。有无关联考点，配置端考点子 Tab 都展示 Tips；学生端考点清单页仅在有关联考点时出现。已填写的 Tips 计入「该知识点已有详细内容」。
    - 影响范围：知识卡片 · 考点子 Tab、平板预览考点页、保存编辑、添加子节点确认
