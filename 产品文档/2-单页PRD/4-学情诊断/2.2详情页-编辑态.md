# 2.2 详情页-编辑态【GPT更新】

## 页面目标

用于对已存在的学情诊断策略进行编辑。用户可在当前页面修改策略的基本信息、题目筛选条件、题目组成配置，并在保存后继续停留当前页面；当本次保存形成已保存未发布变更时，页面显示待发布提示信息，供用户后续执行发布操作。

> 当前页面为编辑态页面，重点承载内容编辑、实时校验、取消编辑、保存编辑能力，不承载新建策略能力。

## 所属页面

策略管理 > 策略广场 > 学情诊断 > 策略详情 > 编辑态

---

## 页面定位

1. 当前页面为策略详情页进入编辑态后的编辑页面。
2. 当前页面用于编辑当前策略已保存的配置内容。
3. 当前页面承载以下能力：
   - 基本信息编辑
   - 题目筛选条件编辑
   - 题目组成配置编辑
   - 实时校验
   - 取消编辑
   - 保存编辑
   - 发布操作（保存后形成未发布变更时）
4. 当前页面不展开描述以下能力：
   - 删除确认弹窗
   - 发布弹窗详细内容
   - 历史发布记录弹窗
   - 定时发布状态条

## 页面结构

### A. 顶部标题与状态区域

用于展示返回入口、策略名称、副标题、版本号、当前状态及保存后待发布提示信息。

| 元素 | 说明 |
|------|------|
| 返回按钮 | 点击后执行离开编辑态逻辑 |
| 页面标题 | 显示当前策略名称 |
| 页面副标题 | 显示：**学情诊断策略配置** |
| 版本号 | 显示当前最新已发布版本号；编辑保存后（未发布）显示 `版本号：--` |
| 状态 | 显示当前线上生效版本状态；编辑保存后（未发布）显示橙色「待发布」标签 |
| 待发布状态条 | 仅在本次保存形成已保存未发布变更后显示（橙色） |
| 定时发布状态条 | 设置定时发布后显示（蓝色） |
| 发布按钮 | 位于待发布状态条右侧，点击后进入发布流程 |

#### 展示规则

1. 页面顶部展示返回按钮、策略名称、副标题、版本号、状态。
2. 页面副标题固定展示为：**学情诊断策略配置**。
3. 页面右上角【版本号】展示规则：
   - 初始进入编辑态：显示当前最新已发布版本号
   - 保存后（未发布）：显示 `版本号：--`
   - 发布成功后：显示实际版本号（如 v1.1）
4. 页面右上角【状态】展示规则：
   - 初始进入编辑态：显示当前线上生效版本状态
   - 保存后（未发布）：显示橙色「待发布」标签
   - 定时发布设置成功：显示蓝色「定时发布」标签
   - 发布成功后：显示绿色「已发布」标签
5. 编辑态页面**不显示**【有更新】标签。
6. 编辑态页面在初始进入时**不显示**橙色待发布状态条。
7. 当用户在编辑态完成保存，且本次保存形成已保存未发布变更后，当前页面显示橙色待发布状态条及【发布】按钮。

#### 待发布状态条（橙色）

**触发条件**：编辑保存后形成未发布变更

| 元素 | 说明 |
|------|------|
| 警示图标 | AlertCircle 图标，橙色 |
| 提示文案 | 「该策略有变更，需要发布后才能生效」 |
| 发布按钮 | 橙色填充按钮，点击弹出发布弹窗 |

**隐藏条件**：
- 立即发布成功后
- 定时发布设置成功后（切换为蓝色状态条）

#### 定时发布状态条（蓝色）

**触发条件**：设置定时发布成功后

| 元素 | 说明 |
|------|------|
| 成功图标 | Check 图标，蓝色 |
| 提示文案 | 显示版本号、定时发布时间（如：「v1.1 版本将于您设定的时间（2024-02-01 02:00）自动发布」） |
| 取消按钮 | 蓝色边框按钮，点击取消定时发布，恢复橙色待发布状态条 |

**取消定时发布后**：
- 蓝色状态条消失
- 橙色待发布状态条重新显示

### B. 基本信息区域

用于编辑当前策略的基础配置信息。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 策略名称 | 单行文本输入框 | 是 | 编辑当前策略名称 |
| 学段 | 下拉选择 | 是 | 编辑当前策略所属学段 |
| 学科 | 下拉选择 | 是 | 编辑当前策略所属学科 |

#### 初始化规则

1. 用户进入编辑态时，基本信息区所有字段均需回显当前策略已保存内容。
2. 编辑态不使用新增页默认值覆盖已有配置。

#### 字段规则

##### 1. 策略名称

1. 为必填字段。
2. placeholder 为：**请输入策略名称**。
3. 保存前必须填写。
4. 策略名称用于详情页标题与首页策略卡片展示。

##### 2. 学段

1. 为必填字段。
2. 选项包括：小学 / 初中 / 高中。
3. 进入编辑态时回显当前已保存学段。
4. 用户可在编辑态中修改学段。

##### 3. 学科

1. 为必填字段。
2. 学科选项随学段联动变化。
3. 进入编辑态时回显当前已保存学科。
4. 用户可在编辑态中修改学科。

#### 联动规则

1. 当用户切换学段时：
   - 学科选项联动更新；
   - 学科按新学段默认规则重置。
2. 当用户切换学科时：
   - 保留当前学段。

用于编辑当前策略的题目筛选条件。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 题目来源 | 标签式单选字段 | 否 | 选择题目来源，不选则不限来源。<br/>**⚠️ 本期暂不做**：该字段因上游题目缓存业务还未完成，无法提供题目来源字段的接口，故本期先不做，待上游完成该需要的开发后，学情诊断业务再把题目来源这个字段给加上。 |
| 年份范围 | 下拉选择 | 是 | 选择题目年份范围 |

#### 初始化规则

1. 用户进入编辑态时，题目来源和年份范围均需回显当前策略已保存值。**（题目来源本期暂不做）**

#### 题目来源规则

> **⚠️ 本期暂不做**：该字段因上游题目缓存业务还未完成，无法提供题目来源字段的接口，故本期先不做，待上游完成该需要的开发后，学情诊断业务再把题目来源这个字段给加上。

1. 题目来源为**标签式单选字段**。
2. 可选项包括：
   - 中考真题
   - 模拟题
   - 竞赛题
   - 创新题
3. 用户同一时刻仅可选择 1 个题目来源。
4. 用户未选择任何题目来源时，表示：**不限题目来源**。
5. 当前业务阶段仅支持单选题目来源。

#### 题目来源辅助说明

**支持单选题目来源，不选则不限来源**

#### 年份范围规则

1. 年份范围为必填下拉字段。
2. 进入编辑态时，字段需回显当前策略已保存的年份范围值。
3. 用户可在编辑态中重新选择年份范围。
4. 保存前必须完成有效选择。

### D. 题目组成配置区域

用于编辑当前策略的题目组成方案。

#### 区域说明

1. 题目组成配置区采用表格形式展示。
2. 用户进入编辑态时，表格需回显当前策略已保存的全部配置方案。
3. 用户可新增配置行、删除配置行、修改各配置字段。
4. 页面至少保留 1 条配置方案，不允许删除至 0 条。

#### 表格列定义

| 列名 | 说明 |
|------|------|
| 知识点总数 | 输入当前配置行所覆盖的知识点数量（1~8 的整数）；表头显示提示：（不能大于8） |
| 单知识点出题数 | 输入每个知识点对应的出题数量 |
| 单知识点题目难度分布 | 配置易 / 较易 / 中档 / 较难 / 难五个难度档位的题目数量 |
| 单知识点选题约束 | 配置当前行的题型约束规则 |
| 调整题数 | 配置在基础题量上的增减量 |
| 总出题数 | 展示当前行单独计算后的总题数 |
| 操作 | 删除当前配置行 |

---

## 题目组成配置字段规则

### 1. 知识点总数

1. 为必填数值字段。
2. 仅允许输入 **1~8 的整数**。
3. **不能大于 8**：当输入值大于 8 时，输入框显示红色边框，下方展示提示文案：**不能大于8**。
4. **不能为 0 或负数**：必须大于 0。
5. 用于表示当前配置行的知识点数量。

### 2. 单知识点出题数

1. 为必填数值字段。
2. 仅允许输入大于 0 的整数。
3. 用于表示每个知识点需要出的题目数量。

### 3. 单知识点题目难度分布

包含 5 个档位：
- 易
- 较易
- 中档
- 较难
- 难

#### 字段规则

1. 5 个档位均为数值输入框。
2. 每个档位仅允许输入**大于等于 0 的整数**。
3. 不允许输入负数、小数、非数字字符。
4. 页面默认展示明确数值，未填写时按 0 展示。

#### 实时校验规则

1. 编辑态页面中，难度分布字段需实时校验。
2. 当 5 个难度档位题数之和 **大于** 单知识点出题数时，当前配置行下方展示红色提示文案：  
   **题目难度分布的总题数不能大于单知识点出题数**
3. 当 5 个难度档位题数之和 **小于** 单知识点出题数时，当前配置行下方展示蓝色提示文案：  
   **题目难度分布的总题数不能小于单知识点出题数**
4. 当 5 个难度档位题数之和 **等于** 单知识点出题数时，不展示校验提示。
5. 保存前仍需再次执行最终校验，未通过则阻断保存。

### 4. 单知识点选题约束

为下拉选择字段，选项包括：
- 全客观题
- 优先客观题
- 不限题型

#### 业务定义

1. **全客观题**：该配置下仅允许选择客观题；若客观题不足，则该知识点对应题量无法由主观题补齐。
2. **优先客观题**：系统优先选择客观题；当客观题数量不足时，允许使用主观题补齐。
3. **不限题型**：系统不对题型做额外限制，客观题和主观题均可参与选题。

#### 辅助说明

**选择优先客观题选项，系统在选题时，会优先选择客观题，客观题题量不足时，用主观题补齐。**

### 5. 调整题数

1. 调整题数表示在基础出题数量上的增减量。
2. 页面通过【-】【当前值】【+】控件调整该值。
3. 当前值可为正数、0、负数。
4. “+”表示增加题量，“-”表示减少题量。

#### 辅助说明

- **题数 + X**：优先从高频知识点增题，无选中高频，则从中频增题，均无则在低频中随机增题  
- **题数 - Y**：优先从低频知识点减题，无选中低频，则从中频减题，均无则在高频中随机减题  
- **选题需满足单知识点难度分布要求**

### 6. 总出题数

1. 每一行总出题数均按当前行单独计算。
2. 计算公式为：  
   **总出题数 = 知识点总数 × 单知识点出题数 + 调整题数**
3. 编辑过程中实时展示当前行总出题数。
4. 保存前需校验当前行总出题数必须大于 0。
5. 删除某一行后，仅移除该行数据，不触发其他行总出题数重新校验刷新。

### 7. 操作列

1. 操作列用于删除当前配置行。
2. 当当前表格仅剩 1 条配置方案时，该行删除操作不可用。
3. 删除任一配置方案后，仅删除对应行数据，不影响其他已保留配置行展示。

---

## 添加配置方案规则

1. 用户可点击表格下方【添加配置方案】新增一条配置行。
2. 新增配置行需带入一组**满足基础校验规则的默认值**。
3. 默认值必须满足：
   - 知识点总数为 1~8 的整数（> 0 且 ≤ 8）
   - 单知识点出题数 > 0
   - 难度分布各档位为非负整数
   - 难度分布总和 = 单知识点出题数
   - 总出题数 > 0
4. **知识点总数唯一性**：新增配置行时，系统需确保新增行的知识点总数与已有配置行不重复。
5. 页面至少保留 1 条配置方案，不允许删除至 0 条。

## 操作按钮区域

| 按钮 | 说明 |
|------|------|
| 取消 | 点击后执行离开编辑态逻辑 |
| 保存 | 点击后执行表单校验，通过后保存编辑结果 |

#### 展示规则

1. 编辑态页面底部固定展示【取消】【保存】按钮。
2. 当前页面不展示【删除】【编辑】按钮。
3. 保存后页面仍停留在当前页面，不跳转离开。

## 交互逻辑

### 1. 进入编辑态

1. 用户在非编辑态详情页点击【编辑】按钮。
2. 系统进入当前策略的编辑态页面。
3. 页面所有字段回显当前策略已保存内容。
4. 页面初始进入编辑态时，不显示待发布状态条。

---

### 2. 编辑表单

1. 用户可修改策略名称、学段、学科、年级等基本信息。
2. 用户可修改题目来源、年份范围等筛选条件。
3. 用户可修改题目组成配置表中的各项字段。
4. 页面在编辑过程中执行实时校验，并按规则展示提示信息。

---

### 3. 添加配置方案

1. 用户点击【添加配置方案】按钮。
2. 系统在表格末尾新增 1 条配置行。
3. 新增行以满足基础校验规则的默认值初始化。
4. 新增后用户可继续编辑该配置行。

---

### 4. 删除配置方案

1. 用户点击某配置行删除按钮时，删除对应配置行。
2. 当仅剩 1 条配置方案时，不允许继续删除。
3. 删除后保留其余配置行内容不变。

---

### 5. 取消编辑 / 返回

1. 底部【取消】按钮与顶部【返回】按钮离开逻辑保持一致。
2. 当用户未对当前页面内容做任何修改时，点击【取消】或【返回】可直接退出编辑态并返回非编辑态详情页。
3. 当用户已修改页面内容但未保存时，点击【取消】或【返回】时，系统弹出未保存离开确认提示。
4. 用户确认离开后，放弃本次未保存修改，并返回非编辑态详情页。
5. 用户取消离开后，停留当前编辑页继续编辑。

---

### 6. 保存编辑

1. 用户点击【保存】按钮。
2. 系统执行完整表单校验。
3. 校验通过后，系统保存当前编辑内容。
4. 保存成功后，页面**仍停留在当前编辑态页面**。
5. 若本次保存相较当前已发布版本形成了已保存未发布变更，则当前页面显示：
   - 橙色待发布状态条
   - 【发布】按钮
   - 版本号显示 `--`
   - 状态显示橙色「待发布」标签
6. 若本次保存未形成有效变更，则当前页面不显示待发布状态条。
7. 保存成功后，页面中的字段内容、版本状态相关信息按最新保存结果回显。

---

### 7. 发布操作

#### 7.1 触发发布

1. 用户点击橙色待发布状态条的【发布】按钮。
2. 系统弹出发布弹窗。

#### 7.2 发布弹窗

| 属性 | 内容 |
|------|------|
| 版本号生成规则 | 次版本号 +1；次版本号为 9 时归零，主版本 +1（如 v1.0 → v1.1，v1.9 → v2.0） |
| 更新说明 | 必填，多行文本输入框 |
| 发布时间选择 | 立即发布 / 定时发布 |

**确认按钮文案**：
| 发布方式 | 按钮文案 |
|----------|----------|
| 立即发布 | 「确认发布」 |
| 定时发布 | 「确认定时发布」 |

#### 7.3 立即发布

1. 用户选择「立即发布」并点击「确认发布」按钮。
2. 系统执行发布操作。
3. 发布成功后：
   - 橙色待发布状态条消失
   - 版本号更新为实际版本号（如 v1.1）
   - 状态显示绿色「已发布」标签

#### 7.4 定时发布

1. 用户选择「定时发布」，设置发布时间。
2. 点击「确认定时发布」按钮。
3. 系统记录定时发布任务。
4. 设置成功后：
   - 橙色待发布状态条切换为蓝色定时发布状态条
   - 显示定时发布时间信息
   - 提供「取消定时」按钮

#### 7.5 取消定时发布

1. 用户点击蓝色状态条的「取消定时」按钮。
2. 系统取消定时发布任务。
3. 取消成功后：
   - 蓝色定时发布状态条消失

#### 3. 校验交互说明

1. **知识点总数不能大于 8**：输入时实时校验，当值 > 8 时，输入框边框变红并显示提示。
2. **知识点总数不能重复**：当存在多条配置方案时，需校验各配置行的知识点总数是否相同；如存在重复，系统显示红色错误提示框。

#### 4. 页面提示展示

1. 题目组成配置表格标题区：当存在多条配置方案时，显示蓝色提示标签：**知识点总数不可重复，同一数值仅允许配置 1 组题目组成方案**
2. 各配置行内：校验失败时，在对应输入框下方显示红色错误提示
3. 配置行下方：知识点总数重复时，在表格下方统一展示红色错误提示框

### 四、同步学场景策略冲突校验

**校验规则**：同一学段-学科组合只能配置一份诊断策略

**触发时机**：保存时校验

**校验范围**：
- 已发布的策略

- 不包括当前正在编辑的策略自身

- 检测到冲突时，阻止保存
- 显示冲突提示弹窗，告知已存在的冲突策略信息

**冲突提示弹窗内容**：

|------|------|
| 标题 | 策略配置冲突 |

| 冲突信息 | 显示冲突策略名称、学段、学科 |
| 操作按钮 | 「我知道了」关闭弹窗 |

## 操作说明

### 1. 编辑操作

1. 用户进入页面后，可直接对所有可编辑字段进行修改。
2. 修改过程中，系统根据字段规则执行联动与实时校验。

### 2. 新增配置方案

1. 用户点击【添加配置方案】后，系统在表格中新增 1 条默认配置行。
2. 新配置行可继续编辑。

### 3. 删除配置方案

1. 用户点击某行删除按钮时，删除对应配置行。
2. 当仅剩 1 条配置方案时，不允许继续删除。

### 4. 保存操作

1. 用户点击【保存】后，系统按字段规则逐项校验。
2. 仅当全部校验通过时，允许保存。
3. 保存成功后，页面停留在当前编辑态页面。
4. 若保存形成已保存未发布变更，则页面显示待发布状态条。

### 5. 取消 / 返回操作

1. 用户点击顶部【返回】或底部【取消】时，执行统一离开逻辑。
2. 若存在未保存修改，需先弹出离开确认提示。

## 业务规则

### 一、编辑态页面规则

1. 当前页面仅描述详情页编辑态。
2. 页面中所有表单字段均为可编辑状态。
3. 非编辑态相关展示逻辑不在本页重复展开。

### 二、字段初始化规则

1. 用户进入编辑态时，页面所有字段均需回显当前策略已保存内容。
2. 编辑态不使用新增页默认值覆盖已有配置。

### 三、题目来源规则

1. 题目来源为标签式单选字段。
2. 用户同一时刻仅可选择 1 个题目来源。
3. 未选择题目来源时，按不限题目来源处理。

### 四、难度分布规则

1. 编辑态页面中，难度分布字段需实时校验。
2. 当总和大于单知识点出题数时，显示红色提示。
3. 当总和小于单知识点出题数时，显示蓝色提示。
4. 当总和等于单知识点出题数时，不显示提示。
5. 保存前仍需进行最终校验。

### 五、总出题数规则

1. 每行总出题数按当前行单独计算。
2. 编辑过程中实时展示当前行总出题数。
3. 保存前需校验当前行总出题数必须大于 0。
4. 删除某一行后，仅移除该行数据，不触发其他行总出题数重新校验刷新。

### 六、离开页面规则

1. 编辑态页面需要未保存离开拦截。
2. 顶部【返回】与底部【取消】采用相同离开逻辑。
3. 用户未保存修改时离开页面，需先进行二次确认。

### 七、保存后状态规则

1. 编辑态点击保存后，页面仍停留在当前页面。
2. 只有在本次保存形成已保存未发布变更时，页面才显示橙色待发布状态条。
3. 若本次保存未形成有效变更，则不显示该提示条。

## 状态与异常说明

### 1. 页面状态

| 状态 | 说明 |
|------|------|
| 加载中 | 页面正在加载当前策略可编辑数据 |
| 编辑中状态 | 用户正在修改页面内容 |

2. 页面需提示对应错误信息。
3. 用户修正后方可再次保存。

1. 当页面存在未保存修改时，点击【返回】或【取消】需弹出未保存离开确认提示。
2. 用户确认离开后返回非编辑态详情页。
3. 用户取消离开后继续停留当前编辑页面。
