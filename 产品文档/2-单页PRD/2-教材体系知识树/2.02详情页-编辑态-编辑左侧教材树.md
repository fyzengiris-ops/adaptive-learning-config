# 2.02 详情页-编辑态-编辑左侧教材树【GPT更新】

# 页面目标
用于在【教材体系知识树】详情页对教材目录结构进行维护。

**进入详情页后，左侧章节树自动处于可编辑状态**，无需点击额外按钮进入编辑态。

本页面需支持：
- 新增章；
- 新增小节；
- 编辑节点名称；
- 删除节点；
- 拖拽排序；
- 根据目录结构变化，动态调整节点是否为末级节点；
- 在目录结构变化后，联动影响右侧知识点、同步课程、练习试卷的维护与展示规则。

> 说明：
> 1. 当前页面聚焦左侧教材树的编辑能力。
> 2. 当前教材目录默认最多只允许到三级；**若乐课网线上实际目录层级大于三级，则以线上实际层级为准，系统需兼容展示和维护**。
> 3. 当前页中对教材树的增删改查，不仅影响当前新功能侧数据，也需同步到乐课网原有维护教材树功能的地方。
> 4. 同样地，若乐课网原有维护教材树功能的地方对教材树进行了增删改查，本页教材树也需要同步更新。
> 5. 仅末级节点支持在右侧直接维护知识点、同步课程、练习试卷；非末级节点仅支持查看聚合内容。
> 6. **编辑左侧章节树后，顶部自动显示待发布提示条**，显示「有 X 项变更待发布，发布后才能生效」。

# 页面区域

## A. 教材信息卡片区
用于展示当前教材的基础信息，包括教材名称、学段、版本、教材版次/年份、当前维护版本号、当前状态。

## B. 章节结构标题区
用于展示【章节结构】标题和拖拽提示信息。

## C. 章节树操作区
用于展示教材目录树，并支持展开/折叠、拖拽排序、添加章节、编辑章节名称、删除章节等操作。**进入详情页后自动显示编辑能力**。

## D. 底部添加章节区
用于提供【添加章】入口，允许用户在底部新增顶级章节。

# 组件说明

## A. 教材信息卡片区组件
- A1. 教材信息卡片：显示教材名称、学段、版本、教材版次/年份、当前维护版本号、当前状态

## B. 章节结构标题区组件
- B1. 标题：显示【章节结构】
- B2. 拖拽提示：显示【拖拽可排序】提示文案

## C. 章节树操作区组件
- C1. 拖拽手柄：编辑态下显示，用于拖拽节点排序
- C2. 展开/折叠图标：有子节点时显示，支持展开/折叠
- C3. 节点名称文本：显示节点名称
- C4. 知识点数量标签：显示当前节点关联的知识点数量
- C5. 编辑按钮：用于进入节点名称编辑态
- C6. 删除按钮：用于删除当前节点
- C7. 添加小节按钮：用于在当前节点下新增小节
- C8. 输入态输入框：用于新增或重命名节点时输入名称
- C9. 输入态确认按钮：用于保存本次新增或编辑
- C10. 输入态取消按钮：用于取消本次新增或编辑

## D. 底部添加章节区组件
- D1. 【添加章】按钮：用于新增顶级章节
- D2. 章新增输入框：点击后展示的章名称输入框
- D3. 章新增确认按钮：保存新增章
- D4. 章新增取消按钮：取消新增章

# 交互逻辑

## 1. 页面进入（自动编辑态）
- 用户从首页点击教材卡片【进入管理】后进入详情页
- **左侧章节树自动处于可编辑状态**，无需点击额外按钮
- 自动编辑态下：
  - 左侧章节树显示拖拽手柄
  - 节点支持新增、编辑、删除、拖拽排序等操作
  - 右侧仍展示当前选中节点对应内容
- 不同角色的编辑权限不同：
  - 教研主管：可编辑教材目录，自动显示全部编辑能力
  - 教研员：不可编辑教材目录，左侧树为只读查看态
- **左右两侧编辑可同时进行**，无互斥限制

## 2. 新增章
- 用户点击底部【添加章】按钮后：
  - 系统在底部展示章名称输入框
  - 输入框自动预填序号标题：
    - 英语学科：预填 `Unit X ` 格式（如：`Unit 1 `、`Unit 2 `）
    - 其他学科：预填 `第X章 ` 格式（如：`第一章 `、`第二章 `）
  - 用户可直接保存使用预填的序号，也可自行编辑修改
  - 输入框自动获取焦点
- 用户输入章节名称后：
  - 点击确认按钮或执行保存操作，则新增章
  - 点击取消按钮，则退出新增态，不保存
- 新增成功后：
  - 新章追加到顶级章节列表末尾
  - 章节名称使用用户输入的内容（包含序号）
  - 左侧章节树刷新
  - 该变更记录为【修改章节树】

## 3. 新增小节（普通场景）
- 用户点击某节点下的【添加小节】按钮后：
  - 系统先判断该节点是否允许新增下级节点
- 若允许新增：
  - 在该节点下方展示输入框
  - 输入框自动预填序号标题（如：`1.1 `、`1.2 `、`2.1.1 `）
  - 系统会自动识别父章节编号：
    - 识别 `第X章 ` 格式的父章节编号
    - 识别 `Unit X ` 格式的父章节编号（英语学科）
    - 识别 `X.Y ` 格式的父章节编号
  - 用户可直接保存使用预填的序号，也可自行编辑修改
  - 输入框自动获取焦点
- 用户输入小节名称后：
  - 点击确认按钮，则保存新增小节
  - 点击取消按钮，则取消新增，不保存
- 新增成功后：
  - 新小节追加到当前父节点子节点列表末尾
  - 父节点自动展开
  - 小节名称使用用户输入的内容（包含序号）
  - 左侧章节树刷新
  - 该变更记录为【修改章节树】

## 4. 新增小节（原末级节点场景）
- 当用户对一个**当前为末级节点**的节点点击【添加小节】时，系统先判断该节点下是否已维护：
  - 知识点
  - 同步课程
  - 练习试卷
- 若当前末级节点下**没有**维护上述数据：
  - 直接进入新增小节输入流程
- 若当前末级节点下**已经维护**上述数据：
  - 系统弹出二次确认提示
  - 提示内容需明确说明：
    - 当前小节是末级小节
    - 若继续添加新的小节，当前小节将变为非末级小节
    - 当前小节下已维护的知识点、同步课程、练习试卷将被删除
- 用户确认后：
  - 才进入新增小节输入流程
- 用户取消后：
  - 终止本次新增小节操作

## 5. 输入框保存与取消交互
- 当新增章 / 新增小节 / 编辑节点名称进入输入态后：
  - 页面展示输入框、确认按钮、取消按钮
- 用户输入内容后：
  - 点击确认按钮：执行保存
  - 点击取消按钮：退出输入态，不保存
- 当前交互以你提供的第二张截图样式为准：
  - 输入框内输入名称
  - 右侧提供确认与取消操作图标
  - 用户可显式点击确认或取消完成交互

## 6. 编辑节点名称
- 用户点击节点上的编辑按钮后：
  - 当前节点切换为输入态
  - 输入框预填当前名称
- 用户修改名称后：
  - 点击确认按钮，保存修改
  - 点击取消按钮，恢复原名称并退出编辑态
- 编辑名称时：
  - 仅修改名称部分
  - 系统编号保持不变
- 保存成功后：
  - 左侧树刷新
  - 该变更记录为【修改章节树】

## 7. 删除节点
- 用户点击节点删除按钮后：
  - 系统弹出二次确认
- 用户确认删除后：
  - 删除当前节点
  - 若当前节点有子节点，则同时删除其全部子节点
  - 左侧树重新计算结构与编号
- 若删除的是当前选中节点：
  - 系统需同步刷新右侧详情展示
- 删除成功后：
  - 该变更记录为【修改章节树】
  - 若因此导致相关数据删除，也需补充对应删除变更记录

## 8. 拖拽排序
- 用户拖拽节点左侧拖拽手柄后：
  - 系统进入拖拽排序状态
- 拖拽释放后：
  - 系统更新节点顺序
  - 自动重新计算对应编号
- 拖拽排序仅允许在合法层级内进行：
  - 顶级章仅可与顶级章排序
  - 同级小节仅可在同级之间排序
  - 不允许通过拖拽改变层级归属
- 排序成功后：
  - 左侧树刷新
  - 该变更记录为【修改章节树】

## 9. 展开 / 折叠节点
- 用户点击展开/折叠图标后：
  - 系统切换当前节点展开状态
- 无子节点的节点不显示展开/折叠图标

## 10. 目录结构变化后的右侧联动
- 若当前选中节点因新增下级节点而由末级节点变为非末级节点：
  - 左侧树刷新当前节点层级状态
  - 右侧详情立即切换为聚合查看态
  - 原节点下原有知识点 / 同步课程 / 练习试卷展示内容清空
  - 三个 Tab 按子节点聚合内容重新展示
- 若当前节点仍为末级节点：
  - 右侧保持可维护态

## 11. 编辑后自动显示待发布提示条
- 用户对左侧章节树进行任何编辑操作后（新增、删除、改名、移动节点）：
  - 顶部自动显示橙色待发布提示条
  - 提示内容：「有 X 项变更待发布，发布后才能生效」
  - 待发布提示条显示在固定提示条上方
- 系统自动记录变更类型：
  - 新增章/小节：记录为【修改章节树】
  - 编辑节点名称：记录为【修改章节树】
  - 删除节点：记录为【修改章节树】
  - 拖拽排序：记录为【修改章节树】
- 若本次目录改动同时导致知识点 / 同步课程 / 练习试卷删除：
  - 系统额外记录对应的删除类型变更

# 业务规则

## 一、目录层级规则
1. 当前教材目录默认最多只允许到三级；**若乐课网线上实际目录层级大于三级，则以线上实际层级为准，系统需兼容展示和维护**。
2. 目录结构支持树形维护，但右侧可维护能力不以“第几级”本身决定，而以**是否为末级节点**决定。
3. 仅末级节点支持直接维护：
   - 知识点
   - 同步课程
   - 练习试卷
4. 非末级节点不支持直接维护上述内容，只支持查看其下子节点聚合后的内容。
5. 当原本的末级节点新增下级节点后，该节点自动变为非末级节点。

## 二、目录同步规则
1. 在本页对教材树进行的增删改查，都需要同步到乐课网原有维护教材树功能的地方。
2. 若乐课网原有维护教材树功能的地方对教材树进行了增删改查，本页教材树也需要同步更新。
3. 新旧两边教材树不允许长期不一致。
4. 本页展示的教材树结构需与乐课网原有教材目录结构保持一致。

## 三、节点编号规则
1. 章、节、子节编号在用户新增时自动预填到输入框中。
2. 预填规则：
   - 添加章：
     - 英语学科：预填 `Unit X `（使用阿拉伯数字，如 `Unit 1 `、`Unit 2 `）
     - 其他学科：预填 `第X章 `（使用中文数字，如 `第一章 `、`第二章 `）
   - 添加小节：预填 `X.Y `（如 `1.1 `、`1.2 `、`2.1 `）
   - 添加三级小节：预填 `X.Y.Z `（如 `1.1.1 `、`1.1.2 `）
3. 用户可编辑预填的序号内容，包括修改序号格式或添加名称。
4. 保存时使用用户输入的完整内容作为节点名称。
5. 删除、拖拽排序后，系统不会自动重新编号，编号以用户输入为准。
6. 当前页不做同级重名校验。
7. 即使同级名称重复，系统也允许保存。

## 四、输入校验规则
1. 节点名称提交前需去除首尾空格。
2. 去除首尾空格后为空，不允许保存。
3. 节点名称不能为空。
4. 当前页不做同级重名校验。

## 五、末级节点变更规则
1. 若当前节点是末级节点，则其可直接维护知识点、同步课程、练习试卷。
2. 若给当前末级节点新增下级节点，则该节点会变为非末级节点。
3. 当末级节点变为非末级节点时：
   - 原节点下已维护的知识点将被删除
   - 原节点下已维护的同步课程将被删除
   - 原节点下已维护的练习试卷将被删除
4. 上述删除动作需在用户确认后才执行。
5. 上述删除结果需进入待发布变更集合。

## 六、右侧详情联动规则
1. 左侧教材树结构决定右侧详情区的展示与可维护范围。
2. 末级节点支持右侧直接维护知识点、同步课程、练习试卷。
3. 非末级节点右侧仅支持查看当前节点下子节点聚合后的内容。
4. 当某节点从末级节点变为非末级节点后：
   - 右侧详情页不再显示直接维护态
   - 后续查看该节点时，按其下属子节点聚合内容展示
   - 聚合展示样式与当前“章节下查看各小节内容”的样式保持一致
5. 三个 Tab（知识点 / 同步课程 / 练习试卷）均遵循相同口径。

## 七、变更记录规则
1. 目录结构编辑相关操作需记录为【修改章节树】。
2. 当目录结构变化导致知识点 / 同步课程 / 练习试卷被删除时，系统还需额外记录：
   - 删除知识点
   - 删除同步课程
   - 删除练习试卷
3. 所有相关变更都需进入待发布变更集合。
4. 发布确认时，这些变更需展示在【本次变更】列表中。
5. **编辑操作后自动触发待发布提示条显示**，无需手动退出编辑态。

## 八、权限规则
1. 教研主管：
   - 可编辑左侧教材树
   - 进入详情页后，左侧章节树自动显示编辑能力（拖拽手柄、编辑按钮、删除按钮、添加按钮）
   - 可执行新增、重命名、删除、拖拽排序等目录编辑操作
2. 教研员：
   - 不可编辑左侧教材树
   - 进入详情页后，左侧章节树为只读查看态，不显示编辑操作按钮
   - 但可编辑末级节点对应的知识点 / 同步课程 / 练习试卷详情内容
3. 本页仅针对“左侧教材树编辑”范围，因此教研员在本页不具备目录编辑权限。
4. **左右两侧编辑可同时进行**，右侧【编辑章节详情】按钮始终可点击。

# 状态与异常

## 页面状态
- 自动编辑态：进入详情页后，左侧树自动显示拖拽手柄、编辑能力、添加入口（教研主管）
- 只读查看态：教研员进入详情页后，左侧树为只读查看态
- 输入态：节点处于新增或重命名输入状态
- 删除确认态：删除节点前的确认状态
- 风险确认态：对末级节点新增下级节点且存在维护数据时的风险确认状态
- 待发布状态：编辑操作后，顶部自动显示待发布提示条

## 异常与边界
1. **节点名称为空**
   - 输入框为空或去除首尾空格后为空，不允许保存

2. **末级节点新增下级节点风险**
   - 若当前末级节点已维护知识点 / 同步课程 / 练习试卷，新增小节前必须弹出风险确认提示

3. **目录同步失败**
   - 若当前页教材树修改后未能同步到乐课网原有教材树，应提示同步异常
   - 不可直接按最终成功处理

4. **反向同步异常**
   - 若乐课网原有教材树已变更，但本页未同步成功，应提示数据同步异常，并刷新后重试

5. **删除失败**
   - 删除节点失败时，应提示删除失败，并保留当前页面状态

6. **排序失败**
   - 拖拽排序保存失败时，应提示失败，并保留当前排序结果或回退到上次成功状态，具体以后续实现拍板为准

7. **详情联动异常**
   - 若目录结构变化后右侧详情未正确刷新，应以前端刷新或重新拉取详情数据为准，避免展示旧数据

# 技术要求

1. 左侧章节树需支持编辑态下的树结构维护。
2. 拖拽排序仅允许在合法层级内进行，不可通过拖拽改变节点层级归属。
3. 输入态需支持展示输入框、确认按钮、取消按钮。
4. 新增 / 编辑输入框出现后，需支持用户显式执行保存与取消操作。
5. 左侧树结构变化后，右侧详情区需同步刷新展示状态。
6. 当存在目录同步风险或同步失败时，需支持异常提示。
7. 页面需支持当前教材树与乐课网原有教材树的一致性展示与同步。
