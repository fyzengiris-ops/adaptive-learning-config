# 1.2 首页 - 新增策略

## 1. 页面概述

| 属性 | 内容 |
|------|------|
| **功能名称** | 新增策略（策略编辑页） |
| **页面路由** | `/adaptive-strategy/strategy/diagnosis/[id]`（新建时 id 为 `new`） |
| **功能描述** | 新建或编辑学情诊断策略，配置策略基本信息、题目筛选条件和题目组成方案 |
| **入口说明** | 从策略广场首页点击「新增策略」按钮进入 |

---

## 2. 交互流程

### 2.1 新建策略流程

```
用户点击「新增策略」按钮
    ↓
进入策略编辑页（新建模式）
    ↓
配置策略参数
    ↓
点击「保存」按钮
    ↓
保存成功 → 进入查看模式，显示「新增」标签
    ↓
可继续「编辑」或「返回」首页
```

### 2.2 编辑策略流程

```
用户点击已有策略卡片
    ↓
进入策略编辑页（查看模式）
    ↓
点击「编辑」按钮
    ↓
进入编辑模式
    ↓
修改策略参数
    ↓
点击「保存」按钮
    ↓
保存成功 → 进入查看模式，显示「有更新」标签
    ↓
可点击「发布」按钮进行发布
```

## 3. 页面结构

### 3.1 标题栏

| 元素 | 说明 |
|------|------|
| 返回按钮 | 点击返回策略广场首页 |
| 页面标题 | 新建时显示「新建策略」+ 副标题「学情诊断策略配置」；编辑时显示策略名称 |
| 状态标签 | 新建保存后（未发布）显示蓝色「新增」标签；发布后标签消失；编辑已有策略保存后显示黄色「有更新」标签 |
| 版本信息 | 新建策略保存后显示「版本号：--」；发布后显示实际版本号 + 查看历史按钮；编辑已有策略显示当前版本号 + 查看历史按钮 |
| 状态标识 | 新建策略未发布时无状态标识；发布后显示已发布（绿色）；编辑已有策略显示已发布（绿色）或待发布（黄色） |

**新增策略版本号显示规则**：

| 阶段 | 版本号显示 |
|------|-----------|
| 新增策略保存后（未发布） | `版本号：--` |
| 立即发布成功后 | `版本号：v1.0` |
| 定时发布成功后 | `版本号：v1.0` |

### 3.2 待发布状态条（橙色）

**触发条件**：
- 新增策略保存后（未发布）
- 查看模式下编辑已有策略且有未发布的变更

| 元素 | 说明 |
|------|------|
| 警示图标 | AlertCircle 图标，橙色 |
| 提示文案 | 「该策略有变更，需要发布后才能生效」 |
| 发布按钮 | 橙色填充按钮，点击弹出发布弹窗 |

**隐藏条件**：
- 新增策略发布成功后（立即发布或定时发布）
- 编辑已有策略发布成功后

### 3.3 定时发布状态条（蓝色）

**触发条件**：
- 新增策略定时发布成功后
- 查看模式下已设置定时发布且无新变更

| 元素 | 说明 |
|------|------|
| 成功图标 | Check 图标，蓝色 |
| 提示文案 | 显示版本号、定时发布时间（如：「v1.0 版本将于您设定的时间（2024-02-01 02:00）自动发布」） |
| 取消按钮 | 蓝色边框按钮，点击取消定时发布，恢复橙色待发布状态条 |

**取消定时发布后**：
- 蓝色状态条消失
- 橙色待发布状态条重新显示

## 4. 表单区域

### 4.1 基本信息区块

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 策略名称 | 单行文本输入框 | 是 | 最大长度 50 字符；placeholder 为「请输入策略名称」 |
| 学段 | 下拉选择 | 是 | 选项：小学 / 初中 / 高中 |
| 学科 | 下拉选择 | 是 | 选项：语文 / 数学 / 英语 / 物理 / 化学 / 生物 |

### 4.2 题目筛选条件区块

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 题目来源 | 多选标签（单选） | 否 | 选项：中考试题 / 模拟题 / 竞赛题 / 创新题；支持单选；不选则不限来源。<br/>**⚠️ 本期暂不做**：该字段因上游题目缓存业务还未完成，无法提供题目来源字段的接口，故本期先不做，待上游完成该需要的开发后，学情诊断业务再把题目来源这个字段给加上。 |
| 年份范围 | 下拉选择 | 是 | 选项：不限 / 近3年 / 近5年 |

**题目来源提示气泡**：
> 因题目缓存支持反写题目来源的能力，仅能在筛选条件只有一个的时候支持反写题目来源，故前期在一次性筛选题目时，只能单选，后期在我们的题库里有很多题目都有题目来源的标签后，可支持多选。
>
> **⚠️ 本期暂不做**：该字段因上游题目缓存业务还未完成，无法提供题目来源字段的接口，故本期先不做，待上游完成该需要的开发后，学情诊断业务再把题目来源这个字段给加上。

### 4.3 题目组成配置区块

以表格形式展示配置项，支持新增、删除配置方案。

#### 4.3.1 表格列定义

| 列名 | 说明 |
|------|------|
| 知识点总数 | 数字输入框，范围 1~8 |
| 单知识点出题数 | 数字输入框，最小值 1 |
| 单知识点题目难度分布 | 5 个数字输入框，分别对应：易 / 较易 / 中档 / 较难 / 难 |
| 单知识点选题约束 | 下拉选择：全客观题 / 优先客观题 / 不限题型 |
| 调整题数 | 加减按钮 + 数字输入框 |
| 总出题数 | 只读显示，计算公式：知识点总数 × 单知识点出题数 + 调整题数 |
| 操作 | 删除按钮（仅编辑态显示；至少保留一条配置时不可删除） |

#### 4.3.2 难度分布校验

**校验规则**：5 个难度档位的题目数量之和必须等于「单知识点出题数」

**显示样式**：
- 校验通过：不显示提示
- 校验不通过（总题数 > 出题数）：显示红色提示「题目难度分布的总题数不能大于单知识点出题数」
- 校验不通过（总题数 < 出题数）：显示蓝色提示「题目难度分布的总题数不能小于单知识点出题数」

#### 4.3.3 多配置行知识点总数校验

**适用范围**：当存在多条配置方案时适用

**校验规则**：同一策略内，各配置行的知识点总数**不能相同**（不可重复）

**显示样式**：
- 当存在知识点总数重复时，显示蓝色提示标签：**知识点总数不可重复，同一数值仅允许配置 1 组题目组成方案**
- 重复行的输入框边框变红，显示红色错误提示：**知识点总数不可重复**

#### 4.3.4 选题约束帮助气泡

> 选择优先客观题选项，系统在选题时，会优先选择客观题，客观题题量不足时，用主观题补齐。

#### 4.3.5 调整题数帮助气泡

> - **题数 + X**：优先从高频知识点增题，无高频则选中频，均无则在低频中随机增题。
> - **题数 - Y**：优先从低频知识点减题，无低频则选中频，均无则在高频中随机减题。
> （选题满足单知识点难度分布要求）

#### 4.3.6 添加配置方案按钮

**位置**：表格下方

**样式**：绿色文字链接，图标为 Plus

## 6. 表单校验规则

| 字段 | 校验规则 | 错误提示 |
|------|----------|----------|
| 策略名称 | 不能为空 | 请输入策略名称 |
| 年份范围 | 不能为空 | 请选择年份范围 |
| 难度分布 | 总题数必须等于单知识点出题数 | 配置X题目难度分布的总题数(实际值)需等于单知识点出题数(期望值) |
| 知识点总数 | 必须大于 0 | 配置X知识点总数必须大于0 |
| 单知识点出题数 | 必须大于 0 | 配置X单知识点出题数必须大于0 |

### 6.1 同步学场景策略冲突校验

**校验规则**：同一学段-学科组合只能配置一份诊断策略

**触发时机**：保存时校验

**校验范围**：
- 已发布的策略
- 待发布的策略（已保存但未发布）
- 不包括已删除的策略

**冲突处理**：
- 检测到冲突时，阻止保存
- 显示冲突提示弹窗，告知已存在的冲突策略信息

**冲突提示弹窗内容**：
| 属性 | 内容 |
|------|------|
| 标题 | 策略配置冲突 |
| 提示文案 | 该学段-学科已配置诊断策略，同一组合仅支持配置一份策略。 |
| 冲突信息 | 显示冲突策略名称、学段、学科 |
| 操作按钮 | 「我知道了」关闭弹窗 |

## 7. 弹窗组件

### 7.1 删除确认弹窗

| 属性 | 内容 |
|------|------|
| 触发条件 | 查看模式下点击「删除」按钮 |
| 布局 | 左侧图标 + 标题；中间文案（包含策略名称）；底部取消和确认按钮 |
| 确认按钮样式 | 红色填充按钮 |

**文案示例**：
> 确定要删除策略「高中数学同步诊断」吗？删除后将无法恢复。

### 7.2 发布弹窗

| 属性 | 内容 |
|------|------|
| 触发条件 | 点击「发布」按钮 |
| 包含元素 | 发布注意事项提示 / 版本号（自动生成）/ 更新说明（必填）/ 发布时间选择（立即发布 / 定时发布）/ 取消和确认按钮 |

**版本号生成规则**：
- 版本号格式：v主版本.次版本（如 v1.0、v1.1）
- 初始版本：v1.0
- 每次发布：次版本号 +1（如 v1.0 → v1.1）
- 次版本号为 9 时，再更新则次版本归零，主版本 +1（如 v1.9 → v2.0）

**发布注意事项提示**：
> 发布将影响线上用户的实际使用，建议避开用户高频使用的时间段。
> 建议发布时段：凌晨 00:00 - 04:00

**发布时间选择**：
- 立即发布：单选按钮
- 定时发布：单选按钮 + 日期选择器 + 时间选择器（默认 02:00）

**更新说明**：
- 必填字段
- 多行文本输入框
- placeholder：「请填写本次更新的主要内容...」

**确认按钮文案**：
| 发布方式 | 按钮文案 |
|----------|----------|
| 立即发布 | 「确认发布」 |
| 定时发布 | 「确认定时发布」 |

### 7.3 历史发布记录弹窗

| 属性 | 内容 |
|------|------|
| 触发条件 | 点击版本号旁的「查看历史」按钮 |
| 内容 | 版本列表（按时间倒序），每条包含：版本号 / 当前版本标签 / 发布时间 / 更新说明 / 发布人信息 |
| 当前版本标识 | 绿色「当前版本」标签 |

## 8. 数据存储

### 8.1 新建策略

保存到 `localStorage` 的 `newDiagnosisStrategies` 字段

### 8.2 编辑已有策略

保存到 `localStorage` 的 `updatedDiagnosisStrategies` 字段

### 8.3 删除策略

保存到 `localStorage` 的 `deletedDiagnosisStrategies` 字段

### 8.4 数据同步

保存成功后触发 `newStrategySaved` 自定义事件，通知一级页面刷新

## 11. 边界情况处理

| 场景 | 处理方式 |
|------|----------|
| 仅有一条配置时 | 隐藏删除按钮 |
| 取消编辑 | 恢复编辑前的数据 |
| 发布成功 | 清除待发布状态，更新版本号 |
| 返回首页（新建后） | 带上场景参数，让首页自动定位到对应场景分组 |
