# 2.10 详情页-导出教材【GPT更新】

# 页面目标
用于将当前教材在【教材体系知识树】中的最新目录结构及知识点信息导出为 Excel 文件，便于存档、离线查看、人工校验和跨系统流转。

导出结果需满足以下目标：
- 导出当前教材的完整教材目录结构；
- 导出各层级目录节点名称；
- 导出各末级节点下实际关联的知识点名称；
- 导出结果口径需与当前教材在教材体系知识树中的最新目录结果保持一致；
- 导出目录口径需与乐课网原有教材树维护口径保持一致；
- 当前导出导出的是页面中的最新编辑结果，不以当前已发布版本内容作为导出依据。

---

知识体系管理 > 教材体系知识树 > 教材详情页 > 右侧详情区标题行 > 导出教材

- A1. 【导出教材】按钮：位于教材详情页右侧详情区标题行，点击后导出当前教材的 Excel 文件

# 交互逻辑

## 1. 触发导出
- 用户在教材详情页顶部点击【导出教材】按钮
- 系统读取当前教材上下文及当前教材最新目录结果
- 系统校验当前教材信息是否完整
- 若校验通过，则进入导出处理流程
- 若校验失败，则提示【教材信息获取失败，暂无法导出】

## 2. 获取导出数据
- 系统获取当前教材在教材体系知识树中的最新目录结构
- 系统获取目录节点下当前实际关联的知识点结果
- 当前导出数据不受以下因素影响：
  - 当前右侧选中节点
  - 左侧章节树展开 / 折叠状态
  - 当前停留的 Tab（知识点 / 同步课程 / 练习试卷）

## 3. 扁平化目录结构
- 系统按教材目录层级将树结构展平成 Excel 行数据
- 当前导出固定输出 4 列：
  - 章节名称
  - 一级小节名称
  - 二级小节名称
  - 知识点名称
- 若某层级不存在，则对应列留空，不做错位填充

## 4. 生成知识点列内容
- 系统读取当前目录节点下实际关联的知识点结果
- 若同一节点下关联多个知识点，则在同一个单元格内拼接输出
- 多个知识点之间使用顿号分隔
- 多个知识点的输出顺序按当前页面维护结果顺序导出

## 5. 生成 Excel 文件
- 系统按照固定表头生成 Excel 文件
- 当前版本导出一个工作表
- 工作表中写入完整教材目录及知识点结果

## 6. 生成文件名
- 系统根据当前教材信息生成导出文件名
- 文件名组成建议为：
  - 教材名称
  - 学段
  - 版本 / 出版社
- 文件名格式：
  - `{教材名称}_{学段}_{版本名称}.xlsx`
- 示例：
  - `数学·九年级上册_初中_浙教版.xlsx`
- 文件名中的非法字符需替换为下划线或安全字符

## 7. 下载文件
- 系统生成 Excel 文件后，触发浏览器下载
- 用户可保存到本地指定位置
- 导出完成后，不改变当前页面状态

# 业务规则

## 一、导出内容规则
1. 当前导出文件仅导出教材目录结构及知识点信息。
2. 当前导出文件不导出同步课程信息。
3. 当前导出文件不导出练习试卷信息。
4. 若后续需要扩展导出范围，应新增字段或新增导出模板，不在当前版本默认包含。

## 二、导出范围规则
1. 导出范围为当前教材的完整目录结构。
2. 不受当前右侧选中节点影响。
3. 不受左侧章节树展开 / 折叠状态影响。
4. 不受当前 Tab 停留位置影响。
5. 点击导出时，始终按当前教材完整目录数据生成 Excel。

## 三、目录一致性规则
1. 导出时使用的教材目录结构，需与当前教材在教材体系知识树中的最新目录结果保持一致。
2. 该目录结果需与乐课网原有教材树维护口径保持一致。
3. 若教材目录因双向同步发生变化，导出结果应以当前最新同步后的目录结果为准。
4. 导出不应使用旧缓存目录或不同步的本地临时目录。

## 四、导出口径规则
1. 点击【导出教材】时，导出的是当前页面中的最新编辑结果。
2. 不以当前已发布版本内容作为导出依据。
3. 即使当前页面存在未发布内容，导出时仍以当前最新编辑结果为准。
4. 导出结果应与当前页面最新可见的教材目录和知识点数据保持一致。

## 五、层级映射规则
1. Excel 固定输出以下 4 列：
   - 章节名称
   - 一级小节名称
   - 二级小节名称
   - 知识点名称

2. 当目录为“章节 → 一级小节”两级结构时：
   - 章节名称列写章名称；
   - 一级小节名称列写一级小节名称；
   - 二级小节名称列留空；
   - 知识点名称列写当前一级小节下的知识点。

3. 当目录为“章节 → 一级小节 → 二级小节”三级结构时：
   - 章节名称列写章名称；
   - 一级小节名称列写一级小节名称；
   - 二级小节名称列写二级小节名称；
   - 知识点名称列写当前二级小节下的知识点。

4. 若某层级不存在，则对应列留空，不做错位填充。

## 六、知识点导出规则
1. 知识点名称列导出的是当前教材目录节点实际关联的知识点结果。
2. 不导出未关联到当前教材目录节点的知识点。
3. 若同一节点下关联多个知识点，则在同一个单元格内拼接输出。
4. 多个知识点之间使用顿号分隔。
5. 多个知识点的导出顺序按当前页面维护结果顺序输出。

## 七、边界导出规则
1. 若某章节下存在一级小节但无知识点：
   - 仍导出该行目录信息；
   - 知识点名称列留空。

2. 若某一级小节下无二级小节：
   - 一级小节名称列写值；
   - 二级小节名称列留空；
   - 知识点名称列按该一级小节实际关联知识点输出。

3. 若某章节下暂无子节点：
   - 仅导出章节名称列；
   - 其他列留空。

4. 若整本教材目录为空：
   - 导出仅包含表头的 Excel 文件。

## 八、文件名规则
1. 文件名中不拼接当前版本号。
2. 文件名建议由以下信息组成：
   - 教材名称
   - 学段
   - 版本 / 出版社
3. 文件名推荐格式：
   - `{教材名称}_{学段}_{版本名称}.xlsx`
4. 文件名中的非法字符需替换为下划线或安全字符。

## 九、权限规则
1. 教研主管可见并可使用【导出教材】按钮。
2. 教研员可见并可使用【导出教材】按钮。
3. 导出教材属于查看 / 导出能力，不属于左侧教材目录编辑能力。
4. 因此教研员应具备当前教材导出权限。

# 状态与异常

## 页面状态
- 正常状态：当前教材信息完整，【导出教材】按钮可用
- 导出处理中状态：系统正在生成 Excel 文件
- 导出完成状态：浏览器开始下载文件

## 异常与边界
1. **当前教材信息异常**
   - 若当前教材信息丢失或加载失败，则导出按钮不可用，或点击后提示【教材信息获取失败，暂无法导出】

2. **整本教材目录为空**
   - 允许导出
   - 导出文件仅包含表头

3. **节点无知识点**
   - 允许导出
   - 对应行的知识点名称列留空

4. **目录层级不满三级**
   - 允许导出
   - 缺失层级对应列留空

5. **文件名过长或含非法字符**
   - 系统按安全规则处理文件名字符
   - 非法字符自动替换

6. **导出失败**
   - 若文件生成失败或下载失败，应提示失败原因，便于用户重试

# 导出模板要求

1. 导出文件格式为 `.xlsx`。
2. 当前版本导出一个工作表。
3. 工作表名称固定为【教材章节】。
4. 表头固定为：
   - 章节名称
   - 一级小节名称
   - 二级小节名称
   - 知识点名称
5. 列顺序固定，不允许随节点层级动态增减列。
6. 列宽可按默认模板设置输出。

---

# 技术要求

1. 系统需支持将树形目录结构稳定展平成固定列结构的二维表。
2. 导出结果需支持中文内容正常显示。
3. 多个知识点需支持在单元格中按顿号拼接输出。
4. 导出时不得依赖当前页面展开 / 折叠状态或当前可视区域。
5. 导出结果需与当前页面最新编辑结果保持一致。
