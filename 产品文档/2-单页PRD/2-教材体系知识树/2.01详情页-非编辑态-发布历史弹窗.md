# 2.01 详情页-非编辑态-发布历史弹窗【GPT更新】

# 页面目标
用于展示当前教材的历史发布记录列表，帮助教研人员查看当前教材的版本变更历史，并追溯各次正式发布的版本信息。

# 所属页面
知识体系管理 > 教材体系知识树 > 教材详情页 > 发布历史弹窗

# 页面区域

## A. 弹窗遮罩层
用于承载弹窗展示背景，突出当前弹窗内容。

## B. 弹窗容器
用于承载发布历史弹窗主体内容，包含标题区、筛选栏、发布历史列表区和底部操作区。弹窗宽度为 600px。

## C. 标题区
用于展示弹窗标题和关闭入口。

## D. 筛选栏
用于展示当前教材所属的学段、学科和版本信息，筛选字段置灰不可选。

## E. 发布历史列表区
用于展示当前教材的历史发布记录列表，支持独立滚动浏览。

## F. 底部操作区
用于提供关闭弹窗的操作入口。

# 组件说明

## A. 弹窗遮罩层组件
- A1. 遮罩层：全屏半透明遮罩，覆盖页面内容
- A2. 遮罩交互：点击遮罩层不关闭弹窗

## B. 弹窗容器组件
- B1. 弹窗主体：居中显示的白色弹窗容器
- B2. 列表滚动区域：发布历史列表在该区域内独立滚动
- B3. 底部操作区：固定在弹窗底部

## C. 标题区组件
- C1. 标题文本：显示【发布历史】
- C2. 关闭按钮：位于弹窗右上角，点击关闭弹窗

## D. 筛选栏组件
- D1. 学段筛选字段：显示当前教材所属学段（高中/初中/小学），置灰不可选
- D2. 学科筛选字段：显示当前教材所属学科，置灰不可选
- D3. 版本筛选字段：显示当前教材所属版本，置灰不可选
- D4. 筛选字段样式：bg-gray-100 text-gray-500 cursor-not-allowed

## E. 发布历史列表区组件
- E1. 历史记录卡片：用于展示单条发布历史记录
- E2. 版本号：显示版本号，如【v1.0】
- E3. 当前版本标签：当前生效版本显示【当前版本】标签
- E4. 发布时间：显示该版本发布时间，格式为【YYYY-MM-DD HH:mm】
- E5. 更新说明：显示本次发布说明
- E6. 发布人信息：显示发布人姓名和账号，格式为【发布人：姓名（账号：XXXXXX）】
- E7. 当前版本高亮样式：当前版本记录使用高亮底色和边框展示
- E8. 普通历史版本样式：非当前版本记录使用普通样式展示
- E9. 空状态：无发布历史时显示空状态提示
- E10. 加载中占位：加载历史记录时显示加载占位
- E11. 加载失败提示：接口失败时显示失败提示和重试入口

## F. 底部操作区组件
- F1. 关闭按钮：点击后关闭弹窗

# 交互逻辑

## 1. 打开弹窗
1.1、点击详情页左侧版本号旁的历史版本图标后，弹出【发布历史】弹窗  
1.2、弹窗打开后，自动加载当前教材的发布历史记录  
1.3、列表默认按发布时间倒序排列，最新记录排在最前  
1.4、弹窗打开后，列表滚动位置定位到顶部  

## 2. 筛选栏展示
2.1、筛选栏位于弹窗标题下方，列表区域上方  
2.2、筛选栏展示当前教材所属的学段、学科和版本信息  
2.3、所有筛选字段均置灰不可选，不可点击、不可修改  
2.4、筛选栏用于展示当前教材的属性信息，与首页聚合历史发布记录弹窗的筛选字段保持一致  

## 3. 查看发布历史
3.1、列表展示当前教材的所有正式发布记录  
3.2、每条记录展示版本号、发布时间、更新说明、发布人姓名和发布人账号  
3.3、当前生效版本对应的记录显示【当前版本】标签  
3.4、当前版本记录使用高亮底色和边框展示  
3.5、非当前版本记录使用普通样式展示  
3.6、历史记录条目仅支持查看，不支持点击跳转  

## 4. 关闭弹窗
4.1、点击右上角关闭图标，关闭弹窗  
4.2、点击底部【关闭】按钮，关闭弹窗  
4.3、点击遮罩层不关闭弹窗  
4.4、按 ESC 不关闭弹窗  
4.5、弹窗关闭后，再次打开时，默认重新加载当前教材发布历史，并将列表滚动位置重置到顶部  

# 业务规则

## 一、数据范围规则
1. 该弹窗仅展示当前详情页所在教材的发布历史记录  
2. 发布历史记录不跨教材聚合展示  
3. 列表内容为当前教材已正式发布的版本记录  
4. 历史记录默认按发布时间倒序排列  

## 二、筛选栏规则
1. 筛选栏展示当前教材所属的学段、学科和版本信息  
2. 所有筛选字段置灰不可选，仅用于信息展示  
3. 筛选栏用于帮助用户理解当前教材的归属属性  
4. 筛选字段与首页聚合历史发布记录弹窗的筛选字段保持一致  

## 三、当前版本标识规则
1. 列表中仅当前生效版本对应的那条记录显示【当前版本】标签  
2. 当前版本记录使用高亮底色和边框区别于其他历史版本  
3. 非当前版本记录使用普通样式展示  
4. 同一教材的发布历史中，仅允许存在一条【当前版本】记录  

## 四、记录内容规则
1. 每条发布记录必须包含以下字段：
- 版本号
- 发布时间
- 更新说明
- 发布人姓名
- 发布人账号
2. 以上字段均为必填字段，不允许缺失  
3. 更新说明用于描述本次发布的主要变更内容  
4. 当前版本记录与普通历史版本记录展示字段一致，仅样式和标签不同  

## 五、详情页版本信息一致性规则
1. 弹窗中标记为【当前版本】的版本号，需与详情页左侧展示的当前版本号保持一致  
2. 当前版本记录即为详情页左侧当前版本信息对应的发布记录  
3. 不允许出现弹窗当前版本与详情页左侧版本号不一致的情况  
4. 详情页左侧仅展示当前版本号信息，不展示发布时间、发布说明和发布人信息  

## 六、权限规则
1. 教研主管可查看发布历史  
2. 教研员可查看发布历史  
3. 发布历史弹窗为只读能力，不提供编辑、删除、恢复版本、跳转详情等操作权限  

## 七、数据一致性规则
1. 发布历史记录以当前教材统一发布数据为准  
2. 当前版本号信息需与详情页左侧版本号口径一致  
3. 不允许出现发布历史与详情页当前版本信息不一致的情况  

# 状态与异常

## 页面状态
- 加载中状态：列表区域显示加载占位
- 正常状态：显示发布历史列表
- 空状态：显示【暂无发布历史】
- 加载失败状态：显示失败提示和重试入口

## 异常与边界
- 无发布历史时：列表区显示【暂无发布历史】空状态
- 发布历史加载失败时：列表区显示失败提示，并支持重试
- 点击遮罩层不关闭弹窗
- 按 ESC 不关闭弹窗
- 关闭弹窗后再次打开，需重新加载数据并将列表滚动回顶部

# 数据来源

| 数据名称 | 来源 | 用途 |
|----------|------|------|
| 当前教材发布历史记录 | 当前教材发布记录存储 / 统一发布数据源 | 展示发布历史列表 |
| 当前版本号信息 | 当前教材发布状态数据 | 标记当前版本记录 |
| 当前教材上下文 | 当前详情页教材上下文数据 | 确定查看对象 |
| 当前用户信息 | 登录用户信息 | 校验查看权限 |

# 接口需求

| 接口名称 | 用途 | 状态 |
|----------|------|------|
| 获取当前教材发布历史接口 | 获取当前教材的发布历史记录列表 | 待补充 |
| 获取当前教材当前版本信息接口 | 获取当前教材当前生效版本号 | 待补充 |
| 获取当前用户查看权限接口 | 获取当前用户是否具备查看发布历史权限 | 待补充 |

# 技术要求

- 弹窗需支持居中展示
- 发布历史列表区需支持独立滚动
- 弹窗需支持加载态、正常态、空态和失败态切换
- 当前版本记录需支持高亮展示
- 当前版本号需与详情页左侧版本号信息保持一致
- 发布历史数据需基于统一发布数据口径展示
