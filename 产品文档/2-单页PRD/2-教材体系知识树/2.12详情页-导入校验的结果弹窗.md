# 2.12 详情页-导入校验结果弹窗【最终版】

# 页面名称
导入教材——校验结果弹窗

# 所属模块
知识体系管理 > 教材体系知识树 > 章节详情页 > 知识点 Tab > 批量导入

# 页面目标
用于承接用户在【教材体系知识树】中上传导入文件并点击【开始校验】后的结果反馈。

该弹窗不是直接执行导入，而是先对上传文件进行校验，并将校验结果清晰反馈给用户，帮助用户明确：
1. 本次上传文件是否可继续导入
2. 教材树路径是否校验通过
3. 文件中的知识点名称是否能在【知识树模块】中匹配到已有知识点
4. 哪些数据校验通过
5. 哪些数据校验失败
6. 哪些数据被跳过 / 未更新
7. 失败原因是什么
8. 当前应执行【仅导入通过项】、【重新上传】、【下载错误明细】还是其他操作

# 上个页面
导入教材弹窗（上传态）

# 下级页面
无

# 页面入口
用户在【教材体系知识树】详情页中点击【批量导入】后进入上传弹窗；
用户选择 Excel 文件后，点击【开始校验】，校验完成后进入本弹窗。

# 页面出口
1. 点击右上角【×】关闭弹窗，返回来源页面
2. 点击【取消】关闭弹窗，返回来源页面
3. 点击【重新上传】返回上传态
4. 点击【仅导入通过项】进入导入执行流程
5. 点击【开始导入】进入导入执行流程
6. 点击【下载错误明细】下载校验结果文件
7. 点击【下载模板】下载标准模板

# 前置说明
1. 本次教材树批量导入的规则与知识树导入保持一致：左侧树结构字段只用于匹配，不用于导入更新
2. 不支持通过导入新增、删除、改名、移动教材树节点
3. 仅支持导入右侧【知识点信息】模块的数据，不涉及同步课程、练习试卷等其他 Tab
4. 文件中的知识点名称，需与【知识树模块】中已维护的知识点进行匹配
5. 若教材树路径匹配通过，但知识点名称未在知识树模块中匹配到，则该行仍判定为失败，不可导入
6. 知识点仅允许关联到叶子章节节点（没有子章节的节点），非叶子节点不可填写知识点
7. 知识点列留空表示“不更新”，不表示清空
8. 若需清空线上已有知识点，需填写系统保留标记【[清空]】

# 页面布局规则
1. 弹窗头部固定
2. 弹窗底部操作区固定
3. 中间内容区域滚动
4. 失败明细默认仅展示失败行
5. 问题分类区默认提供【全部问题】筛选项
6. 校验通过 / 部分通过 / 行级全失败 / 文件级失败 / 无可导入数据五种状态，视觉样式需明显区分

# 页面区域

## A. 弹窗头部
用于展示当前弹窗标题及关闭入口。

### 组件说明
- A1. 标题文本：显示【校验结果】
- A2. 关闭按钮：点击后关闭弹窗，返回来源页面，清空当前临时状态

   - 按钮：取消 / 确定关闭

## B. 校验结果概览区
用于展示本次校验的总体结果。根据校验结果展示不同状态卡片。

### 公共展示信息
所有状态卡片均展示以下基础信息：
1. 文件名称
2. 上传时间
3. 总行数（参与校验的有效数据行数）
4. 通过行数
5. 失败行数
6. 跳过行数（如存在）

> 说明：
> - “总行数”指参与校验的有效数据行数，不包含完全空白行
> - 完全空白行不参与校验、不计入总行数、不计入通过/失败/跳过

### 状态1：校验失败（文件级失败）
适用于整份文件不合法、无法进入行级校验的场景。

#### 组件说明
- B1. 失败图标：红色圆形 X 图标
- B2. 主标题：校验失败，当前文件无法导入
- B3. 辅助说明：请根据下方失败原因修正文件后重新上传
- B4. 结果信息区域，包含：
  - 文件名称
  - 上传时间
  - 校验结果：失败
  - 可导入行数：0 行
- B5. 失败类型标签：文件级失败（红色圆角标签）

### 状态2：部分通过（存在行级失败）
适用于文件本身合法，但部分数据行校验失败的场景。

#### 组件说明
- B1. 提醒图标：橙色圆形三角感叹号图标
- B2. 主标题：校验完成，部分数据可导入
- B3. 辅助说明：通过校验的数据可继续导入，失败数据请下载明细后修正
- B4. 结果信息区域，包含：
  - 文件名称
  - 上传时间
  - 总行数
  - 校验通过行数（绿色）
  - 校验失败行数（红色）
  - 跳过行数（灰色，若存在则展示）

### 状态3：校验通过
适用于文件本身合法，且所有参与更新的数据行全部通过校验的场景。

#### 组件说明
- B1. 成功图标：绿色圆形对勾图标
- B2. 主标题：校验通过，可直接导入
- B3. 辅助说明：本次文件未发现异常数据，可继续导入
- B4. 结果信息区域，包含：
  - 文件名称
  - 上传时间
  - 总行数
  - 通过行数
  - 跳过行数（若存在则展示）

> 注：
> 若文件中存在“知识点列留空”的合法行，这些行记为【跳过 / 未更新】；
> 只要不存在失败行，且存在至少 1 行通过，页面仍展示为【校验通过】。

### 状态4：行级全失败
适用于文件本身合法，但所有有效数据行均未通过校验的场景。

#### 组件说明
- B1. 失败图标：红色圆形 X 图标
- B2. 主标题：校验失败，所有数据行均未通过
- B3. 辅助说明：请根据下方错误明细修正数据后重新上传
- B4. 结果信息区域，包含：
  - 文件名称
  - 上传时间
  - 总行数
  - 通过行数：0 行
  - 失败行数
  - 跳过行数（若存在则展示）

### 状态5：无可导入数据
适用于文件本身合法，所有有效数据行均为“跳过 / 未更新”的场景。

#### 组件说明
- B1. 提醒图标：灰色信息图标
- B2. 主标题：校验完成，无可导入数据
- B3. 辅助说明：当前文件未包含可更新的知识点信息，请补充内容后重新上传
- B4. 结果信息区域，包含：
  - 文件名称
  - 上传时间
  - 总行数
  - 跳过行数
  - 通过行数：0 行
  - 失败行数：0 行

#### 交互限制
1. 当前状态下不允许执行导入
2. 底部不展示【开始导入】或【仅导入通过项】按钮

## E. 错误明细表格区
用于逐行展示失败数据的具体原因，是本弹窗的核心区域。

### 展示规则
1. 仅在【部分通过】或【行级全失败】场景下展示
2. 默认仅展示失败行，不展示通过行和跳过行
3. 默认展示前 10 条，超出时支持展开查看全部
4. 支持跟随问题分类卡片筛选结果联动刷新

### 组件说明
- E1. 表格标题：失败明细
- E2. 右侧显示失败总条数
- E3. 表格字段如下：

| 列名 | 说明 |
|------|------|
| 序号 | 按当前表格展示顺序递增 |
| Excel行号 | 展示原 Excel 中的数据行号，格式如“第4行” |
| 当前教材路径 | 将当前行中非空的教材树标题列拼接为完整路径，格式如：第一章 / 1.1 / 一级小节 |
| 知识点信息 | 展示当前行填写的知识点名称内容，多个知识点按原填写格式展示 |
| 校验结果 | 固定为失败（红色标签） |
| 失败原因 | 展示具体失败原因 |

### 展开 / 收起逻辑
1. 默认展示前 10 条失败数据
2. 超出 10 条时，底部显示【展开查看全部 X 条】按钮
3. 点击后展示全部失败数据
4. 再次点击【收起】恢复默认展示条数

### 常见失败原因文案

#### 教材树路径类
1. 未匹配到线上教材节点
   - 失败原因：系统未在当前教材树中找到与该路径完全一致的章节 / 小节节点

2. 教材树层级断裂
   - 失败原因：当前行教材树层级填写不完整，存在跳级填写

3. 同一教材节点重复导入
   - 失败原因：当前文件中存在多个相同教材路径的数据行

4. 当前行未填写任何教材路径信息但填写了知识点
   - 失败原因：当前行未填写任何教材路径信息，无法定位线上教材节点

#### 知识点匹配类
1. 知识点未在知识树模块中匹配到
   - 失败原因：知识点“XX”未在知识树模块中找到对应知识点
   - 多个未匹配时：多个知识点中存在未匹配项：XX、YY 未在知识树模块中匹配到

2. 知识点无法唯一识别
   - 失败原因：知识点“XX”在知识树模块中存在重名，系统无法唯一确认
   - 多个重名时：多个知识点存在重名：XX、YY 在知识树模块中无法唯一识别

3. 同一行知识点重复填写
   - 失败原因：当前行知识点名称存在重复项

4. 非叶子章节节点填写知识点
   - 失败原因：知识点仅允许关联到叶子章节节点（没有子章节的节点）

5. 清空标记与其他知识点混填
   - 失败原因：清空标记【[清空]】必须单独填写，不可与其他知识点同时出现

# 交互逻辑

## 场景1：选择文件后点击开始校验
1. 用户在上传态弹窗中选择 Excel 文件
2. 上传成功后，【开始校验】按钮置为可点击
3. 用户点击【开始校验】
4. 弹窗进入校验中加载态
5. 系统执行文件级校验
6. 若文件级校验失败，进入【文件级失败态】
7. 若文件级校验通过，继续执行行级校验
8. 行级校验时，按以下顺序执行：
   - 忽略完全空白行
   - 校验教材树路径是否合法（层级连续性）
   - 校验教材树路径是否能匹配到当前教材树中的线上节点
   - 校验当前章节是否为叶子节点（知识点仅允许关联到叶子节点）
   - 校验知识点列是否为空；为空则记为【跳过 / 未更新】
   - 若非空，校验是否为清空标记【[清空]】
   - 若为【[清空]】，校验是否单独填写；通过则该行可导入
   - 若非清空标记，校验知识点名称是否能在知识树模块中匹配到已有知识点
   - 校验知识点名称是否存在重名（无法唯一识别）
   - 校验同一行知识点是否重复填写
9. 根据行级校验结果进入对应态：
   - 全部通过 → 校验通过态
   - 部分通过 → 部分通过态
   - 全部失败 → 行级全失败态
   - 全部跳过 → 无可导入数据态

## 场景2：文件级失败
1. 用户看到整份文件失败原因
2. 用户可选择：
   - 点击【重新上传】返回上传态
   - 点击【下载模板】重新获取标准模板
   - 点击【取消】关闭弹窗
3. 当前场景下不可执行导入

## 场景3：部分通过
1. 用户查看通过 / 失败 / 跳过数据统计
2. 用户查看错误分类卡片，可点击筛选
3. 用户查看错误明细表格
4. 用户可选择：
   - 点击【下载错误明细】下载带结果列的错误明细 Excel
   - 点击【重新上传】返回上传态，清空当前校验结果
   - 点击【仅导入通过项】仅对校验通过的数据行执行导入
   - 点击【取消】关闭弹窗

## 场景4：仅导入通过项
1. 用户点击【仅导入通过项】
2. 弹窗进入导入中加载态
3. 系统仅对校验通过的数据行执行导入
4. 失败行不进入导入
5. 跳过行不进入导入
6. 导入完成后：
   - 成功：展示导入结果态（成功导入 X 行），页面发布状态变为【待发布】
   - 失败：展示导入结果态（导入失败），toast 提示“导入失败，请稍后重试”

## 场景5：校验通过 - 开始导入
1. 用户点击【开始导入】
2. 弹窗进入导入中加载态
3. 系统对所有校验通过的数据行执行导入
4. 跳过行不进入导入
5. 导入完成后：
   - 成功：展示导入结果态（成功导入 X 行），页面发布状态变为【待发布】
   - 失败：展示导入结果态（导入失败），toast 提示“导入失败，请稍后重试”

## 场景6：无可导入数据
1. 用户看到当前文件所有有效数据行均为【跳过 / 未更新】
2. 当前场景下不允许执行导入
3. 用户可点击【重新上传】返回上传态
4. 用户可点击【取消】关闭弹窗

## 场景7：重新上传
1. 用户点击【重新上传】
2. 弹窗返回上传态，清空当前校验结果
3. 用户可重新选择文件

## 场景8：下载错误明细
1. 用户点击【下载错误明细】
2. 系统下载基于原始上传文件生成的结果文件
3. 结果文件在原始文件基础上追加以下结果列：
   - 校验结果
   - 失败原因
4. 下载失败时，toast 提示“错误明细下载失败，请稍后重试”

## 场景9：关闭弹窗
1. 用户点击【取消】或右上角【×】关闭弹窗
2. 关闭后清空当前校验结果和临时状态
3. 再次打开批量导入弹窗时，回到上传态
4. 不保留上次校验结果

## 场景10：当前页面存在未保存编辑时进行批量导入
1. 若用户当前页面存在未保存编辑，仍允许进入批量导入流程
2. 批量导入成功后，导入结果与当前页面未保存编辑内容共同保留在当前编辑态
3. 若导入字段与当前页面已修改但未保存的字段存在冲突，以“后操作生效”为准：
   - 用户后执行的导入结果覆盖当前编辑态中的同字段旧值
4. 页面仍保持【待发布】状态

# 业务规则

## 一、校验与导入分离
1. 用户选择文件后，不自动校验
2. 用户点击【开始校验】后才执行校验
3. 校验仅检查数据合法性，不写入数据
4. 校验通过后，需用户主动点击【开始导入】或【仅导入通过项】才执行导入
5. 不存在“上传即导入”的流程

## 二、文件级失败时，整份文件不可导入
1. 一旦文件级校验失败，不进入行级校验
2. 不允许导入任何通过项
3. 用户必须修正文件后重新上传

## 三、行级失败不阻断其他通过行
1. 若文件级校验通过，则允许对每一行独立校验
2. 失败行不导入，通过行可继续导入
3. 跳过行不导入
4. 行级校验之间互不影响

## 四、教材树标题列只用于匹配，不用于更新
1. 文件中的章节名称、一级小节名称、二级小节名称等左侧教材树字段，仅用于匹配当前教材树节点
2. 不通过导入更新线上教材树结构

## 五、仅支持导入右侧【知识点信息】模块
1. 当前导入能力只对教材树详情页中的【知识点信息】模块生效
2. 不涉及同步课程、练习试卷等其他 Tab

## 六、知识点名称必须先在知识树模块中存在
1. 若文件中填写的知识点名称未在【知识树模块】中维护，则该行失败，不可导入
2. 若知识点名称在知识树模块中存在重名，系统无法唯一识别，该行失败

## 七、知识点仅允许关联到叶子章节节点
1. 叶子章节节点定义：没有子章节的章节节点
2. 若用户在非叶子章节节点的行填写了知识点，该行失败
3. 非叶子章节节点的行，知识点列应留空

## 八、知识点覆盖规则（整体覆盖）
1. 只要教材树路径匹配成功且知识点校验通过，导入时以文件中的知识点信息整体覆盖线上数据
2. 覆盖逻辑：文件中填写的知识点 = 导入后的知识点，不做追加合并
3. 示例：线上为“知识点A、知识点B”，文件中填写“知识点C”，导入后变为“知识点C”
4. 同一行多个知识点中，只要任意一个知识点不合法，则该行整体失败，不做部分导入

## 九、知识点留空与清空规则
1. 知识点列留空 = 不更新，保留线上已有数据
2. 知识点列留空的合法行，记为【跳过 / 未更新】
3. 用户可在知识点列填写【[清空]】来清空线上已有的知识点
4. 【[清空]】为系统保留标记，填写后导入时将清空该章节节点关联的所有知识点
5. 仅当填写内容完全为【[清空]】时才识别为清空标记
6. 【[清空]】不可与其他知识点同时填写，若混填则该行失败

| 文件填写 | 线上数据 | 导入后结果 | 说明 |
|----------|----------|------------|------|
| 知识点A | 知识点B | 知识点A | 整体覆盖 |
| （空） | 知识点B | 知识点B | 留空不更新 |
| [清空] | 知识点B | （空） | 清空标记 |
| 知识点A、知识点C | 知识点B | 知识点A、知识点C | 多个知识点覆盖 |

## 十、空白行与有效数据行规则
1. 完全空白行直接忽略，不参与校验，不计入总行数
2. “完全空白行”指：
   - 教材树标题列全部为空
   - 知识点列为空
   - 去除首尾空格后仍为空
3. 若教材树标题列全部为空，但知识点列存在任意值，则该行失败
4. 该类失败归类为【当前行未填写任何教材路径信息但填写了知识点】

## 十一、知识点分隔与文本清洗规则
1. 多个知识点默认使用顿号【、】分隔
2. 系统在校验前需对知识点字段做基础清洗：
   - 去除首尾空格
   - 去除分隔符两侧空格
3. 同一行中拆分后的空项不计入有效知识点
4. 若拆分后出现重复知识点，则该行失败

## 十二、重复行检测规则
1. 若同一文件中存在多条相同教材路径的数据行，所有重复行均校验失败
2. 失败原因标记为【同一教材节点重复导入】

## 十三、标题层级连续性规则
1. 填写某级标题时，其上级标题必须连续填写
2. 不允许跳级填写（如填了二级小节但一级小节为空）

## 十四、行增减规则
1. 导入支持按行增减上传内容，但不支持通过导入新增教材树节点
2. 用户删除导入文件中的行 = 不更新这些节点，不等于删除线上节点
3. 用户新增行但匹配不到线上节点 → 该行失败，不导入
4. 未上传的节点不处理、不删除、不报错

## 十五、多次导入规则
1. 每次导入只更新本次文件中匹配到且校验通过的节点的知识点信息
2. 不会覆盖之前已导入但本次文件中未包含的节点
3. 同一节点在多次导入中被不同数据覆盖时，后导入的覆盖先导入的

## 十六、未匹配教材节点展示规则
1. 当前模板不包含教材节点 ID，前端展示统一使用【未匹配到线上教材节点】
2. 不再区分“标题被修改导致无法匹配”与“线上无此节点”两类展示口径
3. 失败原因统一表述为：系统未在当前教材树中找到与该路径完全一致的章节 / 小节节点

## 十七、权限规则
1. 仅教研主管可使用批量导入功能
2. 教研员不可使用批量导入功能

## 十八、错误明细下载规则
1. 用户需能下载带失败原因的明细文件
2. 下载文件为 Excel 格式
3. 文件基于用户原始上传文件生成，并追加结果列
4. 结果列包含：校验结果、失败原因

## 十九、结果展示规则
1. 页面中不得仅使用“导入失败”“数据异常”等模糊文案
2. 必须展示具体失败原因
3. 问题分类默认展示【全部问题】
4. 失败明细默认仅展示失败行

## 二十、导入写入位置规则
1. 导入结果写入当前编辑态
2. 不直接影响已发布版本
3. 发布后才对下游业务生效

# 状态与异常

## 页面状态
1. 校验中加载态：系统正在校验文件
2. 文件级失败态：整份文件校验失败
3. 部分通过态：部分行校验通过，部分行校验失败
4. 校验通过态：所有可更新行校验通过
5. 行级全失败态：文件合法但所有有效数据行校验失败
6. 无可导入数据态：文件合法，但所有有效数据行均为跳过 / 未更新
7. 导入中加载态：系统正在执行导入
8. 导入成功态：导入执行成功
9. 导入失败态：导入执行失败

## 异常与边界

| 异常场景 | 处理方式 |
|----------|----------|
| 文件解析失败 | 文件级失败，提示“文件解析失败，请确保上传的是有效的 Excel 文件” |
| 模板表头不匹配 | 文件级失败，提示“模板表头不匹配”，建议下载标准模板 |
| 模板类型不匹配 | 文件级失败，提示“模板类型不匹配，请使用教材树标准模板” |
| 文件内容为空 | 文件级失败，提示“模板内容为空” |
| 选择非 Excel 文件 | 文件级失败，提示“文件格式不支持” |
| 完全空白行 | 直接忽略，不参与校验 |
| 教材路径全空但知识点有值 | 该行失败，提示“当前行未填写任何教材路径信息” |
| 教材树路径匹配不到线上节点 | 该行失败，统一提示“未匹配到线上教材节点” |
| 教材树层级断裂 | 该行失败，提示“教材树层级填写不完整” |
| 同一文件重复路径 | 所有重复行失败，提示“同一教材节点重复导入” |
| 知识点列留空 | 不报错，该行记为跳过 / 未更新 |
| 知识点列填写【[清空]】 | 不报错，导入时清空线上知识点 |
| 【[清空]】与其他知识点混填 | 该行失败，提示“清空标记必须单独填写” |
| 非叶子节点填写知识点 | 该行失败，提示仅叶子节点可填写 |
| 知识点未在知识树模块中匹配 | 该行失败，提示未匹配的知识点名称 |
| 知识点在知识树模块中重名 | 该行失败，提示无法唯一识别 |
| 同一行知识点重复 | 该行失败，提示存在重复项 |
| 同一行多个知识点中任意一个不合法 | 整行失败，不做部分导入 |
| 全部有效行均为跳过 / 未更新 | 展示“无可导入数据态”，不允许导入 |
| 校验接口异常 | toast 提示“校验失败，请稍后重试”，保留当前文件，可再次校验 |
| 下载错误明细失败 | toast 提示“错误明细下载失败，请稍后重试” |
| 导入接口失败 | toast 提示“导入失败，请稍后重试”，校验结果页不关闭，用户可再次尝试 |
| 校验中关闭弹窗 | 允许关闭，再次打开回到上传态 |
| 导入中关闭弹窗 | 弹出二次确认，提示已导入数据不会回滚 |
| 关闭弹窗后重新打开 | 回到上传态，清空之前的校验结果 |

## 数据来源

| 数据名称 | 来源 | 用途 |
|----------|------|------|
| 用户上传文件 | 用户本地 Excel 文件 | 作为批量导入数据源 |
| 线上教材树目录 | 当前教材的章节树数据 | 用于教材路径匹配 |
| 线上知识树知识点集合 | 当前学段学科的知识树数据 | 用于知识点名称匹配与重名检测 |
| 当前教材信息 | 当前页面上下文 | 作为导入目标范围和文件命名 |
| 当前用户角色 | 登录用户信息 | 控制导入权限 |
| 当前编辑态数据 | 当前页面未发布的编辑中数据 | 承接导入写入结果与页面未保存编辑合并 |
