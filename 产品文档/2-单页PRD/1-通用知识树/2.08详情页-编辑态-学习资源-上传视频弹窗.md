# 2.08 详情页-编辑态-学习资源-上传视频流程【GPT更新】

# 页面目标
用于在知识点详情页的【学习资源】模块中完成视频上传流程。  
用户点击【上传视频】后，唤起系统文件选择窗口，一次性选择一个或多个视频文件；选择完成后返回当前页面，并在视频讲解区域内展示上传进度、上传结果及后续视频列表更新情况。

同时，针对当前知识点上传成功的视频资源，需按既有历史业务要求，同步写入乐课网平台对应知识点的微课库中。


# 所属页面
知识体系管理 > 通用知识树 > 详情页 > 编辑态 > 学习资源 > 上传视频流程

# 页面区域

## A. 视频讲解区域
用于承载视频上传入口、上传进度展示、上传结果反馈和视频列表更新。

## B. 系统文件选择窗口
用于从本地选择一个或多个视频文件。

# 组件说明

## A. 视频讲解区域组件
- A1. 上传视频入口：点击后唤起系统文件选择窗口
- A2. 资源库选择入口：用于从资源库选择已有视频
- A3. 视频空态区：无视频时显示上传引导内容
- A4. 上传进度条：用于展示当前视频上传进度
- A5. 上传进度文案：显示当前上传状态和百分比，如【视频上传中... 90%】
- A6. 取消上传入口：在上传进度未达到 100% 前可见，用于取消当前上传
- A7. 视频列表区：上传成功后展示视频项
- A8. 视频项信息：展示视频名称、来源、时长、大小及预览入口

## B. 系统文件选择窗口组件
- B1. 文件选择器：支持从本地选择视频文件
- B2. 多选能力：支持一次性选择多个视频文件
- B3. 文件格式限制：和乐课网上传视频格式保持一致；文件大小限制：和乐课网上传视频大小保持一致

# 交互逻辑

## 1. 打开文件选择窗口
1.1、用户点击【上传视频】按钮  
1.2、系统唤起系统文件选择窗口  
1.3、文件选择窗口支持一次性选择多个视频文件  

## 2. 选择文件
2.1、用户在系统文件选择窗口中选择一个或多个视频文件  
2.2、确认选择后，返回当前学习资源页面  
2.3、系统将本次选择的文件加入当前上传队列  

## 3. 上传中展示
3.1、当文件开始上传后，视频讲解区域从空态或原有状态切换为上传中状态  
3.2、页面内展示上传进度条和进度文案  
3.3、上传进度未达到 100% 时，显示【取消上传】入口  
3.4、用户点击【取消上传】后，终止当前上传流程，并停止进度更新  
3.5、取消上传后，本次未上传完成的视频不加入视频列表，页面恢复到上传前状态或当前已有视频列表状态  

## 4. 上传完成
4.1、上传进度达到 100% 后，视为当前视频上传完成  
4.2、上传完成的视频加入当前视频列表  
4.3、视频列表展示最新上传成功的视频信息  
4.4、若本次选择了多个视频，则按上传完成结果依次加入视频列表  

## 5. 写入乐课网微课库
5.1、当前知识点的视频上传成功后，系统需同步触发乐课网平台微课库写入流程  
5.2、同步写入时，需自动读取并带上当前知识点的以下信息：
- 所属学段
- 所属学科
- 知识点名称
- 当前上传的视频资源信息
5.3、系统需按乐课网教研员在乐课网资源维护平台中的既有维护路径完成同步写入，对应入口为：
- 资源库
- 微课
- 添加微课
- 上传微课
5.4、同步成功后，该视频除出现在当前页面的视频列表中外，也应在乐课网平台该知识点对应的微课库中可被查询和使用  
5.5、若乐课网同步失败，需按约定规则提示失败原因，并保留当前上传成功的视频结果及同步状态  

## 6. 上传失败
6.1、上传失败时，页面提示失败原因  
6.2、失败文件不加入视频列表  
6.3、页面保留当前上下文，不清空已有已上传视频结果  

## 7. 后续保存
7.1、上传成功后的视频结果先写入当前学习资源编辑结果中  
7.2、最终仍需点击顶部【完成编辑】后，统一提交保存  
7.3、若顶部统一保存失败，需保留当前已上传成功的视频结果，避免用户重新操作  

# 业务规则

## 一、页面范围规则
1. 当前流程用于在学习资源模块中上传视频  
2. 当前流程不单独构成独立业务弹窗页面，而是【系统文件选择窗口 + 页面内上传状态反馈】的组合流程  

## 二、文件选择规则
1. 支持一次性选择多个视频文件
2. 上传视频格式限制：和乐课网上传视频格式保持一致；上传视频大小限制：和乐课网上传视频大小保持一致
3. 文件格式校验：仅接受乐课网已支持的格式，其他格式提示「不支持该文件格式」
4. 文件大小校验：单文件不超过乐课网已支持的上传文件的大小，超出提示「仅支持上传X以内的文件」，其中的X是乐课网支持上传的最大内存的数值
5. 文件选择完成后，所选文件进入当前上传队列  

## 三、上传展示规则
1. 上传进度在当前页面的视频讲解区域内展示  
2. 上传进度未达到 100% 前，允许取消上传  
3. 上传进度达到 100% 后，不再显示取消上传入口  
4. 上传成功后，视频加入视频列表  
5. 上传失败时，视频不加入视频列表  

## 四、预览规则
1. 上传成功的视频可在视频列表中进行预览  
2. 视频预览能力与资源来源无关，上传视频和资源库视频均支持预览，预览时用乐课网原本预览视频的组件，新开页预览视频

## 五、乐课网同步规则
1. 针对当前知识点上传成功的视频资源，需同步写入乐课网平台对应知识点的微课库  
2. 同步写入时，必须带上当前知识点所属学段、学科、知识点名称及视频资源信息  
3. 乐课网同步写入逻辑需对齐乐课网既有资源维护业务路径，即：
- 资源库
- 微课
- 添加微课
- 上传微课
4. 用户点击「完成编辑」时，将上传的微课写入到乐课网微课库，用当前账号写入到当前账号对应的维护乐课网微课的模块，写入字段如下：
   - 内容来源：默认写入「自适应学习配置后台自动写入」
   - 学段学科：自动携带当前知识点所属的学段学科
   - 微课类型：自动选择「知识点微课」
   - 教材章节：传入空值
   - 知识点：传入当前知识点
   - 年份：传入当前年份
   - 地区：默认选择全选
   - 级别：默认选择「精品」
   - 对应视频：默认为未下架状态
5. 当用户对该知识点模块的信息操作发布时，将在该知识点模块上传的视频写入到乐课网微课库的视频做上架处理
6. 若写入乐课网微课库失败，需保留当前上传结果，并对写入失败状态进行提示，不影响编辑流程继续

## 六、保存规则
1. 上传成功后的视频结果先写入当前编辑态结果中  
2. 最终提交仍由顶部【完成编辑】统一保存  
3. 若最终保存失败，需保留当前编辑结果  

# 状态与异常

## 页面状态
- 视频空态：显示上传视频和资源库选择入口
- 文件选择中状态：系统文件选择窗口打开
- 上传中状态：视频讲解区域展示上传进度
- 上传成功状态：视频加入当前视频列表
- 上传失败状态：提示失败原因
- 上传取消状态：终止当前上传并恢复页面上下文
- 乐课网写入中状态：用户点击「完成编辑」后，正在将上传的微课写入乐课网微课库
- 乐课网写入成功状态：微课已完成乐课网微课库写入
- 乐课网写入失败状态：微课上传成功，但写入乐课网微课库失败

## 异常与边界
- 上传进度未达到 100% 时，允许取消上传
- 上传进度达到 100% 后，不允许取消本次上传
- 取消上传后，未完成上传的视频不进入视频列表
- 上传失败时，页面保留当前已有视频结果
- 顶部统一保存失败时，保留当前已上传成功的视频结果
- 视频上传成功但写入乐课网微课库失败时：
  - 当前页面视频结果仍保留
  - 需提示写入失败原因
  - 不影响编辑流程继续
- 用户对该知识点模块发布时，将在该知识点模块上传的视频写入到乐课网微课库的视频做上架处理

# 数据来源

| 数据名称 | 来源 | 用途 |
|----------|------|------|
| 本地选择视频文件 | 用户本地文件 | 作为上传源文件 |
| 当前上传进度 | 上传过程数据 | 展示进度条和进度文案 |
| 上传成功视频结果 | 上传结果数据 | 加入当前视频列表 |
| 当前编辑态视频结果 | 编辑态页面缓存数据 | 暂存上传成功视频 |
| 当前已有视频列表 | 学习资源编辑结果 | 展示页面已有视频内容 |
| 当前知识点所属学段 | 当前知识点上下文数据 | 写入乐课网微课库 |
| 当前知识点所属学科 | 当前知识点上下文数据 | 写入乐课网微课库 |
| 当前知识点名称 | 当前知识点上下文数据 | 写入乐课网微课库 |

# 接口需求

| 接口名称 | 用途 | 状态 |
|----------|------|------|
| 上传视频接口 | 上传一个或多个视频文件 | 下期支持 |
| 获取上传结果信息接口 | 返回视频名称、大小、时长等展示信息 | 下期支持 |
| 乐课网微课写入接口 | 用户点击「完成编辑」时，将上传的微课写入乐课网微课库 | 下期支持 |
| 顶部完成编辑统一保存接口 | 统一提交当前学习资源编辑结果 | 下期支持 |

# 技术要求

- 点击【上传视频】后需唤起系统文件选择窗口
- 系统文件选择窗口需支持一次性多选视频文件
- 上传进度需在页面内展示，而不是依赖独立业务弹窗
- 上传进度未达到 100% 前，需支持取消上传
- 上传成功结果需写入当前编辑态数据
- 上传成功后需触发乐课网微课库同步写入
- 乐课网同步写入需带上当前知识点所属学段、学科、知识点名称及视频资源信息
- 最终仍由顶部【完成编辑】统一提交
